基础语法（第 1–2 章）

地基章，概念题多、送分多。先扫清"标识符/缩进/运算符/内置函数"这些死知识，后面才不卡。

🐍第 1 章 · Python 概述
机器/汇编/高级语言、解释型与两种运行方式、标识符与关键字、强制缩进、模块与 pip、math / random 常用成员
重点：基本语法规则
🔢第 2 章 · 数据类型、表达式、内置函数
int/float/complex/bool 描述、常量变量、算术/关系/逻辑/位/身份/成员运算符、优先级结合性、类型转换/range/len 等内置函数
送分章

程序设计（第 3–5 章）

⭐ 设计题高发区。分支/循环是编程题的骨架，列表/元组/集合/字典是每道题都要用的容器，函数是"以函数方式实现"的硬要求。

🔀第 3 章 · 程序控制结构
流程图/N-S 图、if-elif-else 分支、while/for 循环、break/continue/else、异常处理 try-except、完数等设计题套路
设计题高发
🧩第 4 章 · 组合数据类型
列表/元组/集合/字典的创建·访问·切片·操作、可变与不可变、四者对比、切片 [::-1] 与推导式
设计题高发
🧮第 5 章 · 函数
def 定义调用、return 多返回值、形参实参/默认参数/*args/**kwargs、全局局部与 global、递归、lambda
✂️ 5.1.4、5.3.3 不考

数据与处理（第 6–7 章）

字符串方法与文件读写是综合设计题的两大常客（"读一行字符串统计…""按行读文件…"）。

🔤第 6 章 · 字符串
字符串表示与编码、转义字符、运算与切片、split/join、find/replace、isdigit 测试、strip、大小写、f-string 格式化
✂️ 6.3 正则表达式不考
📁第 7 章 · 文件与数据维度
打开-读写-关闭流程、模式 r/w/a、read/readline/readlines、write、with 语句、一维二维高维、CSV 与 JSON
✂️ 7.3 不考

进阶与拓展（第 8–9 章）

课程两大难点章。面向对象概念题多（简答常问区别），科学计算爱考"读代码写结果"。

🧱第 8 章 · 面向对象编程
面向对象 vs 面向过程、类与实例、__init__ 与 self、属性/方法、私有与封装、类方法/静态方法、继承重写、多态、特殊方法
课程难点
📊第 9 章 · 科学计算与可视化
numpy ndarray 属性与创建、pandas Series / DataFrame 创建访问统计排序、matplotlib 折线/柱形/散点图三步法
课程难点
怎么用：先按 1→9 顺序通读一遍（每页 10–15 分钟），把每页末尾「速记小结」和黄色 ⚠️ 易错框抄成笔记；重点把 第 3、4、7 章（设计题高发）的代码套路手敲一遍。
不考内容别花时间：正则表达式（6.3）、5.1.4、5.3.3、7.3。详见课程考纲页首速查表。
