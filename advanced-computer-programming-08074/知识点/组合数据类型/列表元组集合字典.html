〇、四者速览对比

识记 组合数据类型的分类。
类型符号有序?可重复?可变?典型用途
列表 list[ ]有序可重复可变一组同类数据、增删改
元组 tuple( )有序可重复不可变不希望被改的数据、多返回值
集合 set{ }无序不重复可变去重、交并差运算
字典 dict{k:v}按键插入序键不重复可变键值映射、查名字→信息
记忆锚：列表方括号、元组圆括号、字典带冒号键值对、集合只有值且去重。元组唯一"不可变"。

一、列表 list ⭐

领会 创建、访问、切片、操作；综合应用 解决实际问题。
操作写法说明
增append(x) 尾部加 · insert(i,x) 指定位置 · extend(lst) 合并append 加整个元素，extend 展开逐个加
删remove(x) 按值删 · pop(i) 按下标删并返回 · del lst[i] · clear()remove 删第一个匹配值
改/查lst[i]=x · index(x) · count(x) · x in lst下标从 0 起，支持负数（-1 是末尾）
排序sort() 原地排序 · sorted(lst) 返回新列表 · reverse()sort 可加 key=... , reverse=True
a = [3, 1, 4, 1, 5]
a.append(9)         # [3,1,4,1,5,9]
a.remove(1)         # 删掉第一个 1
a.sort()            # 原地升序
print(len(a), max(a), a[0], a[-1])

二、元组 tuple

领会 创建、访问、切片、操作。
元组创建后不能增删改（不可变），访问/切片与列表相同。单元素元组要加逗号：t=(5,)（写 (5) 只是整数 5）。
count(x)、index(x) 可用；没有 append/sort 等修改类方法。可迭代解包：a,b,c=(1,2,3)。 
t = (1, 2, 3)
print(t[0], t[-1], len(t))
x, y, z = t          # 解包 → x=1,y=2,z=3
# t[0]=9  → ✗ TypeError：元组不可变

三、集合 set

领会 创建、访问、操作；综合应用。
集合无序、元素唯一，最常用于去重和集合运算。空集合只能用 set()（{} 是空字典）。 
s = {1, 2, 2, 3}     # 自动去重 → {1,2,3}
s.add(4)             # 增
s.discard(2)         # 删（不存在也不报错）
a, b = {1,2,3}, {2,3,4}
print(a & b)   # 交集 {2,3}
print(a | b)   # 并集 {1,2,3,4}
print(a - b)   # 差集 {1}

四、字典 dict ⭐

领会 创建、访问、操作；综合应用。
字典是键:值的映射，键唯一且必须不可变（可用 str/int/tuple，不能是 list）。
操作写法
取值d[key]（键不存在报 KeyError）· d.get(key, 默认值)（更安全）
增/改d[key]=value（有则改、无则增）· update(其它dict)
删del d[key] · pop(key) · clear()
遍历keys() 所有键 · values() 所有值 · items() 所有键值对
stu = {"name":"小明", "age":20}
print(stu["name"])          # 小明
stu["age"] = 21              # 改
for k, v in stu.items():     # 遍历键值对
    print(k, v)

五、切片与推导式

切片（列表/元组/字符串通用）：seq[start:stop:step]，含头不含尾，可为负、可省略。 
a = [0,1,2,3,4,5]
a[1:4]     # [1,2,3]
a[:3]      # [0,1,2]（省略 start 从头）
a[::2]     # [0,2,4]（步长 2）
a[::-1]    # [5,4,3,2,1,0]（反转，高频！）
列表推导式（一行造列表，设计题神器）：[表达式 for 变量 in 序列 if 条件] 
sq = [x*x for x in range(1, 6)]        # [1,4,9,16,25]
ev = [x for x in range(10) if x%2==0]   # [0,2,4,6,8]

六、本章速记小结

选类型口诀：要改又有序→列表；不想被改→元组；要去重/算交并→集合；要按名字查→字典。
高频坑：① 单元素元组忘逗号 (5,)；② 空集合是 set() 不是 {}；③ d[key] 键不存在报错，用 d.get() 兜底；④ 切片含头不含尾，[::-1] 反转；⑤ 列表 sort() 改自己返回 None，sorted() 返回新值。
