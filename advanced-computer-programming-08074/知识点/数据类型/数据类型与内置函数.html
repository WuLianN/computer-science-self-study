一、基本数据类型

领会 整型、浮点型、复数型、布尔型数据的描述方法。
类型说明写法举例
int 整型整数，无长度限制10, -3, 0b101(二进制), 0o17(八进制), 0x1F(十六进制=31)
float 浮点型带小数点的数3.14, .5, 5., 1.5e3(=1500.0)
complex 复数实部 + 虚部，虚部用 j3+4j；z.real 取实部、z.imag 取虚部
bool 布尔只有两个值True / False（首字母大写）；实质 True=1, False=0
str 字符串用引号括起来的一串字符"hi", 'ok', """多行"""
print(0x1F)       # 31  —— 十六进制
print(1.5e3)     # 1500.0 —— e 后可正负，指数是整数
print(True + True) # 2 —— bool 参与运算按 1 算

二、常量与变量

识记 常量与变量概念、组合数据类型定义。
  • 常量：值不能变的量（数字、字符串字面量；Python 无 const，约定用大写字母名表常量如 PI=3.14）。
  • 变量：不需要先声明类型，赋值即创建，类型由所赋的值决定，可随时改（动态类型）。a=5; a="hi" 合法。
  • 赋值：= 是赋值号（右→左），不是等号；支持 a=b=c=1 链式、a,b=b,a 交换、a,b=[1,2] 序列解包。
  • 组合数据类型：多个数据元素组织在一起（列表/元组/集合/字典，详见第 4 章）。
a, b = 3, 5
a, b = b, a        # 交换 → a=5, b=3（Python 独有巧写法）
print(type(a))     # <class 'int'>

三、运算符与表达式 ⭐

简单应用 算术、关系、逻辑、成员测试运算符；领会 位运算符、身份运算符。
类别运算符注意 / 易错
算术+ - * / // % **/ 永远得浮点（6/3=2.0）；// 整除向下取整（-7//2=-4）；% 取余；** 幂（2**3=8）
关系> < >= <= == !=比较返回 bool；== 判等、= 赋值别混
逻辑and or not用单词不是 &&；短路求值
赋值= += -= *= /= //= **=a+=1 等价 a=a+1
成员in / not in判断元素是否在序列中：2 in [1,2,3] → True
身份is / is not判断是否同一对象（内存地址），不是判值相等
位运算& | ^ ~ << >>按二进制位操作：<< 左移乘2、>> 右移除2
print(7 / 2)    # 3.5（/ 得浮点）
print(7 // 2)   # 3（整除）
print(-7 // 2)  # -4（向负无穷取整）
print(2 and 3)  # 3（都真取后者）
print(0 or 5)   # 5（前者假取后者）
print(1 << 3)   # 8（1 左移 3 位 = 1*2³）

四、运算符优先级与结合性

识记 运算符优先级和结合性。
从高到低（记这条主干就够用）：
() 括号 → ** 幂 → 一元(+/-/not) → * / // % → + - → 移位 → & → ^ → | → 比较(> < == !=) → not → and → or → 赋值
  • 幂 ** 右结合：2**3**2 = 2**(3**2) = 2**9 = 512。
  • 其余算术运算左结合；同级从左到右。
  • 不确定就加括号，考试时也最稳。

五、常用内置函数

简单应用 数学运算、类型转换、输入输出、range/len/type；识记 迭代器函数。
类别函数作用
数学abs() max() min() sum() round() pow()round(3.6)=4；pow(2,3)=8
类型转换int() float() str() bool() list() tuple() set()int("12")=12；str(12)="12"
输入输出print() input()input() 返回的永远是字符串，要算数得 int(input())
序列/信息range() len() type() id() ord() chr()len("abc")=3；type(x) 看类型；ord('A')=65
迭代器iter() next() enumerate() zip()enumerate 带下标、zip 并行打包
range 三要点：range(n)→0..n-1；range(a,b)→a..b-1（含头不含尾）；range(a,b,step) 带步长。list(range(1,10,2))=[1,3,5,7,9]。
s = input("输入数字：")   # s 是 str
n = int(s)                # 转成整数才能运算
print(abs(-5), max(1,9,3), sum([1,2,3]))  # 5 9 6

六、本章速记小结

最易错 4 点：① / 结果一定是 float；② // 向负无穷取整（-7//2=-4）；③ input() 返回字符串；④ = 赋值、== 判等，is 判身份。
优先级主干：括号→幂→单目→乘除→加减→比较→not→and→or。幂右结合，其余左结合。
