一、numpy：ndarray 数组

识记 ndarray 基本属性。
numpy（Numerical Python）核心对象是 ndarray（N 维数组）：同类型元素、比列表快、支持向量化运算。
属性含义
arr.ndim维度数
arr.shape形状（各维大小，元组）
arr.size元素总个数
arr.dtype元素数据类型
import numpy as np            # 约定别名 np
a = np.array([[1,2,3],[4,5,6]])
print(a.ndim, a.shape, a.size)  # 2  (2, 3)  6

二、numpy：创建函数与运算

简单应用 常用数组创建函数、访问数组元素；领会 数组运算与方法。
创建作用
np.array(列表)由列表建数组
np.arange(n)0..n-1（类似 range）
np.linspace(a,b,n)a 到 b 均分 n 份
np.zeros/zeros_like/ones/eye(n)全 0 / 全 1 / 单位阵
np.random.rand(...)随机数数组
运算与方法：数组逐元素运算（a*2、a+b、np.sqrt(a)）；聚合方法 sum() mean() max() min() std()；访问用下标 a[0,1]、切片 a[:,1]（第 1 列）。 
b = np.arange(1, 6)          # [1 2 3 4 5]
print(b * 2)                # [2 4 6 8 10]（逐元素）
print(b.sum(), b.mean())     # 15 3.0

三、pandas：Series

识记 Series 数据结构；简单应用 创建与访问。
Series 是一维带标签数组（有索引 index + 值 values）。 
import pandas as pd
s = pd.Series([90, 85, 78], index=["语文","数学","英语"])
print(s["数学"])            # 85（按标签访问）
print(s.values, s.index)     # 值 / 索引

四、pandas：DataFrame ⭐ 重点

领会 DataFrame 统计、排序；简单应用 创建与访问。
DataFrame 是二维表格（行索引 + 列名），是 pandas 核心，最常用从字典创建： 
df = pd.DataFrame({
    "姓名": ["小明", "小红"],
    "成绩": [88, 95]
})
print(df["成绩"])          # 取一列（Series）
print(df.loc[0])           # 按标签取第 0 行
print(df.describe())       # 统计摘要
df.sort_values("成绩", ascending=False)   # 按列排序
操作方法
查看head() / shape / columns / index
取数据df["列名"] · df.loc[行标] · df.iloc[行号]
统计describe() / mean() / sum() / count()
排序sort_values(列, ascending=)
读文件read_csv() / to_csv()

五、matplotlib：绘图

识记 图像制作过程步骤；领会 折线图、柱形图、散点图绘制。
绘图三步（套路固定）：① 准备 x、y 数据；② 调用绑图函数（plot/bar/scatter）；③ show() 显示。中间可加标题、轴标签、图例美化。 
import matplotlib.pyplot as plt
x = [1, 2, 3, 4]
y = [2, 4, 1, 5]
plt.plot(x, y)          # 折线图（换 bar(x,y) 柱形、scatter(x,y) 散点）
plt.title("示例")       # 标题
plt.xlabel("X"); plt.ylabel("Y")   # 轴标签
plt.show()              # 显示（一定要）
三种图对应函数：折线图 plot()（趋势）、柱形图 bar()（比较）、散点图 scatter()（相关性）。
