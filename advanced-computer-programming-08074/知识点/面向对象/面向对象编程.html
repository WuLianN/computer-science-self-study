一、面向对象 vs 面向过程 ⭐

识记 面向过程、面向对象、对象、类、封装、继承、多态的概念。
名词一句话理解
面向过程以"步骤/函数"为中心，一步步指挥计算机怎么做（如 C 语言）
面向对象以"对象"为中心，把数据和行为封装成对象，靠对象间协作完成
类 class对象的模板/蓝图，定义这一类对象共有的属性和方法
对象 object类的实例，是具体存在的（"小明"是"学生类"的一个对象）
封装把数据和操作包进类里，隐藏内部细节、只暴露接口
继承子类复用父类的属性与方法，可扩展新功能
多态同一方法名，不同对象调用产生不同行为
📝 简答模板（面向对象和面向过程的区别）：面向过程自顶向下、逐步分解为函数调用，性能高但缺少复用；面向对象以对象为单位、有封装、继承、多态，更易维护、复用、扩展，可读性好、适合大型程序。

二、类与实例、构造方法 __init__ ⭐

领会 类的定义方法、构造方法、实例创建与访问方法。
class Student:                 # 类名大写开头
    def __init__(self, name, age):   # 构造方法，创建实例时自动调用
        self.name = name          # 实例属性
        self.age = age
    def intro(self):              # 实例方法
        return f"我叫{self.name}，{self.age}岁"

s = Student("小明", 20)         # 创建实例（实例化），self 不用传
print(s.name)                  # 访问属性 → 小明
print(s.intro())               # 调用方法
  • __init__ 是构造方法，创建对象时自动执行，用来初始化属性。
  • self 代表实例对象本身，是方法的第一个参数；调用时不用手动传。
  • 对象的结构 = 属性（数据） + 方法（行为）。

三、对象成员：属性与方法

简单应用 类属性成员定义、实例属性访问、实例方法。
成员定义位置归属
实例属性__init__ 里 self.x=…每个对象各有一份
类属性类体内直接 x=…所有对象共享
实例方法第一个参数是 self操作本对象数据

四、公有私有、类方法/静态方法

识记 私有方法与公有方法；领会 类方法、静态方法。
  • 私有成员：名字前加双下划线 __（如 __score），外部不能直接访问——这就是封装。要读写就提供公有方法（getter/setter）。
  • 公有成员：普通名字，外部可访问。
  • 类方法 @classmethod：第一个参数是类 cls，操作类属性。
  • 静态方法 @staticmethod：不带 self/cls，只是逻辑上归到类里，不用实例数据。
class Account:
    def __init__(self, bal):
        self.__balance = bal        # 私有属性
    def get_balance(self):          # 公有方法间接访问
        return self.__balance
a = Account(100)
print(a.get_balance())     # ✓ 100
# print(a.__balance)       # ✗ 私有，外部报错

五、继承与方法重写

识记 继承概念；领会 继承的定义、方法重写。
子类在括号里写父类名即可继承；子类重新定义父类同名方法叫方法重写；super() 调用父类版本。 
class Animal:
    def speak(self):
        return "…"
class Dog(Animal):          # Dog 继承 Animal
    def speak(self):        # 方法重写
        return "汪汪"
print(Dog().speak())        # 汪汪

六、多态与常用特殊方法

识记 多态概念、常用重载（特殊）方法。
多态：不同类的对象有同名方法，调用时按对象实际类型执行——配合继承自然实现。
常用特殊方法（双下划线 __xxx__）：
特殊方法触发时机
__init__创建对象（初始化）
__str__print(对象) / str(对象) 时的可读文本
__len__len(对象)
__eq__== 比较
__del__对象销毁

七、本章速记小结

一条链：class 定义类 → __init__+self 建实例属性 → 方法封装行为 → __私有 做封装 → 类(父类) 继承 + 重写 → 多态。
必背：self=实例本身、调用不传；__init__ 自动执行；私有加 __；类方法用 @classmethod(cls)、静态用 @staticmethod；继承把父类写进括号、super() 调父类。
简答高频：①面向对象三大特征=封装/继承/多态；②与面向过程的区别（见第一节模板）。
