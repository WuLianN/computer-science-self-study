一、程序与设计语言类型

识记 程序设计语言的三种类型、程序执行方式。
能被计算机直接执行的只有机器语言（二进制 0/1）。其余语言都要"翻译"成机器语言才能运行。
代际语言特点是否需要翻译
第一代机器语言二进制指令，计算机唯一能直接识别执行不需要
第二代汇编语言用助记符代替机器指令，面向机器需要（汇编程序）
第三代高级语言（Python/C/Java…）接近自然语言、易读易写，与机器无关需要（编译 / 解释）
⚠️ 高频单选陷阱：问"能被计算机直接执行的语言"，答案永远是机器语言，不是高级语言、不是汇编、更不是自然语言。

二、程序的执行方式与 IDLE

识记 IDLE 中 Python 程序的运行方式。
高级语言的两种翻译/执行方式：
  1. 编译执行：一次性把整个源程序翻译成目标代码再运行（C 语言属此类，先生成 .exe）。
  2. 解释执行：逐行读入、逐行翻译执行，不生成独立目标文件。Python 是解释型语言。
Python 程序支持两种运行方式：① 交互式（在 REPL/IDLE 提示符 >>> 下逐句输入立即看得果）；② 脚本式（写成 .py 文件，整体运行）。
# 交互式：>>> 后输入，回车立即出结果
>>> print(1 + 2)
3
# 脚本式：把代码存成 hello.py，再运行该文件

三、Python 基本语法规则 ⭐ 本章重点

领会 注释、标识符、关键字、强制缩进、多行语句、同一行执行多条语句。
规则要点（背这几条就够）
注释单行用 #；多行/文档注释用三引号 '''…''' 或 """…"""。
标识符（变量名）由字母、数字、下划线组成，不能以数字开头，区分大小写，不能用关键字。
关键字系统保留、有专门含义、不能作标识符（如 if for while def class return import True None）。可用 import keyword; print(keyword.kwlist) 查看全部。
强制缩进用缩进表示语句块（相当于 C 的 {}）。同一层级缩进必须一致，推荐 4 个空格。缩进错误会报 IndentationError。
一行多句同一行写多条语句用分号 ; 分隔，如 a=1; b=2。
多行语句一条语句跨多行用续行符 \，或在 () {} [] 括号内自动续行。
# 标识符合法性判断
sum2 = 10     # ✓ 合法
_abc = 3      # ✓ 合法（下划线开头可以）
2sum = 1      # ✗ 数字开头
if  = 5       # ✗ if 是关键字
a*b = 2       # ✗ 含非法字符 *

# 强制缩进：if 块内三句必须同缩进
if sum2 > 5:
    print("大")
    x = sum2 * 2
📌 考纲题型举例里就有："下列正确的变量名是（）A.2sum B.if C.sum2 D.a*b" —— 答案 C. sum2。记忆口诀：字母下划线开头、不用关键字、不混大小写。

四、Python 模块与扩展库

识记 模块的概念、扩展库安装；领会 模块的导入和使用。
模块（module）：一个 .py 文件就是一节模块，把函数、变量、类组织起来便于复用。分标准库模块（随 Python 安装即有）和第三方扩展库（需额外安装）。 
# 三种导入方式
import math                # 用 math.sqrt(x)
from math import sqrt      # 直接用 sqrt(x)
from math import *         # 导入全部成员（不推荐）

# 安装第三方扩展库：在命令行（不是 IDLE 里）用 pip
# pip install 库名      例：pip install numpy

五、math 模块与 random 模块

领会 math 模块常用成员、random 模块常用函数。
math 模块作用random 模块作用
math.sqrt(x)开平方random.random()返回 [0,1) 的随机浮点数
math.pow(x,y)x 的 y 次方randint(a,b)[a,b] 闭区间随机整数
math.ceil(x)向上取整choice(seq)从序列随机取一个元素
math.floor(x)向下取整shuffle(x)原地打乱列表
math.pi / math.e常量 π / euniform(a,b)[a,b] 随机浮点数
import math, random
print(math.sqrt(16))       # 4.0
print(math.ceil(3.2))      # 4
print(random.randint(1,6)) # 1~6 的随机整数（掷骰子）

六、本章速记小结

一条主线：计算机只认机器语言 → Python 是解释型高级语言，可交互式也可脚本运行 → 语法四条硬规定（标识符规则、关键字保留、缩进表语句块、分号/续行符） → 模块用 import 导入、第三方库用 pip 安装 → 记熟 math、random 的常用成员。
本章关键词：机器语言直接执行、解释型、# 注释、4 空格缩进、标识符不以数字开头、pip、math.sqrt、random.randint。
