一、四个符号（看形状认作用）

⭐ 菱形 = 判断（带「是 / 否」两个出口），2026.4 · 选择第 19 题 考的就是这个。窄屏可横滑看图。

二、同一例题，两种画法

例题：求 1~100 中所有偶数之和（顺序 + 循环 + 分支三种结构都有，最适合拿来对照）。 
s = 0
for i in range(1, 101):
    if i % 2 == 0:
        s += i
print(s)   # 2550
图中把 for 展开成等价的 while（i <= 100 判断 + 每次 i += 1），两图才对得上；for 都能改写成 while。
传统流程图：靠带箭头的流程线串起各框；左下那条长回边就是循环。形状按颜色区分：绿=起止、蓝=处理、黄=判断、粉=输出。
N-S 图（盒图）：整张图没有一根箭头。顺序 = 上下叠盒，选择 = 盒内 T / F 左右分栏，循环 = 外层盒套住循环体；结构只能一层层嵌进去，画不出随意跳转。

三、一句话对照

① 流程图自由但容易画出非结构化流程：任意两框之间都能连箭头、能往回跳。
② N-S 图把算法关进一个大矩形，只允许上下堆叠 / 左右分栏 / 层层嵌套，天然强制只用顺序、选择、循环三种结构。
③ 两图画的是同一个算法，对照着看最省事：把流程图里那条「返回判断」的回边，换成 N-S 图里那个黄色的循环盒即可。
