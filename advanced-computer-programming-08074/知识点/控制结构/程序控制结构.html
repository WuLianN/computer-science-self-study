一、控制结构概述与流程图

识记 传统流程图、N-S 流程图的描述方法。
三种基本控制结构：顺序结构、选择（分支）结构、循环结构。结构化程序设计就是只用这三种。
流程图常见符号：椭圆=起止、平行四边形=输入输出、矩形=处理（赋值/计算）、菱形=判断（分支）。
N-S 图（盒图）：把流程图画在矩形框内，用嵌套的盒子表示三种结构，没有随意跳转的流程线，天然强制结构化。

二、选择结构 if / elif / else ⭐

综合应用 单分支、双分支、多分支、嵌套分支程序设计。
# 单分支
if score >= 60:
    print("及格")

# 双分支
if n % 2 == 0:
    print("偶数")
else:
    print("奇数")

# 多分支（elif 只能配在 if 下）
if score >= 90:      g = "A"
elif score >= 80:    g = "B"
elif score >= 60:    g = "C"
else:               g = "D"
  • 条件后面必须有冒号 :，分支体靠缩进区分。
  • 任何非零数、非空对象作条件都视为 True；0、空串、空列表为 False。
  • 三目写法：大 if 条件 else 小，如 m = a if a>b else b（取较大值）。

三、循环结构 while / for ⭐

综合应用 while、for 进行简单循环及多重循环程序设计。
循环语法适用
whilewhile 条件: 循环体次数未知、靠条件控制
forfor 变量 in 序列: 循环体遍历序列 / 已知次数（配 range）
# while：累加 1~100
s, i = 0, 1
while i <= 100:
    s += i
    i += 1

# for：等价写法
s = 0
for i in range(1, 101):   # 1..100
    s += i

# 多重循环：九九乘法表（外层行、内层列）
for i in range(1, 10):
    for j in range(1, i + 1):
        print(f"{j}×{i}={i*j}", end=" ")
    print()               # 每行结束换行

四、break / continue / else

简单应用 break、continue、else 语句在循环中的使用。
关键字作用
break立即跳出整个循环（离开循环体，执行循环后面的语句）
continue跳过本次循环体剩余语句，进入下一次迭代
循环的 else循环正常结束（没有被 break）时才执行 else 块；被 break 打断则不执行
for i in range(1, 6):
    if i == 3: break       # 到 3 就整个退出 → 只打印 1 2
    print(i)

for i in range(1, 6):
    if i == 3: continue    # 跳过 3，其余都打印 → 1 2 4 5
    print(i)

五、异常处理 try…except

识记 异常的分类；简单应用 try…except / else / finally。
异常是运行时发生的错误（如除零、类型错、文件找不到），不处理就程序崩溃。四种写法层层加强： 
# ① 基本：捕获异常
try:
    x = int(input("输入："))
    print(10 / x)
except ValueError:        # 转换失败
    print("不是数字")
except ZeroDivisionError:  # 除零
    print("不能除 0")
else:                      # 没出异常才执行
    print("成功")
finally:                   # 无论如何都执行（常做收尾/关文件）
    print("结束")
主动抛异常用 raise；常见异常类型：ZeroDivisionError、ValueError、TypeError、IndexError、FileNotFoundError、KeyError。

六、典型设计题套路

考纲"简单设计题"样例：输出 1000 以内所有完数（完数=各因子之和等于自身，如 28=1+2+4+7+14）。这是"循环 + 求因子 + 判断"的标准组合： 
for n in range(2, 1000):
    s = 0
    for i in range(1, n):        # 找真因子
        if n % i == 0:
            s += i
    if s == n:
        print(n)                # 6 28 496
可复用套路：① 素数判断（内层试除到 √n）；② 水仙角/完数（拆位或求因子）；③ 累加累乘、计数；④ 穷举（百钱买百鸡）。都是"for 循环 + if 判断 + 计数器/累加器"。

七、本章速记小结

答题硬规则：条件/循环行末的冒号别漏、循环体缩进要对、Python 没有 do-while、没有 switch（多分支用 if-elif-else）。
三个易混：break 退整个循环、continue 跳本次、else 在"没被 break"时执行。
异常四段式：try（冒险做）→ except（出错补救）→ else（没出错才做）→ finally（一定做）。
