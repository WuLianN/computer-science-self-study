一、文件概念与处理流程

识记 文件类型、基本处理流程。
三步流程：打开（open） → 读写（read/write） → 关闭（close）。
文件分类：按数据形式分 文本文件（字符，如 .txt/.csv，读写用字符串）和 二进制文件（字节，如图片、.dat，模式带 b）。文本文件是本章重点。

二、打开模式 r / w / a ⭐

领会 文件打开模式。
模式含义文件不存在时
r只读（默认）报错 FileNotFoundError
w只写，会清空原内容新建
a追加写（保留原内容）新建
r+ / w+ / a+读写视模式而定
加 brb / wb 二进制—
⚠️ w 一打开就把原文件清空——想保留旧内容、在后面加，用 a。

三、读文件三种方式 ⭐

综合应用 文件打开、关闭、读写方法。
f = open("data.txt", "r", encoding="utf-8")
content = f.read()          # ① 一次读全部 → 一个字符串
# line = f.readline()     # ② 读一行 → 字符串（带末尾换行）
# lines = f.readlines()   # ③ 读全部行 → 列表，每行是元素
f.close()

# 最推荐：with 自动关闭 + for 逐行遍历
with open("data.txt", "r", encoding="utf-8") as f:
    for line in f:
        print(line.strip())   # strip 去掉行末换行
区分：read()→整串；readline()→一行；readlines()→行的列表。

四、写文件与 with 语句

综合应用 写入。
with open("out.txt", "w", encoding="utf-8") as f:
    f.write("第一行\n")       # write 不会自动换行，需自己加 \n
    f.writelines(["a\n", "b\n"])
with 的好处：代码块结束自动 close，即使中途异常也保证关闭，推荐替代手写 close。
文件定位：tell() 当前指针位置、seek(n) 移到第 n 字节、flush() 刷新缓冲。

五、数据维度：一维 / 二维 / 高维

识记 一维、二维、高维数据概念。
维度结构Python 表示例子
一维一条数据序列列表 [1,2,3]一周气温
二维行列表格列表的列表 [[..],[..]]成绩表、CSV
高维多维 / 嵌套结构多维列表 / 字典嵌套多维数据、JSON

六、CSV 与 JSON 格式

领会 CSV 文件格式、JSON 格式。
  • CSV（逗号分隔值）：纯文本表格，每行一条记录、字段用逗号分隔，是二维数据典型载体。用 csv 模块或直接 split(",") 处理。
  • JSON（键值/层次结构文本）：用 {} 对象、[] 数组表达高维/层级数据；Python 用 json 模块转换：json.dumps(dict) 转字符串、json.loads(s) 转回对象、dump/load 对文件操作。
import json
d = {"name": "小明", "age": 20}
s = json.dumps(d, ensure_ascii=False)   # dict → JSON 字符串
back = json.loads(s)                     # JSON 字符串 → dict

七、本章速记小结

流程三句：open(文件名,模式,encoding) → read*/write → close（用 with 免写 close）。
模式口诀：r 读(不存在报错)、w 写(清空!)、a 追加(不清空)。
读法区分：read 整串 / readline 一行 / readlines 行列表。write 不自动换行，自己加 \n。
设计题套路："按行读取 + 处理 + 函数实现" → with open(...) as f: for line in f: 调用函数统计。
