一、字符串的表示与编码

领会 字符串的表示；了解编码解码。
  • 单引号 'hi'、双引号 "hi" 等价；三引号 """…""" 表示多行字符串。
  • 字符串不可变：不能 s[0]='X' 原地改，只能生成新串。
  • 编码解码：中文存成字节涉及 UTF-8 / GBK；s.encode() 编码为 bytes，b.decode() 解码为 str。
  • 原始字符串前加 r（r"a\b" 不解释转义），常用于文件路径。

二、常见转义字符

识记 常见转义字符的含义。
转义符含义转义符含义
\\n换行\\t制表符 Tab
\\\\反斜杠本身\\'单引号
\\"双引号\\r回车

三、字符串运算与切片 ⭐

简单应用 字符串的运算。
s = "Hello"
print(s + "!")       # 连接 → Hello!
print(s * 2)         # 重复 → HelloHello
print(len(s))        # 长度 5
print("e" in s)      # True 成员测试
print(s[1])          # e（下标从 0）
print(s[1:4])        # ell（切片含头不含尾）
print(s[::-1])       # olleH（反转）

五、str 对象常用方法 ⭐

简单应用 拆分与连接、查找与替换、测试串、格式化、大小写转换和字符映射。
用途方法例子
拆分 / 连接split(sep) · join(seq)"a,b,c".split(",")→['a','b','c']；"-".join(['a','b'])→"a-b"
查找find(sub) · count(sub)find 返回下标（找不到 -1）；count 出现次数
替换replace(old,new)"aaa".replace("a","b")→"bbb"
测试串startswith / endswith / isdigit / isalpha / isalnum返回 True/False；isdigit 判是否全数字
去空白strip() / lstrip() / rstrip()strip 去两端空格（读文件行常用）
大小写upper() / lower() / title() / swapcase()全大写 / 全小写 / 每词首字母 / 大小写互换
格式化format() · f-stringf"{name}今年{age}岁"（最常用）
line = "  Apple, Banana  "
parts = line.strip().split(",")     # ['Apple', ' Banana']
print("2024".isdigit())            # True
print("hi".upper())                # HI
name, age = "小明", 20
print(f"{name}今年{age}岁")          # f-string 格式化

六、本章速记小结

先记住：正则（re 模块、6.3）不考，别背。字符串三大性质：有序、可切片、不可变。
方法名易混：split 拆成列表 / join 把列表拼成串（方向相反，join 是"分隔符".join(列表)）；find 找不到返回 -1 不报错。
综合设计题常客：读一行字符串统计大写字母个数 → 遍历 for c in s: if c.isupper(): cnt+=1。
