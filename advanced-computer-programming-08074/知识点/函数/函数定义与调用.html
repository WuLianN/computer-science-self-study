一、函数的定义与调用 ⭐

识记 函数概念与作用；领会 定义方法、调用及返回。
作用：把重复的代码封装起来，提高复用、便于模块化。用 def 定义，函数体靠缩进；定义≠执行，必须调用才运行。 
def greet(name):          # name 是形参
    return f"你好，{name}"

msg = greet("小明")        # "小明" 是实参，调用
print(msg)
  • 函数必须先定义后调用（调用点在 def 之后）。
  • 没有 return 时，函数默认返回 None。

二、返回值 return

简单应用 用返回值传递结果。
return 一次可返回多个值（其实返回的是元组），接收时可解包： 
def min_max(a, b):
    return min(a, b), max(a, b)   # 返回元组 (小, 大)

lo, hi = min_max(3, 8)          # 解包 → lo=3, hi=8

三、参数传递 ⭐

识记 形参、实参概念；领会 参数传递方法、可变长形参；简单应用 实参解包。
参数类型写法说明
位置参数f(a,b)按顺序一一对应
关键字参数f(name="小明")按名传，顺序无关
默认参数def f(a, b=10)调用可省略 b；默认参数要写在非默认参数后面
可变长 *argsdef f(*args)收多个位置实参 → 元组
可变长 **kwargsdef f(**kwargs)收多个关键字实参 → 字典
实参解包f(*[1,2]) / f(**{"a":1})把列表/字典拆开传给形参
⚠️ 可变与不可变的传参差异（高频）：传不可变对象（数字/字符串/元组）相当于值传递，函数内改不影响外部；传可变对象（列表/字典）时，函数内 append 等内容修改会影响外部（传的是引用）。

四、变量作用域：全局 / 局部

识记 作用域类型；领会 全局变量与局部变量的作用域和使用。
  • 局部变量：函数内定义，只在函数内有效，函数结束就销毁。
  • 全局变量：函数外定义，整个程序有效。
  • 函数内要修改全局变量，必须先用 global 声明，否则会被当局部变量。
  • 同名时局部优先（遮蔽全局）。
x = 10                 # 全局
def f():
    x = 5             # 局部，与全局 x 无关
def g():
    global x
    x = 99            # 真正改全局 x

五、递归调用

简单应用 递归函数解决实际问题。
递归＝函数自己调用自己。必须有两要素：① 递归终止条件（否则无限递归报错）、② 递归推进（问题规模缩小）。 
def fact(n):
    if n == 1:              # 终止条件
        return 1
    return n * fact(n - 1)   # 递归推进

print(fact(5))              # 120
经典递归题：阶乘、Fibonacci、汉诺塔、求和。

六、lambda 表达式

领会 lambda 表达式函数的定义和调用。
匿名函数：一行小函数，lambda 参数: 返回值表达式（只能一个表达式，自动返回其值）。常作排序 key： 
f = lambda x, y: x + y
print(f(2, 3))              # 5

pts = [(1, 5), (3, 2), (2, 9)]
pts.sort(key=lambda p: p[1])  # 按第二个元素排序

七、本章速记小结

必答模板：综合设计题若要求"以函数方式实现"，就 def 函数名(参数): ... return 结果，再在主程序调用——别只写裸代码。
易错点：① 默认参数放最后；② 改全局要 global；③ 递归必须有终止条件；④ 传可变对象（列表/字典）函数内修改会影响外部；⑤ lambda 只能一个表达式、无需 return。
