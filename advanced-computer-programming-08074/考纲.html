Ⅰ · 课程性质与课程目标

课程性质和特点
通过本课程学习掌握 Python 语言程序设计技术，提前适应企业开发技术要求。课程实践性很强：不仅要掌握 Python 基本语法、字符串处理、文件处理，还要能用面向对象思想设计程序及完成数据分析处理。应切实掌握 Python 基础语法、文件、面向对象、科学计算与可视化等知识。
课程目标（8 条）
  1. 掌握 Python 基本数据类型、表达式及常见内置函数。
  2. 掌握 Python 程序控制结构。
  3. 掌握 Python 异常处理。
  4. 掌握组合数据类型的使用。
  5. 掌握 Python 函数编写及使用。
  6. 掌握文件处理方法。
  7. 掌握面向对象编程方法。
  8. 掌握使用科学计算与可视化技术进行数据分析处理。
与相关课程的联系
要求考生已具备一定程序设计基础，已学习过 C 语言、数据库编程相关知识。
课程重点和难点
重点：Python 语言基础（基础语法、程序结构控制、组合数据类型）。难点：面向对象程序设计、科学计算与可视化。

Ⅱ · 考核目标（四个能力层次）

识记识别记忆课程知识点的概念性内容（基本定义、语法格式、步骤方法、限定规则、特点等），能正确表述、选择和判断。
领会领悟各知识点的内涵和外延，熟悉知识点之间的区别与联系，能根据知识点特性解决不同问题并进行简单分析。
简单应用运用少量知识点分析解决一般应用问题：分析执行结果、补充程序空白、编写简单程序等。
综合应用综合运用多个知识点解决较复杂应用问题：程序设计、分析执行结果、补全程序空白、针对应用问题编写程序等。

Ⅲ · 课程内容与考核要求（9 章）

第 1 章 Python 概述（建议 4 学时）

学习目的与要求：了解程序基本概念和执行方式，熟练掌握开发环境安装与使用，掌握 Python 基本语法规则，了解模块概念，掌握库的安装及使用。
课程内容：1. 程序 ｜ 2. Python 简介、环境的安装和使用 ｜ 3. 基本语法规则 ｜ 4. Python 模块
考核知识点与要求
（一）程序：识记程序设计语言类型、程序执行方式；领会模块的导入和使用。
（二）简介与环境：识记IDLE 中 Python 程序运行方式。
（三）基本语法规则：领会注释、标识符、关键字、强制缩进、多行语句、同一行执行多条语句。
（四）Python 模块：识记模块概念、扩展库安装；领会math 模块常用成员、random 模块常用函数。
重点：基本语法规则。难点：Python 模块的使用。

第 2 章 Python 基本数据类型、表达式和内置函数（建议 8 学时）

学习目的与要求：了解基本数据类型、常量、变量概念，掌握运算符和表达式使用，了解内置函数概念并掌握常用内置函数。
课程内容：1. 数据类型 ｜ 2. 运算符与表达式 ｜ 3. 常用内置函数
考核知识点与要求
（一）数据类型：识记组合数据类型定义、常量与变量概念；领会整型、浮点型、复数型、布尔型数据的描述方法，常量及变量的定义与使用。
（二）运算符与表达式：识记运算符优先级和结合性；领会位运算符、身份运算符的使用；简单应用算数、关系、逻辑、成员测试运算符的使用。
（三）常用内置函数：识记迭代器函数；简单应用常用数学运算函数、类型转换函数、基本输入输出函数、range、len、type 函数。
重点：数值型数据描述方法、运算符使用。难点：常用内置函数的使用。

第 3 章 程序控制结构（建议 8 学时）⭐ 设计题高发

学习目的与要求：了解传统流程图和 N-S 流程图表示问题求解的方法，掌握单/双/多/嵌套分支结构程序设计、循环结构程序设计，掌握异常处理方法。
课程内容：1. 控制结构概述 ｜ 2. 选择结构 ｜ 3. 循环控制结构 ｜ 4. 异常处理结构
考核知识点与要求
（一）概述：识记传统流程图、N-S 流程图描述方法。
（二）选择结构：综合应用单分支、双分支、多分支、嵌套分支结构程序设计。
（三）循环结构：简单应用break、continue、else 语句的使用；综合应用while、for 循环进行简单循环及多重循环结构程序设计。
（四）异常处理：识记异常的分类；简单应用try...except、try...except...else、try...except...else...finally 异常处理程序设计。
重点：选择结构、循环结构程序设计。难点：异常处理结构。

第 4 章 组合数据类型（建议 8 学时）⭐ 设计题高发

学习目的与要求：了解组合数据类型概念，掌握列表、元组、集合、字典的创建、访问与运用。
课程内容：1. 概述 ｜ 2. 列表 ｜ 3. 元组 ｜ 4. 集合 ｜ 5. 字典
考核知识点与要求
（一）概述：识记组合数据类型分类。
（二）列表：领会创建、访问、切片、操作；综合应用运用列表解决实际问题。
（三）元组：领会创建、访问、切片、操作；综合应用运用元组解决实际问题。
（四）集合：领会创建、访问、操作；综合应用运用集合解决实际问题。
（五）字典：领会创建、访问、操作；综合应用运用字典解决实际问题。
重点：列表、元组、集合、字典的创建、访问及操作方法。难点：四者的综合运用。

第 5 章 函数（建议 6 学时）

学习目的与要求：掌握函数定义与调用、参数传递、变量作用域，了解 lambda 函数。
课程内容：1. 定义与调用 ｜ 2. 参数传递 ｜ 3. 变量作用域 ｜ 4. lambda 表达式函数
考核知识点与要求
（一）定义与调用：识记函数概念与作用；领会定义方法、调用及返回、嵌套调用和递归调用；简单应用递归函数解决问题；综合应用运用函数进行模块化程序设计。
（二）参数传递：识记形参、实参概念；领会参数传递方法、可变长形参；简单应用实参解包。
（三）变量作用域：识记作用域类型；领会全局变量与局部变量的作用域和使用。
（四）lambda：领会lambda 表达式函数的定义和调用。
重点：函数定义及调用、参数传递。难点：运用函数进行模块化程序设计。

第 6 章 字符串和正则表达式（建议 6 学时）⚠️ 正则不考

学习目的与要求：了解字符串编码解码，掌握字符串运算、字符串处理内置函数、str 类对象及相关处理方法。
课程内容：1. 字符串概述 ｜ 2. 字符串处理的函数和方法（正则表达式部分不列入考核，教材 6.3 节不考）
考核知识点与要求
（一）概述：识记常见转义字符含义；领会字符串的表示；简单应用字符串的运算。
（二）处理函数和方法：领会常用内置函数；简单应用字符串对象的拆分与连接、查找与替换、测试串、格式化数据、大小写转换和字符映射。
重点：字符串运算、常用内置函数。难点：字符串对象的使用方法。

第 7 章 文件（建议 8 学时）

学习目的与要求：了解文件概念和分类，掌握文件打开、关闭、读写、定位方法，掌握数据维度概念。
课程内容：1. 文件基本处理 ｜ 2. 数据维度
考核知识点与要求
（一）文件基本处理：识记文件类型、基本处理流程；领会文件打开模式；综合应用文件打开、关闭、读写方法。
（二）数据维度：识记一维、二维、高维数据；领会CSV 文件格式、JSON 格式。
重点：文件处理流程、打开模式。难点：文件读写方法。

第 8 章 Python 面向对象编程（建议 8 学时）⭐ 课程难点章

学习目的与要求：了解面向对象编程特点、对象型数据特点和成员构成，掌握类和实例的关系与创建方法，了解继承与多态。
课程内容：1. 面向对象概述 ｜ 2. 类对象与实例对象 ｜ 3. 对象成员 ｜ 4. 继承和多态
考核知识点与要求
（一）面向对象概述：识记面向过程、面向对象、对象、类、封装、继承、多态。
（二）类对象与实例对象：识记对象的结构；领会类的定义方法、构造方法、实例创建与访问方法。
（三）对象成员：识记私有方法与公有方法；领会类方法、静态方法；简单应用类的属性成员定义、实例属性成员访问、实例方法。
（四）继承和多态：识记继承概念、多态概念、常用重载方法；领会继承的定义、方法重载。
重点：面向对象概念、类的定义。难点：类方法、静态方法。

第 9 章 科学计算与可视化（建议 8 学时）⭐ 课程难点章

学习目的与要求：了解 numpy 数组概念，掌握其创建、运算、访问及常用成员方法；了解 pandas 的 Series 与 DataFrame，掌握两种类型的创建和访问；了解 matplotlib 绘图方法。
课程内容：1. 数值计算模块 ｜ 2. 数据分析模块 ｜ 3. 数据可视化模块
考核知识点与要求
（一）数值计算（numpy）：识记ndarray 基本属性；领会数组运算、数组方法；简单应用常用数组创建函数、访问数组元素。
（二）数据分析（pandas）：识记Series、DataFrame 数据结构；领会DataFrame 统计、排序；简单应用Series/DataFrame 的创建与访问。
（三）数据可视化（matplotlib）：识记图像制作过程步骤；领会折线图、柱形图、散点图绘制。
重点：DataFrame 数据创建及访问。难点：可视化图形绘制。

Ⅳ · 大纲说明与考核实施要求

大纲与教材的关系
