能被计算机执行的语言是

第15题点击展开答案
假设 x=1，x*=3+5 % 2 的运算结果是
A. 3B. 4C. 5D. 6
答案：B
解析：增量赋值 x*=表达式 等价于 x = x * (整个右侧表达式)——右侧先整体算完。优先级：% 高于 +，故 3 + 5%2 = 3 + 1 = 4；再 x = 1 * 4 = 4。实跑验证 = 4。两个易错点：① 误以为 *= 只乘 3；② 把 5%2 算错。故选 B。

    k = k - 1

第22题点击展开答案
简述函数调用时的实参的含义，并列举实参的数据形式。
参考答案
含义：实参（实际参数）是调用函数时真正传递给形参的具体数据，写在调用式的圆括号里；形参则是定义函数时占位的参数名，调用时由实参为其赋值。
实参的数据形式（举例）：
① 常量：f(10)、f("hi")；
② 变量：x=3; f(x)；
③ 表达式：f(a+b)、f(2*3+1)；
④ 函数调用（返回值）：f(g(5))；
也可以是列表、字典、对象等任意数据。传递形式还可分位置参数与关键字参数（如 f(a=1, b=2)）。
考点：形参与实参·参数传递
第23题点击展开答案
简述全局变量和局部变量的含义及区别。
参考答案
含义：全局变量在函数外部（模块顶层）定义，作用域覆盖整个模块，函数内一般可读取；局部变量在函数内部定义，只在所属函数内有效，函数执行结束即被销毁。
主要区别：
① 作用域不同：全局变量全局可见，局部变量仅函数内可见；
② 生命周期不同：全局变量随程序/模块存在，局部变量随一次函数调用产生与消亡；
③ 同名遮蔽：函数内若定义与全局同名的局部变量，则局部优先、遮蔽全局；
④ 要在函数内部修改全局变量，必须先用 global 声明，否则会被当作新建局部变量。
考点：变量作用域 global/局部
第24题点击展开答案
在 Python 的实例方法中，通常将哪个名称作为第一个形参？说明其作用。
参考答案：self
名称：约定用 self（并非关键字，只是社区强制惯例，任何名字都可但必须放第一位）。

第25题点击展开答案
执行 len(np.random.randint(1,100,10)) 的结果是多少？请解释原因。
参考答案：10
结果：10。

第26题点击展开答案
编写程序，实现功能：找出200以内能被9整除的最大整数。
参考答案
for i in range(200, 0, -1):       # 从 200 往下倒序枚举
    if i % 9 == 0:                # 能被 9 整除
        print(i)
        break                     # 找到最大的即退出
运行结果：198
套路：要"最大"就从大到小倒序遍历（range(200,0,-1)），第一个满足 i%9==0 的就是答案，找到立刻 break。也可一行算：print(200 - 200 % 9) → 198，或用 9 * (200 // 9) = 198。倒序+break 版最能体现循环思路。
考点：for 倒序遍历 · break
第27题点击展开答案
编写程序，实现功能：计算并输出 s=0!+1!+…+n! 的值（其中 n 由用户输入）。
参考答案
n = int(input("请输入n："))
fact = 1          # 边乘边累积 i!
s = 0
for i in range(0, n + 1):
    if i > 0:
        fact *= i         # fact 由 (i-1)! 变成 i!
    s += fact             # 累加 i!
print(s)
运行示例：n=3 → 0!+1!+2!+3! = 1+1+2+6 = 10；n=5 → 154（均实跑验证）。
套路：阶乘用累乘变量 fact 递推：每轮 fact *= i 就得到 i!，再累加进 s，避免每次重算阶乘（也可用 math.factorial(i)）。注意 0! = 1：初值 fact=1 且 i=0 时不进 if，直接 s += 1 正好把 0! 计入。
考点：for 累加累乘考点：阶乘递推
第28题点击展开答案
编写程序，实现功能：将包含数字和字母的日期字符串中的数字字符换为中文数字，例如输入原始字符串为"2025年5月2日"，最终输出格式为"二零二五年五月二日"。
参考答案
s = input("请输入日期字符串：")
cn = "零一二三四五六七八九"
result = ""
for ch in s:
    if ch.isdigit():            # 是数字字符
        result += cn[int(ch)]   # 映射为对应中文数字
    else:
        result += ch            # 非数字原样保留
print(result)
运行示例：输入 2025年5月2日 → 输出 二零二五年五月二日（实跑验证）。
套路：核心是建一张"数字→中文"映射表（字符串 cn 按下标 0~9 存中文数字），逐字符遍历：ch.isdigit() 判断是否数字，是则用 cn[int(ch)] 替换，否则原样拼接。也可用字典 {'0':'零',...} 或 str.translate，但逐字符 + isdigit 版最直观、最好背。
考点：逐字符遍历与映射替换
第29题点击展开答案
编写一个函数，以整数 n 为参数，实现求 n 的倒序数并返回该数。例如，123 的倒序数为 321。
参考答案
def reverse_num(n):
    return int(str(n)[::-1])    # 转字符串→切片倒序→转回整数

print(reverse_num(123))
运行结果：321（实跑验证）。
套路：最简版是切片三步：str(n) 转字符串 → [::-1] 步长 -1 整体倒序 → int(...) 转回整数（自动去掉前导 0，如 120→"021"→21）。若考"纯算术拆位"，用循环版：
r = 0；当 n>0 时反复 r = r*10 + n%10; n //= 10，最终 r 即倒序数。两种都对，切片版最简洁。

编写程序，实现功能：按行读取数据文件 data.txt 中的字符串，统计每一行字符串中大写字母的个数，将结果（格式："行号:大写字母个数"）写入新文件 result.txt。要求使用函数实现，数据文件与源代码在同一文件夹。
参考答案
def count_upper(s):
    cnt = 0
    for ch in s:
        if 'A' <= ch <= 'Z':     # 也可写 ch.isupper()
            cnt += 1
    return cnt

with open('data.txt', 'r') as fin, open('result.txt', 'w') as fout:
    idx = 1
    for line in fin:             # 文件对象可直接按行迭代
        fout.write("{}:{}\n".format(idx, count_upper(line)))
        idx += 1
运行示例：若 data.txt 三行为 Hello World / abCDeF gHI / no upper here，则 result.txt 写入 1:2、2:5、3:0（实跑验证）。
套路：四个得分点：① 统计逻辑封装成函数（题目硬性要求"使用函数实现"）；② open('data.txt','r') 只写文件名即默认与源码同目录；③ for line in fin 按行读、fout.write(...) 按"行号:个数"格式写，行号用计数器 idx 递增；④ 判断大写 'A'<=ch<='Z' 或 ch.isupper()。用 with 自动关文件是加分习惯。
考点：按行读文件考点：写文件与 with

编写程序，设计书籍类继承体系并进行相应的类测试。
(1) 基类书籍类，实例属性有书名和作者。
(2) 小说类继承自基类，新增一个实例属性表示小说类型。
(3) 教材类继承自基类，新增一个实例属性表示适用的年级，如"高中三年级"。每个类需有自己的构造方法，以及信息输出方法。创建小说类和教材类的实例，并调用信息输出方法输出实例信息。
参考答案
class Book:
    def __init__(self, title, author):
        self.title = title
        self.author = author
    def display_info(self):
        print("书名：{}，作者：{}".format(self.title, self.author))

class Novel(Book):
    def __init__(self, title, author, genre):
        super().__init__(title, author)   # 调用父类构造，复用公共属性
        self.genre = genre
    def display_novel(self):
        print("书名：{}，作者：{}，小说类型：{}".format(self.title, self.author, self.genre))

class Textbook(Book):
    def __init__(self, title, author, grade):
        super().__init__(title, author)
        self.grade = grade
    def display_textbook(self):
        print("书名：{}，作者：{}，适用年级：{}".format(self.title, self.author, self.grade))

Novel("活着", "余华", "长篇小说").display_novel()
Textbook("Python语言程序设计基础教程", "傅清平", "高中三年级").display_textbook()
运行结果：
书名：活着，作者：余华，小说类型：长篇小说
书名：Python语言程序设计基础教程，作者：傅清平，适用年级：高中三年级（实跑验证）。
套路：面向对象继承综合题的评分点：① 基类 __init__ 定义公共属性（书名、作者）；② 子类写法 class Novel(Book): 表达继承；③ 子类构造中用 super().__init__(...) 调父类构造再补新增属性（漏写 super 则 title/author 未初始化，直接丢分）；④ 各类各写信息输出方法，创建实例并 对象.方法() 调用测试。
考点：类与构造 __init__考点：继承与 super()
