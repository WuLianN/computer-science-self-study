Python：两个变量，共用一个列表

a = [10, 20, 30]
b = a
b[0] = 99
print(a)

重点看：执行 b = a 后，图中两个变量的箭头指向哪里。

带着这段代码去体验 ↗
观察后再看结果与变式

输出 [99, 20, 30]。两个变量指向同一个列表，修改列表后，两边都能看到变化。

把第二行改成 b = a.copy()，再运行一次：此时得到两个独立列表，最后输出 [10, 20, 30]。这里的元素都是整数，浅复制已足够完成对比。

C：通过指针修改变量

#include <stdio.h>

int main(void)
{
    int x = 10;
    int *p = &x;
    *p = 99;
    printf("%d\n", x);
    return 0;
}

重点看：p 指向 x，执行 *p = 99 时哪个值发生了变化。

带着这段代码去体验 ↗
观察后再看结果与变式

输出 99。p 保存 x 的地址，*p 访问这个地址处的变量。

把 *p = 99; 改成 *p = *p + 1;，重新预测输出，再逐步验证。

C 语言 · 建议练习顺序

Python · 建议练习顺序

下面链接进入本站 Python 知识点。先写清楚每一步，再尝试简化写法。

  1. 数据类型与内置函数 → 输入、类型转换、数值计算、格式化输出。

每天怎么练 · 上机前怎么准备

建议每天 45～60 分钟

  • 10 分钟：回顾一个知识点，用短代码预测输出、逐步观察。
  • 25～35 分钟：独立做 2～3 道同类基础题，遇到报错先读提示、检查变量。
  • 10～15 分钟：记录错误原因，关掉题解重写；隔两三天再复做一次。
