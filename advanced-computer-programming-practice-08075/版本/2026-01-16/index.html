建议训练方式

  1. 先练基础语法、条件与循环、组合数据类型、函数和异常处理，能从空白文件写出完整程序。
  2. 使用Python Tutor 小实验观察引用、函数与变量变化；用牛客巩固基础。
  3. 在本地 IDLE 中练文件路径、文本与 CSV 读取、字典统计、类和实例；单独练 numpy、pandas 和 matplotlib。
  4. 按员工销售额样例串联“读取 → 处理 → 统计 → 绘图”，检查文件保存、图表标题与标签，再核对当期规则做限时模拟。
