先练什么

先练基础语法、异常处理与函数，再在本地完成文件读取、字典统计和绘图。文件与第三方库部分需要本地环境，不能只靠在线题库。

建议先看本版考核范围，再看原文题型示例；需要补概念时回到本站 Python 知识点。

本页的练习顺序是学习建议；大纲中的题型举例用于理解任务形式，不能当作当期原题或完整考试题库。

动手练习可查看本站自编参考实现：固定区间质数、异常处理变式、销售额统计与绘图，附 Python 源码、自拟 data.txt 和运行结果。
