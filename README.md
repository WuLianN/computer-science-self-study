# 🎓 自考本科 · 计算机科学与技术 学习笔记

个人自学考试（专升本）备考资料仓库。纯静态 HTML/CSS/SVG，无需构建、免登录，已托管 GitHub Pages，可在线直接浏览。

首页「继续阅读」按最近阅读时间排列，每门课程保留一个小节或题号，默认显示最近 4 门，其余可展开。记录仅存本机浏览器，隐藏科目不会删除记录。课程目录遵循 `英文名-五位课程代码`、页面按约定引入 `dock.js`，即可自动接入；知识点和真题的列表导航页不覆盖阅读位置。

> ⚠️ 本仓库内容仅供个人学习交流参考，真题版权归原命题机构所有。

## 🧪 实践资料与时效维护

- 实践课程单独建目录、使用独立代码：C 笔试 **13013** / 实践 **13014**，Python 笔试 **08074** / 实践 **08075**，信息安全笔试 **03344** / 实践 **03345**；另收录数据结构实践 **13004**、软件工程实践 **13006**。首页科目数组中分别展示，不因笔试已通过或被隐藏而隐藏待考实践课。
- 固定课程入口放在课程目录的 `index.html`；学校修订大纲时，在 `版本/YYYY-MM-DD/` 新增整理页与原始 PDF，更新入口的版本记录，保留旧版。日期取官网标注的发布日期，不取网址路径年份、文件下载时间或操作系统修改时间。
- **发布日期、官网核对日期、适用考期分别记录。** 当前五份华南理工大学大纲官网标注日期均为 **2026-01-16**，于 **2026-11-26** 核对与用户提供 PDF 逐字节一致，整理页记录 SHA-256。原文未给出有效截止日，不按跨年自动判废，也不自动认定下一考期适用。
- 报名、缴费、考核日期、地点、软件及可携带资料等，以学校**当期通知与准考证要求**为准。本站不自动监测学校更新；每次报考前人工核对，不把历史报名日期当作当前报名入口提示。
- 取得具体考期通知后，可另按课程目录下的 `通知/年度-批次/` 保存来源与适用期，不覆盖大纲版本；尚未取得的通知不建空目录或填写猜测日期。更新大纲时，同步更新固定入口的摘要、默认链接、核对日期及版本记录，旧版正文与原文保留不动。
- 来源以[华工计算机专业实践大纲目录](https://sce.scut.edu.cn/zkpx/jsjkxyjs/list.htm)、课程发布页及当期通知为准。学校[2026-08-18 公告](https://sce.scut.edu.cn/2026/0818/c16915a633569/page.htm)说明，后续自考工作资讯统一在“华南理工大学继续教育学院”微信服务号“自学考试”专栏发布，旧自考服务号的停用日期为 2026-09-30。
- PDF 原文与本站归纳分开保存；样例只标为“大纲题型举例”，不标成历年真题。发现原文疑点时注明出处，后续自拟题目、数据或答案单独标注。
- 可运行参考实现放在各实践课的 `题型示例.html` 与 `示例代码/`，明确“本站自编、非官方答案”；输入格式和自拟数据写清楚，页面中的代码与可下载源码保持一致。C 示例分别编译；Python 输入变式依赖同目录的 primes.py，绘图示例依赖 matplotlib 与同目录 data.txt。本站验证环境不等同于学校考场环境。
- 数据结构按官网实践代码 **13004** 归档，同时保留 PDF 封面 **13003** 与链表结构体缺少 `next` 的原文差异。软件工程提供 SVG 学习源图和重画步骤，不冒充 StarUML 原生工程；安全管理将已运行的 Python 代码与尚需实验环境复测的 PGP / 防火墙 / MySQL 步骤分开说明，SQL 需先替换实验口令。
