- **真题详解**：三套离散数学真题 + 两套 13013 真题逐题解析，考点标签一键跳转到对应知识小节。
- **13013 真题详解**：只收 2026.4 与 2025.10 两套全国卷，题干与程序代码常显、答案折叠可自测，答案速查表统一放在页尾；客观题与程序分析题均按 C 规则复核并用 gcc 实跑验证（网络流传版共 4 处答案错误已更正）。
- **考前抢分**：按题型频率统计的必考清单 + 可默写代码模板 + 易错坑 + 考场策略，支持 `Ctrl+P` 打印带走。
- **考纲驱动知识点速记卡（08074 / 13009 / 03344 / 13011）**：广东新开课无成套真题，故按考纲逐章拆页（08074 九章 Python、13009 十章 MySQL/SQL、**03344 十章网络空间信息安全**、**13011 十三章大数据与人工智能**），每页含本章目录卡、**四级能力层次标签（识记/领会/简单应用/综合应用）**、代码/语句示例、易错框与速记小结；页首均标注“考纲驱动 + 公开资料补充，非教材原文逐字”。03344 额外把**教材原文清单逐条列全**（病毒七特征与五分类、木马检测六项、入侵六步与七层次、四类攻击术、服务器端六条/维护终端八条、PKI 两套“五部分”、备份五方法等），并给出 **RSA／古典密码计算例题**；注意其**考纲章号与教材章号一一对应**（与 13009 不同），且部分小节在“不考清单”与“考核知识点”中冲突，页面一律**以考核知识点清单为准**。13011 按三篇 13 章整理，含**距离度量/K-均值 trace/线性回归最小二乘/决策树信息增益（官方水果分类）**等算例与**云·物·数·智融合**清单；⚠️ 其**考纲章号 ≠ 教材章号**，最易踩坑的是**考纲第 13 章“机器学习算法实验”＝教材第 15 章 15.1—15.3**（教材第 13/14 整章不考）。
- **考纲整理页（03344 / 08074 / 13009 / 13011）**：广东省考大纲逐章整理，考核知识点按「识记/领会/简单应用/综合应用」四级标签标注；**页首醒目区放指定教材信息与「不纳入考核范围」的教材节次清单**（四门课教材名均与课程名不同，备考买书先看这里）。⏰ 四页均为 **2026 年 10 月收集的考纲快照**，页首有时效提醒——考纲会修订，每次报考前请以广东省教育考试院当期发布为准。
