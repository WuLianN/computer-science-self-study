一、概念与两部分内容

识记 网络空间信息安全的概念；领会 它所包含的两部分内容。
网络空间信息安全：以网络空间（Internet 及其延伸的信息基础设施）为环境，保护其中的信息系统与数据信息不受偶然的和恶意的原因而遭到破坏、更改、泄露，保证系统连续、可靠、正常地运行，即不中断地提供服务。
所包含的两部分内容（简答/填空）：
  1. 网络空间本身（系统/基础设施）的安全——网络硬件、软件及网络运行环境的安全，即网络系统能正常运行、不被破坏和瘫痪，靠的是访问控制、防火墙、入侵检测等技术。
  2. 网络空间中所承载信息（数据/内容）的安全——网络上存储、传输的数据不被泄露、篡改、伪造，靠的是密码技术、数字签名与验证、备份等技术。
🔑 一句话记："设备与系统跑得稳"＋"数据内容不泄露不篡改"——前者是系统安全（静态/动态的运行保障），后者是信息安全（保密性、完整性、可用性）。
📖 教材原口径（简答逐条照此写更稳）：①防治、保护、处置包括互联网、电信网、广电网、物联网、工控网、在线设计网络以及计算系统、通信系统、控制系统在内的各种通信系统及其承载的数据不受损害；②防止对这些信息通信技术系统的滥用所引发的政治安全、经济安全、文化安全、国防安全问题。
信息安全的三个基本属性（贯穿全课程的概念，务必先记牢）：
属性含义被破坏的典型表现对应防护技术（后面各章）
保密性 Confidentiality信息不泄露给未授权者窃听、流量分析、数据泄露密码技术、访问控制（第 4、8 章）
完整性 Integrity数据未被未授权地篡改、增加或删除篡改、伪造、中间人替换数字签名、散列、入侵检测（第 5、9 章）
可用性 Availability授权用户需要时能正常使用拒绝服务攻击、病毒破坏、宕机病毒防范、备份、防火墙（第 2、10 章）
⚠️ 教材 1.4「信息安全、网络安全与网络空间信息安全的区别」不纳入考核——三者范围大小的关系仅作理解（信息安全 ⊃ 网络安全 ⊃ 网络空间信息安全），不要花时间背名词辨析。

二、面临的七类信息安全问题 ⭐⭐ 必背清单

识记 当前网络空间面临的主要七类信息安全问题。
七类问题的记忆主线：一条底层协议（Internet）→ 三项基础服务（邮件/DNS/IP）→ 两类应用（Web/FTP）→ 一个"人"的因素（社工）
#安全问题主要漏洞 / 攻击方式防范措施（要点）
1Internet 安全TCP/IP 协议族设计上缺乏安全机制：明文传输、源地址可伪造、无强认证；路由与广播结构易被监听用安全协议（IPSec/SSL/TLS）加固各层；部署防火墙与入侵检测；全网统一安全策略
2电子邮件安全SMTP 无身份认证→可伪造发件人；明文传输→可被窃听；附件携带病毒/木马；垃圾邮件与钓鱼反垃圾与邮件网关；S/MIME、PEM 做签名与加密；附件先查毒再打开；不点不明链接
3域名系统（DNS）安全域名欺骗/劫持、缓存投毒、DNS 查询报文被监听（可推断访问行为）、分布式拒绝服务打 DNS 服务器DNS 区域传输限制与随机事务 ID；DNSSEC 签名验证；递归与权威服务器分离、多备份解析
4IP 地址安全IP 地址欺骗（利用信任关系冒充授权主机）、ARP 欺骗/广播导致流量被劫持、IP 地址与用户绑定不严采用一次一密的挑战/应答认证而非地址信任；静态 ARP 表项/ARP 防护、端口安全、IP-MAC-端口-交换机四绑定
5Web 站点安全SQL 注入、XSS 跨站脚本、上传漏洞、目录遍历、弱口令与管理后台暴露、页面被篡改见本章第四节"六步措施"（考纲点名简单应用）
6文件传输（FTP）安全FTP 默认匿名访问且账号口令明文传输；上传的脚本/木马直接落在服务器上；目录权限过宽关闭匿名、口令加密存储；改用 SFTP / FTPS / SSH 隧道；上传文件类型白名单与查毒；限制目录访问权限
7社会工程学不攻击机器而攻击人：欺骗、假冒身份、利诱、窥探口令、垃圾邮件钓鱼、尾随进入机房安全制度与培训、最小授权、口令策略与定期更换、双人复核敏感操作、物理门禁与访客登记
🔑 口诀记七类："协（协议）邮 名 址 网 传 人"——Internet 协议、邮件、域名、IP 地址、Web 站点、文件传输、社会工程学。

三、电子邮件与文件传输的安全漏洞与防范 ⭐

领会 电子邮件的安全漏洞和防范措施；FTP 的安全漏洞和防范措施。
（一）电子邮件
安全漏洞（四条，答"漏洞"就写这些）：①SMTP/POP3 协议本身不提供认证与加密，口令以明文在网络上传送，极易被截获；②邮件源地址可伪造，无法确认发件人真实身份；③邮件内容易被截获、篡改和抵赖，缺乏完整性与不可否认性保护；④附件与链接是病毒、木马、钓鱼的主要传播渠道。
防范措施：①邮件加密——传输层用 TLS，内容层用 S/MIME、PEM、PGP 对正文和附件加密；②数字签名验证发件人身份并保证不可抵赖（第 5 章）；③部署反垃圾邮件网关（内容过滤、黑白名单、发件人域名验证 SPF）；④邮件服务器关闭开放转发（Open Relay）；⑤附件先杀毒后打开，不执行来历不明的可执行文件；⑥对员工进行钓鱼邮件识别培训。
📖 教材原列·电子邮件的安全漏洞（六条）：①窃取 Email；②伪造指令攻击；③Email 轰炸；④Email 欺骗；⑤虚构某人名义发出 Email；⑥电子邮件病毒。
教材原列·安全措施：①在邮件系统中安装过滤器，接收任何 Email 之前先检查（过滤）发件人的资料，删去可疑邮件不让它进入邮件系统；②防止 Email 服务器超载（超载会降低传递速度或不能收发 Email）；③如有 Email 轰炸或遇上 Email spamming，就通过防火墙或路由器过滤来自这个地址的邮件炸弹邮包；④防止 Email 炸弹——在路由的层次上限制网络的传输；⑤可写一个 script 程序捕捉邮件炸弹的地址，对其每一次连接自动终止并回复一个声明指出触犯法律；⑥严禁打开 Email 附件中的可执行文件（.exe、.com）及 Word、Excel 文档（这些多是病毒／特洛伊木马的有毒文件）。
（二）文件传输 FTP
安全漏洞：①FTP 支持匿名用户（anonymous）登录，配置疏忽会让外人随意读写；②登录账号与口令明文传输，可被嗅探；③上传目录若授予写权限或可执行，攻击者可上传 WebShell/木马；④下载目录权限过宽会造成源码与敏感配置文件泄露；⑤FTP 本身没有加密和完整性保护。
防范措施：①关闭匿名登录，使用独立账号并限制可访问目录（chroot 隔离）；②用 SFTP（基于 SSH）或 FTPS 取代明文 FTP，或把 FTP 放进 SSH 隧道；③按最小权限分配读/写/执行，上传目录禁止执行；④上传文件做扩展名白名单＋病毒扫描；⑤记录访问日志并定期审计，设置登录失败锁定与传输速率限制。
📖 教材原列·FTP 的安全漏洞（五条）：①代理 FTP 中的跳转攻击（攻击者向目标 FTP 服务器发出 PORT 命令，其中带被攻击主机的地址与端口，命令 FTP 服务器把数据发送给被攻击者）；②FTP 软件允许用户访问系统中所有文件，且文件系统存在可写区域供攻击者删改文件；③地址被盗用（Spoof）——基于网络地址的访问使 FTP 易被冒充；④用户名和密码被猜测；⑤端口盗用。
教材原列·FTP 安全措施：①未经授权的用户禁止进行 FTP 操作，FTP 使用的账号必须在 Password 文件中有记载，且它的口令不能为空；②保护 FTP 用的文件和目录并设置所有权：FTP\bin 与 FTP\exe 目录所有者设为 root，FTP\pub 目录与 FTP 的主目录所有者设为 FTP。

四、Web 站点安全防范措施（应用题模板）⭐

简单应用 根据对 Web 站点安全问题的理解，制定 Web 站点的安全防范措施。
先答"存在哪些安全问题"，再逐条给措施——这是应用题的标准两段式。
Web 站点常见问题：SQL 注入、跨站脚本 XSS、跨站请求伪造 CSRF、上传漏洞与 WebShell、目录遍历与越权访问、弱口令与会话劫持、管理后台暴露、拒绝服务、页面被篡改、证书与传输未加密。
防范措施（六步，答题按 ①～⑥ 分行写）：
  1. Web 服务器与操作系统加固：及时打补丁，关闭不必要的服务、端口和默认共享，删除默认账号与示例页面，最小化安装。
  2. 输入验证与编码：所有用户输入做白名单校验与服务端二次验证，使用参数化查询/预编译语句防 SQL 注入，输出转义防 XSS，禁止拼接 SQL。
  3. 身份认证与会话管理：强口令策略与失败锁定、多因素认证、会话超时与唯一令牌、Cookie 设置 HttpOnly/Secure，管理后台限 IP 访问并单独账号。
  4. 访问控制与权限最小化：按角色授权（RBAC），目录与文件权限分离，禁止目录浏览，上传目录不可执行并使用扩展名白名单。
  5. 传输加密与部署防护：全站 HTTPS（SSL/TLS）；前置防火墙 / WAF（Web 应用防火墙）过滤注入与异常流量，与后台数据库服务器隔离在不同网段。
  6. 安全审计、监测与备份恢复：开启访问日志与安全日志并定期分析、部署入侵检测与网页防篡改系统、定期漏洞扫描与渗透测试、数据与页面定期备份并演练恢复。
📖 教材原列·Web 服务器的安全漏洞（七条，答"存在哪些安全问题"先列这几条）：①安全威胁来源包括外部接口、网络外部非授权访问、网络内部的非授权访问、商业或工业间谍、移动数据；②入侵者重点针对访问某一数据库、表、目录，以破坏或攻击数据为目的；③进行地址欺骗、IP 欺骗或协议欺骗；④非法偷袭 Web 数据（如电子商务或金融信息数据）；⑤伪装成 Web 站点管理员，攻击或控制 Web 站点主机；⑥服务器误认闯入者是合法用户而允许其访问；⑦伪装域名，使 Web 服务器向入侵者发送信息，而客户无法获得授权访问的信息。
📖 教材原列·常见 Web 站点安全措施（十条，可按编号答）：①不把 Web 服务器当无权限用户运行，要设置权限管理；②敏感文件放在基本系统，再设二级系统，敏感数据都不向 Internet 开放；③检查 HTTP 服务器使用的 Applet 和脚本，尤其是与客户交互的 CGI 脚本，防止外部用户执行内部指令；④在 Windows NT 之上运行 Web 服务器并检查驱动器和共享的权限，将系统设为只读；⑤采用 Macintosh Web 服务器更为安全，但缺少 Windows NT 的一些设置特性；⑥克制 daemons 系统的软件安全漏洞（控制服务、网络服务、与时间有关的活动、打印服务等会执行不该执行的功能）；⑦为防止入侵者用电话号码作口令进入站点，要配备能阻止和覆盖口令的收取机制与安全策略；⑧不断更新、重建和改变 Web 站点的连接信息，一般只允许单一类文本作为连接资源；⑨把 Web 服务器放在防火墙后面，可装 Wusage 统计软件控制经代理服务器的信息状况（列出往返最频繁的用户名单）；⑩对安装在公共场所的浏览器作防御措施，防被入侵者改变浏览器配置而获得站点机要信息、IP 地址、DNS 入口号等。
⚠️ 上面十条是教材原文口径（含年代较久的系统举例）；若题目问"结合你所知提出措施"，用上面六步的现代写法得分更高，两者可结合：先列教材要点、再补现代技术名称。
📝 判分点：措施要成组、有条目号，且尽量点出具体技术名称（参数化查询、HTTPS、WAF、RBAC、防篡改、日志审计）——只写"加强管理""提高意识"得分很低。

六、七大趋势：立法与国家安全（领会）

领会 网络安全立法的重要性；网络信息安全对国家安全的重要意义。
考纲只要求"领会"其中两条——立法的重要性、对国家安全的重要性；"七大趋势"作为一个总体判断了解即可（具体七条表述请以教材 1.5 节与配套课件为准）。
① 网络安全立法为什么重要（简答要点）：
  1. 技术措施只能防"能防的"，法律界定行为的边界与责任，让攻击、泄露、不作为都有代价——是安全体系的最后一道防线。
  2. 为关键信息基础设施、数据与个人信息保护提供强制性的等级保护、审计和报告义务，使安全管理有法可依、可核查。
  3. 打击网络犯罪需要取证规则与量刑依据，也才能开展国际司法与执法合作。
  4. 统一标准与规范，避免各家各行其是，促进安全产业可信发展。
  5. 我国已形成以《网络安全法》《数据安全法》《个人信息保护法》《密码法》《国家安全法》与等级保护制度为骨架的法律体系（注意：命题会涵盖考试日前 6 个月内新颁布/修订的法律法规）。
② 网络信息安全对国家安全的重要意义：网络空间已成为继陆、海、空、天之后的第五疆域；政务、金融、能源、交通、通信等关键基础设施都运行在网络之上，一旦失控直接威胁政治安全、经济安全、国防安全与社会稳定；网络攻防具有成本低、隐蔽性强、溯源难、跨域传导快的特点，使"没有网络安全就没有国家安全"。因此网络空间信息安全是构建国家信息化的根本保证，也是电子政务、电子商务、网络银行、远程医疗等系统正常运转的前提。
📌 趋势层面的通行判断（帮助理解，不必逐条背）：由被动防御走向主动防护与可信、由单点技术走向体系化/平台化、立法与标准加速、安全上升为国家战略、云/移动/物联网带来新场景风险、安全服务与产业规模化、国际竞争与合作并存。

七、本章速记小结

六条一句话：
  1. 概念两块：网络系统自身的安全 ＋ 网络中信息（数据）的安全。
  2. 三性：保密性、完整性、可用性——后面每章的技术都在保这三样。
  3. 七类问题：Internet 协议、邮件、域名、IP 地址、Web 站点、文件传输、社会工程学。
  4. 邮件/FTP 的根因：明文传输＋无强认证＋匿名/弱口令＋附件与上传通道。
  5. 九种技术领域＝本书第 2～10 章的目录。
  6. 立法与国家安全：技术防得住漏洞，法律管得住人；网络空间是第五疆域。
