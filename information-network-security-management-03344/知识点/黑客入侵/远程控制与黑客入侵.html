一、远程控制：概念、原理与应用范畴 ⭐

识记 远程控制的基本概念和应用范畴。
远程控制（Remote Control）：借助网络与专用软件，让一台计算机（控制端 / 客户端）越过地理距离，对另一台计算机（被控端 / 服务端）进行如同本机一样的操作——包括屏幕查看、键鼠操作、文件传输、命令执行与系统管理。
教材原文口径（名词解释照此写）：远程控制是指网络管理人员在异地通过计算机网络异地拨号或双方都接入因特网（Internet）等手段，通过网络空间中的一台计算机（主控端 Remote／客户端）远距离去控制另一台计算机（被控端 Host／服务器端）的技术。
技术原理（C/S 模型，四步）：①被控端运行服务端程序并监听端口，注册为开机自启/系统服务；②控制端通过地址与端口发起连接，经身份验证（口令、证书）建立通道；③控制端把键鼠指令、屏幕画面、文件封装成控制指令沿通道传输（通常加密）；④被控端执行指令并把屏幕图像回传，实现"所见即所控"。
应用范畴（教材原列五项）举例
① 远程维护与管理服务器/网络设备巡检、批量部署、故障处置（SSH、远程桌面）
② 远程技术支持帮用户排查问题、代操作电脑、客服屏幕共享
③ 远程教育与交流远程授课、屏幕演示与协同标注、学术研讨
④ 远程办公在家连回单位电脑、跨地访问内网业务系统
⑤ 远程监控远程会诊、上位机对现场设备的远程监控、视频监控与安防值守
被滥用的方向（安全威胁）木马／后门／远控 RAT、僵尸网络控制、越权访问他人主机——同一技术、两种用途，这也是本章要学防范的原因
🔑 常考的一句话区分：远程桌面是"用户主动授权"的远程控制；木马是"未经授权的隐蔽远程控制"——二者技术机理相同，区别在是否知情同意与是否加密认证。

二、Windows 远程控制的实现方式

领会 Windows 平台远程控制的常见实现手段（识记其名称与端口）。
方式说明默认端口 / 备注
远程桌面（RDP）系统自带，图形化登录本机以外主机；需在"系统属性 → 远程"勾选允许，并限定用户TCP 3389；强口令＋网络级认证 NLA

PsExec / WinRM 远程管理在域内跨机执行命令、管理远程服务与 PowerShell 会话常被攻击者用作横向移动工具，需限制

⚠️ 判断题爱考："远程控制软件必须由被控端主动连接控制端才能工作"——错。传统是控制端连入被控端监听端口；而木马/穿透型远控反过来让被控端外连控制端（绕开防火墙与 NAT），因此"只出不进"的主机同样可能已被远控。

三、黑客入侵的基本过程 ⭐⭐

识记 网络空间入侵的基本过程、黑客入侵的基本过程。
📖 教材原列（两个"基本过程"要分开答）：
① 网络空间入侵基本过程——教材只列两点：(1) 网络空间攻击的位置：远程攻击、本地攻击、伪远程攻击；(2) 网络空间攻防模型（进攻方—目标—防守方—安全策略的对抗模型）。
② 黑客入侵网络空间的基本过程（六步，简答主干）：探测并确定入侵目标 → 收集信息与周全分析 → 对端口与漏洞的挖掘 → 实施攻击 → 留下“后门” → 清除日志。
下面那张七步流程图与逐条展开是同一过程的理解版（把“隐藏身份”“维持控制”单列），考试答“六步”更贴合教材。
七步链条既是入侵流程，也是防范清单——每一步都有对应的检测与拦截手段
  1. 隐藏真实身份：使用跳板/代理、匿名网络、肉鸡中转、伪造 IP，掩盖攻击来源以躲避追踪取证。
  2. 收集目标信息（侦察）：查域名与 IP 归属、拓扑与操作系统、开放端口与服务、目录结构与人员信息（WHOIS、DNS 查询、搜索引擎、社会工程学）。
  3. 扫描与查找弱点：端口/服务扫描、漏洞扫描、弱口令口令猜测、抓取可下载的补丁级别信息，寻找可利用的漏洞。
  4. 获取访问权与超级权限（攻击突破）：利用漏洞（缓冲区溢出、注入、默认口令、WebShell）登录，再本地提权至管理员/System/Root。
  5. 植入后门、扩大战果：安装远控木马或服务型后门、添加隐藏账号、建立信任关系，为再次进入留通道；对内网做横向移动。
  6. 清除/伪造痕迹：删除或篡改系统与应用日志、删除临时文件、痕迹清理，甚至植入虚假日志干扰取证。
  7. 实现攻击目的并维持控制：窃取/篡改/删除数据、加密勒索、植入蠕虫扩散、把主机并入僵尸网络，长期潜伏随时复用。
🔑 对应防御：①靠出口管控与溯源，②③靠关闭多余服务与漏洞扫描，④靠补丁＋强口令＋最小权限，⑤靠 IDS/后门查杀与账号审计，⑥靠日志集中异地保存与取证，⑦靠备份恢复与安全响应。问"如何防范黑客入侵"时按这个对应关系答，条理分最清楚。

四、黑客入侵的层次与种类（领会）⭐

领会 黑客入侵的层次与种类。
（一）黑客入侵的层次（教材口径：按进攻方法和危害程度分为七个级别层次）⭐ 常考排序
层次黑客获得的能力危害程度
第一层简单拒绝服务攻击只影响可用性，最轻
第二层本地用户获得非授权读权限本地越权，泄密风险开始上升
第三层本地用户获得非授权写权限
第四层远程用户获得非授权账户信息跨网越权的第一步
第五层远程用户获得特权文件的读权限远程读写特权文件，已属严重入侵
第六层远程用户获得特权文件的写权限
第七层远程用户获得系统管理人员的权限黑客已经攻克系统，最严重
🔑 记法：“拒服 → 本读 → 本写 → 程账 → 程特读 → 程特写 → 程管理”，由轻到重：读在写前、本地在远程前、账户在特权前。第七层的判定标志就是“拿到系统管理员权限＝系统已被攻克”。

层次典型攻击手段防范要点

（二）按攻击行为的种类（两种基本划分，多选常考）：
划分类别破坏的属性特点
按是否改变数据流被动攻击只破坏保密性（窃听、流量分析、sniffer 抓包）不修改数据、难以察觉，故主要靠检测预防与加密防护
主动攻击破坏完整性/可用性/真实性：篡改、伪造、重放、中断、拒绝服务会改动流量、易被发现但难完全阻止，靠认证、签名、入侵防御、冗余抗毁
按攻击技术拒绝服务攻击术资源耗尽型（带宽、连接、CPU）、导致异常型（畸形包使服务崩溃）DoS／DDoS，如 SYN Flood、UDP Flood、CC
数据驱动攻击术缓冲区溢出、输入验证缺陷、格式化字符串漏洞、同步漏洞利用程序代码缺陷获得控制
欺骗术网络欺骗（IP/MAC/DNS/ARP）、身份假冒、恶意代码攻击、中间人靠"冒充"骗取信任或劫持流量
窃听术（教材四类之首）键击记录、网络监听、非法访问数据（补充：字典/暴力猜测、撞库、社工获取口令）属被动攻击，合法用户不易觉察 ⇒ 靠加密与流量隔离防
📖 教材原列·黑客攻击种类（两大类型原文）：①主动攻击：主动攻击包含攻击者访问其所需信息的故意行为；②被动攻击：攻击者主要是收集信息而不是进行访问，数据的合法用户对这种活动不会觉察到，被动攻击包括嗅探、信息收集等攻击方法。
教材原列·目前黑客常用的几种攻击手段与技术（四类）：①窃听术——键击记录、网络监听、非法访问数据；②欺骗术——网络欺骗攻击、恶意代码攻击；③数据驱动攻击术——缓冲区溢出攻击法、输入验证攻击法、格式化字符串攻击法、同步漏洞攻击法；④拒绝服务攻击术——资源耗尽型、导致异常型。
📌 术语小提示：入侵（Intrusion）指一切破坏网络可用性、保密性、完整性的行为；黑客攻击按目的常分成未授权访问、信息泄露、拒绝服务、冒充与篡改四类后果。

五、服务器端的安全防范措施（领会）⭐

领会 服务器端对攻击、病毒和木马软件、故障等的防范。
①对黑客攻击的防范：
  1. 最小化安装与服务：只装必要组件，关闭不用的端口/服务/共享，删除默认账号、示例程序与默认站点。
  2. 及时打补丁与升级，开启自动更新，重点封堵高危漏洞；对 Web 应用同步升级框架与组件。
  3. 访问控制与隔离：防火墙只开放业务端口；服务器分区分层部署（DMZ/内网/数据库分离），数据库服务器不对公网直接开放。
  4. 强认证与最小权限：复杂口令、禁用 Administrator 远程登录、SSH/RDP 用密钥与源地址限制、账号权限按角色分配，禁用明文协议（Telnet/FTP）。
  5. 部署 IDS/IPS、WAF 与流量清洗，对扫描与异常流量告警并联动阻断；对重要页面启用 HTTPS。
  6. 日志审计与异地备份：安全日志集中收集、只读保存、定期分析并异地留存（防止被删改），定期做漏洞扫描与渗透测试。
📖 教材原列·黑客攻击、数据篡改的防范措施（服务器端六条，简答照编号写）：①网站服务器和局域网内计算机之间设置经公安部验证的防火墙，并与专业网络安全公司合作，做好安全策略，拒绝外来的恶意攻击，保障网站正常运行；②在所有网站服务器上安装正版防病毒软件，做到每日对杀毒软件与木马扫描软件进行升级，及时下载最新系统安全漏洞补丁，开启病毒实时监控，防止有害信息对网站系统的干扰和破坏；③网站服务器提供集中式权限管理：针对不同的应用系统、终端、操作人员，由网站运行管理员设置服务器的访问权限并设置相应的密码及口令，不同操作人员设定不同用户名及口令，严禁操作人员设置弱口令、泄露自己的口令，并要求定期更换口令；对操作人员的权限严格按岗位职责设定，并由网站运行管理员定期检查操作人员权限；④在服务器上安装设置 IIS 防护软件防止黑客攻击；⑤网站运行管理员定期做好系统和网站的日常备份工作；⑥网络管理员做好系统日志的留存。
②对病毒和木马软件的防范：安装并常驻防病毒/终端检测响应软件且每日更新病毒库；对上传目录、邮件网关、U 盘介质、外来笔记本接入做入口查杀；关闭自动播放、限制脚本与宏执行；服务器不装无关软件、不浏览外网；对关键系统文件做完整性校验（哈希基线），检测后门与替换；定期全盘扫描＋定期改口令＋账号审计（发现隐藏账号）；重要数据离线备份，勒索类病毒靠备份恢复。
📖 教材原列·病毒与木马软件防范措施（服务器端仅两条，务必写全）：①在所有网站服务器上安装正版防病毒软件，并做好每日对杀毒软件与木马扫描软件进行升级，及时下载最新系统安全漏洞补丁，开启病毒实时监控，防止有害信息对网站系统的干扰和破坏；②不在服务器上安装与网站运行无关的应用软件。
③对故障（可用性与灾难）的防范：关键部件冗余（电源、磁盘 RAID、网卡、双机热备/集群、负载均衡）；UPS 与机房环境（温湿度、防静电、消防）；建立备份与恢复制度（全量＋增量、异地、定期演练恢复，见第 10 章）；配监控告警与运维值班、变更留痕；制定应急预案并按故障等级演练；对网络设备做配置备份与版本管理。
📖 教材原列·网络设备硬件故障的防范措施（四条）：①定期对网络设备进行检测维护，检查网络设备状态，及时发现硬件故障；②定期对备份网络设备进行检测维护，在网络设备出现故障时能够及时更换；③每天要对机房温度、湿度、灰尘情况进行检查，以免因温度、湿度、灰尘等情况导致网络设备损毁；④每天要对机房空调、供电电压等进行检查，以保障网络设备的工作环境良好。

六、网站维护终端的防范措施（综合应用）⭐⭐

综合应用 网站维护终端对攻击、病毒和木马软件、故障等的防范措施。
先说清"维护终端"的风险特点：运维人员用的这台电脑掌握着服务器口令、密钥与后台权限，一旦被控（凭据被盗）危害远大于普通办公机；同时它频繁接触外网与移动介质，是"跳板"的首选目标。所以措施要围绕"终端本身安全 + 凭据安全 + 接入通道安全"三块来答。
①对黑客攻击的防范：
  1. 专用终端、专机专用：维护终端不用于日常上网/收发邮件/玩游戏，避免"一手中毒、全线失守"。
  2. 系统与软件最小化＋及时补丁，关闭共享与远程协助，本地主机防火墙只放行必要出站连接。
  3. 只通过加密通道维护：SSH/HTTPS/VPN/堡垒机（_jump server_）访问服务器，禁用 Telnet 明文管理；关键操作双因素认证。
  4. 接入环境可信：禁止在公共 Wi‑Fi／网吧等不可信网络直连管理界面，必须走 VPN；对可信 IP 做白名单限制。
  5. 账号与权限最小化：维护账号与个人账号分离、按角色授权、操作留痕，重要变更双人复核。
②对病毒和木马的防范：装正规杀毒／终端防护并每日更新病毒库、定期全盘扫描；U 盘等移动介质先查毒再用、不插来路不明的设备（见第 2 章 autorun 处置）；不打开可疑附件与链接、警惕钓鱼邮件与"伪装成发票/账单"的样本；口令与私钥加密保存（用密码管理器，不写在记事本/浏览器自动填充）；下载的工具与脚本先校验哈希与来源；终端开启应用白名单，禁止未知程序运行；定期做后门与账号审计，发现异常外连立即断网取证。
③对故障的防范：终端系统与应用定期备份镜像（快照），配置变更后先备份再操作；关键维护操作留痕并保存变更记录，避免误操作直接改生产（先在测试环境验证）；准备备用终端与离线应急工具包（含干净系统启动盘、必要驱动与工具）；建立值班与应急联系机制、服务器端保留上一版本可回滚；终端故障不影响恢复——凭据与站点代码均有异地备份，随时换机接手。
📖 教材原列·黑客攻击、数据篡改防范措施（网站维护终端八条，综合应用按此答）：①维护人员要做好网站日常维护用设备的安全管理：每天升级杀毒软件病毒库，及时做病毒防护、木马查杀、操作系统及应用软件漏洞修复，日常工作开启病毒实时监控；②不随便打开来源不明的 Excel、Word 文档及电子邮件，不随便点击来历不明的网站；外界存储设备（U 盘、移动硬盘、存储卡、数码设备等）在维护终端上使用前应及时查杀病毒，杜绝安全隐患；③切实做好维护终端共享目录设置管理：共享文件复制结束后应及时取消相应目录的共享设置，杜绝长期设置共享目录，严禁设置完全共享目录；④严禁将涉密类信息存放于维护终端；重要网站或专栏的后台登录地址不得以文件形式存放于维护终端、不得收藏在浏览器收藏夹中，要用纸介质形式存放并妥善保存，如发生丢失应及时上报相关部门主管领导；⑤网站开发人员在网站交付使用前，应将后台发布系统登录文件名设置得尽量复杂：采用字母、数字和特殊符号相结合的方式，长度不得少于 20 个字符；⑥交付使用前务必删除后台发布系统中不必要的功能代码（特别是论坛、博客类功能代码）；⑦交付使用前务必删除后台发布系统中不必要的账户、密码（如系统自带的或测试用的账户）；⑧交付使用前务必做好后台发布系统的管理员账户、密码的设置与数据库防下载工作：坚决杜绝弱口令、弱密码，管理员密码采用字母、数字和特殊符号相结合、长度不得少于 10 个字符，严禁多个网站共用一个管理员密码。
⚠️ 第⑤⑧两条的“不少于 20 个字符／不少于 10 个字符”是教材给出的具体数字，选择题可能直接考。
📖 教材原列·病毒与木马防范措施（网站维护终端五条）：①做好日常维护设备的安全管理，每日升级杀毒软件病毒库与木马扫描软件，及时做病毒防护、木马查杀与漏洞修复，工作时开启病毒实时监控；②不随便打开来源不明的 Excel、Word 文档及电子邮件，不随便浏览来历不明的网站，使用外界存储设备前先查杀病毒；③设置网络共享账号及密码时尽量不要使用常见字符串（如 guest、user、administrator 等）和空密码，密码最好超过 8 位且尽量复杂化；④在运行通过网络共享下载的软件程序之前，应先进行病毒查杀，以免中毒；⑤禁用系统的自动播放功能，防止病毒从 U 盘、移动硬盘、MP3 等移动存储设备进入计算机——方法：在“运行”中输入 gpedit.msc 打开组策略编辑器，依次选择“计算机配置”→“管理模板”→“系统”→“关闭自动播放”→“已启用”→“所有驱动器”→“确定”。
📝 答题加分结构：先答"维护终端为什么特殊"（掌握凭据、是跳板），再分"攻击／病毒木马／故障"三块各写 3～5 条，最后补一句"建立安全管理制度与应急响应流程并定期演练"——制度层面是考纲反复强调的落点。

七、本章速记小结

六条一句话：
  1. 远程控制＝C/S＋端口监听＋身份验证＋指令与画面传输，正当用途与木马滥用的界限是"是否授权、是否加密认证"。
  2. Windows 手段清单：远程桌面 3389、远程协助、Telnet 23（禁用）、SSH 22、PsExec/WinRM、第三方穿透型远控。
  3. 入侵六步（教材）：探测并确定入侵目标→收集信息与周全分析→对端口与漏洞的挖掘→实施攻击→留下“后门”→清除日志；攻击位置分远程／本地／伪远程三类。
  4. 层次七层（拒服→本读→本写→程账→程特读→程特写→程管理），种类先分主动/被动，四类攻击术为窃听术、欺骗术、数据驱动攻击术、拒绝服务攻击术。
  5. 被动攻击难发现、主要靠加密；主动攻击要改流量、主要靠认证与检测阻断。
  6. 服务端防"三样"：攻击（最小化＋补丁＋隔离＋审计）、病毒木马（入口查杀＋完整性校验）、故障（冗余＋备份＋监控）；维护终端再加一块"凭据与通道安全"。
📌 本章识记集中在“过程与概念”，领会在“层次种类与服务器端防范”，综合应用在“维护终端防范”。简答题若问“入侵的一般过程”，按教材六步写全并各加一句对策，是稳分答法；问“维护终端防范措施”时，优先背教材八条＋病毒木马五条（含 20 位／10 位口令长度与 gpedit.msc 关闭自动播放这类具体得分点）。
