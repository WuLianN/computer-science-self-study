一、入侵、入侵手段与入侵防御系统的分类 ⭐⭐

识记 入侵手段、入侵防御系统的分类。
入侵的定义（先背这一句）：所有破坏网络可用性、保密性和完整性的行为都是入侵。（正好对应第 1 章的三性——判断"是不是入侵"就看它破坏了哪个性。）
目前黑客的入侵手段主要有三种：
手段含义破坏的属性对应章节
① 恶意代码以病毒、蠕虫、木马、后门、逻辑炸弹等形式进入并驻留系统，实施破坏、窃取与控制完整性、可用性、保密性都破坏第 2 章（防范与查杀）
② 非法访问未授权访问或越权访问资源：口令破解、地址欺骗、漏洞利用提权、非授权读取／修改数据保密性、完整性第 3、8 章（入侵过程与访问控制）
③ 拒绝服务攻击用资源耗尽、导致异常等方式使系统／网络不能正常提供服务（DoS／DDoS）可用性第 3、7 章（无线 DoS）
入侵防御系统分为两大类：
类别主要用途（教材原文）部署位置关注点
① 主机入侵防御系统
（HIPS）		主要用于检测达到某台主机的信息流、监测对主机资源的访问操作装在被保护主机内部（与操作系统／内核结合）本机文件、进程、注册表、系统配置与进出该主机的流量
② 网络入侵防御系统
（NIPS）		主要用于检测流经网络某段链路的信息流串接在网络链路／边界上（如出口、服务器群前）报文内容与协议、会话状态、攻击特征，可在线阻断
🔑 与"入侵检测系统 IDS"的关系（常作判断题）：IDS 只监视告警、不阻断，多采用旁路镜像抓取信息流；IPS 在其基础上串接部署、能主动反制（阻断）。本章的"检测机制／异常检测"原理两者通用，差别在是否 inline 阻断。

二、两类入侵防御系统的工作过程（领会）⭐⭐

领会 网络入侵防御系统的工作过程、主机入侵防御系统的工作过程。
网络入侵防御系统的工作过程（五步）：
① 捕获信息→② 检测异常信息→③ 反制异常信息→④ 报警→⑤ 登记和分析
  1. 捕获信息：探测器通过集线器／交换机端口镜像／虚拟策略路由等方式取得流经该链路的信息流（报文）；
  2. 检测异常信息：用攻击特征检测、协议译码、异常检测三类机制判定报文是否属于攻击或异常；
  3. 反制异常信息：确认攻击后在线阻断／丢弃报文、切断会话、重置连接，必要时联动 ACL 封禁来源；
  4. 报警：向管理员与安全管理器发出告警（可含级别、攻击类型、源／目的）；
  5. 登记和分析：记录日志、归类统计、形成网络安全状态报告，用于审计、取证与策略优化。
主机入侵防御系统的工作过程（五步）：
① 拦截主机资源访问操作请求和网络信息流→② 采集相应数据→③ 确定操作请求或网络信息流的合法性→④ 反制动作→⑤ 登记和分析
🔑 两条流程的差异点（比较题的答案）：NIPS 的输入是"链路上的信息流"，动作是"捕获 → 检测异常 → 反制异常"；HIPS 的输入多了一类"主机资源的访问操作请求"，所以先拦截、再采集与操作相关的参数、然后判定"合法性"（依据访问控制策略），最后反制与登记。共同点是都以"反制—报警／登记—分析"收尾，形成闭环。

三、网络入侵防御系统的结构（识记）⭐

识记 网络入侵防御系统的结构。
包括：服务器、探测器、安全管理器、管理端口、交换机、集线器。
结构题的三个得分点：①六件套名称；②探测器是核心；③管理网与业务网物理／逻辑分离（两个独立网络）
各部件职责（教材原文口径）：
部件职责
探测器（核心设备）负责信息流捕获、分析、异常检测、反制动作执行及报警和登记等操作，通过管理端（管理端口）和安全管理器相连
安全管理器负责探测器安全策略的配置、报警信息的处理、登记信息的分析与归类，最终形成有关网络安全状态的报告并提供给网络安全管理员
服务器存放策略、日志与规则库等数据并承载管理控制台
交换机／集线器提供管理网互联与信息流的汇聚／镜像（集线器是天然的捕获点，交换机需配端口镜像）
管理端口探测器与管理网之间的专用管理接口，避免用业务口下发策略
⚠️ 判断题高频："为了安全起见，互联探测器和安全管理器的网络与信息传输网络是两个独立的网络。"——正确，且要能说明理由：防止攻击者借业务流量伪造管理指令／篡改策略，也避免管理流量被窃听。

四、入侵检测机制的分类、信息捕获与检测原理（领会）⭐⭐

领会 入侵检测机制的分类、信息捕获机制、各种入侵检测方法的原理。
目前入侵检测机制主要可以分为 3 类：攻击特征检测、协议译码和异常检测。
机制原理（教材口径）优点局限
① 攻击特征检测
（误用检测）		与杀毒软件检测病毒的机制相同：从已发现的攻击中提取出能够标识这一攻击的特征信息，构成攻击特征库，然后在捕获到的信息中进行攻击特征匹配；若匹配到某个攻击特征，则说明捕获到的信息就是攻击信息准确率高、误报少，能直接指出攻击类型只能发现已知攻击，对新型／变形攻击无效，需持续更新特征库
② 协议译码对IP 分组格式、TCP 报文格式进行检测，并根据TCP 报文的目的端口字段值或IP 报文的协议字段值确定报文净荷对应的应用层协议，然后按协议要求对净荷格式、净荷中各字段内容及请求和响应过程进行检测；若发现和协议要求不一致，则表明该信息可能是攻击信息能抓住畸形报文与协议滥用（如溢出、非法字段），不依赖攻击样本需逐协议实现解析，开销大；对符合协议但语义恶意的流量有限
③ 异常检测建立正常网络访问下的信息流模式或正常网络访问规则，然后实时分析捕获到的信息所反映的信息流模式或对网络资源的操作，把分析结果与已建立的信息流模式库或操作规则库相比；若发现较大偏差，则说明发现异常信息能发现未知攻击与内部违规（不依赖特征库）误报率高、依赖"正常"基线质量，需长期训练与维护
信息（流）捕获机制：捕获信息流机制主要讨论探测器工作在探测模式时的信息流捕获方式，有三种：① 集线器；② 交换机端口镜像；③ 虚拟策略路由。
捕获方式怎么做特点
集线器利用集线器共享介质、向所有端口广播的特性，让探测口收到同一冲突域的全部流量最简单、成本低；带宽减半、易拥塞，交换网络中不可用
交换机端口镜像在交换机上配置 SPAN／镜像端口，把源端口的报文复制一份送到探测器所接端口不影响原有通信、可精确选择监测端口／VLAN；需要交换机支持与管理
虚拟策略路由用策略路由／分光等方式把指定流量引导（复制）到探测器再转发灵活可按地址、协议、服务选择性送检，适合大型网络分段监测
🔑 记忆组合："三类检测（特征、译码、异常）+ 三种捕获（集线器、镜像、策略路由）"。问"IPS 用什么方法发现攻击"就答这三类机制并各带一句原理。

五、基于统计机制与规则机制的异常检测实施（简单应用）⭐

简单应用 基于统计机制和基于规则机制的异常检测实施、网络入侵防御系统的安全策略制定。
① 基于统计机制的异常检测（教材做法）：网络入侵防御系统在确保网络处于正常访问状态下时，对捕获到的信息进行登记；对于流经网络入侵防御系统的每个 IP 分组，主要登记：源和目的 IP 地址、源和目的端口号、IP 首部协议字段值、TCP 首部控制标志、报文字节数、捕获时间等。
  1. 建立基线：在正常状态下大量登记上述字段，统计出正常的信息流模式（如各服务的连接数、字节量、时段分布、协议比例）；
  2. 实时测量：继续按同样口径登记当前流量，得到实时统计量；
  3. 偏差比较：把实时值与基线比较，偏差超过设定门限即判为异常（如某端口 SYN 数量骤增 → 疑似扫描／DoS，某主机短时向外发起大量连接 → 疑似蠕虫）；
  4. 反制与学习：触发报警、阻断或限速等反制，并把结果登记分析以修正基线与门限，降低误报。
② 基于规则机制的异常检测（教材做法）：通过分析正常网络访问状态下登记的信息和用户，总结出限制特定用户操作的规则，运行时把每次操作与规则比对，违反规则即视为异常。
规则要素示例
操作发起者（用户／主机）"用户 U 属于财务部"、"主机 A 为 Web 服务器"
操作类型读／写／执行／连接／发送、协议与服务（HTTP、FTP、SMTP）
操作对象目标 IP、目录／表、端口范围、外部站点
条件与限制时段（"仅工作日 9—18 时"）、频次（"每分钟连接数 ≤ 60"）、字节量、来源地；违反即报警／阻断
③ 网络入侵防御系统的安全策略制定（教材给出的落点）：网络入侵防御系统用于防御对 Web 和 FTP 服务器的攻击，采用的入侵检测机制包含攻击特征匹配、协议译码和异常检测（三者组合使用）。
💡 应用题模板（"为某网站设计 IPS 安全策略"）：①部署位置——串接在服务器群入口／出口，管理网独立；②检测组合——特征匹配拦已知攻击（SQL 注入、跨站脚本、FTP 溢出）、协议译码查畸形报文与非法字段、异常检测（统计＋规则）抓未知攻击与异常流量；③反制分级——高危阻断、可疑告警＋限速，并设置旁路（fail-open）与白名单避免误杀业务；④运维闭环——定期更新特征库、重训基线、审阅报告、按最小特权放行必要服务，并与防火墙／病毒防范／日志审计联动。

六、主机入侵防御系统：保护对象、截获机制与访问控制策略 ⭐

识记 主机入侵防御系统的保护对象——主机资源；领会 截获机制的实现；简单应用 访问控制安全策略制定。
保护对象（识记）：主机资源既是攻击目标，也是主机防御系统的保护对象，主要包含网络、内存、进程、文件和系统配置信息（五类）。
截获机制的实现（领会，三步走）：
  1. 前提：实现主机入侵防御系统功能的前提是能够捕获对主机资源的操作请求，收集和操作相关的参数；
  2. 捕获哪些操作：包括对文件系统的访问、对类似注册表的系统资源的访问、TCP 连接建立及其他 I/O 操作等；相关参数有操作对象、操作发起者、操作发起者状态等；
  3. 三种捕获（截获）机制：目前用于捕获操作请求的机制有① 修改操作系统内核；② 系统调用拦截；③ 网络信息流监测。
截获机制做法特点
修改操作系统内核在内核中插入检查点／钩子，所有资源操作都经 IPS 模块判定后再执行最彻底、最难被绕过；开发与兼容风险高（可能与系统更新冲突）
系统调用拦截在用户程序与内核之间的系统调用层拦截并审查调用参数（打开文件、创建进程、连接网络）覆盖面广、实现相对可控；可被特殊手段绕过或被高频调用拖慢性能
网络信息流监测监测本机网卡收发的信息流（如抓包／驱动层过滤），判断进出连接是否可疑能发现达到该主机的攻击与外传行为；但看不到本机内部操作
访问控制安全策略制定（简单应用，教材原句）：访问控制策略根据操作请求的发起者、操作类型、操作对象及用户和系统状态确定操作是否进行。通常情况下，先制定不同安全等级的安全策略，然后将安全策略和用户系统状态绑定在一起构成访问控制策略。
🔑 拆成四要素＋两步更好背：四要素＝发起者 / 操作类型 / 操作对象 / 用户与系统状态；两步＝① 按安全等级定策略 → ② 策略与"用户＋系统状态"绑定成访问控制策略。举例："进程 P（发起者）在系统处于运行态（状态）时欲写（类型）机密级配置文件（对象）"→ 命中"禁止低级进程写高级客体"的策略 → 拒绝并登记。
⚠️ 常见辨析：HIPS 保护的是"主机资源五类"，NIPS 看的是"链路信息流"；问"主机 IPS 能防住什么而网络 IPS 防不住"→ 本机内的文件访问、注册表改动、进程创建、非法提权与内部违规操作（这些不经过网络链路）。

七、本章速记小结

  1. 入侵＝破坏可用性、保密性、完整性的行为；三大手段：恶意代码、非法访问、拒绝服务攻击。
  2. 两大分类：主机 IPS（检测达到主机的信息流＋监测对主机资源的访问操作）、网络 IPS（检测流经某段链路的信息流）。
  3. NIPS 五步：捕获信息 → 检测异常 → 反制异常 → 报警 → 登记和分析。
  4. HIPS 五步：拦截（访问请求＋信息流）→ 采集数据 → 判定合法性 → 反制动作 → 登记和分析。
  5. NIPS 结构六件：服务器、探测器（核心）、安全管理器、管理端口、交换机、集线器；管理网与信息传输网是两个独立网络。
  6. 三类检测机制：攻击特征检测（＝杀病毒机制、只知已知）、协议译码（格式与字段、请求响应一致性）、异常检测（模式／规则库比对，偏差大即异常）；三种捕获：集线器、交换机端口镜像、虚拟策略路由。
  7. 统计机制登记六项：源／目的 IP、源／目的端口、IP 首部协议字段、TCP 首部控制标志、报文字节数、捕获时间；规则机制＝从正常态总结限制特定用户操作的规则；防御 Web／FTP 服务器攻击要三种机制并用。
  8. 主机资源五类（网络·内存·进程·文件·系统配置信息）＋截获三机制（改内核、系统调用拦截、网络信息流监测）＋策略四要素两步走。
🎯 6 学时分配：概述与两类流程 2 学时（两条五步必须一字不差）→ NIPS 结构与三类检测机制 2 学时 → 统计／规则异常检测 1 学时 → 主机 IPS 与访问控制策略 1 学时。本章整章考、无跳过节，重点押"简答＋流程排序＋机制归类"。
