一、计算机病毒：定义与特点 ⭐

识记 计算机病毒的特点。
计算机病毒定义（法规原文，名词解释按此写）：编制或者在计算机程序中插入的破坏计算机功能或者毁坏数据，影响计算机使用，并能自我复制的一组计算机指令或者程序代码。
七大特点（简答必背，答"最基本/最本质"要挑对）：
特点含义备注
传染性能像生物病毒一样把自身复制传播到其他程序、磁盘或主机病毒最基本、最本质的特征，是判断"是不是病毒"的首要依据
非授权性进入用户计算机不需用户授权，靠寄生在正常程序中非法取得运行控制权（不独立执行，随宿主被调起）解释"双击正常文件为什么也中毒"；宏病毒寄生在文档模板的宏里
隐蔽性附着在正常程序或数据中，不易被发现；有的还伪装成系统文件潜伏后常规操作看不出异常
潜伏性侵入后不一定立刻发作，可长期等待触发条件触发条件如日期、次数、特定操作
破坏性占用资源、干扰运行、删改文件、破坏引导区乃至硬件危害程度的最终体现
不可预见性病毒种类繁多、代码风格各异，何时发作、造成什么后果难以预料所以防范必须主动预防，不能等出了事再处理
可触发性长期潜伏，满足预设条件才激活：日期时间（如"黑色星期五"）、运行次数、特定操作、字符计数触发条件就是"发作开关"；另有教材补充针对性／衍生性（可变异生变种，故特征码法会漏检）
📖 教材原列·七大特征（按此顺序背，"传非隐潜破预触"）：①传染性；②非授权性；③隐蔽性；④潜伏性；⑤破坏性；⑥不可预见性；⑦可触发性。上表即按这七项排列。
🔑 选择题常挖的坑：传染性≠破坏性——传染性是病毒的最基本特征；"能自我复制"是定义里的关键词，看到"仅破坏但不复制"（如逻辑炸弹）要能分辨它属于恶意代码而不是严格意义的病毒。

二、病毒的分类（识记）⭐

识记 计算机病毒的分类。
分类依据类别要点与典型
按存在的部位（寄生方式）引导型、文件型、混合型、宏病毒引导型感染引导扇区/主引导记录 MBR（如米开朗基罗）；文件型感染可执行文件（.exe/.com）；混合型两者都染；宏病毒寄生在文档/模板的宏中（Word/Excel 宏病毒，跨平台）
按连接（感染）方式覆盖型、前附型、后附型、起源型（主病毒）、嵌入式覆盖型破坏原程序（不可恢复）；前/后附型把病毒码接在程序头尾，原程序仍可运行故更隐蔽
按破坏程度良性（无害型）、恶性（危险型）良性主要消耗资源、显示奇怪信息；恶性删改文件、破坏分区表甚至 BIOS
按是否变形静态型、多态型、变形（metamorphic）型、加密型多态/变形病毒每次感染改变自身代码特征，专门规避特征码扫描 ⇒ 需要行为监测与启发式
按传播媒介单机（磁盘/U 盘）病毒、网络病毒（蠕虫）、移动设备病毒网络型不需用户操作即可自动扫描传播，扩散速度最快
按操作系统/平台DOS 病毒、Windows 病毒、Linux/Unix 病毒、手机与智能终端病毒了解，用于答"针对特定平台"
📖 教材原列·五种分类依据（简答/多选按这五条写）：①依据病毒寄生的媒介——网络病毒、文件病毒、引导型病毒；②依据其破坏性——良性病毒、恶性病毒；③按其传染途径——驻留内存型病毒、非驻留内存型病毒；④按其不同算法——伴随型病毒、"蠕虫"型病毒、寄生型病毒；⑤按传染对象不同——引导区型病毒、文件型病毒、混合型病毒、宏病毒。
⚠️ 第①条与第⑤条别混：教材把"网络"归入寄生媒介，把"引导区型／文件型／混合型／宏病毒"归入传染对象；下面这张六角度表是便于理解的展开版，答题以上面五条依据为准。
🔑 记忆主线："部位—连接—破坏—变形—媒介—平台"六个角度。考试问"按存在部位分"就答引导型/文件型/混合型/宏病毒四类，别把"网络病毒"混进去（那是按媒介分的）。

三、恶意代码五种类型与对比 ⭐⭐

识记 常见恶意代码的类型；领会 不同类型恶意代码的共同特征和各自特点。
恶意代码（Malicious Code）：无须利用系统弱点、以破坏系统或数据为目的而编写的、不期望使用的程序或代码的总称。常见五类：病毒、蠕虫、木马、后门、逻辑炸弹（有的教材另列间谍软件、广告软件、键盘记录器等）。
共同特征（领会，简答要点）：①都是人为编制的程序或代码片段；②都具有非授权执行/隐蔽潜伏的特点——在用户不知情时运行；③都以干扰、破坏、窃取或控制为后果；④都能借助系统漏洞、合法程序或社会工程学进入并驻留；⑤具有可触发性与一定传染性或传播能力。
类型核心特点是否需宿主 / 是否自我复制典型危害
病毒 Virus传染性；必须寄生在宿主程序或引导区，随宿主被执行而激活需宿主 ／ 复制自身到宿主破坏文件与引导区、占用资源
蠕虫 Worm独立程序，靠扫描漏洞＋自动传播，通过网络指数级扩散；关键字"扫描、攻击、传播"不需宿主 ／ 复制自身为独立进程耗尽带宽与系统资源导致瘫痪（如冲击波、震荡波、 Morris 蠕虫）
木马 Trojan伪装成有用程序诱骗用户运行；关键字"欺骗、隐藏、窃取信息"；不自我复制不需宿主 ／ 一般不复制开后门、远程控制屏幕与文件、偷口令与键盘记录
后门 Backdoor绕过安全控制让远程方再次进入系统的通道；关键字"潜伏"；常由木马或攻击者植入不需宿主 ／ 不复制长期潜伏、随时可被再次控制；替换系统服务程序是经典手法
逻辑炸弹植入正常程序中，满足特定条件（时间、离职、计数）才发作；不传染依附程序 ／ 不复制定时删库、毁数据，多与内部人员报复相关
（补充）间谍软件 / 键录 / 广告软件秘密收集与回传用户行为、口令—隐私与账号泄露
三者最直观的区别：病毒靠宿主＋人执行、蠕虫自己扫自己传、木马靠欺骗且不开新副本

四、木马类与蠕虫类的检测与防范（简单应用）⭐

简单应用 木马类和蠕虫类病毒的检测方法，制定防范方法和措施。
（一）木马的检测方法（五个抓手）
  1. 看进程与任务：任务管理器/进程列表中找陌生、伪装名（如 svch0st.exe）、CPU 或网络占用异常的进程。
  2. 查端口与连接：netstat -ano（Windows）/ ss -tnp（Linux）看异常监听端口与外连地址，用 tasklist /svc 反查 PID 对应程序——木马必开一个"后门端口"。
  3. 查自启动项与注册表：msconfig／任务计划／启动文件夹；注册表 Run 键、AppInit_DLLs、服务列表中被新增的陌生服务。
  4. 文件与系统完整性检查：比对系统文件数字签名与大小、检查 hosts、LSP、驱动、DLL 注入；用反恶意软件工具做全盘特征码＋行为扫描。
  5. 专用工具：木马专杀工具、进程资源管理器（Process Explorer）、端口查看工具、日志与流量分析（发现周期性回连 C&C 服务器）。
📖 教材原列·木马类程序的检测与清除（六项，按编号答）：①查看开放端口；②查看和恢复 win.ini 和 System.ini 系统配置文件；③查看启动程序并删除可疑的启动程序；④查看系统进程并停止可疑的系统进程；⑤查看和还原注册表；⑥使用杀毒软件和木马查杀工具检测和清除木马。
教材原列·木马预防方法和措施（七条）：①不随意打开来历不明的电子邮件，阻塞可疑邮件；②不随意下载来历不明的软件；③及时修补漏洞和关闭可疑的端口；④尽量少用共享文件夹；⑤运行实时监控程序；⑥经常升级系统和更新病毒库；⑦限制使用不必要的具有传输能力的文件。
⚠️ 上面"五个抓手"与 netstat -ano／msconfig 是现代实操版，可作为⑥的举例补充；简答优先写教材六项／七条的编号条目。
木马的防范措施：不从不可信来源下载并运行程序、警惕"双击即运行"的附件；先断网再查杀以免继续外传信息；关闭不必要的共享与远程服务、把默认远程端口改掉；开启防火墙禁止陌生程序对外连接；及时打系统与浏览器补丁；口令强策略并定期更换；使用最小权限账号办公，不用管理员账号上网。
（二）蠕虫的检测方法
  1. 网络流量异常：出口带宽被占满、出现大量对同一端口的扫描连接（如 135/139/445/1433/3389）、内网主机间 ARP/连接风暴。
  2. 主机资源异常：CPU/内存长期高占用、生成大量随机命名文件、不断自我复制使文件数激增、系统变慢或反复重启。
  3. 日志与告警：防火墙/IDS 的扫描与溢出告警、服务器安全日志中的异常登录与漏洞利用记录。
  4. 补丁与漏洞核查：对照已知蠕虫利用的漏洞（如 MS08-067、"永恒之蓝"MS17-010）扫描本机是否未打补丁——未打补丁＋异常外联基本可判定。
  5. 样本确认：在隔离环境/沙箱中运行可疑程序观察其复制与外连行为，比对病毒库特征码。
蠕虫的防范措施（"堵传播路径"是关键）：①及时更新补丁并开启自动更新，先补高危漏洞；②关闭不必要服务与端口、禁用未用的网络共享，边界防火墙阻断异常扫描流量；③部署网络层 IDS/IPS ＋ 全网防病毒（联动），及时升级病毒库；④网络分段与 VLAN 隔离、限制广播域，防止一台染毒全网扩散；⑤关闭自动运行、限制脚本执行（禁用不必要的 ActiveX/宏）、口令策略防弱口令爆破；⑥制定应急预案：断网隔离 → 清杀 → 重装/恢复 → 全网排查 → 通报。

五、典型病毒的检测与清除（综合应用）⭐

综合应用 U 盘、手机等移动设备的病毒防范、检测和清除方法。
（一）常见系统自检方法（识记/领会，检测手段清单）：在干净系统（无病毒环境）下记录基准数据，再与可疑状态比对—— ①中断向量检查（病毒常改写 INT 向量）；②比较检验法（与备份的正常程序逐字节比较）；③CRC 校验／数字签名校验（校验码变化说明被改动）；④特征码（特征字）检查；⑤内存比较与常驻内存检查；⑥引导区比较；⑦日期、长度、簇变化观察（文件莫名变长、修改日期改变）。
杀毒软件工作原理（简答）：特征码扫描法（病毒库比对，最快最常用，但对新病毒与多态病毒失效）→ 行为监测法（监控改写引导区、驻留内存、注入进程、修改共享文件等可疑动作，可发现未知病毒）→ 启发式／代码模拟执行（虚拟机）（静态分析代码结构、在沙箱中模拟运行判断）→ 完整性检查（校验和）与云查杀／信誉库。安装后应常驻内存实时监控、定期全盘扫描、开机自动升级病毒库。
（二）U 盘病毒（Autorun 类）的检测与清除
典型手法：在可移动盘根目录写入隐藏的 autorun.inf ＋ 病毒正文（常伪装成 RECYCLER、svchost.exe 等），利用系统自动播放机制在插入时运行，并把病毒复制到本机、再感染其他盘、修改注册表自启动。
; 可疑的 autorun.inf —— 见到 open/shell 指向可疑 exe 就要处理
[autorun]
open=RECYCLER\svchost.exe      ; 自动运行的程序（病毒本体）
shell=auto          action=打开(&O)
hidefoldericon      ; 隐藏真实文件图标，诱导双击病毒文件
  1. 先关闭自动播放（组策略"关闭自动播放"，或插入时按住 Shift；Windows 10/11 用"一次性自动播放"设置），避免插入即中毒。
  2. 以地址栏/资源管理器方式打开盘符，勾选"显示隐藏文件和文件夹"、取消"隐藏受保护的操作系统文件"，露出 autorun.inf 与伪装文件。
  3. 结束病毒进程并删自启动项：任务管理器结束可疑进程，清理注册表 Run 键与相关服务，删除 %windir% 下复制体。
  4. 删除病毒文件与 autorun.inf（先去掉只读/隐藏属性：attrib -r -h -s /s /d），清空回收站与临时目录。
  5. 用最新病毒库全盘查杀＋扫描其他已插入过的电脑；对重要 U 盘建立写保护或用专用工具免疫（把 autorun.inf 做成只读目录）。
  6. 无法清除时格式化：先备份数据（备份前查毒、不备份可执行文件），再格式化重建。
📖 教材原列·U 盘（移动存储设备）病毒的清除（原文口径，照此写最稳）：打开文件夹选项→在"查看"中取消勾选"隐藏受保护的操作系统文件"、勾选"显示所有文件和文件夹"→单击"确定"→此时在移动存储设备中会看到 autorun.inf、msvcr71.dll、RavMonE.exe 三个文件，全部删除即可；还有一个扩展名为 .tmp 的文件，也可以删除，完成后病毒就清除了。
⚠️ msvcr71.dll、RavMonE.exe（仿冒杀毒软件进程）与 .tmp 是教材点名的具体文件名，答题写出这几个名字最容易拿分；上面六步流程是同一操作的展开版。
（三）手机等移动设备病毒（综合应用答题模板）： 防范——只从官方应用商店下载、拒绝来历不明的 APK/越狱Root、关闭"允许安装未知来源应用"、不点短信/二维码链接、开启锁屏密码与指纹/人脸、关闭不用时的蓝牙/Wi‑Fi/USB 调试、设应用权限最小化、装正规移动安全软件并及时更新系统补丁、重要数据定期备份到可信位置。 检测——看异常现象（话费/流量异常飙升、频繁自动发短信、电量与发热异常、通讯录与短信被改写、弹出广告、应用自行安装）、检查已安装应用列表中的陌生/图标空白/同名伪装应用、检查设备管理器中的陌生蓝牙配对与可疑配置文件（描述文件）、用安全软件做全盘扫描、核对扣费短信与权限访问记录。 清除——教材三步：①安装一款安全软件（如手机管家等）；②打开主界面上的"一键体检"按钮自动检测问题并给出处理建议，再单击"一键清除"删除病毒程序；③若重启后病毒依然存在或提示无法删除，则先获取 ROOT 权限（可用 PC 端一键 ROOT 工具）再进行深度查杀，或改用专门的病毒专杀工具一键查杀。通用处置：断网（飞行模式）＋关机重启进入安全模式，卸载可疑应用与其残留数据，清除可疑设备管理器/管理员权限与描述文件，修改所有重要账号口令（因为短信/密码可能已泄露），必要时查杀或恢复出厂设置（前提是已备份干净数据），最后升级系统与补丁再恢复使用。

六、病毒现象与软硬件故障的判别 ⭐ 难点

简单应用 根据异常现象或运行错误提示，判断是病毒还是软、硬件故障。
观察角度更像病毒更像硬件故障更像软件故障/设置问题
出现方式渐进且会扩散：一台变多台、一个盘变多个盘，且现象可复制到其他机器与特定设备/插槽/线缆绑定，换设备即消失；常伴随异响、报警声、冒烟与特定程序、特定操作或某次更新同步出现，重装/回滚即消失
文件与磁盘文件长度莫名增加、日期被改、出现隐藏/随机名文件、Autorun.inf、引导区报错，但磁盘物理检测正常坏道、读写错误、盘体异响、chkdsk 报物理错误、容量识别异常路径/权限/编码设置错、程序写文件失败、文件被占用
系统资源空闲时 CPU/网络也高、内存持续下降、有陌生进程与异常外连端口、自启动项被加内存条接触不良致蓝屏、过热降频、电源不稳重启、网卡故障丢包程序内存泄漏、服务冲突、驱动版本不匹配、开机加载项过多
网络表现大量对内/对外扫描包、被拉入僵尸网络、账号异地登录、邮件自动外发线路衰减、交换机端口故障、网卡/驱动掉线配置错误（IP/DNS/代理）、防火墙规则、带宽被正常应用占满
查杀验证（决定性）干净环境（PE/杀毒启动盘）下扫描能查出病毒，清除后现象消失杀毒无果、替换硬件/重新插拔后现象消失杀毒无果，重装/回滚软件或改配置后消失
判别四步法（答题顺序）：①问范围——现象是否跨机器扩散（扩散 ⇒ 偏病毒）；②看痕迹——是否有新增进程/端口/自启动/隐藏文件；③查基线——用干净启动盘引导后做校验（文件长度、引导区、CRC、内存）比对；④验证处置——查杀后是否消失，未消失再按硬件替换法、软件回滚法逐项排除。
📖 教材原列·计算机病毒现象（10 项，问"哪些异常现象说明可能感染病毒"逐条答）：①屏幕显示异常，显示出不是由正常程序产生的画面或字符串、屏幕显示混乱；②程序装入时间增长，文件运行速度下降；③用户没有访问的设备出现工作信号；④磁盘出现莫名其妙的文件和坏块，卷标发生变化；⑤系统自行引导；⑥丢失数据或程序，文件字节数发生变化；⑦内存空间、磁盘空间减小；⑧异常死机；⑨磁盘访问时间比平时增长；⑩系统引导时间增长。
📖 教材原列·与病毒现象类似的硬件故障（5 项）：①系统的硬件配置；②电源电压不稳定；③插件接触不良；④软驱故障；⑤关于 CMOS 的问题。
📖 教材原列·与病毒现象类似的软件故障（4 项）：①出现 "Invalid drive specification"（非法驱动器号）；②软件程序已被破坏（非病毒）；③引导过程故障；④用不同的编辑软件程序。
⚠️ 判别题的答法：先引用上面三组清单中的具体现象定性（如"文件字节数变化＋磁盘出现莫名文件"→ 偏病毒；"电源电压不稳定／插拔后恢复"→ 硬件；"提示非法驱动器号且换干净盘启动即恢复"→ 软件），再给验证手段。
🔑 关键判据一句话：病毒现象会"传染"，故障现象只"复现"。若同一台机器换个干净系统盘启动后一切正常、但原盘里有自启动的可疑程序 → 病毒；若换系统也一样报错 → 硬件。

七、本章速记小结

六条一句话：
  1. 定义关键词：插入、破坏功能或数据、影响使用、自我复制的指令或代码。
  2. 特点之最：教材七特征"传非隐潜破预触"，其中传染性是最基本特征。
  3. 分类五依据：寄生媒介／破坏性／传染途径／不同算法／传染对象。
  4. 恶意代码五类：病毒、蠕虫、木马、后门、逻辑炸弹——蠕虫自己传、木马靠骗、后门留通道、炸弹不传染。
  5. 检测三板斧：进程与端口（netstat）→ 自启动与注册表 → 特征码＋行为＋启发式扫描。
  6. 判别看扩散：会传染的是病毒，只复现的是故障；干净启动盘校验是最终判据。
