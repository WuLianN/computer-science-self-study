第1题点击展开答案
网络虚拟空间的载体是指
A. 通信信息系统B. 网民C. 网络协议D. 计算机
答案：A
解析：网络空间信息安全包含两部分内容，网络虚拟空间是依托于通信信息系统这一载体存在的空间；网民是活动主体、计算机是终端设备、网络协议是通信规则，均非"载体"。故选 A。
考点：概念与两部分内容
第2题点击展开答案
在恶意代码中,能够嵌入计算机程序,通过一定触发条件破坏计算机的程序是
A. 病毒B. 木马C. 逻辑炸弹D. 后门
答案：C
解析：逻辑炸弹是预先嵌入程序中的一段代码，在满足特定触发条件（如某日期、某次运行）时才执行破坏动作。病毒需依附宿主并复制、木马靠欺骗诱骗运行、后门是绕过认证的隐蔽入口，都不以"触发条件"为核心特征。故选 C。
考点：恶意代码五种类型

在IPSec的ESP协议中,ESP头包含安全参数索引及

在无线网络的安全级别中,设置严格的用户口令及验证措施,防止非法用户入侵,属于

第18题点击展开答案
RSA的安全性主要基于的数学知识是
A. 因子分解B. 格密码C. 离散对数D. 子群判定
答案：A
解析：RSA 的安全性建立在大整数素因子分解的困难性上（已知公钥 (e,n) 难分解出 p、q 从而求出 d）。离散对数是 ElGamal/DSA 的难题基础，格密码、子群判定属其他体制。故选 A。
考点：非对称密码体系与 RSA

考点：访问控制概念与安全评估级别

参考答案

第23题点击展开答案
对称密码体系
参考答案
要点：对称密码体系（又称私钥密码体制、传统密码体制）指加密密钥与解密密钥相同（或由其中之一可轻易推出另一者），加解密使用同一秘密密钥的一类密码体制。其安全性依赖密钥的保密，典型算法有 DES、AES、IDEA 等。
考点：对称与非对称密码体制
第24题点击展开答案
数字证书
参考答案
要点：数字证书是由权威机构（CA，证书认证中心）签发、用CA 的私钥数字签名的一份电子文件，用以绑定公钥与其持有者身份。它证明公开密钥确实属于证书中所命名的主体，是 PKI 中验证身份、建立信任的基础凭据（一般含版本号、主体、公钥、颁发者、有效期、序列号、签名算法等）。
考点：数字证书与 PKI
第25题点击展开答案
包过滤型防火墙
参考答案
要点：包过滤型防火墙工作在网络层（与传输层），依据预先设定的访问控制规则，逐个检查通过数据报文的源/目的 IP 地址、源/目的端口、协议类型等头部信息，符合规则则放行、否则丢弃。它不检查应用层内容、不维护连接状态，实现简单、透明度高、速度快，但难以防范地址欺骗与应用层攻击。
考点：防火墙的定义与分类

第28题点击展开答案
简述密码技术的定义及使用密码技术的目的。
参考答案
要点： 定义：密码技术是通过对信息进行编码变换（加密）与破解/还原（解密），并配合密钥管理，以保障信息在存储与传输中安全的专门技术，是信息安全的核心技术。
目的（安全密码体制应达到的四个功能/目标）：
  1. 秘密性（保密性）——信息不泄露给未授权者；
  2. 鉴别性（身份认证）——确认通信双方的真实身份；
  3. 完整性——数据未被非法篡改、插入或删除；
  4. 不可否认性（抗抵赖）——发送/接收方事后不能否认其行为。
考点：安全密码体制的功能

第31题点击展开答案
简述入侵检测机制的分类,并对各种类型简要描述。
参考答案
要点（三类检测机制）：
  1. 攻击特征检测（误用检测/模式匹配）——把捕获的数据与已知攻击特征库比对，命中即报警。准确率高、误报少，但只能发现已知攻击、无法检测新型攻击。
  2. 协议译码（协议分析）——对网络流量按协议逐层解析还原，检查是否违反协议规范或存在非法报文，用以发现利用协议漏洞的攻击。
  3. 异常检测——先建立系统/用户正常行为的统计模型（基线），当观测行为明显偏离正常模型即判为异常报警。可发现未知攻击，但误报率高、依赖训练数据。
考点：入侵检测机制的分类

四、案例分析题（1 小题，共 15 分）

第32题点击展开答案
某公司为了提升企业形象,专门建立了一个宣传企业的网站,并聘请了专门的维护工程师进行日常管理维护,为了提升安全,请问:(1)在服务端怎样防范黑客的攻击及数据篡改?(5分)(2)在网站维护终端怎样防范黑客的攻击及数据篡改?(5分)(3)在服务端怎样防范病毒和木马?(2分)(4)在网站维护终端怎样防范病毒和木马?(3分)
参考答案
(1) 服务端防范黑客攻击及数据篡改（要点）：
  1. 及时打补丁、关闭不必要服务与端口，删除默认账号与示例页面，最小化安装；
  2. 部署防火墙/WAF，对输入做白名单校验与参数化查询防 SQL 注入、输出转义防 XSS；
  3. 启用身份认证与会话管理、按最小权限授权、管理后台限 IP 访问；
  4. 全站 HTTPS（SSL/TLS）加密传输；
  5. 部署网页防篡改系统、开启日志审计与入侵检测；
  6. 定期数据与页面备份并演练恢复。
(2) 网站维护终端防范黑客攻击及数据篡改（要点）：
  1. 终端系统补丁与病毒库及时更新，只开放必要软件与服务；
  2. 设置强口令与多因素认证、账户锁定策略，不用管理员账号上网；
  3. 通过加密通道（SSH/VPN/堡垒机）远程维护，禁用明文 Telnet/FTP；
  4. 终端装个人防火墙与实时监控，不随意接入不可信网络；
  5. 最小权限使用、及时更新维护工具，敏感操作留痕审计；
  6. 不打开来历不明邮件/链接，防社会工程学与钓鱼。
(3) 服务端防范病毒和木马（要点）：
  1. 服务器上安装反病毒/反恶意软件并开启实时监控、定期全盘查杀、及时升级病毒库；
  2. 上传/共享文件先杀毒后处理，关闭不必要端口与服务、限制脚本执行，及时打补丁堵住可被蠕虫/木马利用的漏洞。
(4) 网站维护终端防范病毒和木马（要点）：
  1. 安装并实时更新防病毒与木马查杀工具，开启实时监控；
  2. 不随意下载、运行来历不明软件与邮件附件，禁止自动播放；
  3. 及时修补系统/浏览器漏洞、关闭可疑端口，少用共享文件夹；
  4. U 盘等移动介质先查毒再用；
  5. 定期备份并做系统完整性检查。
考点：服务器端安全防范 考点：网站维护终端防范措施

五、应用计算题（1 小题，共 20 分）

第33题点击展开答案
某公司服务器系统使用RSA算法保障安全,假设已知公钥(n,e)=(77,13),p=7,计算q和私钥。
参考答案
解题过程： 
已知 n = 77, e = 13, p = 7。
① 求 q：      n = p × q  →  q = n / p = 77 / 7 = 11
② 求 φ(n)：   φ(n) = (p−1)(q−1) = (7−1)(11−1) = 6 × 10 = 60
③ 求私钥 d：  d 满足  e·d ≡ 1 (mod φ(n))，即 13·d ≡ 1 (mod 60)
              试算：13 × 37 = 481 = 8 × 60 + 1  →  d = 37
④ 结论：      私钥 (d, n) = (37, 77)；公钥 (e, n) = (13, 77)
答：q = 11，欧拉函数 φ(n) = 60，私钥指数 d = 37，故私钥为 (d, n) = (37, 77)。
考点：RSA 计算（密钥生成）
