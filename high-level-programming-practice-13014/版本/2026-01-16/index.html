课程与考核规则

课程：13014《高级语言程序设计》，实践考核；需具备计算机编程基础，已学习对应理论课程。本站对应笔试资料代码为 13013。

形式与时长：计算机上机考核，在规定时间内完成题目，考核时间 120 分钟。

携带资料：原文写明考生可携带教材；未在此处明确其他资料及电子设备的携带规则。

软件环境：原文列出 Windows 7 及以上版本、Visual C++ 6.0。本页保留原文配置，报考前须核对当期是否沿用；不自行推定可用其他编译器替代考场环境。

教材：《高级语言程序设计》，郑岩，机械工业出版社，2017 年版。

成绩：满分 100 分，采用五级评分制：0–59 分不合格、60–69 分合格、70–79 分中等、80–89 分良好、90–100 分优秀。

简单应用：两个整数的公约数

题干前半部分要求编程求两个整数的最大公约数，从键盘输入整数后输出结果。

原文疑点：同一题前文写“最大公约数”，输出要求却写“最小公约数”。本页保留这一差异，不擅自改写学校原题。学习时可先练最大公约数算法；正式考核按现场题意或向监考人员确认。

综合应用：学生成绩处理

使用结构体保存学号、姓名和成绩，统计总分与最高分。按原文要求，应创建学生成绩信息结构体，并用函数分别完成输入、输出和统计，最后在主函数中调用、测试。

建议训练方式

  1. 先练输入输出、分支、循环，能够从空白文件写出可编译、可运行的完整程序。
  2. 将数组处理拆成函数，观察传值、指针和地址传递；可用Python Tutor 的 C 指针实验辅助理解。
  3. 按成绩处理样例练结构体与模块化，再单独补齐文件读写任务。
  4. 熟悉实际采用的编辑器、编译与保存流程；核对当期规则后再做 120 分钟限时模拟。

本节为本站学习建议。在线判题只能覆盖部分训练，完整上机操作仍须在本地完成。
