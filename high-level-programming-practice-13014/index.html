课程身份与考核概览

实践课程：13014《高级语言程序设计》；对应笔试课程 13013。两种考核分别记录通过状态。

来源院校：华南理工大学继续教育学院。其他院校的考生须另查本校要求。

2026-01-16 版内容：围绕三种程序结构、数组、函数与指针、结构体、文件操作训练，原文附两个应用题示例。

原文考核形式：上机考核，120 分钟，满分 100 分，按五级评分制评定，60 分起为合格。

原文软件环境：原文记录 Windows 7 及以上、Visual C++ 6.0；是否仍使用该环境，报考前另行核对。

原文携带资料：原文允许携带教材；其他资料及电子设备的携带要求须另查当期通知。

以上均为所收录版本的记录；日期、场次、软件与携带资料等执行要求，以当期学校通知和准考证要求为准。

先练什么

先复习循环与数组，再练函数和指针；把学生成绩统计拆成输入、输出、总分和最高分等函数，最后在本地完成结构体、文件与限时练习。

建议先看本版考核范围，再看原文题型示例；需要补概念时回到本站 C 语言 知识点。

本页的练习顺序是学习建议；大纲中的题型举例用于理解任务形式，不能当作当期原题或完整考试题库。

每次报考前核对什么

  1. 确认报考院校、实践代码 13014、对应笔试成绩要求及本期开考情况。
  2. 核对本期报名、缴费、考核与准考证打印日期，以及地点、证件和场次。
  3. 确认是否沿用本页大纲，重点检查软件版本、可携带资料、时长与评分规则。
  4. 对照本地已安装环境完成一次独立运行和文件保存；考场规则以当期要求为准。
