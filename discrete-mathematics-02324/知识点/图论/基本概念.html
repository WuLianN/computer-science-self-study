一、图、顶点、边

图 G = (V, E)

顶点（vertex）也叫点、结点；边（edge）连接两个顶点。顶点的集合记作 V，边的集合记作 E。上图：V={a,b,c,d}，E={ab,bc,cd,da}。
阶：顶点个数 |V|，常记作 n。上图 n=4。

二、无向图 vs 有向图

无向 / 有向

无向图：边没有方向，ab 与 ba 是同一条边（左图，普通线段）。
有向图：边有方向，称为弧，ab 表示从 a 到 b（右图，带箭头）。自考里欧拉 / 哈密顿默认讨论无向图，除非题目说明"有向"。
无向图：边不带箭头，ab 与 ba 是同一条边
有向图：边带箭头（弧），a→b ≠ b→a

三、度数（奇度 / 偶度）

度数 d(v)

顶点 v 的度数 = 与它相连的边数。橙点 c 连了 4 条边 → d(c)=4；a、b 各连 1 条 → d=1。
奇度：度数为奇数（如 1、3）；偶度：度数为偶数（如 2、4）。欧拉图判定只看奇度顶点个数，这是全章最关键的桥。

握手定理（总度数必为偶数）

任意无向图：所有顶点度数之和 = 2 × 边数，因此总度数一定是偶数。
直觉：每条边连着两个顶点，给这两点"各 +1 度"，所以每条边对总度数的贡献都是 2。
推论 1（奇度顶点定理）：奇度顶点的个数必为偶数（总度数偶，若奇数个奇度点会使总和变奇，矛盾）。
推论 2（判定门槛）：一个度数序列能构成无向图 ⇒ 度数和必为偶数（必要条件，不满足直接排除）。
两步法（判定度数序列能否成图）：
① 偶数和筛选：先算总和，奇数立刻排除（违反握手定理）；
② 构造验证：对和为偶数的候选，实际画出来验证是否真能连成（偶数和只是必要非充分，如 {3,3,3,1} 和=10 偶却构不成简单图）。
真题示例（2025.10 第14题）：下列度数序列能构成无向图的是？
A {1,1,3,4} 和=9、C {1,2,1,3} 和=7、D {1,1,1,2} 和=5 均为奇数 → 排除；仅 B {1,1,1,1} 和=4 偶数，且可构造两条独立边 (v₁v₂)、(v₃v₄) → 选 B。

四、简单图 / 多重图 / 带环图

先抓定义：简单图 = 无环 + 无平行边

简单图：既没有环（顶点连到自己），也没有平行边（两点之间至多一条边）。
简单图只规定“不许有环、不许有平行边”，不限边数——少连几条边仍是简单图，两两全连则是完全图 Kₙ。
非简单图：只要出现“环”或“平行边”其中之一就不简单。常见两类——多重图（有平行边）、带环图（有自环）。自考判定定理（如 Dirac）通常只对简单图成立。
✓ 简单图（三角形 K₃）
无环、无平行边，两两全连
✓ 仍是简单图（少一条边 a–c）
虚线=去掉的边，不违反定义
✗ 多重图（非简单图）
a–b 有 2 条平行边（一直一弯）
✗ 带环图（非简单图）
a 上有一个自环（边连回自己）
一张图分三类：① 简单图＝无环＋无平行边（可缺边）；② 多重图＝允许平行边；③ 带环图＝允许自环。后两者都属“非简单图”。

五、连通 / 连通分支

连通分支 ω(G)

连通：任意两点间都有路可走。右图被分成两块、互不相连，叫不连通。
连通分支数 ω(G) = 互相独立的不连通块数。右图 ω=2（{a,b,c} 与 {d,e} 各一块）。哈密顿"必要条件"里就用 ω(G−S) 这个量。

六、割点

割点

去掉某顶点（连同它的边）后，图的连通分支数变多，该点就是割点。橙点 c 一删，图裂成左右两块（ω 从 1 变 2）。
这正是欧拉图页里"例①无哈密顿回路"的证法：删割点 c，ω(G−{c})=2 > |{c}|=1，不满足必要条件。

七、子图

子图

从 G 中挑出一部分顶点和边得到的图叫子图。哈密顿"删 S 看 ω(G−S)"就是反复取子图来判定。
若子图含 G 的全部顶点，叫生成子图（如"生成树"）。本页不必深究，知道"挑一部分出来还是图"即可。

八、路径 / 通路 / 回路

三种"走法"

通路（walk）：顶点、边都可重复的走法（最宽松）；起点＝终点的通路称回路。
简单通路（trail，又叫"迹"）：边均不重复的通路；起终相同的称简单回路。
初级通路（path，即"路径"）：点均不重复的通路（除首尾可相同）；起终相同的称初级回路/圈。
两个特例：欧拉回路＝过所有边的简单回路（边不重复）；哈密顿回路＝过所有点的初级回路（点不重复）。
一句话记：欧拉管"边重复没"，哈密顿管"点重复没"。
简单通路（迹） a→b→c→d→e→c
边不重复，但点 c 走了两次（橙实心）→ 不是路径
简单回路 六条边各走一次回到起点
边不重复、闭口（欧拉回路就这种），c 重复→非初级回路
初级通路（路径） a→b→c→d→e
点、边都不重复（最严格）；比左图少最后一步 e→c
初级回路（圈） a→b→c→a
除首尾 a 外点不重复的闭走法

九、特殊图：完全图 Kₙ 与完全二部图 Kₘ,ₙ

完全图 Kₙ

完全图：n 个顶点的简单图，任意两个点都恰好连一条边（“两两全连”，一个都不落）。
边数 = C(n,2) = n(n−1)/2：每个点连其余 n−1 个点，共 n(n−1) 次“连线”，但每条边被两端各数一次（a–b 与 b–a 是同一条）→ 再 ÷2。
每个顶点的度数都 = n−1。常见：K₃=三角形(3边)、K₄=方块加两对角线(6边)、K₆=6×5/2=15 边。
完全图 K₄：4 点两两全连
边数 = 4×3/2 = 6，每点度 3
K₄ 删边成生成树：橙色留 3 条（n−1）
虚线是删掉的 3 条（=6−3）
完全二部图 K₃,₃：分两拨、同拨不连
跨拨全连，边数 = 3×3 = 9
完全二部图 Kₘ,ₙ：把点分成两组（m 个 + n 个），同组内互不连、跨组两点全连；边数 = m×n。K₃,₃（9 边）与 K₅（10 边）是“非平面图”的两个经典例子，平面图那节会用到。
“删边成树”通用公式：从 Kₙ 删边得到一棵含全部 n 点的生成树（树只有 n−1 条边），需删去 C(n,2) − (n−1) = (n−1)(n−2)/2 条。
真题（2026.4 第15题）：K₆ 边数 = 6×5/2 = 15，6 阶树边数 = 6−1 = 5 → 删去 15−5 = 10（选 B）。
真题（2026.4 第25题填空）：K₃,₃ 的边数 = 3×3 = 9（跨组全连、组内无边）——顺带它也是非平面图的经典例子（与上方 K₃,₃ 图对应）。

十、平面图与欧拉公式

什么是平面图

平面图：能画在平面上使得任意两条边除公共端点外不相交的图。能把图这样无交叉地画出来，就叫图的一个平面嵌入；画好后边把平面切成的每一块区域称为面，其中最外面那一块叫无界面（外部面）。
一个面的次数 = 围成它的边数（若一条边两侧是同一个面，即割边，则计 2 次）。
不是所有图都是平面图——K₅（5 个顶点两两相连）与 K₃,₃ 是最经典的两个非平面图，无论怎么挪点都会出现交叉。
完全图 K₄ 的一个平面嵌入
无边交叉 → 是平面图；内部 3 个三角面 + 1 个外部面，共 f=4
带割边的树（无圈，只有 1 个面）
紫虚线=沿割边 b–d 描边界：去 ↑ + 回 ↓ 走过两遍 → 计 ×2
面的“次数”怎么数：普通边夹在两个不同面之间，各算 1 次；割边（右图橙色 b–d）两侧是同一个面，绕这个面走一圈会“去 ↑ + 回 ↓”经过它两遍，所以算 2 次。合起来每条边都被数 2 次 → Σ 各面的次数 = 2m。（记不住过程就先只记结论：割边算 2 次。）
欧拉公式（连通平面图）：顶点数 n、边数 m、面数 f（含无界面）满足 n − m + f = 2（如上图 K₄：4−6+4=2 ✓）。
两个推论：普通平面图 m ⩽ 3n − 6；二部图（无三角形）更强 m ⩽ 2n − 4。⚠ 它们只是必要条件——只能拿来“证伪”非平面图，不能反过来证明一定平面。
判非平面（高频）：K₅（n=5、m=10 > 3n−6=9）、K₃,₃（n=6、m=9 > 2n−4=8）都因超出上界而非平面；K₃,₃ 必须用 2n−4，误用 3n−6 会判不出。
