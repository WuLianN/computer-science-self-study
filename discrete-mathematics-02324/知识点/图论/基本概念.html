一、图、顶点、边

图 G = (V, E)

顶点（vertex）也叫点、结点；边（edge）连接两个顶点。顶点的集合记作 V，边的集合记作 E。上图：V={a,b,c,d}，E={ab,bc,cd,da}。
阶：顶点个数 |V|，常记作 n。上图 n=4。

二、无向图 vs 有向图

无向 / 有向

无向图：边没有方向，ab 与 ba 是同一条边（左图，普通线段）。
有向图：边有方向，称为弧，ab 表示从 a 到 b（右图，带箭头）。自考里欧拉 / 哈密顿默认讨论无向图，除非题目说明"有向"。

三、度数（奇度 / 偶度）

度数 d(v)

顶点 v 的度数 = 与它相连的边数。橙点 c 连了 4 条边 → d(c)=4；a、b 各连 1 条 → d=1。
奇度：度数为奇数（如 1、3）；偶度：度数为偶数（如 2、4）。欧拉图判定只看奇度顶点个数，这是全章最关键的桥。

四、简单图 / 多重边

简单图

简单图：无环（顶点到自己不连边）、无平行边（两点之间至多一条边）。自考判定定理（如 Dirac）通常只对简单图成立。
多重图：两点间可有多条平行边（下图右，a–b 两条）。带环或平行边的就不是简单图。
✓ 简单图：无环、无平行边
任意两点间至多 1 条边
✗ 多重图：a–b 之间有 2 条平行边
（一条直、一条弯，数得出来）

五、连通 / 连通分支

连通分支 ω(G)

连通：任意两点间都有路可走。右图被分成两块、互不相连，叫不连通。
连通分支数 ω(G) = 互相独立的不连通块数。右图 ω=2（{a,b,c} 与 {d,e} 各一块）。哈密顿"必要条件"里就用 ω(G−S) 这个量。

六、割点

割点

去掉某顶点（连同它的边）后，图的连通分支数变多，该点就是割点。橙点 c 一删，图裂成左右两块（ω 从 1 变 2）。
这正是欧拉图页里"例①无哈密顿回路"的证法：删割点 c，ω(G−{c})=2 > |{c}|=1，不满足必要条件。

七、子图

子图

从 G 中挑出一部分顶点和边得到的图叫子图。哈密顿"删 S 看 ω(G−S)"就是反复取子图来判定。
若子图含 G 的全部顶点，叫生成子图（如"生成树"）。本页不必深究，知道"挑一部分出来还是图"即可。

八、路径 / 通路 / 回路

三种"走法"

通路（walk）：顶点、边可重复地走一遍（最宽松）。
路径（path/trail 与 path 的混用注意）：自考语境下常指"边不重复"的走法；若还要求点不重复则称初级通路。
回路（circuit）：起点=终点的通路。其中欧拉回路=边不重复且回起点；哈密顿回路=点不重复（除首尾）且回起点。
一句话记：欧拉管"边重复没"，哈密顿管"点重复没"。
