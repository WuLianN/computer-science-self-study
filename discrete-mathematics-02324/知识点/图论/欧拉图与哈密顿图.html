欧拉图 与 哈密顿图 —— 一个看“边”走一遍，一个看“点”走一遍，最易混的一对。

欧拉：边不重复哈密顿：点不重复
🏠 首页 📚 知识点导航
看不懂“度数 / 奇度 / 连通分支 / 割点”等术语？先读 图论 · 基本概念。
核心区别（先记住这个）：
欧拉：存在一条通路/回路，每条边恰好走一次（关心“边”）。
哈密顿：存在一条通路/回路，每个顶点恰好访问一次（关心“点”）。

欧拉图判定（无向图，连通前提下）：
· 欧拉回路 ⟺ 所有顶点度数都是偶数。
· 存在欧拉通路（每条边恰走一次）⟺ 奇度顶点数为 0 或 2：0 个时即上面的欧拉回路（回到起点）；恰 2 个时是开放通路，必从其中一个奇度点出发、到另一个结束。
哈密顿图判定（较难，注意只是“充分/必要”而非等价）：
· 必要条件：若有哈密顿回路，则对任意顶点子集 S，删去 S 后图的连通分支数 ω(G−S) ≤ |S|。（常用来证伪：找到某个 S（如割点）使 ω>|S|，就无哈密顿回路。）
· 充分条件（Dirac 定理）：n≥3 的简单图，若最小度 δ(G) ≥ n/2，则必有哈密顿回路。（是充分非必要，δ 小也可能有。）
图解：为什么欧拉判定只看“奇度顶点是 0 个还是 2 个”

度数＝一个顶点连出去的边数；奇度顶点＝度数是奇数的点。
把“走欧拉路线”想成一笔连续描、每条边只描一次：每当你穿过一个顶点（既不是出发点也不是落脚点的“途中点”），都必须一进一出配成一对地用掉 2 条边 → 途中点度数必为偶数。只有起点和终点可以各多出一条、成了奇数。于是奇度点只可能是这两种情况：

0 个奇度点（全偶）→ 欧拉回路
沿 1→2→3→4 走一圈回到起点 a（第 4 步 d→a 正好合口）
恰 2 个奇度点 → 欧拉通路
比左图多一条斜边 a–c → a、c 变奇度。走 1→2→3→4→5 只能从奇度点 a 出发、在奇度点 c 结束，回不到起点

一句话记住：全偶度＝能绕一圈回到起点（回路）；恰 2 个奇度＝只能从一个奇度点走到另一个奇度点（通路，开口不闭合）。
为什么不会是 1 个或 3 个奇度点？因为“握手定理”：所有顶点度数之和＝边数×2（必为偶数），奇度点必须成对出现，所以奇度点个数永远是偶数——欧拉相关只可能是 0 或 2（详见 图论·基本概念 · 握手定理）。

易错点：① 把“欧拉”和“哈密顿”的判定混为一谈——欧拉只看度数奇偶，哈密顿没有这种简单等价；② 看到“所有点都连通、看起来能绕一圈”就乱判哈密顿，忘了要每个点恰好一次；③ 忽略 Dirac 是充分条件：满足 δ≥n/2 一定有，但不满足也可能有；④ 欧拉通路的两个奇度点，方向搞反（从哪个到哪个）。
