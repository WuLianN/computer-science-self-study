一、个体、谓词与量词

个体：被讨论的对象。具体个体（常量，如"张三"）与个体变元（变量 x、y）。
谓词：刻画个体的性质或个体间的关系。一元谓词 F(x) 表性质，二元谓词 G(x,y) 表关系。
个体域（论域）：个体变元的取值范围。全总个体域 = 宇宙一切对象；限定论域需加"特性谓词"。
两个量词：
符号名称含义等价直观（有限域）
∀x全称量词对论域中每一个 x像合取 F(a)∧F(b)∧…
∃x存在量词论域中至少存在一个 x像析取 F(a)∨F(b)∨…
还有存在唯一量词 ∃!x：恰有一个 x 满足。

二、谓词公式：辖域、约束变元与自由变元

量词的辖域：紧跟量词后面的最短公式（无括号时只盖住下一个原子式；有括号 (∀x) 则盖住括号内全部）。
约束变元：出现在某量词辖域内、且被该量词限定的变元（如 ∀x P(x) 里的 x）。
自由变元：不被任何量词约束的变元（如 ∀x P(x,y) 里的 y）。公式含自由变元时其真假依赖赋值，本质是"开语句"。
改名规则：约束变元可一致地换成新名（∀x P(x) ≡ ∀z P(z)），自由变元不可改名。
真题呼应："下列公式中 x 是自由变元的是" —— 逐项看 x 是否落在某个 ∀x / ∃x 的辖域内。只要有一处 x 未被约束，它就是自由出现。别把辖域看窄/看宽。

量词的辖域：嵌套的方框

无括号时量词只管“下一个原子式”加括号才能拓宽辖域；内层被外层嵌套

三、自然语言符号化（含"所有/存在/唯一"）

限定论域（非全总域）时的黄金搭配：
"所有 A 都是 B" → ∀x(A(x)→B(x))　（全称配 →，绝不用 ∧）
"存在 A 是 B" → ∃x(A(x)∧B(x))　（存在配 ∧，绝不用 →）
"没有 A 是 B" → ¬∃x(A(x)∧B(x)) ≡ ∀x(A(x)→¬B(x))
"恰有一个 A" → ∃x(A(x)∧∀y(A(y)→y=x))

例：经典翻译

设 F(x)：x 是自然数，G(x)：x 是整数，论域为实数。
• "所有自然数都是整数" → ∀x(F(x)→G(x))
• "有的实数是有理数" → ∃x(R(x)∧Q(x))
• "不存在最大的自然数" → ∀x(N(x)→∃y(N(y)∧y>x))（每个自然数都有比它更大的）
最易错：把"所有 A 是 B"写成 ∀x(A(x)∧B(x))（错！这断言了论域全是 A 且全是 B）；把"存在 A 是 B"写成 ∃x(A(x)→B(x))（错！只要有一个非 A 就自动为真）。牢记全称→、存在∧。

四、量词的等值演算与否定

量词否定律（德摩根推广）：
¬∀x P(x) ≡ ∃x ¬P(x)　（"并非所有"＝"存在不"）
¬∃x P(x) ≡ ∀x ¬P(x)　（"不存在"＝"所有都不"）
辖域收缩 / 扩张（当公式某部分不含被约束变元时）：
∀ 分配 ∧∀x(P(x)∧Q) ≡ ∀x P(x)∧Q（Q 无自由 x）
∃ 分配 ∨∃x(P(x)∨Q) ≡ ∃x P(x)∨Q
量词对 →∀x(P(x)→Q) ≡ ∃x P(x)→Q；∃x(P(x)→Q) ≡ ∀x P(x)→Q
同类量词可换序（∀x∀y ≡ ∀y∀x、∃x∃y ≡ ∃y∃x）；异类量词不可换序（∀x∃y ≢ ∃y∀x）。

例：否定并前移

¬∀x(P(x)→∃y Q(y)) ≡ ∃x ¬(P(x)→∃y Q(y)) ≡ ∃x(P(x)∧∀y ¬Q(y))。先把 → 化 ¬∨，再逐层用否定律把 ¬ 推进辖域。

量词对当方阵（Square of Opposition）

四角关系一图记全红虚线＝矛盾(一真一假)；上边＝反对(不同真)；下边＝下反对(不同假)；左右竖线＝差等(上真⇒下真)

五、前束范式

前束范式：所有量词都集中在公式最前面，其后是不含量词的母式，形如 Q₁x₁Q₂x₂…M(x₁,x₂,…)，其中每个 Qᵢ ∈ {∀,∃}。
  1. 用蕴含等值式消去 →、↔（A→B ≡ ¬A∨B）。
  2. 把 ¬ 内推到各原子谓词前（用量词否定律、德摩根）。
  3. 若约束变元重名，用改名规则换成不同变元。
  4. 用辖域扩张把所有量词提到最左，保持原有先后顺序，得到前束范式。

例

求 ∀x P(x)→∃y Q(y) 的前束范式：
① 消 →：¬∀x P(x)∨∃y Q(y)　② 内推 ¬：∃x ¬P(x)∨∃y Q(y)　③ 提前量词：∃x∃y(¬P(x)∨Q(y)) ∎（母式 ¬P(x)∨Q(y)）
易错：前提取量词时，若量词在蕴含前件里被 ¬ 覆盖，提出来要变号（∀↔∃）。这是前束范式题的最大失分点。

六、谓词推理理论（四条量词规则）

在命题逻辑推理规则（MP、MT、析取三段论…）之外，增加四条量词规则：
简称名称形式
US / UI全称量词消去∀x A(x) ⟹ A(c)（c 为论域中任意特定个体）
UG全称量词引入A(c)（c 任意）⟹ ∀x A(x)
ES / EI存在量词消去∃x A(x) ⟹ A(c)（c 是新常元，之前未出现过）
EG存在量词引入A(c) ⟹ ∃x A(x)

例：构造有效论证

前提：∀x(F(x)→G(x))，∃x F(x)；结论：∃x G(x)。
  1. ∃x F(x)　（前提引入 P）
  2. F(c)　（2 存在消去 ES，c 为新常元）
  3. ∀x(F(x)→G(x))　（前提引入 P）
  4. F(c)→G(c)　（4 全称消去 US）
  5. G(c)　（3、5 假言推理 MP）
  6. ∃x G(x)　（6 存在引入 EG）∎
使用顺序与限制：先消存在量词 ES（引入新常元）再消全称量词，避免常元冲突；UG 引入全称时该常元必须是"任意"而非 ES 引入的特定常元。每步注明规则与依据，同命题逻辑。

七、本章小结与真题呼应

一句话主线：拆结构（个体+谓词+量词）→ 定辖域（分约束/自由变元）→ 符号化（全称配→、存在配∧）→ 会否定（¬∀≡∃¬、¬∃≡∀¬）→ 化前束范式（消→、内推¬、改名、提量词）→ 用四条量词规则（US/UG/ES/EG）串命题推理做证明。
