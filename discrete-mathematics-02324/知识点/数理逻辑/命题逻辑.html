一、命题与联结词（含自然语言翻译）

命题：能判断真假的陈述句，真值只能是 真(1/T) 或 假(0/F)。疑问句、祈使句、感叹句、含未定变元的开语句都不是命题。
原子命题：不能再拆分的命题，用大写字母 P、Q、R 表示。
复合命题：由原子命题 + 联结词构成。
五个基本联结词（务必牢记对应的中文句式）：
符号名称读法 / 自然语言真值要点
¬P否定非 P、P 的否定与 P 相反
P∧Q合取P 并且 Q、P 而且 Q全真才真
P∨Q析取P 或者 Q（可兼或）全假才假
P→Q条件如果 P 那么 Q；P 仅当 Q唯一假：前真后假(1→0)
P↔Q等价P 当且仅当 Q两者相同才真
三个“条件 / 蕴含”别混：
对象名称一句话
→（符号）条件联结词造公式的运算本身
A→B（公式）蕴含式一个公式，可列真值表；CP 针对它
A→B ≡ ¬A∨B（定律）蕴含等值式消去 → 的等值律

四联结词的真值“地图”

P→Q（蕴含式）只怕“P真而Q假”，其余全真
P∧Q（合取）全真才真，其余三格皆 0
翻译三大易错句：
① "只要 P 就 Q" = P→Q（充分条件，P 在前）；"只有 P 才 Q" = Q→P（必要条件，Q 在前）。口诀：只要→前件，只有→后件。
② "P 仅当 Q" = P→Q（“仅当”引必要条件、放后件）；"P 除非 Q" = ¬Q→P（即 P∨Q，意为“不作 Q 则 P”、Q 是 ¬P 的必要条件）。
③ "P 是 Q 的充分条件" = P→Q；"P 是 Q 的必要条件" = Q→P。

例：把句子符号化

设 P：今天下雨，Q：我去登山。
• "如果今天不下雨，我就去登山" → ¬P→Q
• "只有今天下雨，我才不去登山" → 不去登山→下雨，即 ¬Q→P（"只有 A 才 B"＝B→A，此处 B＝"不去登山"）
• "我今天既下雨又去登山" → P∧Q

二、命题公式与真值表

把命题变元、联结词与括号按规则组合即得命题公式。联结词优先级（高→低）：
¬ ＞ ∧ ＞ ∨ ＞ → ＞ ↔；括号内最先。相同优先级从左到右。
真值表：n 个变元有 2ⁿ 行赋值。约定按二进制顺序枚举（P 为最高位），例如 3 变元 8 行依次为 000,001,…,111。

例：三变元公式的真值表片段

对 (P→Q)∧(Q→R)，逐行算 P→Q、Q→R 再合取。列表时先固定 P 的 4 个 0、4 个 1，再让 Q 两个 0 两个 1 交替，R 逐个 0/1 交替——这是最不易乱的填表顺序。
成真的赋值 vs 成假的赋值：使公式为 1 的赋值叫成真赋值，为 0 的叫成假赋值。它们正是第五章写主析取范式（取成真行）与主合取范式（取成假行）的依据，别记反。

三、公式分类：重言式 / 矛盾式 / 可满足式

按真值表结果列（最后一列）分类：
重言式（永真式） 全部为 1；
矛盾式（永假式） 全部为 0；
可满足式 至少有一个 1（重言式是可满足的特例；非重言的可满足式指既有 1 又有 0）。
三者关系：重言式 ⊂ 可满足式（永真必可满足）；矛盾式与可满足式互斥（永假式没有任何成真赋值，故不可满足）。判定方法：算真值表看最后一列，或等值演算化到 1 / 0 / 其它。
真题呼应：判定 "(P∧Q)→Q" 是重言式（化简得 ¬P∨1≡1）；"(P→Q)∧P∧¬Q" 是矛盾式（含 P∧¬Q 必为 0）；"既非永真又非永假"就是可满足式——这类 2 分选择题几乎每卷必考。

四、等值演算（核心等值式速查）

若 A↔B 为重言式，则 A 与 B 等值，记 A≡B。等值演算就是用下表逐代换化简公式。
名称等值式
双重否定¬¬A ≡ A
交换律A∧B ≡ B∧A；A∨B ≡ B∨A
结合律(A∧B)∧C ≡ A∧(B∧C)；∨ 同理
分配律A∧(B∨C) ≡ (A∧B)∨(A∧C)；A∨(B∧C) ≡ (A∨B)∧(A∨C)
德摩根律¬(A∧B) ≡ ¬A∨¬B；¬(A∨B) ≡ ¬A∧¬B
吸收律A∧(A∨B) ≡ A；A∨(A∧B) ≡ A
幂等律A∧A ≡ A；A∨A ≡ A
同一律A∧1 ≡ A；A∨0 ≡ A
否定/支配律A∧¬A ≡ 0；A∨¬A ≡ 1；A∧0≡0；A∨1≡1
蕴含等值式A→B ≡ ¬A∨B（去蕴含的关键！）
逆否等值式A→B ≡ ¬B→¬A
等价等值式A↔B ≡ (A→B)∧(B→A) ≡ (A∧B)∨(¬A∧¬B)
化简套路：先用蕴含等值式把 →、↔ 全变成 ¬ 与 ∧∨，再用德摩根把 ¬ 压到变元上，最后用分配 / 吸收 / 互补合并。例：(P→Q)→Q ≡ ¬(¬P∨Q)∨Q ≡ (P∧¬Q)∨Q ≡ P∨Q（吸收）。

五、主范式（小项 / 大项 / 主析取 / 主合取）

小项（极小项 m）：n 个变元各出现一次的合取式；n 变元共 2ⁿ 个小项，每个恰在唯一一组赋值下为 1。
大项（极大项 M）：n 个变元各出现一次的析取式；共 2ⁿ 个，每个恰在唯一一组赋值下为 0。
编号规则（下标怎么来）：把赋值看成二进制。
· 小项 mi：变元取 1 写原变量、取 0 加否定。如赋值 P=0,Q=1,R=0（即 010=2）→ m2=¬P∧Q∧¬R。
· 大项 Mi：恰好相反，变元取 0 写原变量、取 1 加否定。如 010=2 → M2=P∨¬Q∨R。

主范式下标怎么来：010 的二进制读法

小项与大项的下标相同、取反规则相反同一行：小项取“1原/0否”，大项取“0原/1否”
主范式求法（真值表法，最稳）：
  1. 列出公式的完整真值表，标出每一行结果（0 或 1）。
  2. 主析取范式：取所有结果为 1 的行，写出对应小项，用 ∨ 连接，记 Σ(下标…)。
  3. 主合取范式：取所有结果为 0 的行，写出对应大项，用 ∧ 连接，记 Π(下标…)。
  4. 两式的下标互补（合起来正好是 0…2ⁿ−1 全体），可互相校验。

例：求 (P→Q)→(Q→R) 的主合取范式

公式为 0 当且仅当"前件真、后件假"：后件 Q→R=0 需 Q=1,R=0；此时前件 P→Q=P→1=1 恒成立，P 可 0 可 1。
故成假赋值为 010(=2)、110(=6) → 主合取范式 = M2∧M6 = (P∨¬Q∨R)∧(¬P∨¬Q∨R)。
验证：先化简原式得 ¬Q∨R，再补变元 P 即得同式。
性质对照（常考）：不同小项之合取恒为 0（矛盾式）；不同大项之析取恒为 1（重言式）。重言式主析取取满 2ⁿ 个小项、主合取为空；矛盾式主合取取满 2ⁿ 个大项、主析取为空。

六、推理理论（P / T / CP 规则）

有效推理：前提全真时结论必真（即 (前提合取)→结论 为重言式）。构造证明用三条基本规则：
规则 P（前提引入）：证明过程中可随时引入任一前提。
规则 T（结论引入）：由前面已有公式，用等值式或推理规则得到的公式可引入。
规则 CP（附加前提）：当结论是 A→B 形时，把 A 当附加前提，只要推出 B，即完成证明。
常用推理规则（配合规则 T 使用）：
名称形式
假言推理 MPA, A→B ⟹ B
拒取式 MT¬B, A→B ⟹ ¬A
析取三段论A∨B, ¬A ⟹ B
假言三段论A→B, B→C ⟹ A→C
化简A∧B ⟹ A
附加A ⟹ A∨B
合取引入A, B ⟹ A∧B

例：CP 规则证明（见全国2025年4月卷第35题）

前提：P∨Q，¬P∨¬R，Q→S；结论：R→S。
结论是蕴含式 → 用 CP，把 R 作附加前提：
  1. R　（附加前提，CP）
  2. ¬P∨¬R　（前提引入 P）
  3. ¬P　（1、2 析取三段论：R 使 ¬R 假）
  4. P∨Q　（前提引入 P）
  5. Q　（3、4 析取三段论）
  6. Q→S　（前提引入 P）
  7. S　（5、6 假言推理 MP）
  8. R→S　（1、7 CP 规则）∎
📌 同类型变式：全国2026年4月卷第35题也考 CP，前提换成 P→¬Q、P∧R、Q∨S（结论仍为 R→S）——把 R 作附加前提后，先由 P∧R 化简得 P，再 MP 得 ¬Q、析取三段论得 S。（2025年10月卷未考 CP 证明）
易错：① 每一步都要在括号里注明依据（哪两条 + 哪条规则），这是给分点；② CP 只在结论是蕴含式时用，把前件搬到前提位；③ 别把 MP（有 A、A→B 得 B）与"肯定后件"谬误（有 B、A→B 推不出 A）搞混。

七、本章小结与真题呼应

一句话主线：翻译（找联结词、分清"只要/只有"）→ 真值表（2ⁿ 行、成真/成假）→ 判类型（永真/永假/可满足）→ 等值演算（先消 →↔，再德摩根，后分配吸收）→ 主范式（成真行配小项写 Σ、成假行配大项写 Π，下标互补）→ 推理（P/T/CP，结论是蕴含式就 CP）。
