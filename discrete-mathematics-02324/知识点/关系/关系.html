一、二元关系（定义）

定义 1　笛卡尔积与二元关系
笛卡尔积：A×B = { (a,b) | a∈A, b∈B }。
二元关系 R：A×B 的任一子集，记作 R⊆A×B。若 (a,b)∈R 记作 aRb。
当 A=B 时称 A 上关系；关系 R 的定义域 dom R、值域 ran R 分别由出现于有序对首/次的元素组成。
定义 2　关系的三种表示
• 集合：罗列有序对，如 R={(1,2),(2,3)}。
• 关系矩阵 MR：m×n 的 0-1 矩阵，mᵢⱼ=1 ⟺ (aᵢ,bⱼ)∈R（与图论的邻接矩阵同源）。
• 关系图（有向图）：顶点为元素，有向边 (a,b) 表示 aRb。

例：A={1,2,3}，R={(1,2),(2,3)}

・关系的复合（R₁∘R₂）

定义　关系的复合运算
设 R₁ ⊆ A×B、R₂ ⊆ B×C，则 R₁ 到 R₂ 的复合记作 R₁∘R₂（仍习惯叫“右复合”：先走 R₁、再走 R₂）：
R₁∘R₂ = { ⟨p,r⟩ | ∃q ( ⟨p,q⟩∈R₁ ∧ ⟨q,r⟩∈R₂ ) }
读法：“从 p 经 R₁ 能到某个中转点 q，从 q 经 R₂ 能到 r”，则 ⟨p,r⟩ 属于复合关系。（用 p/q/r 中性字母，避开题里的具体元素防撞名。）

例（2026.4 填空第20题同款）：A={1,2,3,4}、B={a,b,c}、C={x,y}

R₁={⟨1,a⟩,⟨2,a⟩,⟨3,c⟩,⟨4,b⟩}，R₂={⟨a,x⟩,⟨a,y⟩,⟨b,y⟩}。
“从每个起点走两步”（先 R₁ 后 R₂）：
· 1→a→x、a→y ⇒ ⟨1,x⟩、⟨1,y⟩；· 2→a→x、a→y ⇒ ⟨2,x⟩、⟨2,y⟩；
· 3→c，但 c 在 R₂ 中无出边 ⇒ 3 不产生任何有序对；· 4→b→y ⇒ ⟨4,y⟩。
∴ R₁∘R₂ = {⟨1,x⟩,⟨1,y⟩,⟨2,x⟩,⟨2,y⟩,⟨4,y⟩}（共 5 个）。
💡 矩阵法：MR₁∘R₂ = MR₁ · MR₂（用布尔乘：乘法→∧、加法→∨）。复合关系不一定是函数（一个起点可经多个中转点到达多个终点）。

二、关系五大性质（定义 + 判定）

定义 3　五大性质（A 上关系 R）
• 自反：∀x∈A, xRx（每点连自己）。
• 反自反：∀x∈A, ¬xRx（每点都不连自己）。
• 对称：若 xRy 则 yRx（边成对）。
• 反对称：若 xRy 且 yRx，则 x=y（不同点间无双向边）。
• 传递：若 xRy 且 yRz，则 xRz。

图示：自反 / 对称 / 传递 长什么样

自反：每点都有自环
对称：边成对（a→b 必有 b→a）
传递：有 a→b、b→c 必补 a→c
口诀：自反看“自环”、对称看“成对”、传递看“补齐捷径边”。缺一条就破功——只有 a→b 没 b→a 则不对称；有 a→b、b→c 却无 a→c 则不传递。

图示：反自反 / 反对称 长什么样（对照自反 / 对称）

反自反：每点都不连自己（无自环），其他边随意
反对称：不同点间无双向边（有 a→b 则无 b→a）
对照：对称=边成对（a→b 必有 b→a，含自环）；反对称=a→b 与 b→a 不能同时出现（除非 a=b）。一个"要求双向"、一个"禁止双向"，极易混淆，记住各自看"双向边"。
一眼判定：从矩阵 / 关系图看性质
性质矩阵特征关系图特征
自反主对角线全 1每个顶点有自环
反自反主对角线全 0无自环
对称矩阵对称（M=Mᵀ）边成对出现（含自环）
反对称i≠j 时 mᵢⱼ、mⱼᵢ 不同时为 1不同顶点间无双向边
传递若 mᵢⱼ=mⱼₖ=1 则 mᵢₖ=1有路径 i→j→k 则必有边 i→k
易错：① 自反与反自反可同时不成立（如 R={(1,1),(2,3)}），但不能同时成立；② 对称与反对称可同时成立（恒等关系 IA 既对称又反对称）；③ 传递判定要查“所有两步路径”，别漏看。

三、闭包（定义 + 公式）

定义 4　闭包
包含 R 且具有某性质、且被任何具该性质的关系包含的最小关系，称为 R 的该性质闭包：
• 自反闭包 r(R)：R∪IA（补上所有自环）。
• 对称闭包 s(R)：R∪R⁻¹（补上反向边）。
• 传递闭包 t(R)：R∪R²∪R³∪…（补上所有可达路径）。
定理 1　闭包公式
r(R)=R∪IA，s(R)=R∪R⁻¹，t(R)=R∪R²∪⋯∪Rⁿ（|A|=n 时只需到 Rⁿ）。
注：计算 Rᵏ 用矩阵布尔乘法（与图论邻接矩阵 Aᵏ 数途径同源）。
恒等关系 IA = { ⟨x, x⟩ | x ∈ A }
R的逆 R⁻¹ = { ⟨y, x⟩ | ⟨x, y⟩ ∈ R }

图示：三种闭包分别在图上“补”什么（基于 R={(1,2),(2,3)}）

r(R) 自反闭包：给每个点补自环（R∪Iₐ）
s(R) 对称闭包：每条边补反向边（R∪R⁻¹）
t(R) 传递闭包：有路径就补直连边（R∪R²∪…）
蓝边是原关系 R，橙边是闭包新补的边——“最小”即只补到刚好满足性质为止，不多补。

Warshall 算法：高效求传递闭包 t(R)（O(n³)）

令 W⁽⁰⁾ = M_R；对 k=1,2,…,n 逐层更新：
W⁽ᵏ⁾[i][j] = W⁽ᵏ⁻¹⁾[i][j] ∨ ( W⁽ᵏ⁻¹⁾[i][k] ∧ W⁽ᵏ⁻¹⁾[k][j] )
其中 ∨=布尔或、∧=布尔与；语义即"能否经第 k 个点中转从 i 到 j"。

四、等价关系与划分（定义 + 定理）

定义 5　等价关系
A 上关系 R 若同时满足自反、对称、传递，则称 R 为等价关系，记作 ∼。
定义 6　等价类 · 商集 · 划分
• 等价类 [a] = { x∈A | a∼x }（与 a 等价的全体）。
• 商集 A/∼ = { [a] | a∈A }（所有等价类组成的集合）。
• 划分：A 的非空子集族 π，满足两两不交且并集为 A。
定理 2　等价关系 ↔ 划分（一一对应）
每个等价关系唯一确定一个划分（其等价类构成划分）；每个划分也唯一确定一个等价关系（同块内等价）。即等价关系与划分等价。

图示：一个划分 = 若干互不相交的块（同一块内两两等价）

读图：同一椭圆内的元素用细线相连，表示它们两两等价（∼）；不同椭圆间无任何连线。三块非空 · 两两不交 · 并为 A → 恰好是一个划分。此图的商集 A/∼ = {{1,2},{3,4,5},{6}}。

五、偏序关系与哈斯图（定义）

定义 7　偏序关系
A 上关系 R 若同时满足自反、反对称、传递，则称 R 为偏序关系，记作 ≤。装备偏序的集合 (A,≤) 称偏序集。
📎 此定义是「格与布尔代数」页 §一、二 的地基——格 = 任意二元都有最小上界/最大下界的偏序集。
定义 8　哈斯图
画偏序时省略自环与传递边，越往上元素越大，只画“直接覆盖”的边。是格、布尔代数最直观的图示工具（详见 格与布尔代数 中的菱形格示例）。
定义 9　偏序集的特殊元素
设 B⊆A：
• 极大元 / 极小元：B 中没有元素比它更大 / 更小（未必唯一）。
• 最大元 / 最小元：比 B 中每个元素都大 / 小（若存在则唯一）。
• 上界 / 下界：比 B 中每个都大 / 小的元素（可不在 B 中）。
• 最小上界 lub（并 ∨）/ 最大下界 glb（交 ∧）：所有上界中最小者 / 所有下界中最大者。
📎 “最小上界/最大下界”正是格页里 a∨b、a∧b 的来源。

图示：哈斯图上认清“极大/极小、最大/最小、上/下界、lub/glb”

偏序集 (A,≤)，A={a,b,c,d,e}，覆盖关系 a≺c、b≺c、c≺d、c≺e
逐条对照定义 9 读本图：
• 极小元=a、b（下方没元素），极大元=d、e（上方没元素）。
• 最小元/最大元不存在：因为 a、b 不可比 → 没“同一个”元素排在所有人下方；同理 d、e。
• 取子集 B={a,b}：上界是 c、d、e（都 ≥a 且 ≥b），最小上界 lub(B)=c；下界为空，glb 不存在。
• 取子集 B={d,e}：下界是 c（及传递下来的 a、b），最大下界 glb(B)=c。
• 本图 c 这个绿点就是“lub 与 glb 集中到同一处”的直观体现，也是格页里 ∨ / ∧ 两种写法在同一元素上的交汇。

六、核心定理速记

定理 3　性质判定特征
自反↔主对角全1；反自反↔主对角全0；对称↔M=Mᵀ；反对称↔异对角不同时为1；传递↔两步路径必有直达边。
定理 4　偏序特殊元素的存在性
• 最大元 / 最小元若存在则唯一；极大元 / 极小元可多个。
• 有限偏序集必有极大元与极小元。
• 最小上界 / 最大下界（若对所有二元对都存在）即构成格（见格页）。

七、真题呼应

主线小结：二元关系（矩阵/图）→ 五大性质（自反/对称/反对称/传递）→ 闭包（r/s/t 公式）→ 等价关系↔划分 → 偏序关系与哈斯图（极大/极小、最大/最小、上/下界、确界）。
高频考点：① 给矩阵/图判断性质；② 求闭包、求等价类与商集；③ 画哈斯图并找特殊元；④ 偏序与格的衔接（最小上界/最大下界）。配合 真题详解 中“关系性质”“哈斯图”“等价划分”相关大题一起刷。
