一、集合的概念与表示

集合是"确定的、互不相同的一些对象"构成的整体，元素与集合是属于关系 ∈ / ∉。三种表示法：
列举法：把元素一一列出，如 {1,2,3}；
描述法（谓词法）：{x | P(x)}，满足性质 P 的 x 全体；
文氏图：用封闭曲线直观表示集合及其关系。
集合三特性：确定性（元素是否属于非此即彼）、互异性（无重复元素）、无序性（{1,2}={2,1}）。

二、特殊集合：空集 / 子集 / 幂集

空集 ∅：不含任何元素，∅ ⊆ A 对任意 A 成立，且 ∅ 是唯一的。
子集 A ⊆ B ⟺ ∀x(x∈A→x∈B)；真子集 A ⊂ B：A⊆B 且 A≠B。
相等：A⊆B 且 B⊆A ⇔ A=B（双向包含是证等集的通法）。
幂集 P(A)（也记 2^A）：A 的全部子集构成的集合。若 |A|=n，则 |P(A)|=2ⁿ。

例：幂集

A={a,b} → P(A)={∅,{a},{b},{a,b}}，共 2²=4 个元素。
注意 ∅∈P(∅) 且 P(∅)={∅}（1 个元素）；a∈A 与 {a}⊆A 是不同层次（元素 vs 子集），是最常考的区分点。

三、集合运算与运算律

运算定义
并 A∪B{x | x∈A ∨ x∈B}
交 A∩B{x | x∈A ∧ x∈B}
差 A−B{x | x∈A ∧ x∉B}（属于 A 但不属于 B）
补 Ā（绝对补）全集 U 中不属于 A 者，Ā=U−A
对称差 A⊕B(A−B)∪(B−A) = (A∪B)−(A∩B)
运算律与命题逻辑等值式一一对应：交换、结合、分配（∪∩ 互相分配）、德摩根 (A∪B)的补 = Ā∩B̄、(A∩B)的补 = Ā∪B̄、吸收 A∪(A∩B)=A。

文氏图：五种运算的着色区域

A∪B两圆全部
A∩B中间重叠
A−B只留 A 去掉重叠
ĀA 以外全阴影
A⊕B去掉中间，只留两侧
真题呼应：对称差 A⊕B 的元素 = "只属于其一"者。求 A⊕B 可先并后交再差：(A∪B)−(A∩B) 最快。德摩根律考"补的并＝交的补"，别把 ∪∩ 写反。

四、笛卡尔积

有序对 <a,b>：a 为第一分量、b 为第二分量，<a,b>=<c,d> ⟺ a=c 且 b=d（有序！）。
笛卡尔积 A×B = {<a,b> | a∈A ∧ b∈B}。若 |A|=m, |B|=n，则 |A×B|=m·n。
性质：一般 A×B ≠ B×A（不交换）；(A×B)×C ≠ A×(B×C)（不结合）；对∪、∩满足分配律：A×(B∪C)=(A×B)∪(A×C)。
二元关系就是 A×B 的子集——这正是关系一章的出发点。

笛卡尔积 A×B：每个 a 配每个 b

A×B = {<a,1>,<a,2>,<a,3>,<b,1>,<b,2>,<b,3>}2×3=6 条连线＝6 个有序对

五、有限集合的计数（容斥原理）

两集合：|A∪B| = |A| + |B| − |A∩B|。
三集合：
|A∪B∪C| = |A|+|B|+|C| − |A∩B| − |A∩C| − |B∩C| + |A∩B∩C|
口诀：单加、双减、三重加，交替进行。若讨论"至少属于其一"用并；"都不属于"用 |U| − |A∪B∪C|。

例

30 人中会英语 18、日语 15、德语 12，英日 7、英德 6、日德 5、三语都会 3。至少会一门 = 18+15+12 −7−6−5 +3 = 30，故一门都不会 = 30−30 = 0 人。

容斥原理：三圆重叠的加减层次

|A∪B∪C| = 单加 − 双减 + 三重加颜色越深＝被重复算得越多，需逐层修正

六、函数（映射）：单 / 满 / 双射

函数 f: A→B：对 A 中每个元素，按 f 在 B 中唯一确定一个像。A 叫定义域 dom f，像的集合叫值域 ran f（⊆B）。
单射（一对一）：不同原像→不同像，x₁≠x₂ ⇒ f(x₁)≠f(x₂)；
满射：值域＝陪域，ran f = B（B 中每个元素都有原像）；
双射（一一对应）：既单且满。

例：判断单/满

f:{1,2,3}→{1,2,4}，f=<1,1>,<2,2>,<3,4>：三个像 1,2,4 互不相同→单射；值域{1,2,4}=陪域→满射，故为双射。判断满射看"值域是否等于陪域"，判断单射看"有无两个原像撞同一个像"。

单射 / 满射 / 双射：看箭头怎么连

单射非满无人撞像，但 d 无原像
满射非单1、2 撞向 a，但 a、b 都有原像
双射不撞像、无剩余，一一对应

七、函数的复合与逆；映射个数

复合 g∘f：先做 f 再做 g，(g∘f)(x)=g(f(x))。复合仍为函数，但一般 f∘g ≠ g∘f。
逆函数 f⁻¹：当且仅当 f 是双射时存在，满足 f⁻¹∘f = IA。单射保证"可逆不歧义"，满射保证"处处有定义"。
映射计数（|A|=m，|B|=n）——选择/填空高频：
全体函数 A→Bnᵐ（每个 A 元素独立选 B 中像）
单射个数A(n,m)=n!/(n−m)!（要求 n≥m，否则为 0）
双射个数m=n 时为 n!，否则 0
满射个数n!·S(m,n)，S(m,n) 为第二类 Stirling 数
易错：① 函数要求 A 中每个元素都有唯一像——"一个原像对应多个像"不是函数；② 单射/满射判定要对着具体陪域看，换陪域结论可能变；③ 满射公式含 Stirling 数，小题常给小数字让你枚举或用容斥验证，别死记。

八、本章小结与真题呼应

一句话主线：表示（∈ 与 ⊆ 分清元素/子集）→ 造集合（幂集 2ⁿ、笛卡尔积 m·n）→ 做运算（并交差补对称差 + 德摩根）→ 数元素（容斥"单加双减三重加"）→ 讲映射（单/满/双射定义）→ 复合与逆（双射才可逆）→ 算个数（nᵐ、A(n,m)、n!、n!·S(m,n)）。

集合是关系与代数结构的地基，学完本页直接衔接 关系（A×B 的子集）与 代数系统（集合 + 运算）。映射计数、幂集元素数、对称差、容斥几乎每卷都有 1–2 道小题，见 真题详解。
