一、偏序集（定义）

定义 1　偏序关系与偏序集
偏序关系 ≤：在集合 S 上满足 自反、反对称、传递 的关系。
装备偏序的集合 (S,≤) 称为偏序集。
定义 2　上界 / 下界 · 最小上界 / 最大下界
• 上界 u：比子集 A 中每个元素都大；下界 d：比每个都小。
• 最小上界 lub（并，记作 a∨b / sup）：所有上界中最小者。
• 最大下界 glb（交，记作 a∧b / inf）：所有下界中最大者。
• 哈斯图：省略自环与传递边，越往上越大，只画“直接覆盖”的边。
为什么用 ∨、∧ 表示最小上界 / 最大下界？
① 符号来源：∨ 来自拉丁语 vel（“或”），逻辑里是 OR；∧ 叫 wedge，逻辑里是 AND。
② 统一记号：在幂集格 (P(U),⊆) 中 A∨B = A∪B（并/或）、A∧B = A∩B（交/与），于是四类结构被同一对符号统一：
结构∨（并 / join）∧（交 / meet）
格（偏序）最小上界 lub最大下界 glb
集合并集 ∪交集 ∩
逻辑或 OR与 AND
布尔代数同上同上
③ 形状记忆：∨ 尖朝上 = 两元素“往上汇合”到公共上界（join）；∧ 尖朝下 = “往下汇合”到公共下界（meet）。
④ 对偶原理：∨ 与 ∧ 镜像对称，故任意格定理交换 ∨↔∧、0↔1、≤↔≥ 后仍成立。

二、格（两种等价定义）

定义 3　格（偏序视角）
格 (L,≤) 是“任意两个元素都有最小上界和最大下界”的偏序集。
即 ∀a,b∈L，a∨b（最小上界）与 a∧b（最大下界）都存在。
定义 4　格（代数视角）
(L,∧,∨) 上两运算满足三条公理：
① 交换律 a∧b=b∧a，a∨b=b∨a；
② 结合律 (a∧b)∧c=a∧(b∧c)（∨ 同理）；
③ 吸收律 a∧(a∨b)=a，a∨(a∧b)=a。
两种定义等价：偏序视角里 lub/glb 直接给出 ∧ 与 ∨；代数视角里用 a≤b ⟺ a∧b=a（或 a∨b=b）反推偏序。其中 a∨b 在偏序视角是“最小上界”的名字（定义等式），在代数视角才是“先有运算、再证它等于最小上界”——两视角是同一件事的两种出发点。

哈斯图直观：菱形格看 a∨b 与 a∧b

例 {0, a, b, 1}（0 最小、1 最大，a 与 b 不可比；0/1 是顶/底符号，a、b 是抽象标签，非数值）。
a∨b（最小上界）：a、b 的公共上界只有 1 → a∨b = 1。
a∧b（最大下界）：a、b 的公共下界只有 0 → a∧b = 0。
任取两元素都能唯一确定 ∨ 与 ∧ → 这正是格。
定义 5　幂集格（标准例子）
取全集 U，(P(U), ⊆) 是格：A∧B = A∩B（最大下界），A∨B = A∪B（最小上界）。也是布尔代数（见第四节）。
幂集格 (P({a,b}), ⊆)越往上“包含越多”；{a}、{b} 不可比，上确界为并、下确界为交

三、特殊格：分配 / 有界 / 有补（定义）

定义 6　分配格 / 有界格 / 有补格
分配格 满足分配律：a∧(b∨c) = (a∧b)∨(a∧c)（其对偶 ∨ 对 ∧ 也成立）。
有界格 存在最大元 1（∀a, a∨1=a 且 a∧1=1）与最小元 0（∀a, a∧0=a 且 a∨0=0）。
有补格 有界，且每个 a 都有补元 a' 使 a∨a'=1 且 a∧a'=0。
易错：① “分配”是格的额外性质，并非所有格都分配；② 反例 钻石格 M₃、五角格 N₅ 不是分配格（判“非分配”的标准）；③ 有补格里补元未必唯一，只有分配格中才唯一；④ 1、0 是格的顶/底，不是群里的幺元/零元。
钻石格 M₃三个原子 a、b、c 两两不可比 → 非分配
五角格 N₅链 0<a<b<1 旁支 c（与 a、b 不可比）→ 非分配

四、布尔代数（定义 + 定律）

定义 7　布尔代数
布尔代数 = 分配的有补格（既分配又有补）。
也可定义为带 0、1、′ 的代数系统 (B,∧,∨,′,0,1) 满足一组公理（如 Huntington 公理）。
例：幂集格 (P(U),∩,∪,补,∅,U) 是布尔代数；|U|=n 时该代数有 2ⁿ 个元素。
布尔代数常用定律（记忆用）
• 幂等 a∨a=a，a∧a=a；交换 / 结合 / 吸收 / 分配；
• 互补律 a∨a'=1，a∧a'=0；
• 同一/零律 a∨0=a，a∧1=a，a∨1=1，a∧0=0；
• De Morgan 律 (a∨b)'=a'∧b'，(a∧b)'=a'∨b'；双重否定 (a')'=a。

五、核心定理速记

定理 1　序与运算等价刻画
a≤b ⟺ a∧b=a ⟺ a∨b=b（格中比较两元素大小的等价写法）。
读法：a≤b = a 在 b 下方；a∧b=a = 往下找 a、b 的公共下界落在 a（a 已是 b 的下界）；a∨b=b = 往上找公共上界落在 b（b 已是 a 的上界）。三者同真同假。
例（菱形图）：(a,1) 可比较 → a≤1、a∧1=a、a∨1=1 全成立；(a,b) 不可比 → 三者全不成立。
定理 2　补元唯一性
在分配格中，每个元素的补元唯一。即若 a 有补元，则只有一个 a'。
定理 3　分配格消去律（证明题杀手锏）
若 a∧c = b∧c 且 a∨c = b∨c，则 a = b。
证：a = a∧(a∨c) = a∧(b∨c) = (a∧b)∨(a∧c) = (a∧b)∨(b∧c) = b∧(a∨c) = b∧(b∨c) = b。
定理 4　De Morgan 律与互补律
(a∨b)'=a'∧b'，(a∧b)'=a'∨b'；(a')'=a；a∨a'=1，a∧a'=0。
注意：仅在分配格（布尔代数）环境下自由套用，普通格不适用。

六、真题呼应

主线小结：偏序集（哈斯图）→ 格（任意二元有 ∨/∧，两种定义等价）→ 加性质得分配 / 有界 / 有补格 → 分配且有补 = 布尔代数（幂集格是标准模型）。
高频考点两类：分配格消去律（证明两元素相等）、De Morgan / 互补律（布尔化简）。配合 真题详解 中“分配格消去律”“布尔代数”大题一起刷。
