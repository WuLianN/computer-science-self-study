一、代数系统与二元运算（引子）

一个代数系统 = 集合 + 其上若干运算。本页只讨论一个或两个二元运算 *（对集合中任意两元素，* 唯一确定一个结果）。
封闭性：∀a,b∈G，a*b∈G。这是后面所有结构（半群、群、环）的共同起点——运算结果不能“跑出”集合。
下面从最弱的结构“半群”逐级加强条件，一直推到“群”，再扩展到“环 / 域”。

📌 符号约定（先认清运算符号，别默认是“乘/加”）

本页的 *、· 都是抽象二元运算的占位符，具体规则由题目定义，未必是日常的乘/加：
• *（单运算，群用）：可能被定义成 x*y=x+y+xy、矩阵乘法、置换复合等——先看清规则再套公理。
• + 与 ·（双运算，环/域用）：· 常直接写成 ab；(R,+) 是加法群（幺元记 0），(R,·) 再配上对加法的分配律。
• ℤₙ / “模 n”：ℤₙ = {0,1,…,n−1}（即除以 n 的全部余数）；凡出现 ℤ₆、ℤₙ 或“取模”，运算一律是先按普通方式算、再除以 n 取余数（像钟表绕圈）——正因如此才会冒出 2·3=0 这种“零因子”怪事。
• aᵏ：把 a 用同一运算重复 k 次（乘法群即 a·a·…·a；加法群里就是 k·a）。e＝幺元（环/域中加法幺元记 0、乘法幺元记 1）；a⁻¹＝a 的逆元。

二、半群 · 独异点 · 群（谱系与四大公理）

单运算结构从弱到强逐级加条件：
半群 封闭 + 结合律（只需两条）；
独异点 半群 + 存在 幺元 e；
群 独异点 + 每个元素都有逆元。
即 半群 ⊂ 独异点 ⊂ 群。群是这一谱系的最顶层，其四条公理如下：
① 封闭性：∀a,b∈G，有 a*b∈G；
② 结合律：∀a,b,c∈G，(a*b)*c = a*(b*c)；
③ 幺元 e：∃e∈G，∀a∈G，e*a = a*e = a；
④ 逆元：∀a∈G，∃a⁻¹∈G，使 a*a⁻¹ = a⁻¹*a = e。
若还满足 交换律（a*b=b*a），则称阿贝尔群（交换群）。自考常见群：整数加群 (Z,+)、模 n 加群 (Zₙ,+)、n 次单位根乘法群。
单运算谱系（逐级加条件）半群 ⊂ 独异点 ⊂ 群 ⊂ 阿贝尔群，每往右多一条公理

例：同一谱系的三级

• (Z,+)：封闭、结合、幺元 0、每元有逆元 → 群（阿贝尔群）。
• (N,+)（N={0,1,2,…}）：封闭、结合、幺元 0，但除 0 外无加法逆元 → 独异点，非群。
• (正偶数,×)：封闭、结合，但无幺元（1 不在集合内）→ 仅是半群。
真题呼应 · 幂等元只有 e：群中满足 x*x=x 的元素只有幺元 e。证明：x²=x 两边左乘 x⁻¹ 得 x=e。这条常出现在“元素性质”小题，记住即可秒答。

零元（吸收元）

双边零元 θ：∀a∈G，a*θ = θ*a = θ，即任何元素和 θ 运算都被“吸收”成 θ。
左零元 L：∀x，L*x = L；右零元 R：∀x，x*R = R。左右都满足时才是双边零元。
关键性质：若代数系统同时有幺元 e 与零元 θ，且 |G|>1，则 e ≠ θ（否则 e=θ ⇒ 任意 a = a*e = a*θ = θ，全集合塌成一点，矛盾）。所以 |G|>1 的群里不存在零元。
例：① (R,×) 中 0 是零元（a×0=0）；② 矩阵乘法中零矩阵是零元；③ (Z,+) 中没有零元——这里的 0 是幺元（a+0=a），并非吸收元。
2025年10月真题·第12题方向：常考“左零元 ≠ 右零元”——左零元只要求 L*x=L，右零元只要求 x*R=R，二者一般不相等，审题别搞反“左 / 右”方向（见 2025年10月 真题详解第12题）。

三、子群判定

子群：H⊆G，若 H 对 G 的同一运算 * 也构成群，记作 H≤G。
判定定理 1（最常用）：H≤G ⟺ H≠∅ 且 ∀a,b∈H，都有 a*b⁻¹∈H。
判定定理 2（有限情形）：若 H 是 G 的非空有限子集，且对 * 封闭，则 H 自动是子群（有限 ⟹ 每元素阶有限 ⟹ 逆元落在 H 内）。

例：整数加群 (Z,+) 的子群

取 H = 全体偶数。① H≠∅；② 任取 a,b∈H，a−b 仍是偶数 ∈H ⟹ 由判定定理 1，H≤(Z,+)。同理 n 的倍数集 nZ 都是 (Z,+) 的子群。
  1. 先证 H 非空（通常含幺元 e 即可，e∈H 很好用）。
  2. 任取 a,b∈H，算 a*b⁻¹，证明仍属于 H。
  3. 结论：满足判定定理 1 ⟹ H≤G。若 H 有限则只需验证封闭。

四、循环群与生成元

循环群：存在元素 g∈G，使 G = {gᵏ | k∈Z}（乘法记法）或 G={kg|k∈Z}（加法记法），记作 G=⟨g⟩，g 叫生成元。
无限循环群：≅ (Z,+)，生成元恰 2 个（±1，即 g 与 g⁻¹）。
n 阶循环群：≅ (Zₙ,+)，生成元个数 = φ(n)（欧拉函数，与 n 互质的个数）。
例：(Z₈,+) 的生成元为 1,3,5,7（φ(8)=4）。
关键性质：循环群的子群仍是循环群；n 阶循环群的子群与 n 的正因子一一对应。
易错：生成元个数别数错——(Zₙ,+) 是 φ(n) 个而不是 n 个；无限循环群只有 2 个生成元，不是 1 个。

五、群的阶与元素的阶

群的阶 |G|：群中元素个数。元素的阶 ord(a)：使 aᵏ = e 成立的最小正整数 k。
核心公式：ord(a) = n ⇒ ord(aᵏ) = n / gcd(n, k)（gcd 即“最大公约数”）。
⚠ 这里的 n 是元素 a 自己的阶 ord(a)，不一定是群的阶 |G|；只有“循环群 + a 是生成元”时 ord(a) 才等于 |G|，才能直接拿群阶当 n。

2026年4月真题 · 第12题这样用（一步到位）

题目是 10 阶循环群、a 是生成元 → a 自己的阶就是 10，直接套公式（k=4）：
ord(a⁴) = 10 / gcd(10, 4) = 10 / 2 = 5
一句话记法：aᵏ 的阶 = a 的阶 ÷（a 的阶与 k 的最大公约数）。gcd(10,4)=2 就是「10 和 4 的最大公约数」。考前只背这一句就够做题。

六、Cayley 表与常见小群速查

把有限群 G 的运算列成 |G|×|G| 的表，行头、列头为元素，格内为乘积。
拉丁方性质：每行、每列都是 G 中元素的一个排列（不重不漏）——这是判断“给定表是否为群”、以及填表的关键。
群表还可读结构：幺元所在行/列与表头同序；每行恰有一个 e（该行元素即该列元素的逆）。

七、陪集 · 正规子群 · 商群 · 拉格朗日定理

设 H≤G，a∈G，定义 左陪集 aH = {ah | h∈H}（右陪集 Ha 同理）。陪集把 G 划分成等大小、两两不交的块。
拉格朗日定理：|G| = [G:H] · |H|，即 子群阶 |H| 整除群阶 |G|，[G:H] 为 H 在 G 中的指数（陪集个数）。
推论：① 元素的阶整除群阶，且 a^|G| = e；② 素数阶群必为循环群（也是阿贝尔群）；③ p（素数）阶群只有自身与 {e} 两个子群。
正规子群 N ◁ G：∀a∈G，aN = Na（左右陪集相等）。交换群的每个子群都正规；指数为 2 的子群必正规。
商群 G/N：以 N 的所有陪集为元素、运算 (aN)(bN)=(ab)N 构成的群，|G/N|=[G:N]。
为什么要“正规”？只有 N 正规，陪集乘法 (aN)(bN)=(ab)N 才与代表元选取无关（运算良好定义），G/N 才能成群。判断商群是否成立，先问 N 是否正规。

陪集把群划分成等大的块 & 子群格

拉格朗日：|G| = [G:H]·|H| = 3×2 = 6三个陪集不重不漏地拼成整个 G
V₄ 的子群格（哈斯图）顶层 G、中层 3 个 2 阶子群、底层 {e}

例：|G|=6 能有什么子群？

由拉格朗日，|H| 只能整除 6，即 |H|∈{1,2,3,6}。因此 G 不可能有 4 阶或 5 阶子群——用“整除性”可快速排除错误选项，是判定题的常考切入点。

八、置换群 Sₙ 与循环分解

置换：集合到自身的双射。对称群 Sₙ：{1,…,n} 上全部置换关于“复合”成群，|Sₙ| = n!，幺元是恒等置换，运算一般不交换（n≥3）。
任一置换可唯一分解为不相交循环之积；置换的阶 = 各循环长度的最小公倍数 lcm。
对换（2-循环）：任何置换可写成对换之积；对换个数的奇偶性决定奇/偶置换；全体偶置换成 交错群 Aₙ，|Aₙ| = n!/2。

例：求置换的阶

置换 (1 2 3)(4 5)（一个 3-循环、一个 2-循环，不相交）的阶 = lcm(3,2) = 6。S₃ 中：恒等阶 1、三个对换阶 2、两个 3-循环阶 3，与“阶整除 |S₃|=6”吻合。

九、群同态与同构

同态 φ:G→G′：保持运算，φ(a*b) = φ(a)∘φ(b)。特别地 φ(e)=e′、φ(a⁻¹)=φ(a)⁻¹。
单同态= injective、满同态= surjective、双同态= 同构（记 G≅G′，结构完全相同）。
核 ker φ={a∈G | φ(a)=e′} 必是 G 的正规子群；像 φ(G) 是 G′ 的子群。
分类：无限循环群 ≅ (Z,+)；n 阶循环群 ≅ (Zₙ,+)。判断两群是否同构，先看阶、再看是否交换、元素阶的分布是否一致。

例：不同构的判定

(Z₄,+) 与 V₄ 都是 4 阶交换群，但 Z₄ 有 4 阶元（生成元），V₄ 元素阶只到 2 → 二者不同构。“元素阶的分布”是同构判断题的常用切入点。

十、环与域（双运算结构）

环与域都在集合上定义两个二元运算（通常记作 + 与 ·）。从弱到强：环 → 整环 → 域。
双运算谱系（环 → 域）环 ⊂ 交换幺环 ⊂ 整环 ⊂ 域；Z 只到整环（非零元无乘逆），Q/R/C 是域

① 环 (R,+,·)

① (R,+) 是阿贝尔群（幺元记 0）；
② (R,·) 是半群（封闭、结合）；
③ 乘法对加法满足分配律：a·(b+c)=a·b+a·c，(a+b)·c=a·c+b·c。

② 整环

先认符号 ℤ₆：ℤₙ 表示“除以 n 的全部余数”组成的集合，ℤ₆ = {0,1,2,3,4,5}；它的加/乘都按“先普通算、再除以 6 取余数”来（像钟表绕圈，6 就绕回 0）。
再拆“交换幺环”：它不是新怪物，而是在“环”上再叠两个条件——① 交换：乘法可交换（a·b = b·a）；② 幺：乘法有幺元（单位元）1 且 1≠0。
所以 整环 = 交换幺环 + 无零因子（层层加码：环 → 交换幺环 → 整环）。
零因子：两个都非零的元素，乘起来却等于 0。如 ℤ₆ 中 2·3 算出 6，而 6 除以 6 余 0 → 在 ℤ₆ 里就等于 0，所以 2、3 是零因子。
无零因子：没有上述怪事，即 a·b=0 必然 a=0 或 b=0（⇔ 消去律成立）。
例：整数环 (Z,+,×) 是整环；反例：ℤ₆ 虽是交换幺环，却有零因子 2·3=0 → 不是整环。

③ 域 (F,+,·)

两种等价定义（你书上用的是第②种）：
定义 A（本页）：在环基础上，(F\{0},·) 是阿贝尔群（F\{0} = 去掉 0 的非零元集合）。
定义 B（教材常见）：F 是整环，且 |F|≥2，且 ∀a∈F*（=F−{0}）都有 a⁻¹∈F。
等价性：整环已保证交换 / 幺元 / 无零因子；再加“每非零元可逆”，则 F\{0} 在乘法下自然成群（封闭由“无零因子”保证：a,b≠0 ⇒ a·b≠0）。你书上 F* = F−{0} 就是这里的 F\{0}。
为什么要求 |F|≥2？|F| 是 F 的元素个数，|F|≥2 即“F 至少含 2 个元素”。它用来排除只有一个元素、且 0=1 的退化平凡环——整环与域都要求 0≠1，所以必须 |F|≥2（F\{0} 才有意义）。

例

• (Z,+,×)：是整环（交换、有幺元 1、无零因子），但 2 在 Z 中无乘法逆元 → 整环，非域。
• (Q,+,×)、(R,+,×)、(C,+,×)：加减乘皆封闭、非零元皆可逆 → 域。
• 有限域 GF(p)（p 为素数，模 p 运算）：也是域。
易错：① 域必须先是个整环（交换幺环且无零因子），不是任意环加逆元就成域；② 环的乘法只要求半群；③ “域”要求非零元对乘法成群，教材记作 F* = F−{0}，所以 Z 不是域、一般矩阵环也不是域；④ 分配律是环区别于“单纯两个半群”的关键，审题看清“对哪个运算分配”。
