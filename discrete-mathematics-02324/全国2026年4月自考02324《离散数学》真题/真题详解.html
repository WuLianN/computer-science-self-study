一、单项选择题（每小题2分，共30分）

第1题点击展开答案
设 P：0.4 是有理数，Q：0.4 可写成分数。命题"0.4 是有理数当且仅当 0.4 可写成分数"可符号化为
A. P→QB. P↔QC. Q→PD. P∧Q
答案：B  P↔Q
解析："当且仅当"是双条件（等价）联结词的标准中文对应词，符号化为 P↔Q。
对照记忆：若P则Q → P→Q；只有P才Q → Q→P；P且Q → P∧Q；P或Q → P∨Q。
考点：联结词与自然语言对应 →
第2题点击展开答案
下列命题公式是重言式的是
A. P∧¬PB. (P∨Q)→QC. (P∧Q)→QD. P∧¬Q
答案：C
解析：重言式 = 永真式（任何赋值下真值都为 1）。
A：P∧¬P ≡ 0，是矛盾式。
B：P=1、Q=0 时 (1∨0)→0 = 0，非永真。
C：(P∧Q)→Q = ¬(P∧Q)∨Q = ¬P∨¬Q∨Q = ¬P∨1 ≡ 1，重言式（前件为真时 Q 必为真，属"化简律"）。
D：P=0 时为 0，非永真。
考点：重言式判定 →等值演算 →
第3题点击展开答案
设命题公式 A 为矛盾式且含有 4 个命题变元，则 A 的主合取范式含大项的个数为
A. 2B. 4C. 8D. 16
答案：D  16
解析：n 个变元共 2ⁿ 个大项（极大项）；主合取范式由"使公式为 0 的赋值"对应的大项合取而成。
A 为矛盾式 ⇒ 全部 2⁴ = 16 组赋值都使 A 为 0 ⇒ 主合取范式含 16 个大项。
对照记：矛盾式 → 主合取范式取满（2ⁿ 个大项）、主析取范式为空；重言式 → 主析取范式取满（2ⁿ 个小项）、主合取范式为空。
考点：主合取范式 →n 变元共 2ⁿ 个大项/小项
第4题点击展开答案
设论域为正整数集，真值为假的命题是
A. ∀x∀y(y>x²)B. ∀x∃y(y=x²)C. ∃x∃y(x²+y²=13)D. ∃x∀y(x²⩽y)
答案：A
解析：论域 = 正整数 {1,2,3,…}，逐项判断：
A（假）✔：取 x=2、y=1，y>x² 即 1>4 不成立 → 全称命题有反例即为假。
B（真）：对每个 x 取 y=x² 即可。
C（真）：取 x=2、y=3，4+9=13。
D（真）：取 x=1，则 x²=1 ⩽ 一切正整数 y。
💡 全称命题只需一个反例即为假；存在命题只需举出一个例子即为真。
考点：谓词命题真值 →量词含义
第5题点击展开答案
设 R(x)：x 是有理数，L(x,y)：x 大于 y。命题"没有最小的有理数"可符号化为
A. ∀x(R(x)→(∃y)(R(y)∧L(x,y)))B. ∃x(R(x)→(∀y)(R(y)∧L(x,y)))C. ∀x(R(x)∧(∃y)(R(y)∧L(x,y)))D. ∃x(R(x)→(∃y)(R(y)→L(x,y)))
答案：A
解析： 直译原命题："没有最小的有理数" = ¬∃x(R(x)∧∀y(R(y)→(y>x ∨ y=x)))。
等价的正面说法：任意一个有理数 x，都存在比它更小的有理数 y，即 ¬∃ 化 ∀ 后得 ∀x(R(x)→∃y(R(y)∧¬L(y,x)))；由实数三分律（x≠y 时 ¬(y>x) ⇔ x>y）得 ∀x(R(x)→∃y(R(y)∧L(x,y))) = 选项 A。

排除法更快："没有最小的"是对每个有理数的全称陈述，主量词必须是 ∀x 且"是有理数"作前件用 →，只可能形如 ∀x(R(x)→…) → 仅 A 符合。
C 写成 ∀x(R(x)∧…) 意为"宇宙万物都是有理数"，错；B、D 以 ∃x 开头，只说"存在某个有理数…"，语气太弱。
考点：命题的谓词符号化 →全称配 →、存在配 ∧三分律
第6题点击展开答案
设 X={a,b,c}，R={<a,a>,<c,c>,<b,b>,<b,c>}，则关系 R 在 X 上不是
A. 自反的B. 反对称的C. 传递的D. 对称的
答案：D（不对称）
解析：逐条检验（R 的有序对：a→a、c→c、b→b、b→c）
自反？✔需含 <a,a>、<b,b>、<c,c> —— 三者齐全 → 自反成立。
反对称？✔唯一的非对角对是 <b,c>，其反向 <c,b>∉R，无违反 → 反对称成立。
传递？✔需检验"两跳能否短路"：<b,c> 与 <c,c> 得 <b,c>∈R；<b,b> 与 <b,c> 得 <b,c>∈R；其余都是对角元素参与，均无违反 → 传递成立。
对称？✘<b,c>∈R 但 <c,b>∉R → 不对称。

故 R 满足自反、反对称、传递（事实上是一个偏序关系），唯独不满足对称性 → 选 D。
考点：关系性质判定 →对称：<x,y>∈R ⇒ <y,x>∈R
第7题点击展开答案
设 A={1,2,3}，B={a,b}，f={<1,a>,<2,a>,<3,b>}，则下列选项正确的是
A. f 是满射函数B. f 的逆是 B 到 A 的函数C. f 是单射函数D. f 不是 A 到 B 的函数
答案：A
解析：f(1)=a、f(2)=a、f(3)=b，A 中每个元素都有唯一像 → 是 A 到 B 的函数（排除 D）。
满射？B 中每个元素都有原像：a 的原像 {1,2}，b 的原像 {3} → 是满射 ✔
单射？1≠2 但 f(1)=f(2)=a → 不是单射（排除 C）
逆是函数？f⁻¹={<a,1>,<a,2>,<b,3>}，a 对应两个值 → 不是函数（排除 B）
💡 逆关系是函数 ⇔ 原函数是双射；本题 f 只满不单，故逆不是函数。
考点：单射/满射/双射 →
第8题点击展开答案
设 X={1,2,3}，Y={1,2,4}，则 X 到 Y 的单射函数的个数为
A. 2B. 4C. 6D. 27
答案：C  6
解析： 注意 X、Y 都是 3 元集（|X|=|Y|=3）。单射要求 X 中不同元素映到 Y 中不同元素，逐个安排：
  · 1 的像：Y 中任选 → 3 种； · 2 的像：不与前者相同 → 2 种； · 3 的像 → 1 种
共 3×2×1 = 3! = 6 种，即排列数 A(3,3)。
（当 |X|=|Y| 时，单射⇔满射⇔双射，故也等于双射个数 3! = 6。选项 D 的 27 = 3³ 是 X到Y 的全部函数个数，不是单射。）

通用公式（务必记）：|X|=m、|Y|=n 时
  · 函数总数： nᵐ； 
  · 单射总数：（m⩽n）A(n,m) = n!/(n−m)!，m>n 时为 0
  · 满射总数：（m⩾n）n!·S(m,n)（容斥），m<n 时为 0； 
  · 双射总数：m=n 时 m!，否则 0
考点：特殊函数计数 →单射数 = A(n,m)
第9题点击展开答案
若 R 是定义在集合 A 上的一个偏序关系，则 R 不满足
A. 对称性B. 传递性C. 自反性D. 反对称性
答案：A
解析：偏序关系的定义 = 自反 + 反对称 + 传递，三条都写进定义，唯独不要求对称性。
实例：整除关系是偏序，2|4 成立而 4|2 不成立 → 不对称。
对比记忆：等价关系 = 自反+对称+传递；偏序关系 = 自反+反对称+传递；严格偏序（如 <）= 反自反+反对称+传递。
考点：偏序关系定义 →等价关系 vs 偏序关系
第10题点击展开答案
设集合 A,B,C 满足 |A|=2，|B|=3，|C|=5，则 A×B×C 的元素个数是
A. 10B. 11C. 30D. 60
答案：C  30
解析：笛卡尔积元素个数 = 各集合基数相乘：|A×B×C| = 2×3×5 = 30。
元素形如 <a,b,c>：第一位 2 种、第二位 3 种、第三位 5 种（乘法原理）。A 的 10 = |B|×|C| 只是两两之积。
考点：笛卡尔积基数 →乘法原理
第11题点击展开答案
在自然数集 N 上，下列运算中满足结合律的是
A. x*y=2xB. x*y=yC. x*y=|x−y|+1D. x*y=2x+y
答案：B
解析：结合律要求 (x*y)*z = x*(y*z) 对一切 x,y,z 成立，逐个把两边展开：
A（x*y=2x）✘：此运算的意思是"结果 = 第一个量的 2 倍"。
  (x*y)*z = 2·(x*y) = 2·(2x) = 4x；  x*(y*z) = 2x（左量是 x）。两者不等（x≠0 时）→ 不结合。
B（x*y=y）✔：此运算"结果 = 第二个量"。
  (x*y)*z = y*z = z；  x*(y*z) = x*z = z。两边恒等 → 满足结合律。
C（x*y=|x−y|+1）✘：取 x=0,y=2,z=5：(0*2)*5 = 3*5 = |3−5|+1 = 3；0*(2*5) = 0*4 = |0−4|+1 = 5，不等 → 不结合。
D（x*y=2x+y）✘：(x*y)*z = 2(2x+y)+z = 4x+2y+z；x*(y*z) = 2x+(2y+z) = 2x+2y+z，x≠0 时不等 → 不结合。

💡 为什么 B 一定结合？x*y=y 叫"右投影"运算，(x*y)*z 与 x*(y*z) 都等于最右的 z。这类题只需把"两括号位置"分别代入定义式，看是否恒等。
考点：运算结合律验证 →套路：分别展开 (x*y)*z 与 x*(y*z)
第12题点击展开答案
已知 <G,*> 是 10 阶循环群，a 是群 G 的生成元，则元素 a⁴ 的阶是
A. 2B. 4C. 5D. 10
答案：C  5
解析：公式：n 阶循环群中 |aᵏ| = n / gcd(n,k)。
本题 |a⁴| = 10 / gcd(10,4) = 10 / 2 = 5。
验证：(a⁴)⁵ = a²⁰ = (a¹⁰)² = e；而 (a⁴)¹=a⁴、(a⁴)²=a⁸、(a⁴)³=a¹²=a²、(a⁴)⁴=a¹⁶=a⁶ 均不为 e → 最小正整数确为 5。
💡 连带结论：aᵏ 是生成元 ⇔ gcd(n,k)=1；10 阶循环群有 φ(10)=4 个生成元。
考点：循环群元素的阶 →|aᵏ| = n/gcd(n,k)
第13题点击展开答案
设 A 是由所有被 6 整除的整数组成的集合，则 A 在普通整数加法和普通整数乘法运算下构成的代数系统是
A. 偏序集B. 域C. 整环D. 环
答案：D  环
解析：A = 6Z = {…, −6, 0, 6, 12, …}。
是环：加法封闭（6m+6n=6(m+n)）、加法交换群（零元 0、负元 −6m 都在 A 中）、乘法封闭（6m·6n=6·(6mn)∈A）、乘法对加法分配 → 满足环的全部公理 ✔
不是整环：整环要求"交换环 + 有乘法单位元 e≠0 + 无零因子"。A 中没有单位元（单位元应是 1，而 1∉6Z）→ 排除 C。
不是域：域要求每个非零元有乘法逆元，6 的逆元 1/6 不是整数 → 排除 B。
偏序集只涉及集合与一个偏序关系，与两种运算无关 → 排除 A。
💡 层级链：半群 → 幺半群 → 群 → 环 → 整环（交换、含幺、无零因子）→ 除环 → 域（交换除环），每往上多一条要求。
考点：环/整环/域判定 →6Z 无单位元，故只是环
第14题点击展开答案
下列度数序列中，能构成简单连通无向图的是
A. {1,1,2,2,3}B. {1,1,2,2,4}C. {1,1,3,4,5}D. {0,1,2,3,4}
答案：B
解析：三重检验：① 度数和为偶数（握手定理）；② 每个度数 ⩽ n−1（简单图无环无重边）；③ 无孤立点且 m ⩾ n−1（才可能连通）。
A：和 = 9 为奇数 → 连无向图都不存在，排除。
C：含度数 5，而 n=5 时最大度只能是 4 → 不是简单图，排除。
D：含 0 度点（孤立点）→ 不可能连通，排除。
B ✔：和 = 10（偶数）→ m = 5 ⩾ n−1 = 4；最大度 4 = n−1 合法。构造：设 v₅ 度为 4，与其余 4 点各连一条边（此时序列变为 4,1,1,1,1），再在其余点中取两点补一条边 → 度数序列 {4,2,2,1,1} 即 B，且 v₅ 与所有点相邻故连通。
考点：度数序列可图化 →握手定理 + 最大度 n−1 + 连通条件
第15题点击展开答案
完全图 K₆ 通过删边得到一棵 6 阶树，需要删去的边数为
A. 6B. 10C. 11D. 12
答案：B  10
解析：K₆ 边数 = C(6,2) = 6×5/2 = 15；6 阶树边数 = n−1 = 5 → 需删去 15−5 = 10 条。
💡 一般公式：n 阶完全图取其生成树需删 C(n,2)−(n−1) = (n−1)(n−2)/2 条边；n=6 时 5×4/2 = 10。
考点：完全图边数 →树的边数 = n−1

二、填空题（每小题2分，共20分）

第16题点击展开答案
命题公式 (P∧(P→Q))→¬Q 是 ____ 式。
答案：可满足式（非永真也非永假）
解析：先化简前件：
P∧(P→Q) = P∧(¬P∨Q) = (P∧¬P)∨(P∧Q) = P∧Q（这就是"假言推理"有效式）
故原式 = (P∧Q)→¬Q = ¬(P∧Q)∨¬Q = ¬P∨¬Q∨¬Q = ¬P∨¬Q = ¬(P∧Q)
赋值 P=0,Q=0 时为 1；赋值 P=1,Q=1 时为 0 → 既非永真也非永假，是可满足式。
💡 填空答题词三选一：重言式（永真式）／矛盾式（永假式）／可满足式。
考点：公式类型判定 →等值演算化简
第17题点击展开答案
任意两个不同大项的析取式为 ____ 式。
答案：重言式（永真式）
解析： 大项（极大项）Mᵢ 的性质：n 个变元共 2ⁿ 个大项，每个大项恰在唯一一组赋值下为 0，其余赋值下都为 1；不同大项对应不同的那组"为 0"的赋值。
取 Mᵢ、Mⱼ（i≠j）：使 Mᵢ=0 的那组赋值必使 Mⱼ=1，反之亦真 → 任何赋值下二者至少一个为 1 → Mᵢ∨Mⱼ 恒为 1，是重言式。
对偶记：任意两个不同小项的合取式为矛盾式（小项只在唯一赋值下为 1，两个不同小项不可能同时为 1）。
考点：大项/小项性质 →不同大项之析取=永真
第18题点击展开答案
设 N(x) 表示"x 是自然数"，Q(x) 表示"x 是有理数"，命题"所有自然数都是有理数"使用量词可符号化为 ____ 。
答案：∀x(N(x)→Q(x))
解析："所有 A 都是 B" = 全称量词 + 蕴含：∀x(N(x)→Q(x))，读作"对任意 x，若 x 是自然数，则 x 是有理数"。
易错：写成 ∀x(N(x)∧Q(x)) 就变成"宇宙中一切东西既是自然数又是有理数"，显然不对。
口诀：全称搭 →（蕴含），存在搭 ∧（合取）。如"有些自然数是偶数" → ∃x(N(x)∧E(x))。
考点：谓词符号化 →∀用→、∃用∧
第19题点击展开答案
已知 S={n|1⩽n⩽100, n∈Z}，A={n|n−1 为 5 的倍数, n∈S}，则 |A| = ____ 。
答案：20
解析：n−1 是 5 的倍数 ⇔ n ≡ 1 (mod 5) ⇔ n = 5k+1。
由 1 ⩽ 5k+1 ⩽ 100 得 0 ⩽ k ⩽ 19.8 → k = 0,1,2,…,19，共 20 个。
列出验证：A = {1, 6, 11, 16, 21, 26, 31, 36, 41, 46, 51, 56, 61, 66, 71, 76, 81, 86, 91, 96} 共 20 个（下一个 101 已超出 S）。
💡 注意 1 本身符合条件（1−1=0 是 5 的倍数），别漏；项数 = ⌊(末项−首项)/公差⌋+1 = ⌊(96−1)/5⌋+1 = 20。
考点：集合描述法与计数 →同余类计数
第20题点击展开答案
设集合 A={1,2,3,4}，B={a,b,c}，C={x,y}，从 A 到 B 的关系 R₁ 与从 B 到 C 的关系 R₂ 分别为 R₁={<1,a>,<2,a>,<3,c>,<4,b>}，R₂={<a,x>,<a,y>,<b,y>}，则 R₁∘R₂ = ____ 。
答案：{<1,x>,<1,y>,<2,x>,<2,y>,<4,y>}（共 5 个有序对，3 无像）
解析：因 R₁⊆A×B、R₂⊆B×C，此处记号表示右复合（先走 R₁ 再走 R₂）：
R₁∘R₂ = {<p,r> | ∃q(<p,q>∈R₁ ∧ <q,r>∈R₂)}　（p=起点、q=中转点、r=终点；故意用 p/q/r 避开题里的 a,b,c、x,y，防撞名）
逐个起点"走两步"（R₁：1→a、2→a、3→c、4→b；R₂：a→x、a→y、b→y）：
  · 1→a→x ⇒ <1,x>；1→a→y ⇒ <1,y>
  · 2→a→x ⇒ <2,x>；2→a→y ⇒ <2,y>
  · 3→c，而 c 在 R₂ 中无出边 ⇒ 3 不产生任何有序对
  · 4→b→y ⇒ <4,y>
💡 画箭头图、"从每个起点走两步"是最不易错的方法。
考点：关系的复合 →
第21题点击展开答案
设 A={0,1}，则 A² = ____ 。
答案：{<0,0>,<0,1>,<1,0>,<1,1>}（即 A×A）
解析：A² 是笛卡尔积 A×A 的简写，元素是有序对（不是集合的集合）：A² = {<0,0>, <0,1>, <1,0>, <1,1>}，|A²| = 2² = 4。

第22题点击展开答案
已知 <G,*> 是群，且 a,b∈G，a*x = b，则 x = ____ 。
答案：a⁻¹*b
先补知识点（这步的依据）：
  · 单位元 e：和任何元素运算都不改变它，e*x = x*e = x。
  · 逆元 a⁻¹：群里每个元素都有它，专门用来“抵消”a 自己，a⁻¹*a = a*a⁻¹ = e。
  · 为什么要乘 a⁻¹：x 被左边的 a 缠住，要解出 x 就得把 a 消掉。群里没有“除法”，“消掉 a”就靠乘它的逆元 a⁻¹——和普通代数里 3x=b → x=b÷3=3⁻¹·b 是一个道理。
解答（两边同「左乘」a⁻¹，一步一行）：
原式a*x = b
① 两边左乘 a⁻¹a⁻¹*(a*x) = a⁻¹*b
② 结合律挪括号(a⁻¹*a)*x = a⁻¹*b
③ 逆元 a⁻¹*a = ee*x = a⁻¹*b
④ 单位元 e*x = xx = a⁻¹*b ✓
方向别搞反：若方程是 x*a = b，则应右乘 a⁻¹，解为 x = b*a⁻¹。群不必交换，a⁻¹*b 与 b*a⁻¹ 一般不等。
这正是群中“消去律/除法唯一可解”：a*x=b 与 x*a=b 都有唯一解。
考点：群中方程求解 →左乘逆元解 a*x=b
第23题点击展开答案
无向图 G 是欧拉图的充分必要条件是 G 是 ____ 。
答案：连通的且所有结点度数均为偶数
解析： 欧拉图（存在经过每条边恰好一次且回到起点的欧拉回路）的充要条件：G 连通 ∧ 每个结点度数为偶数。
对比：欧拉通路（不要求回起点）充要条件：G 连通 ∧ 奇度结点个数为 0 或 2（恰为 2 时，起点与终点就是这两个奇度点）。

充分性构造：从某点不断走未走过的边，因度数均偶必能回到起点；若未覆盖全部边，由连通性可找到与已走回路共点的另一子回路，"环套环"拼接即可扩大。
考点：欧拉图判定定理 →连通 + 全偶度

质数（又叫素数） = 大于 1 的自然数中，只能被 1 和它本身整除的数（除了 1 和自身，再没有别的正因数）。
常用小质数：2、3、5、7、11、13、17、19…（2 是唯一的偶质数）。⚠ 1 不是质数（也不算合数）；像 4=2×2、9=3×3、15=3×5 这种能被拆开的是合数。

第33题点击展开答案
设 G 为连通简单平面图，G 的顶点数为 n，边数为 m，且 G 的每个面至少由 3 条边围成。证明：m ⩽ 3n−6。
答案：用欧拉公式 + 面的次数关系证明
证明：设 G 有 f 个面（包括一个无界面）。
① 每个面至少由 3 条边围成，故一切面的次数之和 ⩾ 3f；又平面图中每条边至多被 2 个面共用（割边只计 1 次），故面的次数之和 = 2m。因此
    3f ⩽ 2m　⟹　f ⩽ 2m/3
② 由 欧拉公式（连通平面图）：n − m + f = 2 ⟹ f = 2 − n + m。
代入①：2 − n + m ⩽ 2m/3，两边乘 3：
    6 − 3n + 3m ⩽ 2m　⟹　m ⩽ 3n − 6。∎
💡 应用：此不等式是平面图的必要条件，常用反证法判非平面图。如 K₅：n=5、m=10，而 3n−6=9，10>9 → 非平面。
考点：平面图欧拉公式 →m⩽3n−6
第34题点击展开答案
设 f 是从集合 A 到集合 B 的一个函数，定义 A 上的关系 R：<a,b>∈R 当且仅当 f(a)=f(b)。证明：R 是 A 上的一个等价关系。
答案：自反 + 对称 + 传递，三条逐一证明

对称：若 <a,b>∈R，则 f(a)=f(b)，等式对称得 f(b)=f(a) ⟹ <b,a>∈R。✔
传递：若 <a,b>∈R 且 <b,c>∈R，则 f(a)=f(b) 且 f(b)=f(c)，由等式传递性 f(a)=f(c) ⟹ <a,c>∈R。✔
三条均满足，故 R 是 A 上的等价关系。∎
💡 这个 R 就是“同像关系”：把 f 值相同的元素归为一类，恰好构成 A 的一个划分（等价类 = f 在各像上的原像）。
