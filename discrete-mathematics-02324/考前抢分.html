三、🟡 高频（2/3 套出现）——有余力再抓

这些不是每年必考，但近三套出现两次，投入产出比高。

🌴 二叉树三种遍历

先根根左右 / 中根左根右 / 后根左右根——"根"在第几位就是第几种。出现：25.10-32、26.4-32。▶ 遍历动画

💎 哈斯图 + 极大/极小元

最爱考"整除关系"。画分层图，最上=极大、最下=极小；子集 B 的极大极小在 B 内看。出现：25.10-30、26.4-28。

🧮 映射计数

A→B 函数 |B|^|A|；单射 A(n,m)=n!/(n−m)!（|A|=m→|B|=n，需 n≥m）；双射 n!；A 上二元关系 2^(n²)；等价关系数=划分数(Bell)。出现：26.4-8、25.4-11。

🌀 循环群元素的阶

|aᵏ| = n / gcd(n,k)；aᵏ 是生成元 ⇔ gcd(n,k)=1；生成元个数 φ(n)。出现：26.4-12、25.4-21。

🕸 完全图 / 生成树计数

Kₙ 边数 n(n−1)/2；Kₙ 生成树数 n^(n−2)(Cayley，🌱超纲了解即可)；K₃,₃ 边数 3×3=9。出现：26.4-15/25、25.4-8。

🚚 欧拉图充要条件

欧拉图 ⇔ 连通 + 所有顶点次数为偶；半欧拉(有欧拉通路) ⇔ 恰 2 个奇点。出现：填空 25.4-23、26.4-23。

四、📌 6 个"闭眼默写"模板（配三套真题实解）

每类给"套路 + 一道真考过的题 + 可照抄的步骤"。练熟这 6 个 ≈ 30 分到手。

1主析取 / 主合取范式

套路：主析取取真值表为 1 的行→写极小项(变量=1 记原形、=0 记否定，用 ∧ 连)→行间用 ∨；主合取取为 0 的行→写大项(变量=0 记原形、=1 记否定，用 ∨ 连)→行间用 ∧。
真题 2026.4 第26题：求 (P→Q)→(Q→R) 的主合取范式。
▼ 展开可抄步骤
  1. A→B 为 0 ⟺ A=1 且 B=0。要整体为 0：需 Q→R=0 ⟺ Q=1,R=0；此时 P→Q=P→1=1 恒成立，P 任取。
  2. 为 0 的赋值：010(=M₂)、110(=M₆)。
  3. 大项（0 写原形、1 写否定）：M₂=P∨¬Q∨R，M₆=¬P∨¬Q∨R。
  4. 主合取范式 = (P∨¬Q∨R) ∧ (¬P∨¬Q∨R)。

2Kruskal 最小生成树（第31题·年年考）

套路：① 边按权升序排 → ② 从最小开始，不构成回路就选 → ③ 选满 n−1 条停 → ④ 报权之和 W。▶ 看动画
真题 2025.10 第31题：边权 (a,b)=1,(b,c)=2,(a,c)=3,(a,e)=4,(c,e)=5,(c,d)=6,(e,d)=7，求最小生成树的权。
▼ 展开可抄步骤
  1. 排序后依次试：1 选 a–b ✔；2 选 b–c ✔；3 (a,c) 与 a–b–c 成圈 ✘；4 选 a–e ✔；5 (c,e) 成圈 ✘；6 选 c–d ✔（5 点已 4 边，结束）。
  2. 边集 {a–b, b–c, a–e, c–d}，W = 1+2+4+6 = 13。
💡 判圈口诀：若新边两端已在同一棵连通块里就成圈、舍弃；否则合并两块、入选。

3三种闭包 r / s / t（关系大题）

公式：自反 r(R)=R∪IA（补所有自环）；对称 s(R)=R∪R⁻¹（补所有反向边）；传递 t(R)=R∪R²∪…∪Rⁿ（n=|A|，走两步能到的补上）。
真题 2025.10 第26题：A={1,2,3}，R={⟨1,1⟩,⟨1,3⟩,⟨2,2⟩,⟨3,2⟩}，求 r,s,t。
▼ 展开可抄步骤
  1. r(R)：补 IA={⟨1,1⟩,⟨2,2⟩,⟨3,3⟩} → 结果多 ⟨3,3⟩。
  2. s(R)：R⁻¹={⟨1,1⟩,⟨3,1⟩,⟨2,2⟩,⟨2,3⟩} → 并入即补 ⟨3,1⟩,⟨2,3⟩。
  3. 传递：1→3→2 得 ⟨1,2⟩；R²={⟨1,1⟩,⟨1,2⟩,⟨1,3⟩,⟨2,2⟩,⟨3,2⟩}，已闭合 → t(R)=该集合。

4握手定理 / 度数序列（选择题送分）

核心：∑deg(v) = 2|E|（度和必为偶数）→ 反推边数或顶点数。判度数序列能否成图：度和为偶数才行（奇数个数必为偶数个）。6 阶简单图最大度 = 5。
典型："每个顶点度数为 2、共 7 个顶点"→ ∑=14 → |E|=7。"12 条边"→ ∑=24。

5循环群元素的阶（填空/单选）

公式：|aᵏ| = n / gcd(n,k)；aᵏ 是生成元 ⇔ gcd(n,k)=1；n 阶循环群生成元个数 = φ(n)。
真题 2026.4 第12题：10 阶循环群，a 为生成元，求 |a⁴|。
▼ 展开可抄步骤
  1. |a⁴| = 10 / gcd(10,4) = 10 / 2 = 5（选 C）。

6CP 规则推理证明（证明大题常见套路 · 2025.4、2026.4 考于第35题；2025.10 该位为图论证明）

套路：结论是"蕴含式 R→S"时，把 R 当附加前提，只用它推出 S，最后写"由 CP 得 R→S"。
真题 2026.4 第35题（下方步骤即对应本套）：前提 P→¬Q、P∧R、Q∨S；结论 R→S。同型题 · 2025.4 第35题（前提 P∨Q、¬P∨¬R、Q→S，亦用 CP）；2025.10 未考。

五、🎯 考场抢分策略（会做先放，不会做会蒙）

  • 先扫简答 26–32：Kruskal、主范式、闭包、二叉树遍历几乎必出现且最稳，先把这 30 分捞到手再回头做选填。
  • 大题写步骤分：即使最终结果算错，"排序/取真值/补边"的过程写全也能拿大部分分，别空着。
  • 选择题蒙法：关系性质、重言矛盾式、握手定理是纯概念，先排除明显错的；实在不会，"个数型"优先想 2^n / n^m / n(n−1)/2 这几个公式套。
  • 证明不会也别空：写出"前提引入 → 某律 → 结论"三五行框架，判卷按步给分。
  • 时间分配：选填 ≤35 分钟，简答 40 分钟，证明 20 分钟，留 15 分钟检查简答。
  • 目标管理：简答 30 + 选填 25 + 证明框架 6–10 ≈ 61–65，够及格，不必追求高分题。
