课程与考核规则

课程：13004《数据结构与算法》实践考核。原文要求已学习数据结构与算法、C 语言程序设计理论课。

形式：上机考核，120 分钟；可携带教材。满分 100 分，五级评分制，60 分起合格。

环境或工具：Windows 7 及以上、Visual C++ 6.0。

教材：《数据结构与算法》，辛运帏、陈朔鹰，机械工业出版社，2024 年版。

五级划分：0–59 分不合格、60–69 分合格、70–79 分中等、80–89 分良好、90–100 分优秀。

核对位置：原文 PDF 第 2 页 ↗。软件和携带规则仍以当期执行要求为准。

考核范围

以下为原文第 2 页归纳，不据样例推定固定题量或分值。

模块要求归纳训练对应（本站建议）
链表实现链表基本操作，并用基本操作解决应用问题。本课图书管理参考程序：建表、遍历、插入、查找。
循环队列掌握存储特点并实现基本操作。补练入队、出队、判空判满与首尾下标回绕。
数组与广义表课程内容列数组与广义表基本操作；考核范围具体写二维数组存储、按下标访问，并输出入口到出口的所有路径。数组索引和路径问题分别练习；原文未进一步说明路径问题的具体模型。
二叉树、堆、哈夫曼课程内容含二叉树算法、堆基本操作、哈夫曼树及编码；范围强调二叉链表与哈夫曼算法。补遍历、堆调整、构树与编码，不把内容项误作固定题量。
图邻接矩阵、邻接表、边集三种存储与基本算法。补存储转换与遍历，明确访问标记。
排序实现基本排序，比较关键字比较次数和元素移动次数。对相同输入做计数；先说明移动次数如何统计。

原文题型举例及说明

原文要求使用链式存储保存图书编号、名称、价格；通过函数实现创建初始链表、显示全部图书、指定位置插入、按图书编号查找，并在主函数菜单中调用。

结构体缺项：原文第 3 页的 struct node 仅列三个业务字段，没有链接指针。本站参考实现补入 struct node *next;，并说明位置编号、重复编号和输入格式均为练习约定；这些补充不属于学校原文。

原题位置：原文 PDF 第 3 页 ↗；实现与解析另见本站自编参考练习。

训练与验收建议

先复习 C 结构体、指针和动态内存，再把建表、遍历、插入、查找拆成函数。完成图书管理后，补循环队列、树、图与排序比较，不能只练大纲中的一个样例。

  1. 写明输入、前提和预期结果，按功能拆分任务。
  2. 覆盖正常、边界和异常情况；解释出现该结果的原因。
  3. 整理源文件或工程、运行结果或截图，并确认保存位置与命名。
  4. 核对当期要求后，完成一次 120 分钟独立模拟。

本节为学习建议，不能代替学校当期交付和评分要求。
