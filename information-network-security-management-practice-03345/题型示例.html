凯撒密码：代码与测试

映射约定：仅循环移动 ASCII 英文字母，大小写分别保留；数字、标点、中文不变。密钥对 26 取模，支持负数；解密使用相反偏移量。

知识点：凯撒密码按固定偏移替换字母，属于替代密码，不是置换字符位置。大纲范围还包括置换密码，但附录此处写的是凯撒密码。此古典算法仅用于教学，不能用于实际敏感信息保护。

下载 caesar.py；只用 Python 标准库，无需额外安装依赖。

python caesar.py enc 3 "Attack at 9:00!"
# Dwwdfn dw 9:00!
python caesar.py dec 3 "Dwwdfn dw 9:00!"
# Attack at 9:00!
python caesar.py enc -1 "Abc XYZ"
# Zab WXY
"""Self-authored Caesar cipher exercise, not an official answer.

Only ASCII letters rotate; case, digits, punctuation and other text persist.
This classical cipher is for learning, not for protecting real information.
"""
import argparse
import string


def caesar(text: str, shift: int) -> str:
    shift %= 26
    source = string.ascii_lowercase + string.ascii_uppercase
    lower = string.ascii_lowercase
    upper = string.ascii_uppercase
    target = lower[shift:] + lower[:shift] + upper[shift:] + upper[:shift]
    return text.translate(str.maketrans(source, target))


def main() -> None:
    parser = argparse.ArgumentParser(description=__doc__)
    parser.add_argument("mode", choices=("enc", "dec"))
    parser.add_argument("shift", type=int)
    parser.add_argument("text")
    args = parser.parse_args()
    shift = args.shift if args.mode == "enc" else -args.shift
    print(caesar(args.text, shift))


if __name__ == "__main__":
    main()

自测包括空串、0 / 26 / 29 / -1 偏移、大小写边界、中文和标点；应满足 caesar(caesar(text, k), -k) == text。

PGP：加密传递与解密核验

  1. 准备密钥：发送者 A、接收者 B 分别创建实验密钥对；仅交换公钥，核对指纹后再使用。私钥和口令由各自保管。
  2. 准备附件：将凯撒偏移量保存为 key.txt（本例内容为 3），而非只保存凯撒密文。密文 cipher.txt 另交给 B，供最终复原验证；这是本例的实验安排。
  3. 加密：在 PGP Desktop 的文件加密 / PGP Zip 流程中选择 key.txt，使用接收者 B 的公钥加密。若练签名，另用发送者 A 的私钥签名；签名属于本站扩展练习。
  4. 发送与接收：在实验邮箱中把实际加密产物作为附件发送，记录所用接收者密钥。这里练“文件加密后发邮件”；自动邮件插件的界面和设置另按考场版本核对。
  5. 核验：B 用自己的私钥解密，所得偏移量应仍为 3；若附签名，再用 A 的公钥验证。用收到的偏移量对 cipher.txt 做凯撒解密，应恢复自拟明文。另用不匹配的密钥尝试，应无法完成相应解密或验签。

保留结果：密钥标识和指纹核对记录、加密附件、收件记录、解密得到的偏移量与最终复原文本；截图不要包含私钥或口令。

流程参考 Broadcom 官方 PGP 文件加密说明 ↗。不同版本菜单有差异，本文未在 PGP Desktop 中实机复测。

防火墙：限制指定程序出站

原题要求限制相关软件访问外网，因此核心是出站规则 + 指定可执行文件。本例选择阻止该程序全部出站流量，范围比“仅外网”更宽；若题目还要求保留内网访问，必须按题给网段限定远程地址，不能直接照抄。

  1. 在实验机先确认目标程序能正常连接测试服务，并记下真正发起连接的 EXE 路径；避免把启动器当成网络进程。
  2. 打开 Windows Defender 防火墙“高级安全” → 出站规则 → 新建规则 → 程序，选择该 EXE → 阻止连接 → 选择实验网络配置文件 → 命名。保留防火墙开启。
  3. 断开旧会话并让该程序发起新连接，验证被阻止；换一个未被匹配的程序连接同一服务，验证仍正常。仅看到规则已创建还不能说明效果正确。
  4. 保存规则方向、程序路径、配置文件和连接结果。实验结束后仅删除自己创建的规则，再次连接以验证恢复。

现代 Windows 的 PowerShell 等价参考如下；路径为需替换的实验示意值。原文未规定 Windows 版本；若考场较旧、没有 NetSecurity 模块，使用界面按要求操作。

# On a Windows lab machine, use an elevated PowerShell.
# Replace the path with the absolute path of the lab test program.
$programPath = (Resolve-Path -LiteralPath 'C:\Lab\TestClient.exe' -ErrorAction Stop).Path
$ruleName = 'CS03345-Lab-Block-TestClient'
New-NetFirewallRule -Name $ruleName -DisplayName $ruleName `
    -Direction Outbound -Program $programPath -Action Block -Profile Any
Get-NetFirewallRule -Name $ruleName
Get-NetFirewallRule -Name $ruleName | Get-NetFirewallApplicationFilter
# After saving evidence, remove ONLY this lab rule:
# Remove-NetFirewallRule -Name $ruleName

参数依据 Microsoft New-NetFirewallRule 文档 ↗。此命令仅供阅读和实验，本站未在当前主机创建或修改任何防火墙规则。

MySQL：分角色授权

-- Self-authored lab, not an official answer. Requires MySQL 8.0+.
-- Run once as a lab administrator on an isolated local MySQL instance.
-- Replace BOTH password placeholders before execution.
-- Existing objects with these names intentionally cause an error.
CREATE DATABASE cs03345_lab;
CREATE TABLE cs03345_lab.staff (
    id INT PRIMARY KEY,
    name VARCHAR(40) NOT NULL
);
INSERT INTO cs03345_lab.staff VALUES (1, 'Alice');

CREATE ROLE 'cs03345_reader'@'localhost',
            'cs03345_editor'@'localhost';
GRANT SELECT ON cs03345_lab.staff
    TO 'cs03345_reader'@'localhost';
GRANT SELECT, INSERT, UPDATE ON cs03345_lab.staff
    TO 'cs03345_editor'@'localhost';

CREATE USER 'cs03345_read'@'localhost'
    IDENTIFIED BY 'REPLACE_WITH_UNIQUE_READER_LAB_PASSWORD';
CREATE USER 'cs03345_edit'@'localhost'
    IDENTIFIED BY 'REPLACE_WITH_UNIQUE_EDITOR_LAB_PASSWORD';
GRANT 'cs03345_reader'@'localhost'
    TO 'cs03345_read'@'localhost';
GRANT 'cs03345_editor'@'localhost'
    TO 'cs03345_edit'@'localhost';
SET DEFAULT ROLE 'cs03345_reader'@'localhost'
    TO 'cs03345_read'@'localhost';
SET DEFAULT ROLE 'cs03345_editor'@'localhost'
    TO 'cs03345_edit'@'localhost';

SHOW GRANTS FOR 'cs03345_read'@'localhost'
    USING 'cs03345_reader'@'localhost';
SHOW GRANTS FOR 'cs03345_edit'@'localhost'
    USING 'cs03345_editor'@'localhost';

必须分别登录，不能只看管理员窗口

登录命令不把口令直接写在命令行；-p 后交互输入。localhost 账户与其他来源账户不能混为一谈。

mysql -u cs03345_read -p
# Then repeat in another session:
mysql -u cs03345_edit -p

每个实验用户先单独执行以下语句，确认实际身份和活动角色。新会话应启用其默认角色。

SELECT CURRENT_USER(), CURRENT_ROLE();
SELECT * FROM cs03345_lab.staff;
