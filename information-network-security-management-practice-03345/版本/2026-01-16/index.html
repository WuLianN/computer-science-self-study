课程与考核规则

形式：计算机机房现场上机考核，120 分钟；开卷，可携带教材。本 PDF 未单独列出分值和等级划分，不沿用其他课程的评分细则。

环境或工具：Snort、PGP Desktop、MySQL；附录另要求使用 Windows 自带防火墙。

教材：《网络空间信息安全》，苏永红、蒋天发主编，电子工业出版社，2022 年第 2 版。

原文题型举例及说明

原文“企业安全管理与实现”要求：用任意语言实现凯撒密码加解密，以偏移量为密钥；借助 PGP 将上面设置的偏移量通过邮件发送；用 Windows 自带防火墙限制相关软件访问外网；在 MySQL 中实现不同角色的授权管理。

本站用 Python 实现凯撒加解密，另列字符范围等练习约定，并给出 PGP、防火墙与 MySQL 的操作及验收清单。PGP 要传递的是偏移量（密钥），不要误写成只发送凯撒密文。样例没有完整覆盖 SSL、入侵检测和备份恢复，这些内容仍需按范围另练。

原题位置：原文 PDF 第 6 页 ↗；实现与解析另见本站自编参考练习。

训练与验收建议

先运行凯撒密码小程序，再按“配置前状态 → 操作 → 正向验证 → 反向验证 → 保存证据”完成 PGP、防火墙和数据库授权。综合题以操作结果为核心；SSL、Snort、备份恢复仍在范围内，需要另做专项训练。

  1. 写明输入、前提和预期结果，按功能拆分任务。
  2. 覆盖正常、边界和异常情况；解释出现该结果的原因。
  3. 整理源文件或工程、运行结果或截图，并确认保存位置与命名。
  4. 核对当期要求后，完成一次 120 分钟独立模拟。
