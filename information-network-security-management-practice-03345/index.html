课程与考核概览

课程身份：03345《信息与网络安全管理》实践课程，按独立科目记录。来源为华南理工大学继续教育学院；其他主考院校须另查本校要求。

本版范围：对称密码与 SSL、PGP 邮件安全、防火墙与入侵防御、数据库访问控制及备份恢复。

原文考核：计算机机房现场上机考核，120 分钟；开卷，可携带教材。本 PDF 未单独列出分值和等级划分，不沿用其他课程的评分细则。

原文工具：Snort、PGP Desktop、MySQL；附录另要求使用 Windows 自带防火墙。这是该版本的记录，当期是否沿用须另行核对。

原文教材：《网络空间信息安全》，苏永红、蒋天发主编，电子工业出版社，2022 年第 2 版。

先练什么

先运行凯撒密码小程序，再按“配置前状态 → 操作 → 正向验证 → 反向验证 → 保存证据”完成 PGP、防火墙和数据库授权。综合题以操作结果为核心；SSL、Snort、备份恢复仍在范围内，需要另做专项训练。

大纲样例：企业安全管理与实现：凯撒加密、PGP 发送、软件外网访问限制、MySQL 分角色授权。

先读本版范围，再做本站自编参考练习。本站补充的代码、业务假设、数据、图和验收标准均为学习资料，非官方答案。
