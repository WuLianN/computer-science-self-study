一、单项选择题（每小题2分，共30分）

第1题点击展开答案
关于 C 程序组成特点描述正确的是
A. C程序中主函数位置任意B. C程序中必须有预处理命令C. C程序中预处理命令通常放在主函数内的开始位置D. C程序每一条语句后面都以分号作为语句的结束，包括预处理命令
答案：A
解析：程序执行总从 main 开始、在 main 结束，主函数与其他函数在源文件中的位置可任意，其他函数通过调用语句执行（教材 P51）。B：预处理命令非必需；C：预处理命令写在函数外、不能放进 main 体内；D：预处理命令不以分号结尾。
考点：C程序结构与预处理
第2题点击展开答案
不属于转义字符常量的是
A. '\n'B. '\p'C. '\b'D. '\101'
答案：B
解析：\n(换行)、\b(退格)、\101(八进制转义=字符A) 均合法；\p 不是 C 定义的转义序列（教材 P62）。
考点：转义字符常量
第3题点击展开答案
设 float a;，以下赋值语句不正确的是
A. a=789.456;B. a=-789.456;C. a=3.14e2.6;D. a=1.89e2;
答案：C
解析：科学计数法 e 后的指数必须是整数。3.14e2.6 指数为小数，语法错误。D 的 1.89e2=189 合法。
考点：实型常量（指数形式）
第4题点击展开答案
下列选项中比 "++" 运算符优先级高的是
A. [ ]B. <C. %D. %=
答案：A
解析：优先级 [] ()（最高）> ++ -- > * / % > < > 赋值 %=。只有下标 [] 高于 ++。
考点：运算符优先级
第5题点击展开答案
设 int i=3;，以下表达式正确的是
A. i+3++B. --(i+3)C. ++(i++)D. i+3
答案：D
解析：++/-- 只能作用于左值（变量），不能作用于常量或表达式的值。A 对常量 3 自增、B/C 对表达式值自减/自增，均非法。D 是普通算术表达式，合法。
考点：自增自减与左值
第6题点击展开答案
根据 C 语言的运算规则，正确的除法运算是
A. -5/3=1B. 5/2.0=2C. 5.0/2=2D. 5/2.0=2.5
答案：D
解析：整数相除向零取整：-5/3=-1（A 错）。只要有浮点数即按浮点运算：5/2.0=2.5、5.0/2=2.5（B、C 错，D 对）。
考点：整除与类型提升
第7题点击展开答案
C 程序中外部变量的作用域是
A. 整个源程序文件B. 从文件开头开始到定义外部变量的位置结束C. 从定义外部变量的位置开始到第一个相邻函数结束D. 从定义外部变量的位置开始到其所在的源程序文件结束
答案：D
解析：外部（全局）变量在函数外定义，作用域从定义位置起，到本源程序文件结束（教材 P198）。定义之前不可见。
考点：变量作用域
第8题点击展开答案
关于递归函数描述正确的是
A. 允许递归定义函数，也允许递归调用函数B. 允许递归定义函数，不允许递归调用函数C. 不允许递归定义函数，允许递归调用函数D. 不允许递归定义函数，也不允许递归调用函数
答案：C
解析：C 语言不允许函数的（嵌套/递归）定义——不能在函数体内再定义一个函数；但允许递归调用（函数自己调用自己，如阶乘）。故选 C。
⚠ 别被"递归定义"字面迷惑：这里指"定义函数"这件事不能嵌套进行。
考点：递归 vs 嵌套定义

用来将全局变量作用域限制在本文件的关键字是
A. autoB. constC. staticD. extern
答案：C
解析：用 static 修饰的全局变量作用域被限制在本文件（内部变量），其他文件无法引用（教材 P196）。extern 作用相反。
考点：static 限定作用域
第10题点击展开答案

第11题点击展开答案
指向字符型数据的指针数组定义是

答案：C

第12题点击展开答案

三、程序分析题（每小题4分，共16分）

第26题点击展开答案
阅读下列程序，写出输出结果。
#include <stdio.h>
int main()
{   int x=1,y=9,z;
    switch(x<y && --x)
    {   case 0: x=4;    printf("%d",x);
        case 1: x+=4;   printf("%2d",x);
        case 2: --x;    printf("%2d",x); break;
        default: x%=3;  printf("%2d\n",x);
    }
    return 0;
}
答案：4 8 7
解析：求 x<y && --x：先 1<9=1（真），再算 --x→x=0，值为0，故 1 && 0 = 0 → 匹配 case 0。
① case0：x=4，printf("%d",4)→4（无 break 继续下落）
② case1：x+=4→8，printf("%2d",8)→␣8（宽度2，前补空格）
③ case2：--x→7，printf("%2d",7)→␣7，遇 break 退出。
最终连续输出：4 8 7（4、空格8、空格7）。default 未执行。
考点：switch 下落 · 逻辑与短路 · %2d 宽度
第27题点击展开答案
阅读下列程序，写出输出结果。
#include <stdio.h>
int main()
{   int i,j,m=10;
    for(i=1;i<3;i++)
    {   for(j=1;j<=2;j++)
        {   m--; }
        m--;
    }
    printf("%d",m);
    return 0;
}
答案：4
解析：外层 i=1、2 共 2 轮。每轮：内层 j=1、2 执行 2 次 m--，内层结束后再 1 次 m--，即每轮减 3。两轮共减 6。m = 10 − 6 = 4。
考点：嵌套循环计数
第28题点击展开答案
阅读下列程序，写出输出结果。
#include <stdio.h>
struct keyword
{   char key[20];
    int id;
} k[]={"void",1,"char",2,"int",3,"float",4};
int main()
{   printf("%c,%d",k[2].key[2],k[2].id);
    return 0;
}
答案：t,3
解析：结构体数组 k[2] 对应 {"int",3}。k[2].key="int"，三个字符依次是 i(0)、n(1)、t(2)，故 k[2].key[2]='t'；k[2].id=3。按 %c,%d 输出：t,3。
⚠ 网络流传答案写“n,3”，是把下标从 1 开始数了；C 数组下标从 0 开始，第 3 个字符才是 key[2]。已用 gcc 实测为 t,3。
考点：结构体数组 · 字符串下标
第29题点击展开答案

#include <stdio.h>

五、程序设计题（每小题8分，共16分）

第33题点击展开答案
PM2.5 数值 0~35（含0不含35）为优，35~75（含35和75）为良，75 以上为污染。输入 PM2.5，输出空气质量。
参考答案（if-else 多分支）
#include <stdio.h>
int main()
{   float pm25;
    printf("请输入PM2.5数值: ");
    scanf("%f", &pm25);
    if (pm25 >= 0 && pm25 < 35)
        printf("空气质量为优\n");
    else if (pm25 >= 35 && pm25 <= 75)
        printf("空气质量为良\n");
    else if (pm25 > 75)
        printf("空气质量为污染\n");
    else
        printf("输入的PM2.5数值不合法\n");
    return 0;
}
套路：区间判断用 if / else if / else 多分支，边界"含/不含"对应 <= 与 < 要写准。这类"分段"题是程序设计高频题型，务必背熟多分支结构。
考点：多分支 if-else · 区间边界
第34题点击展开答案
计算整型数组 x 中相邻两个元素的和依次存入数组 a，输出 a 的所有元素。x 长度为10，从键盘输入。
参考答案（数组遍历）
#include <stdio.h>
int main()
{   int x[10], a[9];
    int i;
    printf("请输入10个整数: \n");
    for(i=0; i<10; i++) scanf("%d", &x[i]);
    for(i=0; i<9; i++) a[i] = x[i] + x[i+1];   /* 相邻两元素之和 */
    printf("数组a的元素为: \n");
    for(i=0; i<9; i++) printf("%d ", a[i]);
    return 0;
}
套路：10 个元素相邻求和得 9 个，故 a 长度 9、循环 i<9，核心式 a[i]=x[i]+x[i+1]。数组题注意循环上界与越界（x[i+1] 最大到 x[9]）。
考点：数组 · 相邻元素处理
