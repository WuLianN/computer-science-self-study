三、🟡 高频（2/3 套出现）——有余力再抓

这些近三套出现了两次，投入产出比很高，尤其带"陷阱"的那几个。

🧷 转义字符

合法：\n \t \b \r \\ \' \" \0 \ddd(八进制) \xhh。非法：\p \q \c 这类没定义的字母。'\0' 是空字符（值 0），'0' 是字符 0（值 48）。出现：26.4-2、25.10-2。

📎 typedef

typedef long C; = 给已有类型起别名，不产生新类型、不分配内存。常与 #define 对比考。出现：26.4-13、25.10-13。

🧨 带参宏展开（括号陷阱）

#define P(x) x/x → P(4+6) 展开成 4+6/4+6=11，不是 1！宏是纯文本替换、实参逐个代入形参位置。写宏要给参数和整体都加括号。出现：26.4-14、25.10-14。

🔁 递归 vs 嵌套调用/定义

自己调自己 = 递归调用（允许）；A 调 B 叫嵌套调用；函数体内不能再定义函数（不允许嵌套定义）。出现：26.4-8、25.10-8。

📐 整除与类型提升

整/整 = 整（向零取整，-5/3 = -1）；有浮点参与就按浮点算（5/2.0 = 2.5）；% 两侧必须整型。出现：26.4-6、25.4-24。

📊 二维数组按行存放

int a[3][4]：第 i 行是 a[i][0..3]，初始化列表按行填满。看清 printf 在内层还是外层循环——写输出题常在这里设套。出现：25.10-28、25.4-29。

四、📌 8 个"闭眼默写"模板（配三套真题实解）

第 30–34 题的答案几乎都是这几个模板的变形。练熟这 8 个 ≈ 30 分到手。

1字符串连接（strcat）

套路：① i 走到 s1 末尾 → ② 把 s2 逐字符搬到 s1[i] 并同步 i++ j++ → ③ 补 '\0'。
void strcat(char s1[], char s2[])
{   int i = 0, j = 0;
    while (s1[i] != '\0') i++;      /* 定位 s1 尾部 */
    while (s2[j] != '\0') {
        s1[i] = s2[j];
        i++; j++;
    }
    s1[i] = '\0';                   /* 别忘了结束符 */
}
真题 2026.4 第30题：s1="abcd#"、s2="efg" → 三空分别是 s2[j]、'\0'、strcat(s1,s2)，结果 "abcd#efg"。

2子串复制 / 删除子串（整体左移）

套路：复制——起点 m-1、走到 strlen(s1)；删除——跨过 n 个：a[i]=a[i+n]，循环到 strlen(a)-n，最后 a[i]='\0'。
/* 从第 m 个字符起复制到 s2 */
for (i = m-1; i < strlen(s1); i++, j++)
    s2[j] = s1[i];
s2[j] = '\0';

/* 从第 k 个字符起删除 n 个（25.4 第34题） */
for (i = k; i < strlen(a) - n; i++)
    a[i] = a[i+n];
a[i] = '\0';
真题 2026.4 第31题：三空 s1、strlen(s1)、s1[i]。同型 · 2025.4 第34题（删除子串）。

3子串逆序（首尾指针交换）

套路：p 从 str+a 起步，q 从 str+b-1 起步，while(p<q) 交换后 p++、q--。注意参数 b 是"末字符下标+1"。
void fun(char *str, int a, int b)   /* 逆序下标 a ~ b-1 */
{   char *p = str + a, *q = str + b - 1, t;
    while (p < q) {
        t = *p; *p = *q; *q = t;
        p++; q--;
    }
}
/* 调用：fun(s, 2, 6) 把 "like" 逆成 "ekil" */
真题 2025.10 第31题：三空 str+b-1、q--、s,2,6。⚠ 传 5 只会逆 "lik"，这是最容易错的一处。

4结构体数组求最值（打擂台）

套路：先定义数组 w[5]；max=w[0].age 当擂主；从 i=1 起逐个比，更新 max=w[i].age；最后输出 max。
struct worker { int no; int age; } w[5];
int i, max;
max = w[0].age;
for (i = 1; i < 5; i++)
    if (max < w[i].age)
        max = w[i].age;
printf("max age:%d\n", max);
真题 2026.4 第32题：三空 w[5]、w[i].age、max1。同型 · 2025.4 第32题（结构体求平均 + flag==0 判空）。

5结构体数组查找（strcmp + 判未命中）

套路：strcmp(a,b)==0 才是相等；找到了就 break；循环结束后用 j==i 判断"没找到"（比另设 flag 简洁）。
for (j = 0; j < i; j++)
    if (strcmp(person[j].name, na) == 0) {
        printf("%s:%s\n", person[j].name, person[j].tel);
        break;
    }
if (j == i) printf("No match!\n");   /* 走到头 = 没找到 */
真题 2025.10 第32题：三空 !=、i++、j==i。⚠ 循环条件 strcmp(...,"#")!=0 表示"姓名不等于 # 就继续读"。

6多分支区间判断（if-else 阶梯）

套路：区间从低到高写；"含端点"用 <=、"不含"用 <；最后一定留 else 处理非法输入；条件之间用 && 连。
if (x >= 0 && x < 35)        printf("优\n");
else if (x >= 35 && x <= 75) printf("良\n");
else if (x > 75)             printf("污染\n");
else                         printf("输入不合法\n");
真题 2026.4 第33题：PM2.5 空气质量分级（0~35 优 / 35~75 良 / 75 以上污染），8 分题，只要分支不漏就满分。

7循环枚举 + 求余判断（整除类求和）

套路：sum 必须先置 0；枚举 1~k（i<=k 含端点）；"或"用 ||，别拆成两个 if（公倍数会加两次）。% 判整除：i%3!=0 即不能被 3 整除。
int sum = 0, i;
for (i = 1; i <= k; i++)
    if (i % 13 == 0 || i % 17 == 0)   /* 或，不是且 */
        sum += i;
真题：2025.10-33（13 或 17 的倍数之和）、2025.4-33（m~n 间不能被 3 整除之和，条件写 i%3!=0）。

8数组递推（项号 vs 下标，最容易差一）

套路：前两项手写定值；从 i=2 起推；"第 i+1 项"的下标是 i——题里说"奇数项/偶数项"时，判的是 (i+1)%2，不是 i%2。
a[0] = 0;  a[1] = 1;                 /* 第1、2项 */
for (i = 2; i < 20; i++)
    if ((i+1) % 2 != 0)  a[i] = a[i-1] + a[i-2];  /* 奇数项求和 */
    else                 a[i] = a[i-1] - a[i-2];  /* 偶数项求差 */
真题 2025.10 第34题：正确序列 0 1 1 0 1 1 2 1 3 2 5 3 8 5 13 8 21 13 34 21。⚠ 网络版用 i%2==1 从第 3 项起就全错，是典型案例。

五、🧨 最容易记错的 12 个坑（年年考）

这些不是"知识点"，是"阅卷老师就等着你错"的陷阱。考前扫两遍。
陷阱正确结论
'\0' vs '0' vs 0'\0' 值 0（串结束符）；'0' 值 48（字符零）；数字 0 和 '\0' 等价
++x vs x++前缀先加后用、后缀先用后加；用在下标/循环里最容易差一
&& / || 短路左边已定结果，右边根本不执行，所以右边的 i++ 不会发生
数组下标从 0 开始！第 3 个字符是 a[2]，"第 m 个"对应下标 m-1
整型除法5/2=2、-5/3=-1（向零取整），不是四舍五入；5/2.0=2.5
% 的两侧只能是整型，写 5.0%2 直接编译错误
switch 的 break没有 break 就继续往下执行所有 case（落穿），程序分析题必考
printf("%2d")是宽度 2、右对齐补空格，不是保留 2 位小数（%.2f 才是小数位）
static 局部变量只初始化一次，程序运行期间一直存在，未赋值自动为 0 → 程序分析必考
结构体 vs 结构体指针变量用 p.age；指针用 p->age 或 (*p).age；定义类型不分配内存，定义变量才分配
类型转换写法只有 (double)x / (double)(a+3)，没有 double(x)（那是 C++）
文件函数fopen 返回 FILE*；FILE 定义在 stdio.h；按存储分文本/二进制、按内容分程序/数据

六、⚠️ C89 标准：写代码前先看这一段

教材（郑岩《高级语言程序设计》机械工业出版社 2017）按 ANSI C / C89 出题。你平时用 Dev-C++/VS 默认按 C99 及以上编译，写习惯了会在答题时踩坑——下面的写法在考卷上都算错。
C99 及以上（不要这么写）C89（考卷要求）
int i = 0; 写在任何位置都行，随用随声明所有变量声明必须写在块（{ }）的最前面，声明完才能写第一条语句
for (int i = 0; i < n; i++)for 括号里不能声明变量，必须先在块首写 int i;，再 for (i = 0; …)
// 单行注释不支持 //，只能用 /* … */，且多行注释不能嵌套
long long、inline、_Bool、restrict、snprintf这些关键字/函数 C89 里都没有，写出来就是语法错
int a[n]; 用变量做数组长度（变长数组）数组长度必须是常量表达式，用变量开数组判错
int a[3] = {[0]=1, [2]=3}; 指定初始化器只能按顺序写 {1, 0, 3}
✅ 能放心用的标准库：stdio.h（printf / scanf / gets / puts / fopen / fclose / fgets）、string.h（strlen / strcpy / strcat / strcmp）、ctype.h（isdigit / islower / toupper）、math.h（sqrt / fabs / pow）——这些在 C89 里全部存在，考卷也只用这些。
🖊️ 答题习惯建议：程序填空/设计题先在函数开头把要用到的变量一次性声明完（int i, j, sum = 0;），再写语句——既符合 C89，又不会因为中途声明丢格式分。

七、🎯 考场抢分策略

  • 先扫第 32 题：三套卷这一题全是结构体数组，先看它考"求最值"还是"查找"，心里有底再回头做客观题。
  • 程序分析题一定动笔打草稿：把每次循环后的变量值列成小表格（i、j、m 各一列），别在脑子里算——短路、落穿、static 三件事最容易算错。
  • 写输出题注意格式：%2d 有前导空格、"%d " 有尾随空格、\n 会换行。按原样把空格也写出来，别自己"美化"。
  • 程序填空题每空都填：填错不扣分。常见坑位就是"'\0'""strlen()""&""i++"这几个，宁可猜也别空。
  • 程序设计题写完整骨架：#include + main + 变量定义 + 输入 + 处理 + 输出 + return 0，即使算法只写一半，结构分也能拿 3–4 分；评分说明明确写"程序不完整可酌情给分"。
  • 时间分配：单选 20 分钟、填空 15 分钟、程序分析 20 分钟、程序填充 20 分钟、程序设计 25 分钟，留 10 分钟检查拼写（printf 写成 print、少了分号最亏）。
  • 目标管理：客观 35 + 分析 10 + 填充 9 + 设计 8 ≈ 62，够及格。别死磕最后一道 8 分难题而丢掉前面的送分题。
