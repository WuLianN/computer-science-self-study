第 8 章 · 结构体类型与自定义类型

前面学的类型都是"单个值"，结构体把不同类型的数据打包成一个整体——一个学生 = 学号 + 姓名 + 成绩。这一章投入产出比极高：每套卷 4 道客观点 + 1 道程序填充（约 15 分），而且题型极其固定。

一、为什么需要结构体

一个学生有学号（int）、姓名（字符串）、成绩（float）——类型不同，一个数组装不下。结构体就是"自己定义一个类型"，把这些数据打包成一个整体。
结构体（structure）= 由若干个"成员"组成的构造数据类型。成员的类型可以不同，可以是基本类型、数组、指针，甚至另一个结构体。

二、类型定义与三种变量声明

① 先定义类型，再定义变量（最常用）： 
struct student {              /* struct 是关键字，student 是结构体名 */
    int no;
    char name[20];
    float score;
};                            /* ← 分号千万不能少 */

struct student s1, s2;        /* 用类型名定义变量，struct 不能省 */
② 定义类型的同时定义变量： 
struct student {
    int no;
    char name[20];
} s1, s2;                     /* 花括号后、分号前就是变量名 */
③ 省略结构体名（匿名结构体），直接定义变量： 
struct {
    int no;
    char name[20];
} s1;                         /* 没有类型名，以后无法再定义同类型变量 */
核心结论（年年考）：定义结构体类型时，系统不会为成员分配内存；只有定义变量时才分配。
2025.10 真题·第 12 题 描述正确的是"结构体类型可以嵌套定义"（答案 A）：
· B 错——成员可以是数组、指针、结构体，不限于基本类型；
· C 错——定义类型只描述"格式"，不分配内存；
· D 错——同类型成员可以一行写 int year, month, day;。
sizeof 提示：sizeof(struct student) 不一定等于各成员大小之和——编译器可能插入对齐填充字节。自考一般不考对齐细节，但"类型大小 ≠ 成员之和"这句要记住。

三、成员引用：. 与 ->

场景写法例
结构体变量变量名.成员名s1.no、s1.name
指向结构体的指针指针->成员名p->no　等价于　(*p).no
嵌套成员一层层往下点s1.birthday.year
为什么 *p.no 是错的：点号 . 的优先级高于 *，所以 *p.no 被解释成 *(p.no)——而 p 是指针，根本没有成员 no。正确写法必须加括号：(*p).no，而 p->no 是它的简写。 
struct student s = {1, "Li", 90.5};
struct student *p = &s;

printf("%d %s %.1f\n", s.no, s.name, s.score);      /* 变量用 . */
printf("%d %s %.1f\n", p->no, p->name, p->score);   /* 指针用 -> */
printf("%d\n", (*p).no);                             /* 与 p->no 完全等价 */
1 Li 90.5
1 Li 90.5
1
2026.4 真题·第 12 题 已定义 struct date{int year,month,day;} birth; 和 int *p;，成员引用正确的是 *p = birth.year;（答案 C）——引用成员的标准写法就是"结构体变量.成员名"。
两条整体操作规则：① 同类型的结构体变量可以整体赋值（s2 = s1; 合法，逐成员复制）；② 但不能整体输入输出——scanf("%d", &s1)、printf("%s", s1) 都是错的，必须一个成员一个成员地读写。

四、初始化与结构体数组

单个变量：按成员顺序给初值，可以部分初始化（其余补 0 / '\0'）。 
struct student s = {1, "Li", 90.5};     /* 完整 */
struct student t = {2, "Wang"};         /* 部分：score 自动补 0 */
结构体数组：每个元素用一对花括号括起来最清楚。 
struct student a[3] = {
    {1, "Li",    90.5},
    {2, "Zhang", 85.0},
    {3, "Wang",  78.5}
};
printf("%s\n", a[1].name);              /* Zhang */
扁平写法（真题第 28 题就考这个）：内层花括号可以全省略，编译器按成员顺序依次填充。 
struct keyword {
    char key[20];
    int id;
} k[] = {"void", 1, "char", 2, "int", 3, "float", 4};
/* 8 个初值 → 每个元素 2 个成员 → 共 4 个元素 */
元素keyid
k[0]"void"1
k[1]"char"2
k[2]"int"3
k[3]"float"4
2026.4 真题·第 28 题 输出 k[2].key[2] 和 k[2].id → k[2] 是 {"int", 3}，key[2] 是第 3 个字符 t → 答案 t,3。
两步走：先按"每 2 个初值一个元素"数出下标，再数字符（下标从 0 开始）。

结构体数组的固定套路：求最值（2026.4 第 32 题）

#include <stdio.h>

struct worker { int no; int age; } w[5];   /* 第一空：定义含 5 个元素的数组 */

int main(void)
{
    int i, max1;

    for (i = 0; i < 5; i++)
        scanf("%d%d", &w[i].no, &w[i].age);

    max1 = w[0].age;                        /* 打擂台：先拿下标 0 的 */
    for (i = 1; i < 5; i++)
        if (max1 < w[i].age)
            max1 = w[i].age;                /* 第二空 */

    printf("max age:%d\n", max1);           /* 第三空 */
    return 0;
}
规律：结构体数组求最值，比较的是 w[i].成员，暂存的也是成员的副本——千万别写 max1 = w[i];（类型不匹配）。

五、嵌套定义与自引用指针

嵌套：一个结构体的成员可以是另一个结构体。 
struct date {
    int year, month, day;
};

struct student {
    int no;
    struct date birthday;      /* 成员是结构体（这里必须已定义过 date） */
    struct student *next;      /* 自引用：只能是指针 */
};

/* 访问：一层层点下去 */
s.birthday.year
s.next->no
写法是否合法说明
struct date birthday;✓date 类型已定义，大小确定
struct student *next;✓指针大小固定，且可以"先声明后补全"
struct student next;✗自己包含自己，大小无限大
自引用为什么必须是指针：结构体的大小要在定义时算出来，如果成员又是一个同类型的完整结构体，就成了"俄罗斯套娃"，永远算不完；指针的大小是固定的（2 或 4 字节），所以合法。这也是下一章链表能成立的根本原因。

六、共用体（union）

共用体的所有成员共用同一块内存，同一时刻只有一个成员有意义。 
union data {
    int i;          /* 2 字节 */
    char c;         /* 1 字节 */
    float f;        /* 4 字节 */
};

union data u;
u.i = 65;
printf("%c\n", u.c);    /* A —— 改了 i，c 也跟着变（同一块内存） */
对比项结构体 struct共用体 union
内存各成员各占一块，总大小 ≥ 成员之和所有成员共用一块，大小 = 最大成员的大小
同时有效所有成员同时有效同一时刻只有一个有效
赋值影响互不影响改一个成员会覆盖其他成员
用途：几个数据不会同时使用、又想省空间时用；也常用来"用同一块内存按不同类型解读"。考试只考"共享内存"和"大小取最大成员"这两点。

七、枚举（enum）

枚举把一组相关的名字列出来，本质是整数常量。 
enum week { MON, TUE, WED, THU, FRI, SAT, SUN };
/* 默认：MON=0, TUE=1, WED=2, … SUN=6 */

enum color { RED = 1, GREEN = 5, BLUE };
/* 指定后：RED=1, GREEN=5, BLUE=6（紧跟上一个 +1） */

enum week today;
today = WED;
printf("%d\n", today);      /* 2 */
要点说明
默认值第一个枚举值为 0，后面依次 +1
可指定任意一个都可以赋初值，其后的成员在它基础上继续 +1
本质枚举值是 int 型常量，可以参与运算、可以输出 %d
不能输入scanf("%d", &today) 不规范——枚举变量应按名字赋值

八、typedef 与 #define 的区别

typedef 给"已有类型"起一个别名，不产生新类型。 
typedef long C;              /* C 是 long 的别名 */
C a, b;                      /* 等价 long a, b; */

typedef struct student {     /* 给结构体类型起别名，最常用 */
    int no;
    char name[20];
} STU;

STU s1;                      /* 以后不用再写 struct student */
对比项typedef#define
处理阶段编译阶段，由编译器识别预处理阶段，纯文本替换
作用只能给类型起别名任意文本都能替换（常量、表达式、类型名）
结尾分号要写 ;不写 ;
类型检查有没有（替换完才编译）
是否产生新类型不产生，只是别名也不产生
2026.4 真题·第 13 题 typedef long C; 的含义是"定义 long 类型的别名"（答案 D）。
2025.10 真题·第 13 题 typedef 的作用是"定义已有数据类型的别名"（答案 D）。
陷阱选项是"定义新类型"——C 里 typedef 从不产生新类型。
为什么给结构体起别名要用 typedef：不起别名时每次都得写 struct student s1;，struct 三个字母不能省（C 里 student 单独不是类型名）；起了别名后写 STU s1; 就行，少敲字、也不容易漏 struct。

九、本章小结与真题呼应

五个必背结论：
① 定义类型不分配内存，定义变量才分配（2025.10-12 的 C 项就错在这）；
② 变量用 .、指针用 ->，p->x ≡ (*p).x；
③ 同类型结构体可整体赋值、不可整体输入输出；
④ 结构体数组初始化可以省内层花括号，按成员顺序依次填；
⑤ union 共享内存、大小取最大成员；enum 从 0 递增；typedef 只是别名、不产生新类型。
