二、FILE 指针与 fopen

C 不直接操作文件，而是通过一个"文件指针"间接操作。 
#include <stdio.h>

FILE *fp;                          /* FILE 是系统定义的结构体类型 */
fp = fopen("data.txt", "r");       /* 打开文件，返回文件结构体的地址 */
if (fp == NULL) {                  /* 打开失败返回 NULL，必须判断 */
    printf("文件打开失败\n");
    return 1;
}
/* … 读写操作 … */
fclose(fp);                        /* 用完一定要关 */
要点说明
FILE 在哪定义在 stdio.h 中（不是 stdlib.h），所以文件操作必须包含 stdio.h
FILE * 干什么接收 fopen 返回的地址，之后所有读写函数都靠它定位文件
打开失败fopen 返回 NULL（空指针），不判断就往下读会崩
关闭fclose(fp)：把缓冲区内容写回磁盘并释放文件结构
2026.4 真题·第 15 题 关于文件型指针描述正确的是"用于接收文件打开函数返回的内容"（答案 D）。
2025.10 真题·第 15 题 文件型指针的作用是"接收文件打开函数返回的地址"（答案 C）。
三年考同一句话：FILE * 就是接 fopen 的返回值。

三、12 种打开方式

6 种基本方式 × 加不加 b（二进制）= 12 种。
方式含义文件不存在时已存在时
"r"只读失败，返回 NULL从开头读
"w"只写新建清空全部内容再写
"a"追加写新建保留原内容，在末尾追加
"r+"读写失败，返回 NULL从开头读写
"w+"读写新建清空后可读可写
"a+"读 + 追加新建读从开头，写只追加到末尾
加 b 就是二进制方式："rb"、"wb"、"ab"、"rb+"、"wb+"、"ab+"（b 的位置在 + 之前）。
最常考的一句话：用 "w" 打开一个已存在的文件，原有内容会被全部清除。
路径写法：Windows 下写路径要双斜杠或用正斜杠——fopen("d:\\data\\a.txt", "r") 或 fopen("d:/data/a.txt", "r")。单斜杠 \d 会被当成转义字符。

四、六组读写函数

类别读写说明
字符fgetc(fp)fputc(ch, fp)一次一个字符，读到文件尾返回 EOF（-1）
字符串fgets(s, n, fp)fputs(s, fp)最多读 n-1 个字符，自动补 '\0'
格式化fscanf(fp, "%d", &x)fprintf(fp, "%d", x)与 scanf/printf 只差第一个参数
数据块fread(buf, size, n, fp)fwrite(buf, size, n, fp)读写 n 个大小为 size 的数据，用于二进制文件
判断 / 关闭feof(fp)fclose(fp)是否到文件尾 / 关闭文件
定位ftell(fp)rewind(fp)、fseek(…)取当前位置 / 移动位置指针
最常用的一段——逐字符复制文件： 
int ch;                          /* 必须用 int：要能存下 EOF（-1） */

while ((ch = fgetc(fp)) != EOF)
    fputc(ch, fpout);
为什么用 int 不用 char：fgetc 正常返回 0~255，结束时返回 EOF（一般是 -1）。char 装不下 256 种状态，用 char 接会导致"文件里有 0xFF 字节时提前结束"。

五、feof 与 fclose

feof(fp) 返回非 0 表示"刚刚读到过文件尾"，注意它是事后判定：读完最后一个字符时 feof 仍是 0，必须再读一次失败后才置位。 
while (!feof(fp)) {              /* 不推荐的写法：会多处理一次 */
    ch = fgetc(fp);
    putchar(ch);
}
推荐写法（靠返回值判断，天然正确）： 
while ((ch = fgetc(fp)) != EOF)
    putchar(ch);
fclose(fp) 做两件事：① 把缓冲区里没写回磁盘的数据冲刷出去；② 断开文件指针。不关文件可能丢数据，程序结束前每个打开的流都要关。

六、文件定位：rewind / fseek / ftell

函数原型作用
rewindvoid rewind(FILE *fp)把位置指针移回文件开头，无返回值
fseekint fseek(FILE *fp, long offset, int origin)从 origin 起移动 offset 字节；成功返回 0
ftelllong ftell(FILE *fp)返回当前位置距文件开头的字节数；失败返回 -1L
origin 的三个取值（宏，定义在 stdio.h）：
宏值含义
SEEK_SET0从文件开头算
SEEK_CUR1从当前位置算
SEEK_END2从文件末尾算
fseek(fp, 0L, SEEK_END);       /* 跳到文件末尾 */
len = ftell(fp);               /* 文件长度 = 末尾位置距开头的字节数 */
rewind(fp);                    /* 回到开头，准备重新读 */
最常用的一招：用 fseek + ftell 求文件长度（上面三行就是标准写法）。

七、完整例子与本章小结

写文件 + 读文件：完整闭环

#include <stdio.h>

int main(void)
{
    FILE *fp;
    int i;

    fp = fopen("num.txt", "w");            /* 写方式打开（不存在会自动建） */
    if (fp == NULL) {
        printf("cannot open\n");
        return 1;
    }
    for (i = 1; i <= 5; i++)
        fprintf(fp, "%d ", i);
    fclose(fp);                            /* 写完必须关，否则可能没落盘 */

    fp = fopen("num.txt", "r");            /* 换成读方式再打开 */
    if (fp == NULL) {
        printf("cannot open\n");
        return 1;
    }
    while (fscanf(fp, "%d", &i) == 1)       /* 成功读入 1 项就继续 */
        printf("%d ", i);
    fclose(fp);
    return 0;
}
1 2 3 4 5
读循环的三种等价判断：fscanf(...) == 1、(ch = fgetc(fp)) != EOF、fgets(s, n, fp) != NULL——都比 while (!feof(fp)) 稳。
本章只要背四句话：
① 按内容分程序文件和数据文件，按存储形式分文本文件和二进制文件；
② FILE * 定义在 stdio.h，专门接收 fopen 返回的地址，返回 NULL 就是打开失败；
③ "w" 会清空已有文件，"a" 在末尾追加；fgetc 用 int 接、判 EOF；
④ 用完必须 fclose。四组函数记法：字符 f 前缀、字符串带 s、格式化加 f、数据块 fread/fwrite。
