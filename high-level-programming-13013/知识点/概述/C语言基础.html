一、C 语言的发展与 7 个特点

来历：1972 年由美国贝尔实验室的 Dennis Ritchie（里奇）在 B 语言基础上设计，最初用于编写 UNIX 操作系统；1978 年 Kernighan 与 Ritchie 合著《The C Programming Language》（K&R 标准）；1983 年美国国家标准协会制定 ANSI C（即 C89），1990 年被 ISO 采纳。本课程（教材 2017 年版）按 C89 命题。
特点说明 / 考点
兼有高级、低级语言特性既能写结构化程序，又能直接访问内存地址、做位运算（这是它比其他高级语言"更贴近机器"的地方）
简洁紧凑只有 32 个关键字、9 种控制语句，源程序短
运算符丰富34 种运算符，表达式类型灵活
数据结构丰富基本类型之外还有数组、指针、结构体、共用体等构造类型
结构化语言用函数作模块单位，只用三种基本结构
可移植性好与具体机器无关，换平台只需重新编译
生成目标代码质量高接近汇编语言的效率
教材还提到一条缺点式的特点：C 的语法限制不太严格、程序设计自由度大——所以编译器常常"不报错但结果错"，这也是本课程爱考陷阱题的根源。

二、基本词法：字符集 / 标识符 / 关键字 / 分隔符

1. 字符集

C 源程序由三类基本字符构成：字母（A–Z、a–z）、数字（0–9）、下划线 _，再加上各种标点符号和运算符（+ - * / % = < > ( ) { } [ ] , ; : ' " # & | ! ? ~ ^ \ 等）。

2. 标识符（名字）——3 条硬规则 + 2 条建议

  1. 只能由字母、数字、下划线三种字符组成，不能出现 % # - 空格 等。
  2. 第一个字符必须是字母或下划线，不能是数字（3a、2nd 都非法）。
  3. 不能用关键字作标识符，且严格区分大小写（sum、Sum、SUM 是三个不同的名字）。
建议：见名知义（score 而不是 a1）；变量名全小写、常量全大写，这是教材与试卷都默认的风格。
合法：_x、sum1、maxValue、a_b　|　非法：3x（数字开头）、m-n（含减号）、int（关键字）、float（关键字）

3. 关键字（C89 共 32 个，小写）

autobreakcasecharconstcontinuedefaultdodoubleelseenumexternfloatforgotoifintlongregisterreturnshortsignedsizeofstaticstructswitchtypedefunionunsignedvoidvolatilewhile
易错三点：① main、printf、scanf 都不是关键字（main 是函数名，后两个是库函数名）；② define、include 也不是关键字——它们是预处理命令名，前面必须带 #；③ C89 里没有 inline、long long、_Bool、restrict，写出来是错的。

4. 分隔符

C 语言的分隔符包括 逗号 和 空格 两种，用来把各个语法单位隔开（如 int a, b; 里的逗号、int a 之间的空格）。
2026.4 真题·第 18 题 C 语言的分隔符包括 逗号 和空格两种。

三、注释：只能用 /* */ 且不能嵌套

写法是否 C89说明
/* 说明 */✓ 唯一合法写法可跨行，编译时被替换成一个空格，不参与编译；不能嵌套
// 说明✗ C99 才有本课程按 C89 阅卷，答题时写 // 属于不规范写法
注释可以出现在程序的任意位置（包括语句与语句之间、函数内外），只要不把字符串或标识符从中间劈开。
2025.10 真题·第 1 题 "C 程序的任意位置都可以加注释"——正确；同题的 A 项"C 程序的基本单位是语句"错在基本单位是函数。

四、5 类基本语句与复合语句、空语句

C 语句是程序执行的最小单位，必须以分号结尾。教材把语句分成 5 类：
类别形式 / 例子说明
控制语句if…else、for、while、do…while、continue、break、switch、return、goto共 9 种，完成分支与循环（第 4 章）
函数调用语句printf("hi\n");函数调用 + 分号
表达式语句a = b + c;　i++;最常用；只写 a+b; 也合法，只是算完就丢
空语句;什么也不做，循环体为空时常用
复合语句{ … }用花括号把多条语句括成一个整体，又称语句块 / 分程序
复合语句的两层身份：① 它是一个整体，可以当作一条语句放在 if、for 后面（所以"if 后面管多条语句要加花括号"）；② 它自成作用域，里面定义的变量出了 } 就消失（第 6 章讲作用域时要用）。
2025.10 真题·第 19 题 用 { } 括起来的多个语句称为 复合语句（语句块）。
三个"分号"陷阱：
① if (x > 0); 多的那个分号把 if 变成了"空语句"，后面 { } 里的代码无论条件真假都会执行。
② for (i = 0; i < n; i++); 同理，循环体成了空语句。
③ 复合语句的 } 后面一般不加分号（写成 }; 多数编译器只警告，但习惯上不要加）。

五、C 程序的组成：函数、main、分号

四句话讲完 C 程序结构（考单选、也考判断）：
  1. C 程序由函数组成，函数是 C 程序的基本单位；至少有一个 main 函数，且只能有一个。
  2. 程序执行总是从 main 开始、到 main 结束；被调用的其他函数不会自己跑。
  3. main 函数的位置任意——可以写在所有函数之前，也可以写在最后，不影响执行顺序。
  4. 预处理命令以 # 开头，必须写在函数外（通常在文件开头），且不以分号结尾。
每条语句以分号结束，但：预处理命令不是语句，不加分号；函数定义的头 int main(void) 也不加分号；复合语句的 } 后一般不加。

例：一个完整的 C 程序骨架

#include <stdio.h>              /* ① 预处理命令：文件开头、函数外、无分号 */
#define N 10                   /* ② 宏定义也属于预处理，同样无分号 */

int max(int a, int b);         /* ③ 函数声明（原型），后面章节讲 */

int main(void)                 /* ④ 主函数：程序入口，位置任意 */
{
    int x, y, m;

    scanf("%d%d", &x, &y);     /* ⑤ 函数调用语句 */
    m = max(x, y);             /* ⑥ 表达式语句：以分号结尾 */
    if (m > N)                 /* ⑦ 控制语句 */
        printf("big\n");
    else
        printf("small\n");
    return 0;
}

int max(int a, int b)
{
    return (a > b) ? a : b;
}
注意：main 写在中间、max 写在最后，程序照样先从 main 跑——这就是"主函数位置任意"的实证。
易错：C 程序的基本单位是函数，不是语句、不是文件；一个 C 程序有且只有一个 main；main 不能被其他函数调用（2025.10-1 的 D 项就错在这里）；一条语句可以写成多行，一行也可以写多条语句。

七、本章小结与真题呼应

一条主线：字符集 → 拼成标识符（3 条规则）→ 关键字不能当名字（32 个）→ 词法单位用逗号和空格分隔 → 语句分 5 类（控制/函数调用/表达式/空/复合）→ 函数组成程序，main 是唯一入口且位置任意 → 预处理命令以 # 开头、放函数外、无分号 → 编译得 .obj、链接得 .exe。
