一、计算机语言的三代与语言处理程序

计算机只认二进制，但人不可能直接写二进制。按"离机器有多远"分三代：
代名称形式特点
第一代机器语言二进制指令代码计算机能直接识别执行，速度快；难写、难读、难移植
第二代汇编语言用助记符（如 MOV、ADD）表示指令仍与具体机器相关，需汇编程序翻译
第三代高级语言接近自然语言的语句，如 C、Pascal与机器无关、可移植，需编译或解释
语言处理程序：把"人能读的源程序"翻译成"机器能执行的目标程序"。
汇编程序——汇编语言 → 机器语言；编译程序——整个源程序一次性翻译，生成目标程序；解释程序——逐句翻译、译一句执行一句，不生成目标程序。
一句话记住：机器语言是唯一能被计算机直接识别执行的语言；高级语言必须经过"翻译"。C 语言属于高级语言，用的是编译方式（不是解释）。
2025.10 真题·第 16 题 机器语言是用二进制代码表示的能被计算机识别和执行的指令（答"指令/指令系统"）。

二、算法：定义与 5 个特性

算法：解决一个问题的方法和步骤。程序 = 数据结构 + 算法；算法是程序的灵魂，程序是算法的实现。
教材给出算法必须满足的 5 个特性（考填空、也考单选判断）：
特性含义反面例子
有穷性有限步之内必须结束，且每步都在合理时间内完成死循环、无限等待输入
确定性每一步的含义必须确切，不能有二义性"取较大的一个数"却没说相等怎么办
可行性每一步都能分解为可执行的基本操作要求"求任意方程的精确解析解"
零个或多个输入可以有输入，也可以没有（如直接输出常数）——
一个或多个输出必须有输出，否则算法毫无意义算完不打印、不返回任何值
易错：输入可以是零个（"零个或多个"），但输出必须是一个或多个——"零输出"的算法一定错。另外"有穷性"说的是步骤有限，不是"运行快"。

三、算法的三种描述方法

1. 自然语言

用汉语/英语按步骤写。优点是人人看得懂；缺点是容易啰嗦、有歧义，遇到分支和循环描述不清。

2. 流程图（传统流程图）

用规定图形表示操作，直观、便于检查。教材要求的四种基本图形：
图形名称表示
圆角矩形 / 椭圆起止框开始、结束
矩形处理框赋值、计算等一个处理步骤
平行四边形输入输出框输入数据、输出结果
菱形判断框根据条件成立与否走两条路
另有流程线（带箭头的线）表示执行方向，连接点（小圆圈）用于跨页连接。

3. N-S 结构化流程图（盒图）

把整个算法装在一个大矩形里，取消流程线，只用矩形框的嵌套表示顺序、选择（⊤ 形分叉）、循环（L 形回边）。好处是不可能画出非结构化的流程，自然保证"只有一个入口、一个出口"。

四、程序与程序设计：结构化 + 三种基本结构

结构化程序设计的核心思想（三句话，填空常考）：
  1. 自顶向下：先想整体，再往下拆。
  2. 逐步细化：每一层都细化成具体操作，直到能用三种基本结构写出来。
  3. 模块化：把大问题拆成功能单一的小模块，一个模块一个入口一个出口。
它要求任何程序都只由 顺序、选择、循环 三种基本结构组成；复杂问题靠这三种结构的组合、嵌套实现。

三种基本结构对照

顺序结构A→B→C 依次执行，无分支无回头
选择结构P 成立走 A，不成立走 B，只走一条
循环结构（当型）P 成立就执行 A，再回来判 P
三种结构的共同点：只有一个入口、只有一个出口；结构内每一部分都有机会被执行到；结构内不存在"死循环"（循环有出口）。
教材原话，两套卷都考：
2026.4 真题·第 22 题 任何程序都可由顺序、选择、循环三种基本结构组成，复杂问题可通过三种基本结构的组合、嵌套实现。
2025.10 真题·第 17 题 结构化程序设计又称为面向过程的程序设计。（因为它以"要做什么步骤"为中心，而不是以数据/对象为中心）

五、C 程序从源码到运行的 4 步

步骤动作产物（Windows 下）
1 编辑在编辑器中写源代码，存成文本文件源程序 .c
2 编译编译程序检查语法，把源程序翻译成机器指令目标文件 .obj
3 链接链接程序把目标文件与库函数等连接成整体可执行文件 .exe
4 运行执行可执行文件，得到结果—（调试时改回第 1 步）
编译阶段只做"翻译 + 查语法"；只有链接之后才有可执行文件。像 printf 这种库函数，代码在库文件里，必须靠链接才接得上——所以漏写 #include <stdio.h> 时常常是"编译警告 + 链接报错"，两句提示并不在同一阶段。

例：一个最小的 C 程序

#include <stdio.h>              /* 预处理：把标准输入输出头文件包含进来 */

int main(void)                 /* 主函数：程序唯一的入口 */
{
    int a, b, max;             /* C89：所有声明写在块首 */

    scanf("%d%d", &a, &b);     /* 输入两个整数 */
    if (a > b)
        max = a;
    else
        max = b;
    printf("max = %d\n", max);  /* 输出结果 */
    return 0;                  /* 返回 0 表示正常结束 */
}
这段代码里已经出现了后面几章的全部骨架：预处理器（第 9 章）、变量声明（第 3 章）、输入输出（第 4 章）、选择结构（第 4 章）、函数（第 6 章）。

六、本章小结与真题呼应

一条主线：计算机只认二进制 → 所以要有"语言的三代"和"翻译程序" → 写程序前先想清楚算法（5 个特性）→ 算法用流程图或 N-S 图描述 → 落到代码上必须只用三种基本结构（顺序/选择/循环）组合嵌套 → 最后经"编辑 .c → 编译 .obj → 链接 .exe"才能运行。
