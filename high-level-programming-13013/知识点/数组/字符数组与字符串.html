一、字符串的本质：'\0' 结尾

C 语言没有字符串类型，它用字符数组 + 结尾的 '\0'（ASCII 0，空字符）来表示字符串。
"abc" 占 4 个字节：'a'、'b'、'c'、'\0'。strlen("abc") = 3，而 sizeof("abc") = 4。
所有字符串函数都是"遇到 '\0' 就停"——没有 '\0' 的字符数组不是字符串，用 %s 输出会一路读到内存垃圾里，出现乱码。
下标01234
字符abc\0（未用）
三个必须分清的东西：
写法是什么值
'\0'空字符（ASCII 0）字符串结束标志
'0'数字字符 0ASCII 48
0整数 0数值 0

二、两种初始化与"长度够不够"

写法实际内容占字节是字符串吗
char s[] = "abc";a b c \04✓ 是
char s[3] = "abc";a b c（没有 \0）3✗ 不是，用 %s 会越界
char s[] = {'a','b','c'};a b c3✗ 只是普通字符数组
char s[] = {'a','b','c','\0'};a b c \04✓ 手动加 \0 才行
char s[10] = "abc";a b c \0 后全 010✓ 剩余自动补 0
长度规则：char s[10] 最多装 9 个字符 + 1 个 '\0'。判断"够不够"时，一定要给 '\0' 留一个位置：长度为 n 的字符串至要 char s[n + 1]。

三、输入输出：scanf %s 与 gets

方式能否读空格结束条件注意
scanf("%s", s)不能遇到空格 / Tab / 回车数组名 s 前面不能加 &（s 本身就是地址）
gets(s)能只遇回车会把回车换成 '\0'，读整行首选
printf("%s", s)—遇到 '\0'同样不加 &
puts(s)—遇到 '\0'输出完自动换行
char name[20];

scanf("%s", name);     /* 输入 "Li Ming" 只能读到 "Li" */
gets(name);            /* ✓ 能读到 "Li Ming" 整行 */
printf("%s\n", name);
易错：① scanf("%s", &s) 虽然常"能跑"，但类型不对，正规写法不加 &；② char s[5]; gets(s); 输入超长字符会写越界，C 不检查；③ 先 scanf("%d") 再 gets(s)，gets 会读到之前残留的回车（第 4 章那个坑），此时要先 getchar();。

四、四个库函数（含返回值含义）

都在 <string.h> 里：
函数调用返回值 / 结果易错
strlenn = strlen(s);字符串长度（不含 '\0'）是"到第一个 '\0' 为止"的字符数
strcpystrcpy(s1, s2);把 s2 连同 '\0' 复制到 s1不能用 s1 = s2（数组名不能赋值）；s1 必须够大
strcatstrcat(s1, s2);把 s2 接到 s1 末尾（从 s1 的 '\0' 处开始写）s1 必须有足够剩余空间；结果在 s1 里
strcmpr = strcmp(s1, s2);按 ASCII 逐字符比较：s1>s2 返回正数，相等返回 0，小于返回负数不能用 s1 == s2（那比的是地址）；"相等"要判 == 0
strcmp 的比较规则：从头开始逐字符比，遇到第一处不同就按 ASCII 码定胜负；若前面都一样，则长的那个大（因为它的下一个字符不是 '\0'）。例："abc" < "abd"（'c'<'d'）；"ab" < "abc"（'ab' 结束）。

五、六个必背模板（真题原型）

模板 1 · 求长度（strlen 的自写版）

int mylen(char s[])
{
    int i = 0;
    while (s[i] != '\0')      /* 或写 while (s[i]) */
        i++;
    return i;
}

模板 2 · 字符串连接（2026.4 第 30 题）

要求：把 s2 接到 s1 末尾，结果存在 s1 中。

void mycat(char s1[], char s2[])
{
    int i = 0, j = 0;

    while (s1[i] != '\0')          /* 第一步：找到 s1 的末尾 */
        i++;
    while (s2[j] != '\0') {        /* 第二步：从这一位开始覆盖写 */
        s1[i] = s2[j];
        i++;
        j++;
    }
    s1[i] = '\0';                  /* 第三步：补上结束符，别忘！ */
}
三步走：找尾 → 搬运 → 补 '\0'。三个空基本就对应这三步。

模板 3 · 子串复制（2026.4 第 31 题）

要求：把 s1 中第 m 个字符开始的全部字符复制到 s2。第 m 个字符的下标是 m − 1。

int main(void)
{
    char s1[100], s2[100];
    int m, i, j = 0;

    gets(s1);
    scanf("%d", &m);
    for (i = m - 1; s1[i] != '\0'; i++) {   /* 起点 m-1，一直搬到末尾 */
        s2[j] = s1[i];
        j++;
    }
    s2[j] = '\0';                            /* 补结束符 */
    puts(s2);
    return 0;
}
注意：题目说"第 m 个"用的是日常序数（从 1 数），而下标从 0 数，所以起点是 m-1。这是本题唯一的坑。

模板 4 · 子串逆序（2025.10 第 31 题）

要求：把 "I like C" 里的 "like" 逆序 → "I ekil C"。参数 a、b 是下标区间 [a, b)。

void fun(char *str, int a, int b)   /* 逆序 str[a] ~ str[b-1] */
{
    char *p = str + a;
    char *q = str + b - 1;          /* 末字符是 b-1，不是 b */
    char t;

    while (p < q) {                 /* 相遇就停，只换一半 */
        t = *p;
        *p = *q;
        *q = t;
        p++;
        q--;                        /* 两个指针都要往中间走 */
    }
}
调用：fun(s, 2, 6) 处理下标 2~5（即 "like"）。端点最容易写错：右端是 b-1，循环条件是 p < q。

模板 5 · 删除子串（2025.4 第 34 题同型）

void delstr(char s[], char sub[])
{
    int i = 0, j = 0, k;
    int n = mylen(sub);

    while (s[i] != '\0') {
        for (k = 0; k < n; k++)         /* 试着匹配 sub */
            if (s[i + k] != sub[k])
                break;
        if (k == n)                     /* 全部匹配上 → 跳过这 n 个字符 */
            i += n;
        else
            s[j++] = s[i++];            /* 不匹配 → 保留当前字符 */
    }
    s[j] = '\0';
}
思路：用两个下标 i（读）和 j（写），i 走得快、j 走得慢，相当于"原地删除"。

模板 6 · 大小写转换与字符统计（2025.10 第 30 题）

#include <ctype.h>

for (i = 0; s[i] != '\0'; i++) {
    if (s[i] >= 'a' && s[i] <= 'z')        /* 小写 → 大写 */
        s[i] = s[i] - 32;                   /* 也可写 toupper(s[i]) */
    else if (s[i] >= 'A' && s[i] <= 'Z')    /* 大写 → 小写 */
        s[i] = s[i] + 32;
    else if (isdigit(s[i]))
        s[i] = '0';                         /* 数字统一替换成字符 '0' */
}
为什么是 32：'a'=97、'A'=65，差 32。也可以写成 s[i] - 'a' + 'A'，可读性更好。

六、sizeof 与 strlen 千万别混

项目sizeofstrlen
是什么运算符（编译期求值）库函数（运行期数到 '\0'）
算的是占用的总字节数，含 '\0'字符个数，不含 '\0'
char s[]="abc"43
char s[10]="abc"103
需要头文件吗不需要需要 <string.h>
经典例题：char a[] = {"lovely\n"}; 则 sizeof(a) = 8（7 个字符 + '\0'），strlen(a) = 7。若 p = &a[1]，则 strlen(p) = 6（从 'o' 数到 '\0'）。
2026.4 真题·第 29 题 char a[]={"lovely\n"}; char *p=&a[1]; 求结果，答案 6——因为 p 指向 'o'，'o','v','e','l','y','\n' 正好 6 个字符，'\0' 不算。

七、二维字符数组

存多个字符串用二维字符数组：第一维是"第几个串"，第二维是"每个串最长多少"。 
char name[3][10] = {"Zhang", "Li", "Wang"};

printf("%s\n", name[1]);     /* Li —— name[1] 就是一个字符串 */
printf("%c\n", name[1][0]);  /* L  —— 再下一层就是单个字符 */
写法含义
name[i]第 i 个字符串（相当于一个一维字符数组名）
name[i][j]第 i 个字符串的第 j 个字符
char *p[3] = {"Zhang","Li","Wang"};指针数组：更省内存，但每个串长度可不同（第 7 章）
为什么 char s[3][10] 浪费空间：每个串都按 10 字节分配，"Li" 只用了 3 字节，剩下 7 字节空着。指针数组只存地址，比较省——这就是第 11 题"指针数组 vs 字符数组"的考点。

八、本章小结与真题呼应

一条主线：字符串 = 字符数组 + '\0' → 初始化时给 '\0' 留位置 → 读入用 gets（能吃空格）或 scanf("%s")（不能吃空格）→ 所有操作都是"找到尾 → 搬运 → 补 '\0'"三个动作 → 库函数只记四个（strlen/strcpy/strcat/strcmp），strcmp 判等要用 == 0。
