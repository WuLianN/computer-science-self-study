一、作用域三档：局部 / 全局 / 外部

种类定义位置作用域（可见范围）
局部变量函数体内 / 复合语句内只在本函数或本复合语句内有效，出了 } 就不可见
全局变量（外部变量）函数外从定义位置开始，到本源程序文件结束（定义之前不可见）
外部变量（跨文件）在另一个文件中定义本文件用 extern 声明后才能用
2026.4 真题·第 7 题 外部变量的作用域是"从定义外部变量的位置开始到其所在的源程序文件结束"（答案 D）。不是整个源程序文件——定义之前的函数看不见它；也不是到"第一个相邻函数结束"。
为什么"定义之前不可见"？编译是从上往下扫描的，扫描到某个函数时，如果这个全局变量还没被定义，编译器不知道它是什么。想让它对自己后面的所有函数都可见，就把定义写在文件最前面。

二、四种存储类别总表（背这一张）

存储类别修饰对象作用域生存期初值
auto（默认）局部变量所定义的函数或复合语句函数调用期间（进函数建、出函数毁）不确定（垃圾值）
static 局部局部变量所定义的函数 / 复合语句整个程序运行期间（只初始化一次）0
register局部变量所定义的函数 / 复合语句函数调用期间不确定
extern全局变量 / 函数可跨文件整个程序取决于真正的定义
全局（无 static）变量本文件（多文件可见）整个程序0
static 全局全局变量仅本文件整个程序0
一句话记忆：static 有两个"身份"——修饰局部变量时延长寿命（不重新初始化）；修饰全局变量/函数时缩小作用域（只在本文件可见）。方向正好相反，考题最爱在这里绕。
2025.10 真题·第 6 题 下列变量定义会自动赋初值的是 static int a;（答案 D）——只有 static 和全局变量自动置 0，int m;、char c;、register int n; 都是垃圾值。
2025.10 真题·第 7 题 声明为 auto 类型变量的作用域是所定义的函数或复合语句（答案 B）。

三、static 局部：只初始化一次

static 局部变量 = "寿命被延长到整个程序、但名字只在函数里可见"的变量。它存放在静态存储区，函数返回后值仍然保留，下次进函数接着用；而且只在第一次进入时初始化一次。

例：连续调用 4 次，看 k 会不会被重置（2025.10 第 29 题）

#include <stdio.h>

int f(int j)
{
    static int k;            /* 只初始化 1 次，默认值 0 */
    k++;
    return k + j;
}

int main(void)
{
    int i;
    for (i = 1; i <= 4; i++)
        printf("%d ", f(10));
    printf("\n");
    return 0;
}

对比：如果把 static 去掉，每次调用都是新的 k（垃圾值），结果就完全不是这个序列了。
三个必记结论：① static 局部只初始化一次；② 它的初值一定是 0（不写也是 0）；③ 它的作用域不变——出了函数还是不可见，只是"活得久"。

四、static 全局：把作用域锁在本文件

全局变量加 static → 变成"内部变量"：作用域只在本文件，其他文件即使写 extern 也引用不到。
2026.4 真题·第 9 题 用来将全局变量作用域限制在本文件的关键字是 static（答案 C）。extern 的作用正好相反——它扩大作用域，让别的文件也能用。
写法叫什么其他文件能否使用
int g;（文件级）外部变量能（extern int g;）
static int g;内部变量 / 静态全局不能
static int f(void)内部函数不能

五、extern：声明，不是定义

extern 用来"引用"别处（别的文件或本文件后面）已经定义的变量/函数——它只是声明，不分配内存。 
/* 文件 a.c */                  /* 文件 b.c */
int total = 0;                  extern int total;      /* 声明：total 在别处定义 */
                                void add(void) { total++; }   /* 现在可以用了 */
定义声明（extern）
分配内存分配不分配
能否重复只能一次可以多次
能否赋初值能不能（赋了就成了定义）
不写存储类别时：局部变量默认 auto，全局变量默认"外部"（可跨文件）——所以平时写 int g; 就已经是外部变量了，extern 只在跨文件引用时才必须写。

六、同名屏蔽与默认类别

局部变量与全局变量同名时，在局部变量的作用域内，全局变量被"屏蔽"（不起作用）。 
int x = 10;                    /* 全局 */

int main(void)
{
    int x = 20;                /* 局部，屏蔽了全局的 10 */
    printf("%d\n", x);         /* 20 */
    {
        int x = 30;            /* 更内层，再屏蔽一层 */
        printf("%d\n", x);     /* 30 */
    }
    printf("%d\n", x);         /* 回到 20 */
    return 0;
}

七、本章小结与真题呼应

一条主线：先分作用域（局部只在函数/块内、全局从定义处到文件末、跨文件靠 extern）→ 再分存储类别（auto 进函数建出函数毁、static 局部活得久且只初始化一次、register 想放寄存器、extern 只声明不分配）→ 最后记住两条"自动为 0"的只有 static 和全局，static 修饰全局 = 锁在本文件（extern 反过来）。
