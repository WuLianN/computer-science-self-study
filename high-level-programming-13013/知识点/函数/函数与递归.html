一、函数的分类与定义格式

分类方式种类说明
按来源库函数 / 用户自定义函数库函数由系统提供（printf、strlen），要用就 #include 对应头文件
按有无参数有参函数 / 无参函数无参要写 (void) 或 ()
按有无返回值有返回值 / 无返回值（void）void 函数不能用 return 值;
定义格式： 
/* 返回类型  函数名(形参类型 形参名, …) */
int max(int a, int b)
{
    int m;                 /* 函数体：先声明，后语句（C89） */

    if (a > b)
        m = a;
    else
        m = b;
    return m;              /* 把结果交回调用处 */
}
三个要点：① 函数不能嵌套定义——一个函数的 { } 里不能再写另一个函数的定义（但可以在里面调用别的函数）；② 形参只在函数内部有效；③ 函数定义的头部不加分号（加了分号就变成"声明"）。

二、返回值与 return

规则说明
类型要匹配return 的表达式类型应与函数返回类型一致，不一致会自动转换
只执行一次一个函数里可以有多个 return，但只执行第一个被执行到的，执行后立即返回
void 函数可以不写 return;，也可以写 return;（不带值），但不能写 return 值;
不写 return非 void 函数若没执行到 return，返回值是不确定的（考试里算错）
返回值的三种用法：赋值给变量 m = max(a,b);、直接输出 printf("%d", max(a,b));、参与表达式 s = max(a,b) * 2;。返回值只有一个——想"带回多个结果"必须靠指针（第 7 章）。

三、函数声明（原型）为什么必须有

函数声明（原型声明）：返回类型 函数名(参数类型表);　例：int max(int, int); 或 int max(int a, int b);
  1. 编译是从上往下看的：如果函数定义写在使用它的函数之后，编译器此时还不知道这个函数有几个参数、返回什么，必须先"打个招呼"。
  2. 所以要么把定义写在 main 之前，要么在 main 之前（或文件开头）写一行原型声明。
  3. 调用函数前，应让编译程序预先了解函数的有关信息，也就是对被调函数进行声明。2025.10 真题·第 22 题 答案就是"声明"。
#include <stdio.h>

int max(int a, int b);        /* ← 声明：告诉编译器"有这么个函数" */

int main(void)
{
    printf("%d\n", max(3, 5));   /* 调用时编译器已知道 max 的返回值和参数 */
    return 0;
}

int max(int a, int b)          /* 定义可以放在后面 */
{
    return (a > b) ? a : b;
}
声明与定义的区别：声明只交代类型信息（后面加分号，不写函数体，不分配空间）；定义真正写出函数体（不带分号）。一个函数只能定义一次，可以声明多次。

四、调用与值传递：单向的

调用格式：函数名(实参表);　实参与形参必须个数相同、顺序对应、类型一致或可转换。
值传递是"复制粘贴"：调用时把实参的值复制一份给形参，之后形参怎么改，都影响不到实参。形参是函数内部的局部变量，函数一返回就消失。

经典反例：这样交换是无效的

void swap(int a, int b)     /* 形参 a、b 只是副本 */
{
    int t;
    t = a;  a = b;  b = t;
}

int main(void)
{
    int x = 1, y = 2;
    swap(x, y);
    printf("%d %d\n", x, y);  /* 输出 1 2 —— 根本没换 */
    return 0;
}
1 2
为什么没用：swap 里换的是 a、b 两个副本，主函数里的 x、y 毫发无伤。正确写法是把地址传进去（swap(&x, &y)，形参写成 int *a），第 7 章详讲。

五、嵌套调用 vs 递归调用

概念含义是否允许
嵌套调用函数 A 调用函数 B，函数 B 再调用函数 C —— 调用链条可以有很多层✓ 允许
嵌套定义在函数 A 的 { } 里再定义一个函数 B —— C 语言不允许✗ 禁止
递归调用函数自己调用自己（直接递归），或 A 调 B、B 又调 A（间接递归）✓ 允许
2025.10 真题·第 8 题 主函数调用 x()，x() 又调用 y()，属于函数的 嵌套调用（答案 A）。
2026.4 真题·第 8 题 正确答案是"不允许递归定义函数，允许递归调用函数"（答案 C）——这里的"递归定义"指的是“在函数体内再定义一个函数”这种嵌套定义，C 语言禁止；而自己调自己是正当的递归调用。

六、递归三要素与两个经典例

写递归只问三件事，缺一样就死循环 / 栈溢出：
  1. 终止条件（边界）：什么时候直接给答案、不再递归。
  2. 递推关系：原问题怎么化成规模更小的同类问题。
  3. 向终止靠拢：每次递归参数都必须比原来更接近边界。

例 1：阶乘 n!

long fact(int n)
{
    if (n == 0 || n == 1)      /* 终止条件 */
        return 1;
    return n * fact(n - 1);    /* 递推：n! = n × (n-1)! */
}

/* main 里：printf("%ld\n", fact(5));  →  120 */
跟踪一次 fact(3)：3×fact(2) → 3×2×fact(1) → 3×2×1 = 6。递归是"先往下走到边界，再一层层往上乘"。

例 2：斐波那契数列（第 34 题的递推原型）

int fib(int n)
{
    if (n == 1 || n == 2)      /* 前两项都是 1 */
        return 1;
    return fib(n - 1) + fib(n - 2);
}
注意：这个递归写法清晰但极慢（重复计算），考试写它没问题；实际工程里用数组递推（第 5 章）。
递归最容易犯的两个错：① 忘了终止条件 → 无限递归，运行时"栈溢出"；② 终止条件写错方向，如 if (n == 0) 但参数是 n+1 递增，永远到不了 0。
答程序分析题的技巧：递归题一定从最小规模往上推（先算 f(1)、f(2)，再 f(3)），别从大往小猜。

七、数组作参数与返回指针

（1）数组作函数参数：形参写成 int a[] 或 int a[10] 或 int *a，三种写法完全等价，传过去的是首地址。
结果：函数内部对 a[i] 的修改会真的改掉原数组（因为操作的是同一块内存）。这是"值传递"的例外——数组名传的是地址。
副作用：数组长度信息丢了，所以必须额外传一个长度参数：void show(int a[], int n)。在函数里 sizeof(a) 得到的是指针大小，不是数组总字节数。 
void add1(int a[], int n)      /* 每个元素加 1 */
{
    int i;
    for (i = 0; i < n; i++)
        a[i]++;                /* 直接改掉了主函数里的数组 */
}
（2）返回指针的函数：int *fun(int n) 表示函数返回一个 int * 类型的值。
2025.10 真题·第 10 题 能接收 int *fun() 返回值的是 指针变量（答案 B）——返回的是地址，必须用同类型指针接。注意：绝不能返回局部变量的地址（函数一结束，那块内存就失效了）。

八、本章小结与真题呼应

一条主线：函数 = 返回类型 + 名字 + 形参表 + 函数体 → 不能嵌套定义，可以嵌套调用 → 用之前要么写在前、要么先声明（原型）→ 调用时值传递是单向复制，想改实参必须传地址 → 递归三要素（终止、递推、靠拢），从最小规模往上推 → 数组作参数传的是地址、长度要另传 → 返回指针要用指针变量接。
