一、指针是什么：地址与指针变量

内存的每个字节都有一个编号，这个编号就是"地址"。一个变量占几个字节，它的地址就是第一个字节的地址。
指针 = 地址（一种数据类型）；指针变量 = 专门用来存放地址的变量。
所以"指针是存放数据的内存单元地址"这个说法是对的（2025.10 真题·第 9 题 的 D 项），而"指针可以实现动态分配内存""通过指针可以直接访问变量的值"也都对；错的那项是"指针可以直接访问内存"之类表述。指针的本质是地址，不是数据本身。
变量地址内容说明
int x200025x 占 2000–2001 两个字节
int *p30002000p 里存的是 x 的地址
写法：int *p;　—— 星号 * 说明"p 是个指针"，int 说明"p 指向的数据是 int 型"（叫基类型）。
基类型为什么重要：它决定了两件事——① 通过 p 取值时一次读几个字节；② p+1 到底往后跳多少字节。int *p 的 p+1 跳 2 字节（16 位机），char *p 的 p+1 跳 1 字节。

二、& 与 *：一对互逆运算

符号名称作用例
&取地址运算符得到变量的地址p = &x;　p 指向 x
*指针运算符（解引用）顺着地址取出/修改那个变量的值*p = 25;　等价于 x = 25;
互逆关系：*&x 就是 x；&*p 就是 p。
一句话：*p 出现在赋值号左边是"写"，出现在右边是"读"，两种用法都指向同一块内存。 
int x = 10, y;
int *p;

p = &x;          /* p 指向 x */
y = *p;          /* 读：y = 10 */
*p = 99;         /* 写：x 也变成 99 —— 通过指针改了变量 */
printf("%d %d\n", x, y);
99 10

三、初始化：类型必须匹配

写法是否合法原因
int x, *p = &x;✓int 指针指向 int 变量
char c, *p = &c;✓类型一致
char *pc = NULL;✓NULL 是空指针（不指向任何地方），可以赋给任何指针
int x, *px = &x, *py = px;✓让 py 也指向 x
int x; float *p = &x;✗基类型不匹配：float 指针不能指向 int 变量
int *p = 2000;✗不能直接把一个整数当地址赋给指针（(int *)2000 强转才行）
2026.4 真题·第 10 题 初始化不正确的是 int x; float *p = &x;（答案 B）——基类型不匹配。
补充：指针变量本身也占内存（16 位机 2 字节、32 位机 4 字节），所以可以有"指向指针的指针"（第 13 页）。
野指针（考试与工程里都致命）：int *p; 只定义没赋值，p 里是垃圾地址，此时 *p = 5; 会写坏别的内存甚至直接崩。定义指针时要么立刻让它指向某个变量，要么赋 NULL。

四、指针的算术运算

运算含义例（int *，int 占 2 字节）
p + n / p - n向前/向后移动 n 个元素，不是 n 个字节p+1 的地址增加 2 字节
p++ / p--指向下一个 / 上一个元素遍历数组全靠它
p1 - p2两个指针之间隔了几个元素同类型、同一数组内才有意义
p1 < p2比较地址先后循环条件常用 p < a+n
p1 + p2、p * 2非法两个地址相加没有意义
关键理解：p+1 不是"地址 +1"，而是"地址 + sizeof(基类型)"。这就是为什么 int * 加 1 跳 2 字节、double * 加 1 跳 8 字节。

五、指针与一维数组：a[i] ≡ *(a+i)

数组名是首元素的地址（一个常量），所以：
a[i] ≡ *(a + i) ≡ *(p + i) ≡ p[i]　（其中 p = a;）
四种遍历写法完全等价： 
int a[5] = {1, 2, 3, 4, 5}, i;
int *p;

for (i = 0; i < 5; i++)  printf("%d ", a[i]);        /* ① 下标法 */
for (i = 0; i < 5; i++)  printf("%d ", *(a + i));    /* ② 数组名 + 偏移 */
for (p = a; p < a + 5; p++) printf("%d ", *p);       /* ③ 指针法（最常用） */
for (p = a, i = 0; i < 5; i++) printf("%d ", p[i]);  /* ④ 指针下标法 */
两个细节：① a 是地址常量，a++ 非法；但 p = a; p++ 合法（p 是变量）。
② sizeof(a) 是整个数组的字节数，sizeof(p) 只是指针的字节数——数组名一当参数传出去就退化成指针，长度信息就丢了。

六、指针与字符串

字符串可以用字符数组存，也可以用字符指针指向它： 
char s1[] = "hello";      /* 数组：可读可写，占 6 字节 */
char *s2  = "hello";      /* 指针：指向字符串常量，只读，别去改它 */

printf("%s\n", s1);       /* hello */
printf("%c\n", *(s2 + 1));/* e —— 指针 + 偏移取单个字符 */
用指针遍历字符串（第 31 题的自写版基础）： 
char *p = s1;
while (*p != '\0') {
    putchar(*p);
    p++;                  /* 指针往下走一个字符 */
}
2026.4 真题·第 29 题 char a[]={"lovely\n"}; char *p=&a[1]; —— p 指向 'o'，从 p 数到 '\0' 共 6 个字符（o v e l y \n）。做这类题先把指针落在哪个字符上标出来，再数字符。
易错：char *s = "abc"; 里的 "abc" 是字符串常量，存放在只读区，s[0] = 'A'; 运行时会崩。要修改就写成 char s[] = "abc";。

七、指针作函数参数：唯一能"改实参"的办法

第 6 章说过：值传递是单向复制，swap(x, y) 换不了。把地址传进去就能换了——因为函数拿到的是"原件的位置"，可以直接改原件。 
void swap(int *a, int *b)      /* 形参是指针，接收地址 */
{
    int t;
    t = *a;
    *a = *b;
    *b = t;                    /* 改动的是主函数里的变量 */
}

int main(void)
{
    int x = 1, y = 2;
    swap(&x, &y);              /* 传地址，不是传值 */
    printf("%d %d\n", x, y);
    return 0;
}
