一、数据类型的四大家族

大类包含要点
基本类型整型（int / short / long / unsigned）、字符型 char、实型（float / double）、枚举型 enum系统已定义好，直接用
构造类型数组、结构体 struct、共用体 union由基本类型按规则组合而成
指针类型int *、char * …存放的是地址，不是数据本身
空类型void无返回值 / 无参数 / 通用指针
2025.10 真题·第 20 题 由基本数据类型按一定规则组合而成的复杂数据类型称为 构造数据类型（也叫复合数据类型）——填"构造类型"或"复合数据类型"都对。

二、整型：字节数、值域与符号

类型16 位机字节数32 位机字节数值域（16 位）
short / short int22−32768 ~ 32767
int24−32768 ~ 32767

值域公式（记住就能推）：占 n 位 → 无符号 0 ~ 2ⁿ−1；有符号 −2n−1 ~ 2n−1−1。
16 位 = 2 字节：无符号 2¹⁶−1 = 65535；有符号 −32768 ~ 32767。unsigned 的最小值是 0，永远没有负数。
2026.4 真题·第 21 题 在 16 位 PC 中，一个 unsigned 型变量的值域是 0 到 65535。
2025.10 真题·第 21 题 在 16 位编译器中，一个 int 型变量一般占用 2 字节。
怎么判断题目是 16 位还是 32 位？题干会明说"16 位 PC / 16 位编译器"——只看题干，别用自己电脑的 4 字节去答。

三、实型与字符型

实型（浮点型）

类型字节有效数字值域
float46–7 位约 ±3.4e38
double815–16 位约 ±1.7e308
实型不能用 % 求余，也不能做位运算；比较两个实型是否相等要用"差的绝对值小于一个小数"。

字符型

char 占 1 字节，存的是字符的 ASCII 码（本质是小整数，可参与算术运算）。
必背三个码：'0' = 48、'A' = 65、'a' = 97。
字符 '0' 与数字 0 完全不同：'0' 的值是 48，'0' + 1 得 '1'；而 0 + 1 得 1。把小写字母转大写就是 c = c - 32;（97−65=32）。

四、常量：整型 / 实型 / 字符 / 字符串

常量：程序运行过程中值不能改变的量。分直接常量（字面量）和符号常量（有名常量）两类。
种类合法写法非法写法 / 陷阱
整型常量123（十进制）、017（八进制，以 0 开头 = 15）、0x1F（十六进制 = 31）、123L（长整型）、123U（无符号）08、0x1G（八进制/十六进制里出现了越界数字）
实型常量小数形式 3.14、.5、5.；指数形式 1.5e3、1.5E-3、1e5e2.6（指数必须是整数）、e5（e 前必须有数字）、3.14e（e 后必须有数字）
字符常量'a'、'A'、'0'、'\n'、'\101'（八进制转义）'ab'（只能一个字符）、"a"（这是字符串）
字符串常量"a"、"hello"、""（空串）"a" 实际占 2 字节（'a' 和 '\0'）
指数形式的两个硬规定（年年考）：① e（或 E）前面必须有数字；② e 后面必须是整数，不能带小数点。
2026.4 真题·第 3 题 a=3.14e2.6; 错误（指数 2.6 不是整数），而 1.89e2、3.14e2 都合法。
还有一处：float a = 789.456; 合法（实型常量默认 double，赋给 float 只是精度损失，不算错）。

六、const 有名常量与变量初始化

有名常量（符号常量）：用 const 定义，在定义时就必须赋初值，之后不能再改。有名常量的值是通过"赋初值"的方式获得的，不是运行时算出来的。 
const float PI = 3.14159;      /* 定义时必须给值，以后再赋值就报错 */
const int N = 10;               /* 之后可作数组长度：int a[N]; 合法 */

PI = 3.14;                      /* ✗ 错：const 常量不能被重新赋值 */
方式写法关键点
const 有名常量const int N = 10;有类型、有地址，参与类型检查；教材首选
#define 宏常量#define N 10纯文本替换，没有类型（第 9 章），不加分号
枚举常量enum {N = 10};本质是整型（第 8 章）

变量的定义与初始化

格式：类型名 变量名1, 变量名2 …;　如 int a, b, sum;
  1. 必须先定义后使用，而且 C89 要求定义写在块的开头（所有可执行语句之前）。
  2. 定义时不初始化的变量，其值是不确定的垃圾值（static 变量除外，见第 6 章）。
  3. 一行可以定义多个同类型变量，中间用逗号分隔，最后是分号。
  4. 变量名遵循标识符规则，同一作用域内不能重名。
int a = 1, b, c = 3;            /* a、c 有初值，b 是垃圾值 */
int x, y;
x = y = 0;                      /* 从右往左：先 y=0，再 x=0，两个都变成 0 */
2026.4 真题·第 16 题 有名常量的值通过 赋初值 的方式获得。
2025.10 真题·第 3 题 C 语言中定义有名常量所用的关键字是 const（define 不是关键字，是预处理命令名）。

七、类型转换：隐式提升与强制转换

（1）隐式转换（自动转换）：混合运算时按"精度不降低"的方向转换：
char / short → int → unsigned → long → float → double　（赋值时高精度赋给低精度会"截断"，只是不报错）
（2）强制类型转换：格式只有一种——
(类型名) 表达式　例：(double)x、(int)(a+b)、(float)(3)
必须加括号把整个表达式括起来，否则只转换第一个操作数。转换只是"取个中间值"，原变量的类型和值都不变。 
int a = 5, b = 2;
double x;

x = a / b;                       /* ✗ 先整除得 2，再转成 2.0 */
x = (double)a / b;               /* ✓ 2.5：先把 a 转成 5.0 再除 */
x = (double)(a / b);             /* ✗ 2.0：括号里先整除完再转 */
2026.4 真题·第 24 题 将 (a+3) 强制转换成双精度实型：(double)(a+3)。
2025.10 真题·第 5 题 将 x 强制转化成双精度实型：(double)x。
两个必错写法：double(x)（C 语言没有这种"函数式转换"）、x(double)（顺序反了）。

八、本章小结与真题呼应

一条主线：类型分四族（基本 / 构造 / 指针 / 空）→ 基本类型记字节数与值域（16 位 int 是 2 字节、unsigned 是 0~65535）→ 常量要会判断写法（指数 e 前有数字、后是整数；转义字符只认表里的）→ 有名常量用 const 且定义时赋初值 → 转换只有 (类型名)表达式 一种写法。
