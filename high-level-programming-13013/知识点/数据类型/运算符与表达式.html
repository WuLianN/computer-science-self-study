一、运算符的九大类别

类别运算符注意
算术+ - * / % 双目，++ -- 单目/ 两侧都是整数时做整除；% 两侧必须是整数
关系< <= > >= == !=结果是 1（真）或 0（假）
逻辑! && ||结果只有 0/1，且 && || 短路
赋值= 及复合赋值 += -= *= /= %=右结合，从右往左算
条件? :三目，右结合
逗号,从左到右算，整个表达式的值是最后一个
位运算& | ^ ~ << >>按二进制位操作，操作数须为整型
sizeofsizeof(类型/变量)是运算符不是函数，编译期就求出字节数
其他& 取地址、* 解引用、. -> 成员、(类型) 强制转换第 7、8 章讲
C89 共有 34 种运算符——这个数字记一下，有时会考"运算符丰富"这个特点。

二、优先级与结合性总表（背这一张）

从上到下优先级由高到低，共 15 级：
级运算符结合性说明
1()　[]　->　.左 → 右最高：括号、下标、成员
2! ~ ++ -- + -（正负）*（解引用）&（取地址）(类型) sizeof右 → 左单目运算符，全部右结合
3*　/　%左 → 右乘除求余
4+　-左 → 右加减
5<<　>>左 → 右移位
6< <= > >=左 → 右关系
7==　!=左 → 右等于/不等于（比大小关系低一级！）
8& 按位与左 → 右位运算整体低于关系运算
9^ 按位异或左 → 右
10| 按位或左 → 右
11&&左 → 右逻辑与
12||左 → 右逻辑或
13? :右 → 左条件
14= 及各种复合赋值右 → 左赋值
15,左 → 右最低：逗号
三个必须刻进脑子的事实：① 单目运算符优先级最高（仅次于括号等），且是右结合；② 算术 > 关系 > 逻辑 > 赋值 > 逗号；③ 赋值和条件运算符是右结合，其余绝大多数左结合。
2026.4 真题·第 4 题 比 ++ 优先级高的只有第 1 级的 []、()、->、.——所以答案是 []；<、%、%= 都比 ++ 低。
2025.10 真题·第 4 题 &&、%、--、>= 中最高的是单目的 --。
2026.4 真题·第 19 题 单目运算符的结合方向是 自右向左。注意：该题官方答案栏误印"从左至右"，按 C 标准应为右结合，本站按正确答案标注。

三、算术运算：整除与求余的两条铁律

铁律 1：/ 两边都是整数 → 整除，结果向零取整（直接砍掉小数部分）。
5/2 = 2　5/2.0 = 2.5　5.0/2 = 2.5　-5/3 = -1（不是 −2，向零取整）　5/-3 = -1
铁律 2：% 两边只能是整数，结果符号与被除数（左边那个）相同。
7%3 = 1　-7%3 = -1　7%-3 = 1　-7%-3 = -1　5%2.0 非法（右边是实型）
说明：C89 对"负数求余的符号"未作强制规定，主流编译器（含考试用的 Turbo C / Dev-C++）按"与被除数同号"实现，答题按教材这条答即可。
类型提升：只要有一边是实型（float/double），另一边就自动转成实型，做的是实数除法。10/4*2.0 = 2*2.0 = 4.0（先整除再乘，不是 5.0！）
2026.4 真题·第 6 题 正确的除法运算是 5/2.0 = 2.5；-5/3 得 −1 不是 1，5/2.0 不是 2，5.0/2 不是 2（是 2.5）。
答题技巧：看到除法先看两边类型，只要出现 .0 或 float/double 变量，就按实数算；否则一律整除。

四、自增自减：前后缀与"必须是变量"

写法含义在表达式中的值
++i（前缀）先 i = i + 1，再用加完之后的值
i++（后缀）先用原来的值，再 i = i + 1加之前的值
--i / i--同理，减 1同上
int i = 3, a, b, c;
a = i++;      /* a = 3，i 变成 4 */
b = ++i;      /* i 先变 5，b = 5 */
c = i-- + --i;  /* ✗ 别这么写：同一表达式中对同一变量多次自增，结果依赖编译器 */
只能作用于"变量"（左值），不能作用于常量或表达式：
写法对错原因
i++✓i 是变量
i + 3✓普通加法表达式，没问题
i+3++✗3 是常量，不能自增（而且被解析成 (i+3)++）
--(i+3)✗括号里是表达式，没有内存单元可改
++(i++)✗i++ 的结果是"值"不是变量
2026.4 真题·第 5 题 int i=3; 后表达式正确的是 i+3；其余三项都是把 ++/-- 用在常量或表达式上。
2025.10 真题·第 18 题 int x=3, y=4; 则 ++x<y 的值是 0：先 x 变 4，再算 4<4 为假，关系表达式的值就是 0。

五、关系与逻辑：结果只有 0 和 1，还有短路

关系运算结果：真为 1，假为 0。逻辑运算结果也只有 0/1，判断标准是"非 0 即真"。
运算符为真的条件是否短路
a && ba、b 都非 0a 为 0 时，b 根本不计算
a || ba、b 有一个非 0a 非 0 时，b 根本不计算
!aa 为 0—
短路求值就是"跳过副作用"：如果右边写了 ++i，而左边已经决定了结果，i 就不会被加 1。程序分析题里最爱考这一点。

例：短路让右边的自增"没有发生"

int i = 1, r;
r = (i > 5) && (i++);        /* i>5 为假 → i++ 不执行 */
printf("%d,%d\n", r, i);
0,1　　← r 为 0（假），i 仍是 1；若把 && 换成 ||，i++ 也不会执行而 r 为 1
2025.10 真题·第 26 题 与 2026.4 真题·第 26 题 都是"自增 + 短路"的连环题：推的时候每算一步就把变量的新值写在旁边，遇到 && 左边为假 / || 左边为真，立刻跳过后面的所有自增。
两个高频坑：
① if (a = 0) 是赋值不是比较，值恒为 0 → 条件永远假；要比较必须写 a == 0。
② 0 < x < 10 在 C 里不表示"x 在 0 到 10 之间"：先算 0 < x 得 0 或 1，再拿这个结果和 10 比，结果恒为真。正确写法：x > 0 && x < 10。

六、赋值、逗号、条件、sizeof

（1）赋值：= 右边先算，再赋给左边；右结合，a = b = c = 0 等价于 a = (b = (c = 0))。
复合赋值：a += b 等价于 a = a + b；x *= y + 1 等价于 x = x * (y + 1)（右边整体参与，不是 x*y+1）。
写法等价于
a += ba = a + b
a -= ba = a - b
a *= b + 1a = a * (b + 1)
a /= ba = a / b（两边都整型时按整除）
a %= ba = a % b
（2）逗号表达式：表达式1, 表达式2, …, 表达式n，从左到右依次执行，整个表达式的值是最后一个，优先级最低。 
int a, b;
a = (1, 2, 3);                 /* a = 3 */
b = 1, 2, 3;                   /* 这是赋值语句 + 逗号表达式：b = 1 */
（3）条件表达式：e1 ? e2 : e3，e1 非 0 取 e2，否则取 e3；右结合，可嵌套。 
max = (a > b) ? a : b;         /* 等价于 if (a>b) max=a; else max=b; */
sign = (x > 0) ? 1 : (x < 0) ? -1 : 0;   /* 嵌套，右结合 */
（4）sizeof：求类型或变量占用的字节数，是运算符不是函数。注意 sizeof('a') 在 C 中是 4（字符常量按 int 处理），而 sizeof(char) 是 1——这一点与 C++ 不同。

七、位运算一眼带过

位运算只对整型数据按二进制位操作，考得少（两套卷都没直接考），但要知道符号：
运算符名称例（以 8 位示意）
a & b按位与6 & 3 = 110 & 011 = 010 = 2（常用于"取某几位"）
a | b按位或6 | 3 = 110 | 011 = 111 = 7（常用于"置某位为 1"）
a ^ b按位异或6 ^ 3 = 5（相同为 0、不同为 1；a^a=0，可用来交换两数）
~a按位取反~0 = −1（补码表示）
a << n左移 n 位相当于乘 2ⁿ（高位溢出丢弃）
a >> n右移 n 位相当于除以 2ⁿ（负数右移补 1，结果与编译器实现相关）
别混：&（按位与）与 &&（逻辑与）、|（按位或）与 ||（逻辑或）、^（按位异或）与数学的"次方"完全是两回事。

八、本章小结与真题呼应

一条主线：先背优先级——括号 → 单目 → 算术（* / % 高于 + -）→ 移位 → 关系 → 相等 → 位运算 → 逻辑 → 条件 → 赋值 → 逗号，单目与赋值、条件右结合，其余左结合 → 再看类型：两边都整型就是整除/求余 → 再看有没有 ++/--（只能在变量上，前后缀取值不同）→ 最后看有没有 &&/||（短路会跳过右边、连带跳过自增）。
