一、循环三要素与三种语句

任何循环都必须回答三个问题，缺一个就是死循环或跑错次数：
  1. 初值：循环变量从哪儿开始（i = 1;）。
  2. 条件：什么时候继续（i <= 100）。
  3. 增量：每轮怎么变化（i++）。
语句特点循环体最少执行次数
while (条件) 循环体;先判断，后执行0 次（条件一开始就假）
do 循环体; while (条件);先执行，后判断；末尾必须有分号1 次
for (初值; 条件; 增量) 循环体;三要素写在一行，最紧凑0 次（条件一开始就假）
三者可以互相改写：任何一个 for 都能拆成 while； for (i=1; i<=n; i++) s+=i; ⇔ i=1; while (i<=n) { s+=i; i++; }

二、while 与 do-while：至少执行几次

while：条件不成立就一次都不做

int i = 1, sum = 0;
while (i <= 100) {        /* 先判断 */
    sum += i;             /* 累加 */
    i++;                  /* 增量，忘了就是死循环 */
}
printf("%d\n", sum);      /* 5050 */

do-while：不管条件如何，先做一次

int n;
do {
    scanf("%d", &n);     /* 先读一次，再判断合不合法 */
} while (n <= 0);         /* 注意这个分号！漏了直接编译错误 */
典型用途："至少输入一次、直到输入合法为止"——用 while 做不到"先做后判"，用 do-while 最自然。
最常考的一句话：do-while 的循环体至少执行一次；while 和 for 可能一次都不执行。题目问"哪个循环体一定至少执行一次"，答 do-while。

三、for 的执行顺序与省略写法

执行顺序（背下来，程序分析题全靠它）：
① 求初值（只做一次）→ ② 判断条件（假就结束）→ ③ 执行循环体 → ④ 求增量 → 回到 ②
写法含义是否合法
for (i=0; i<10; i++)标准写法✓
for (;;)死循环（靠 break 跳出），等价 while (1)✓
for (i=0; i<10; ) + 体内 i++增量写在循环体里✓
for (i=0, j=10; i<j; i++, j--)初值、增量都可以是逗号表达式✓（要写成逗号表达式，不能直接写两个分号）
for (int i=0; i<10; i++)C99 才允许在 for 里声明变量✗ C89 禁止
三个表达式都能省，但两个分号一个都不能省：for ( ; ; ) 合法，for ( ) 非法。

四、break 与 continue 的差别

语句作用范围效果
break;循环 / switch结束整个循环，直接跳到循环后面的第一条语句
continue;只能用在循环里结束本次循环，跳过剩余语句，进入下一次（for 会先做增量）
int i;
for (i = 1; i <= 10; i++) {
    if (i == 3) continue;     /* 只跳过 3 */
    if (i == 6) break;        /* 到 6 就整体结束 */
    printf("%d ", i);
}
printf("\n");                 /* 输出：1 2 4 5 */
1 2 4 5
嵌套时的关键：break 和 continue 都只管自己所在的最内层循环，不能一次跳出两层（要跳两层得用 goto 或加标志变量）。

五、嵌套循环：外层一次，内层一轮

口诀：外层转一圈，内层跑满一整轮。总次数 = 外层次数 × 内层次数（前提是内层次数与外层无关）。
最容易错的一点：内层循环的"初值"每轮都会重新执行——所以 j = 1 必须写在 for 的初值里，不能提到外层去（一旦提到外面，第二轮内层就会从上次结束的位置开始，次数全乱）。

例：只给内层加大括号——"少一对花括号"的经典坑（2025.10 第 27 题同型）

int i, j, w = 0;
for (i = 4; i > 1; i--)
    for (j = 1; j < i; j++)
        w += j;
printf("%d\n", w);
外层 i内层 j 取值本轮累加w 累计
41,2,3+66
31,2+39
21+110
1不进入（1 < 1 假）010
10
注意：这里没写花括号，内层 for 就是外层唯一的循环体，语法完全正确；但如果在外层里面还想写一条别的语句，就必须加 { }，否则那条语句只在外层结束之后执行一次。

④ 素数判断for (i=2;i*i<=n;i++) if (n%i==0) break;　循环正常结束才是素数—

例 1：能被 13 或 17 整除的数求和（2025.10 第 33 题）

#include <stdio.h>

int main(void)
{
    int k, i, sum = 0;

    scanf("%d", &k);
    for (i = 1; i <= k; i++)                 /* 枚举 1 ~ k */
        if (i % 13 == 0 || i % 17 == 0)      /* 是 13 或 17 的倍数 */
            sum += i;
    printf("%d\n", sum);
    return 0;
}
三个得分点：枚举范围含 k（<= 不是 <）、用 || 不是 &&、sum 初始化成 0。

例 2：判断素数（循环 + break 的经典组合）

int n, i, flag = 1;

scanf("%d", &n);
if (n < 2)
    flag = 0;
else
    for (i = 2; i * i <= n; i++)
        if (n % i == 0) {
            flag = 0;
            break;              /* 找到因子就不是素数，立刻结束 */
        }
if (flag)
    printf("%d 是素数\n", n);
else
    printf("%d 不是素数\n", n);
为什么写 i*i <= n：因子成对出现，只需试到 √n，既正确又快。i < n 也对，只是多跑很多轮。

七、手推循环题的"变量跟踪表"

程序分析题（第 27 题）不要心算，画一张表，一行一轮，绝不会错：
  1. 先写下所有会被修改的变量名（循环变量 + 累加变量）。
  2. 每执行一轮，记下这一轮结束时各变量的值。
  3. 特别注意：循环变量是先加还是先用（++i/i++）、判断用的是 < 还是 <=、内层变量每轮是否重置。
  4. 最后写输出时，逐个字符核对分隔符（空格、逗号、换行都算分）。

八、本章小结与真题呼应

一条主线：三要素（初值、条件、增量）→ 三种写法（while 可能 0 次 / do-while 至少 1 次 / for 最紧凑）→ break 跳整层、continue 只跳本轮 → 嵌套"外层一圈、内层一轮"，内层初值必须每轮重置 → 五类套路（累加、累乘、最值、素数、穷举/递推）几乎覆盖所有大题。
