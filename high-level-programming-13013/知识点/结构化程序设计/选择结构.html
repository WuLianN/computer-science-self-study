一、条件的本质：非 0 即真

C 没有"布尔类型"（C89），任何表达式都能当条件：值为 0 视为假，非 0 视为真。真正的关系必须是 0 或 1；但 if (5)、while (n) 都是合法的。
写法结果为什么
if (a = 0)永远为假这是赋值：把 0 赋给 a，整个表达式的值就是 0
if (a = 5)永远为真赋值后表达式的值是 5（同时把 a 改成了 5）
if (a == 0)按实际判断这才是"比较"
if (x)x 非 0 就是真等价于 x != 0
防御性写法（养成本能）：把常量写在左边，if (0 == a)——万一漏写一个等号，编译器会报"不能给常量赋值"，错误当场暴露，而不是藏到运行时。

二、if 的三种形式与四条铁律

形式写法执行
单分支if (条件) 语句;条件真才执行，假就跳过
双分支if (条件) 语句1; else 语句2;二者必执行其一
多分支if (c1) s1; else if (c2) s2; … else sn;从上往下判断，命中一个就跳出整条链
  1. 条件必须用圆括号括起来，括号后不能加分号（if (x > 0); 是"条件成立时执行空语句"）。
  2. if / else 后面"管"的只有一条语句；要多条必须用 { } 变成复合语句。
  3. else 不能单独出现，它必须跟着一个 if。
  4. 多分支是"短路"的：前面的条件一旦成立，后面的 else if 一律不再判断——所以区间要按从大到小或从小到大的顺序排，别乱序。
最经典的两个错误（每年都有人踩）：
if (x > 0); → 多了个分号，条件成立时的"语句"变成空语句，下一行无条件执行。
if (x > 0)
    printf("正");
    printf("数"); → 第二个 printf 不在 if 里，永远执行。

三、嵌套 if 与悬空 else

else 永远与它上面最近的那个"还没有配对"的 if 配对——不管缩进写得多好看。 
if (a > 0)
    if (b > 0)
        printf("a>0 且 b>0\n");
else
    printf("else 到底跟谁走？\n");   /* ✗ 实际跟里面的 if (b>0) 配对！ */
正确做法：用花括号把意图写死。 
if (a > 0) {
    if (b > 0)
        printf("a>0 且 b>0\n");
} else {                             /* ✓ 现在明确属于外层 if */
    printf("a<=0\n");
}

四、switch：case 常量、break 与"下落"

格式： 
switch (表达式) {
case 常量1:
    语句序列1;
    break;
case 常量2:
    语句序列2;
    break;
default:
    语句序列n;
}
要点说明
表达式类型只能是整型（含 char、enum），不能是实型、字符串；switch(x) 里 x 是 float 直接编译错误
case 后面必须是常量表达式（case 1:、case 'A':、case 2+3:），不能是变量，各 case 的值不能重复
default可以没有；位置任意（放中间也行），但只在所有 case 都不匹配时才进入
break跳出整个 switch；没有 break 就"下落"，继续执行下一个 case 的语句（不管它的值匹配不匹配）
配对原则先算表达式的值 → 找到匹配的 case 作入口 → 一路往下执行，直到遇到 break 或 switch 结束

例：没有 break 的"下落"（2026.4 第 26 题同型）

int x = 2;
switch (x) {
case 1: printf("A ");
case 2: printf("B ");      /* 从这里进入 */
case 3: printf("C ");      /* 没有 break → 继续下落 */
        break;
default: printf("D ");
}
printf("\n");
B C
推法：x = 2 → 从 case 2 进入 → 打印 B → 没有 break → 落进 case 3 打印 C → 遇到 break 跳出。匹配只决定"从哪儿进"，不决定"到哪儿停"。
什么时候"故意不写 break"是合法的？多个值走同一段代码时： 
switch (ch) {
case 'a':
case 'A': printf("元音 A\n"); break;   /* 大小写共用一段 */
case 'b':
case 'B': printf("辅音 B\n"); break;
default : break;
}
除这种"多入口一段代码"外，每个 case 都要有 break。

五、多分支区间判断（第 33 题标准套路）

switch 只能判"等于某个常量"，判断区间必须用 if-else 链。写法上有两条铁律：
  1. 区间必须首尾相接、不重不漏：每一档都写清"含不含边界"，如 x >= 0 && x < 35、x >= 35 && x <= 75、x > 75。
  2. else if 的顺序按从小到大（或从大到小）排，利用"命中即跳出"，后面的条件不必再重复前面的下界。

例：PM2.5 空气质量（2026.4 第 33 题）

规则：0 ~ 35（含 0 不含 35）为优；35 ~ 75（含 35 和 75）为良；75 以上为污染。

#include <stdio.h>

int main(void)
{
    int pm;

    scanf("%d", &pm);
    if (pm >= 0 && pm < 35)              /* 含 0，不含 35 */
        printf("优\n");
    else if (pm >= 35 && pm <= 75)        /* 含 35 和 75 */
        printf("良\n");
    else if (pm > 75)                      /* 75 以上 */
        printf("污染\n");
    else
        printf("输入无效\n");              /* 负数兜底，不写也不扣分 */
    return 0;
}
边界自检：35 落在第二档（第一档 < 35 不含它）；75 也在第二档；76 进第三档。把边界值 0 / 35 / 75 / 76 各代进去手推一遍，能挡住 90% 的丢分。
另一种常见写法（利用命中即跳出）： 
if (pm < 35)
    printf("优\n");
else if (pm <= 75)
    printf("良\n");
else
    printf("污染\n");
第二种更短，但只在前一档已经排除了小值时才成立；如果题目要求"负数也要报错"，就必须用第一种写法。

六、本章小结与真题呼应

一条主线：条件看"非 0 即真" → 单分支 / 双分支 / 多分支（命中即跳出，顺序别乱）→ 多条语句记得加花括号 → else 配最近未配对的 if（用花括号写死）→ switch 只能判整型等于某常量，case 后必须是常量，忘写 break 就下落 → 判区间只能用 if-else 链，边界含不含必须逐字对齐题目。

两套卷本章的题：2026.4-26 switch 下落 + 短路（答案 4 8 7）、2026.4-33 PM2.5 多分支区间判断（8 分，边界错一个就整题减分）。
做题口诀：先定入口，再看有没有 break，最后把边界值代一遍。
