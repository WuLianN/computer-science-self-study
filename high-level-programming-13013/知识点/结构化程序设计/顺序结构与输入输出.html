一、顺序结构与语句回顾

顺序结构：程序按书写顺序逐条执行，没有分支也没有回头。它是另外两种结构的基础——选择结构和循环结构的"每一支"里面，都是顺序结构。
语句写法作用
赋值语句变量 = 表达式;把右边算出来存进左边（左必须是变量）
函数调用语句printf(…);把控制权交给函数，做完再回来
复合语句{ … }多条语句当一个整体用
空语句;什么都不做
赋值的方向性：a = b 是把 b 的值给 a，a 原来的值被覆盖；反过来写就换了一个意思。考试里常靠这一点出"交换两个变量"的题——必须用t = a; a = b; b = t;，不能直接 a = b; b = a;。

二、printf：格式符与宽度精度

格式：printf("格式控制串", 输出表列);　格式串里的 % 后跟格式符，一个格式符对应后面一个输出项。
格式符含义例（值 → 输出）
%d十进制整型printf("%d", 42) → 42
%o八进制（无 # 时不带前导 0）15 → 17
%x / %X十六进制（小写/大写）255 → ff / FF
%u无符号十进制负数会按无符号解释成很大的数
%c单个字符'A' → A
%s字符串（遇到 '\0' 停）"abc" → abc
%f实型，默认 6 位小数3.14 → 3.140000
%e指数形式31400.0 → 3.140000e+04
%g自动选 %f 或 %e 中较短的一种—
%%输出一个百分号—
宽度与精度：%m.n格式符 —— m 是最小宽度（不够左边补空格，超过就按实际输出），n 是小数位数（对 %s 则是取前 n 个字符）；- 表示左对齐；0 表示补 0。

例：同一批值用不同宽度输出

printf("%d|%5d|%-5d|%05d|\n", 42, 42, 42, 42);
printf("%f|%.2f|%8.2f\n", 3.14159, 3.14159, 3.14159);
printf("%s|%5s|%-5s|%.2s\n", "abc", "abc", "abc", "abc");
42|   42|42   |00042|
3.141590|3.14|    3.14
abc|  abc|abc  |ab
关键：%5d 输出 42 时左边补 3 个空格；%-5d 补在右边；%05d 补 0。%2d 输出 487 时宽度不够，按实际 3 位输出，不会截断。
2026.4 真题·第 26 题 就用到了 %2d 的宽度规则（答案 4 8 7）：宽度不足时原样输出，所以三个数之间是靠格式串里自己写的空格分开的，不是靠 %2d 补齐。

三、scanf：地址表、分隔符与返回值

格式：scanf("格式控制串", &变量1, &变量2 …);
要点说明
必须写 &除了字符数组名（本身就是地址），其余变量都要加 &。漏写 & 是程序填空题最常见的扣分点（常常是"能编译、运行崩"）
不能有精度scanf("%5.2f", &x) 非法（scanf 可写宽度，但不能指定小数位）
普通字符要原样输入scanf("%d,%d", &a, &b) 输入时必须写成 3,5；写成 3 5 则 b 读不到
%d/%f 自动跳过空白scanf("%d%d", &a, &b) 的输入可以用空格、Tab、回车任意分隔
%c 不跳过任何字符scanf("%c", &ch) 会把空格、回车都读进来
返回值成功读入的变量个数；遇到输入结束或格式不匹配返回 0 / EOF

例：两种分隔写法的差别

int a, b;
scanf("%d%d", &a, &b);        /* 输入 3 5  或 3<回车>5 都行 */

scanf("%d,%d", &a, &b);      /* 必须输入 3,5 —— 漏了逗号 b 就永远读不到 */

scanf("%d\n", &a);            /* ✗ 别在 scanf 里加 \n，它要求你再输入一个非空白字符 */

四、字符与字符串输入输出四函数

函数调用形式作用注意
putcharputchar(ch);输出一个字符参数可以是字符常量、变量或整型 ASCII 码
getcharch = getchar();从键盘读一个字符没有参数；返回 int；连空格和回车都会读
putsputs(s);输出一个字符串自动在末尾加一个换行
getsgets(s);读入一整行（可含空格）遇到回车结束，并把回车换成 '\0'；能读空格，这是它和 scanf("%s") 的关键区别
四个函数都声明在 <stdio.h> 里。字符分类/转换函数（isupper、islower、isdigit、toupper、tolower）在 <ctype.h> 里，字符串处理函数（strlen、strcpy、strcat、strcmp）在 <string.h> 里。考试给的代码框架里，头文件已经写好了，别自己加。

例：读一整行再逐字符处理（2025.10 第 30 题同一套路）

#include <ctype.h>
#include <stdio.h>

int main(void)
{
    char s[100];
    int i;

    gets(s);                          /* 读整行，含空格 */
    for (i = 0; s[i] != '\0'; i++) {  /* 遍历到字符串结束符 */
        if (isupper(s[i]))
            s[i] = tolower(s[i]);
        else if (islower(s[i]))
            s[i] = toupper(s[i]);
        else if (isdigit(s[i]))
            s[i] = '0';               /* 数字统一变成字符 '0' */
    }
    puts(s);
    return 0;
}
这一题的三个空分别是：循环条件 s[i] != '\0'、判断大写 isupper(s[i]) / 判断小写 islower(s[i])、数字替换成 '0'。

五、缓冲区里的回车——最阴的坑

键盘输入先进缓冲区，函数再从缓冲区取。用 scanf("%d", &n) 读完数字后，你敲的那个回车还留在缓冲区里；紧接着的 getchar() 或 gets() 会立刻把它读走，看起来就像"程序跳过了输入"。 
int n;
char ch;

scanf("%d", &n);        /* 输入 5<回车> —— 回车留在缓冲区 */
ch = getchar();        /* ch 得到的是 '\n'，不是你想输入的字符！ */
getchar();             /* ✓ 补救：先吃掉那个回车，再读下一个字符 */
三种常用补救：① 在读字符前多写一个 getchar();；② 用 scanf(" %c", &ch);（格式串里加一个空格，表示跳过所有空白字符）；③ 干脆统一用 gets 读整行再自己解析。

六、本章小结与真题呼应

一条主线：顺序结构就是"一条接一条" → 输出用 printf，重点记 10 个格式符 + %m.n 宽度精度（%2d 不够宽就按实际输出）→ 输入用 scanf，变量前面必须有 &、格式串里的逗号要跟着输、%c 连回车都吃 → 整行读用 gets（能吃空格），整行写用 puts（自动换行）→ 遇到"跳过了输入"，先想到缓冲区残留的回车。

本章在两套卷里不单独出客观题，但每一道程序填空（30–32 题）和程序设计（33–34 题）的第 1 行都在用它：2025.10-30 用 gets + ctype.h 做大小写转换，2026.4-31 用 gets + strlen 做子串复制，2026.4-34 用 scanf 读 10 个数。
记住一句话：读入写错，后面全错。
