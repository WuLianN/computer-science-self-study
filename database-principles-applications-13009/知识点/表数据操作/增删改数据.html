一、插入数据 INSERT：五种写法 ⭐

识记 插入语句的概念与类别；简单应用 正确编写各类插入语句。
概念：INSERT 属于 DML（数据操纵语言），向已存在的表中增加新行（元组），不改变表结构。 
表结构：student(sno, sname, ssex, sage, sdept)

-- ① 全列插入：值的顺序必须与列定义顺序完全一致，列名可省略
INSERT INTO student VALUES ('20210001','小明','男',20,'计算机');

-- ② 指定列插入：未给出的列取 DEFAULT，无默认值则为 NULL（要求 NOT NULL 就报错）
INSERT INTO student(sno, sname, ssex) VALUES ('20210002','小红','女');

-- ③ 一次插入多条记录（值组用逗号分隔，MySQL 支持，标准 SQL 早期不支持）
INSERT INTO student(sno, sname) VALUES
    ('20210003','小刚'),
    ('20210004','小美'),
    ('20210005','小强');

-- ④ 插入子查询结果（把另一张表的行灌进来）
INSERT INTO history_stu
    SELECT * FROM student WHERE sage > 22;

-- ⑤ INSERT IGNORE / ON DUPLICATE KEY UPDATE（了解：主键冲突时忽略或改为更新）
INSERT IGNORE INTO student(sno, sname) VALUES ('20210001','小明');
⚠️ 判分点：①列名与值个数、顺序、类型要一一对应；②字符串、日期值必须加单引号，数字不加；③省略列名时必须给全所有列的值，少给一个就报 "Column count doesn't match value count"。

二、REPLACE 语句（领会）

领会 REPLACE 语句的含义。
REPLACE 语法与 INSERT 完全一样，区别在遇到主键/唯一键冲突时的行为：
语句无冲突时有主键/唯一键冲突时
INSERT插入新行报错，插入失败
REPLACE插入新行先 DELETE 旧行，再 INSERT 新行（未给出的列变成默认值/NULL，不是保留原值！）
REPLACE INTO student(sno, sname) VALUES ('20210001', '小明改');
-- 若表已有 sno='20210001'，该行被删除并重新插入，ssex/sage/sdept 变 NULL
🔑 概念表述：REPLACE = "有则替换、无则插入"，实现"插入或覆盖"效果；它依赖表上存在主键或唯一索引，没有键时行为退化成普通 INSERT。

三、修改数据 UPDATE ⭐

识记 修改全部记录与修改指定记录两种方法；简单应用 用 UPDATE 完成记录修改。
-- ① 修改指定记录：带 WHERE，只影响匹配的行
UPDATE student SET sage = 21 WHERE sno = '20210001';
UPDATE student SET sdept = '软件学院', sage = sage + 1
       WHERE ssex = '男' AND sage > 20;     -- 一次改多列、列自身参与运算

-- ② 修改全部记录：不写 WHERE，全表所有行都按 SET 表达式更新
UPDATE student SET sage = sage + 1;

-- ③ 用子查询提供条件或新值（了解）
UPDATE sc SET grade = grade * 1.1
   WHERE cno IN (SELECT cno FROM course WHERE credit >= 4);
要素规则
语法骨架UPDATE 表名 SET 列1=值1, 列2=值2 [WHERE 条件]
SET 右侧可以是常量、表达式（sage+1）、子查询
WHERE 省略作用于全部行——这是最常见的"危险写法"，考试爱问后果
执行结果返回 Rows matched / Changed；条件不匹配时不报错、改动 0 行
⚠️ 别把 SET 写成 = 之外的比较，也别用 UPDATE ... VALUES（语法错误）。改表结构是第 3 章的 ALTER TABLE，改数据才是 UPDATE。

四、删除数据 DELETE 与 TRUNCATE ⭐

识记 删除数据的两种方法、删除全部记录的两种方式；领会 删除指定记录与删除全部记录的区别；简单应用 DELETE 语句。
删除数据的两种方法（按语句分类）：① DELETE —— DML，可带 WHERE，一次删一行或一批；② TRUNCATE TABLE —— DDL，只能清空整张表。 
-- ① 删除指定记录
DELETE FROM student WHERE sno = '20210005';
DELETE FROM sc WHERE grade < (SELECT AVG(grade) FROM sc);   -- 条件用子查询

-- ② 删除全部记录的两种方式
DELETE FROM student;        -- 方式 A：DELETE 不带 WHERE，逐行删除
TRUNCATE TABLE student;     -- 方式 B：清空表（重建表，速度快）
对比项DELETE（无 WHERE）TRUNCATE TABLE
语言类别DMLDDL
删除方式逐行删除，写入 undo 日志直接释放数据页，不逐行删
速度慢（大表尤甚）快
可否回滚可以（在事务中 ROLLBACK）隐式提交、不可回滚
触发器激活 DELETE 触发器不激活触发器
WHERE可以带不能带条件
AUTO_INCREMENT计数器保留重新从 1 开始
外键限制子表有引用则按级联动作处理被外键引用的表不能 TRUNCATE
📝 简答模板（删除指定记录与删除全部记录的区别）：删除指定记录用 DELETE FROM 表 WHERE 条件，只影响满足条件的元组；删除全部记录可以①省略 WHERE 的 DELETE（逐行删除、可回滚、较慢），或②TRUNCATE TABLE（属于 DDL，直接清空、速度快、不可回滚、不触发行级触发器，也不能带条件）。DROP TABLE 则是把表结构连同数据一起删除，属第三种层次。

五、DML 与完整性约束的关系（领会）

领会 增删改如何受实体完整性、参照完整性制约（衔接第 7 章）。
操作可能违反MySQL 的应对
INSERT主键重复 / 非空列给 NULL / CHECK 不满足 / 外码在被参照表中不存在报错，语句失败
UPDATE 主码导致子表外码悬空按外键定义的 ON UPDATE 动作处理
DELETE 被引用行参照完整性按 ON DELETE 动作：CASCADE 级联删子表 / SET NULL 置空 / RESTRICT·NO ACTION（默认）拒绝删除
CREATE TABLE sc (
  sno CHAR(8), cno CHAR(3), grade SMALLINT,
  PRIMARY KEY(sno, cno),
  FOREIGN KEY(sno) REFERENCES student(sno)
      ON DELETE CASCADE ON UPDATE CASCADE   -- 学生删除时其选课记录一并删除
);
🔑 记牢：默认动作是 RESTRICT（拒绝），不是级联。想让删父行时子行跟着变，必须显式写 CASCADE 或 SET NULL。而且这些动作只有 InnoDB 引擎支持。

六、本章速记小结

INSERT 四种必背写法：全列（VALUES 顺序必须与列一致）、指定列（INSERT INTO 表(列…) VALUES (值…)）、多行（值组用逗号）、插查询结果（INSERT INTO … SELECT）；INSERT IGNORE 属了解项。
REPLACE：键冲突时先删后插，没写的列会变 NULL——不是"部分更新"。
UPDATE：SET 可多列、可用表达式；漏写 WHERE = 全表被改。
DELETE vs TRUNCATE：逐行/可回滚/可带条件 ↔ 整表/不可回滚/无条件/DDL。
DROP 是删表（结构+数据），DELETE/TRUNCATE 只删数据，表结构还在。
外键默认 RESTRICT，级联要显式写 ON DELETE CASCADE。
