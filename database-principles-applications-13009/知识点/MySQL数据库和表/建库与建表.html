一、MySQL 简介与查看数据库（识记）

识记 用 SHOW DATABASES 查看已有数据库。
MySQL 是开源的关系型数据库管理系统（DBMS），采用客户端 / 服务器体系结构：一个 MySQL 服务器可管理多个数据库，一个数据库含多张表，一张表含多行多列。常用组件：MySQL Server、命令行客户端 mysql、图形工具（MySQL Workbench、phpMyAdmin、Navicat）。 
-- 登录
mysql -u root -p
SHOW DATABASES;            -- 查看所有数据库（本章唯一要求识记的查看语句）
SELECT VERSION();           -- 查看版本（了解）
MySQL 8 自带的四个系统库：mysql（用户与权限表所在库，见第 8 章）、information_schema（元数据/表结构）、performance_schema（性能统计）、sys（性能视图封装）。

二、定义数据库四条语句 ⭐

识记 CREATE / ALTER / DROP DATABASE 与 USE 语句；简单应用 四类语句的使用。
-- ① 创建数据库（IF NOT EXISTS 可省略，重复创建不报错）
CREATE DATABASE IF NOT EXISTS student_mgr
    DEFAULT CHARACTER SET utf8mb4;
-- ② 使用（选择）数据库：之后的操作都在这个库里
USE student_mgr;
-- ③ 修改数据库属性（只能改字符集/排序规则，不能改名→改名要新建再迁移）
ALTER DATABASE student_mgr DEFAULT CHARACTER SET gbk;
-- ④ 删除数据库：连同其中所有表一起删除，慎用
DROP DATABASE IF EXISTS student_mgr;
语句作用关键细节
CREATE DATABASE 库名建库可加 IF NOT EXISTS 与字符集子句
USE 库名选为当前库未 USE 时用 库名.表名 全限定访问
ALTER DATABASE改库的属性改的是字符集/排序规则，不改名
DROP DATABASE删库可加 IF EXISTS；不可回滚
SHOW DATABASES列出所有库—
⚠️ 三个高频错：① CREATE DATABASE 后不写分号直接接下一条语句；② 库名/表名在 MySQL 中区分大小写取决于操作系统（Linux 敏感、Windows 不敏感），答题按 SQL 标准写即可；③ 别把 USE 当成"创建"——它只是选择当前数据库。

三、表的基本概念与表结构（识记 / 领会）

识记 表的概念与组成；领会 表结构的含义、表 / 列 / 属性的关系。
表（Table）是 MySQL 中存储数据的基本逻辑单元，一个表由行（记录/元组）和列（字段/属性）构成。
三层视角叫法说明
物理/日常数据库 → 表 → 记录（行）→ 字段（列）→ 值一个库多张表，一张表多行
关系模型术语关系 → 元组 → 属性 → 分量表 = 关系；行 = 元组；列 = 属性（第 2 章已学）
三级模式对应基本表 = 模式；视图 = 外模式；存储文件 = 内模式选择题常客，SQL 支持三级模式
表结构由什么决定：每张表的列名、列的数据类型、宽度/精度、约束（主键/非空/唯一/默认值）、字符集、存储引擎等构成表结构（元数据），可通过 DESC 表名 查看。表结构是"型"，表数据是"值"——定义表就是定义结构，与插入数据是两回事（第 4 章）。

四、MySQL 常用数据类型 ⭐

识记 MySQL 常用数据类型；领会 各类型含义、数字类型的选择、类型选择遵循的原则。
类别类型范围 / 长度说明
整数TINYINT有符号 −128 ~ 1271 字节，适合年龄、布尔标记
SMALLINT−2¹⁵ ~ 2¹⁵−12 字节

类型选择遵循的原则（简答/领会）：①在满足取值范围前提下选占存储空间最小的类型（能 TINYINT 就不用 INT）；②长度要"够用就好"，不要一律 VARCHAR(255)；③定长用 CHAR、变长用 VARCHAR（性别、国家码、学号→CHAR；姓名、备注→VARCHAR）；④涉及精确计算（货币）用 DECIMAL，不用 FLOAT/DOUBLE；⑤日期时间用专门类型，不要用字符串存，否则无法直接比较与函数计算；⑥尽量避免使用 BLOB/TEXT，必要时单独建表存放；⑦考虑将来扩展与索引长度限制。
⚠️ 高频辨析：TIMESTAMP vs DATETIME——前者4 字节、受时区影响、范围只到 2038，且列可设自动填充/自动更新；后者 8 字节、范围大、不受时区影响。

五、定义表 CREATE TABLE ⭐

识记 创建表的语句；简单应用 CREATE TABLE 的使用。
-- 列级约束写法（最常见）
CREATE TABLE student (
    sno    CHAR(8)  NOT NULL PRIMARY KEY,   -- 主码
    sname  VARCHAR(20) NOT NULL,              -- 非空
    ssex   ENUM('男','女') DEFAULT '男',    -- 默认值
    sage   SMALLINT,
    sdept  VARCHAR(20)
);

-- 表级约束写法（多列共同构成主键时必须这样写）
CREATE TABLE sc (
    sno CHAR(8), cno CHAR(3), grade SMALLINT,
    PRIMARY KEY (sno, cno)              -- 复合主键
);
建表时能一起声明的东西：列名与类型、NOT NULL / DEFAULT / AUTO_INCREMENT、PRIMARY KEY、UNIQUE、FOREIGN KEY ... REFERENCES、CHECK（8.0.16 起生效）、表选项 ENGINE=InnoDB DEFAULT CHARSET=utf8mb4。约束语句的增删改在第 7 章详讲。
📝 考纲·题型举例·综合题第 (3) 问就是"用 SQL 语句建立'科室'表"——科室(科室名, 地址, 电话)，主码科室名。范答：
CREATE TABLE 科室 (科室名 VARCHAR(20) PRIMARY KEY, 地址 VARCHAR(50), 电话 CHAR(12));（写清主码、给出合理类型即得分）

六、改表、删表与查看 ⭐

识记 查看 / 修改 / 删除表的语句；简单应用 ALTER TABLE、DROP TABLE、SHOW TABLES。
-- 查看
SHOW TABLES;                    -- 当前库中所有表
DESC student;                   -- 查看表结构（= DESCRIBE / SHOW COLUMNS FROM student）
SHOW CREATE TABLE student;      -- 查看建表原语句（了解）

-- 修改表结构：ALTER TABLE 表名 动作
ALTER TABLE student ADD email VARCHAR(30);          -- ① 增加列
ALTER TABLE student DROP email;                     -- ② 删除列
ALTER TABLE student MODIFY sname VARCHAR(30) NOT NULL;  -- ③ 改列的类型/约束（不改名）
ALTER TABLE student CHANGE sname stuname VARCHAR(30);    -- ④ 改列名（必须重写类型！）
ALTER TABLE student RENAME TO stu;                  -- ⑤ 改表名

-- 删除表：先删有外键引用的表会报错，要先删子表
DROP TABLE IF EXISTS stu;
动作关键字易混点
加列 / 加约束ADD加约束也写作 ADD CONSTRAINT 名 PRIMARY KEY(列)
删列 / 删约束DROPDROP PRIMARY KEY、DROP FOREIGN KEY 名
改列属性（不改名）MODIFY只重写类型和约束
改列名（可带属性）CHANGE 旧名 新名 类型必须把类型一起写全，否则报错
只改新名RENAME COLUMN 旧 TO 新等价于 CHANGE 的改名用法（了解）
⚠️ MODIFY 与 CHANGE 的区别是简答/选择爱考点：CHANGE 能改列名、且要重复写数据类型；MODIFY 不能改名、只改类型与约束。另一个坑：ALTER TABLE 改的是表结构（DDL），UPDATE 改的是表数据（DML），别写反。

七、本章速记小结

库五句：SHOW DATABASES / CREATE DATABASE / USE / ALTER DATABASE / DROP DATABASE。
表六句：SHOW TABLES / DESC / CREATE TABLE / ALTER TABLE（ADD·DROP·MODIFY·CHANGE·RENAME） / DROP TABLE。
复合主键只能写在表级：PRIMARY KEY (sno, cno)。
类型口诀：整数从小往大选、定长 CHAR 变长 VARCHAR、钱用 DECIMAL、日期别用字符串。
模式对应：基本表=模式、视图=外模式、存储文件=内模式。
改名只能新建迁移：MySQL 没有 ALTER DATABASE ... RENAME；改表名用 ALTER TABLE ... RENAME TO。
