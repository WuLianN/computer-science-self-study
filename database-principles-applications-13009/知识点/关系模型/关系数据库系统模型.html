一、关系模型的三个组成部分（识记）

识记 关系模型的三个组成部分。
与"数据模型三要素"一一对应，只是换成关系语境：
  • 数据结构——一个关系模型中只有一个结构：满足一定条件的二维表（关系）；实体与实体间联系都用关系表示，所以结构简单、一致。
  • 数据操作——查询（选择、投影、连接、除、并、差、交）＋ 增删改，操作对象和结果都是集合。
  • 数据的完整性约束条件——实体完整性、参照完整性、用户定义的完整性（详见第三节）。

二、关系的形式化定义与术语 ⭐

领会 关系数据结构的形式化定义。
设 Dᵢ = {d₁, d₂, …, dₖ} 为域（Domain）——一组具有相同数据类型的值的集合，D₁ × D₂ × … × Dₙ 的子集叫做在域 D₁, D₂, …, Dₙ 上n 度（元）的关系（Relation），记作 R(D₁, D₂, …, Dₙ)。关系里的每个元素 t = (d₁, d₂, …, dₙ) 叫做一个元组。
形式化术语二维表里的通俗说法示例（学生表）
关系 R一张表学生表 Student
元组（tuple）一行记录(2021001, 小明, 20)
属性（attribute）一列学号 / 姓名 / 年龄
域 Domain一组具有相同数据类型的值的集合（教材原文，识记）0~150 的整数（年龄的取值域）
分量元组中的一个值第 2 个分量"小明"
目 / 度（arity）列数（属性个数）3 列 → 度为 3
基数（cardinality）行数（元组个数）50 个学生 → 基数 50
候选码 / 主码能唯一标识一行的属性（组）；选定的那个学号
主属性 / 非主属性包含在任一候选码中的属性 / 其余属性学号是主属性，年龄是非主属性
外码（外键）本表属性是另一张表的主码选课表的"学号"
关系的性质（规范化的二维表应满足）：
① 列的同质性: 同域、类型一致。
② 列名唯一性：每列具有不同的属性名。
③ 行列次序无关：（集合无序，交换两行仍是同一关系）。
④ 分量原子性：分量值是原子的，即每个分量都必须是不可分的数据项。
⑤ 元组相异性：关系中任意两个元组的候选码不能相同。
⚠️ 易错："行列次序无关"是关系模型的数学性质，但 MySQL 表里加 ORDER BY 才能控制显示顺序——理论题按"无关"答。

三、关系的三类完整性规则 ⭐ 简答常考

领会 关系的完整性规则。
完整性规则内容MySQL 中由谁保证
实体完整性若属性组 K 是基本关系的主码，则 K 中的属性值不能为空且不能重复（主码任一属性都不得取 NULL）PRIMARY KEY / UNIQUE
参照完整性若 F 是参照关系的外码且与关系 S 的主码 X 相容，则外码取值或者为空值（无对应参照）、或者必须是 S 中某元组的主码值FOREIGN KEY + ON DELETE/UPDATE 动作
用户定义的完整性针对具体应用的数据须满足的语义约束（年龄 0~150、性别只能"男/女"、成绩非空）CHECK / NOT NULL / 默认值 / 数据类型
📝 简答模板："关系的完整性包括实体完整性（主码唯一非空，保证元组可区分）、参照完整性（外码须在被参照关系中有对应主码或为空，保证表间联系有效）和用户定义的完整性（由应用语义决定的约束）。"第 7 章会把这三条落到 SQL 语句上，两章要对着学。

四、关系操作及其特点（识记）

识记 关系操作的组成及关系操作语言的特点。
组成：查询（选择、投影、连接、除、并、差、交）＋ 增、删、改。
特点（简答/多选）：①操作对象和结果都是集合（一次处理一批元组，称为集合操作方式/一次一集合）；②语言是声明式的——只说"做什么"不说"怎么做"，用户不必指定存取路径；③以关系代数 / 关系演算为数学基础；④有高度的自动生成性，便于接口、便于优化；⑤一个关系模型只有一种数据结构，语言简单一致。
两类关系语言：过程化——关系代数（用运算符号表达"怎么求"）；非过程化——关系演算（用谓词表达"求什么"，分元组演算与域演算）。SQL 是两者折中的实用语言。

五、关系代数：运算三要素与分类（识记）

识记 关系代数的概念、运算三要素、运算分类。
关系代数：用一组运算符对关系进行运算来表达查询的语言，运算对象是关系、结果也是关系。
运算三要素：①运算对象（一个或两个关系）；②运算符；③运算结果（仍是一个关系）。
分类运算符目数说明
传统集合运算∪ 并、− 差、∩ 交、× 笛卡尔积二目前三者要求Union 相容，即列数相同，且对应的属性列都出自同一个域
专门关系运算σ 选择、π 投影、⋈ 连接、÷ 除一目 / 二目关系运算的核心特色
扩展运算外连接、ℑ 分组聚合、ρ 更名—了解即可，考试以上面两栏为主

六、八种运算逐个过 + 例题 ⭐⭐

简单应用 进行简单的关系代数运算。

以下用考纲题型举例中的图书管理系统：图书(条形码, 书名, 作者姓名, 出版社, 单价)、读者(借书证号, 姓名, 性别)、借阅(借书证号, 条形码, 借书日期, 还书日期)。

运算记号语义例：查询要求关系代数表达式
选择σF(R)挑满足条件的行（水平方向）借阅证号 2001 的记录σ借书证号='2001'(借阅)
投影πA(R)挑指定的列并去重（垂直方向）所有作者的姓名π作者姓名(图书)
并R ∪ S属于 R 或 S 的元组（自动去重）借过书或某名单π(借阅) ∪ π(其他)
差R − S属于 R 但不属于 S没借过书的读者π借书证号(读者) − π借书证号(借阅)
交R ∩ S同时属于 R 与 S＝R − (R − S)两条件都满足R ∩ S
笛卡尔积R × SR 每个元组依次拼接 S 每个元组；结果度=相加、基数=相乘无条件全组合图书 × 借阅
θ 连接R ⋈A θ B S先做 ×，再选跨表属性满足关系运算 θ 的元组价格低于借阅上限…图书 ⋈单价>50 借阅
除R ÷ S找出与 S 中全部元组都有联系的 R 元组（答"所有/全部"就用它）借遍了全部书的读者π借书证号,条形码(借阅) ÷ π条形码(图书)
例题 1（考纲·题型举例·简单设计题）用关系代数查询"数据库系统原理"这本书的作者姓名。
π作者姓名( σ书名='数据库系统原理'(图书) )
先选择定位行，再投影取列——顺序不能写反（写反了也能算，但读题思路是"筛选→输出"）。
例题 2（差运算套路）查询没有借过任何书的读者姓名。
π姓名( 读者 ⋈ ( π借书证号(读者) − π借书证号(借阅) ) )
差运算前必须先把两侧投影成同样的列（Union 相容），这是最常见的失分点。
例题 3（连接 + 选择）查询读者"小明"借过的书名。
π书名( σ姓名='小明'(读者) ⋈ 借阅 ⋈ 图书 )
三表串联靠自然连接自动匹配同名属性（借书证号、条形码）。
例题 4（除运算）查询借了全部图书的读者借书证号。
π借书证号, 条形码(借阅) ÷ π条形码(图书)
题面出现"全部 / 所有 / 都"→ 想除法；被除关系要留下"目标列 + 除列"。
⚠️ 写表达式的三条硬规则：①投影自动去重、选择不去重；②做并/差/交前两侧必须同度且对应列同域；③除法的结果度 = 被除关系的度 − 除关系的度。

七、等值连接 vs 自然连接 vs 外连接 ⭐

领会 运算规则；等值连接与自然连接的区别。
类型条件结果列结果行
等值连接θ 取"="，可指定任意属性对保留两个表中重复的同名属性列只保留匹配上的行
自然连接特殊的等值连接：必须在两组同名（同域）属性间自动进行去掉重复列，同名列只留一份只保留匹配上的行
外连接把不匹配的元组也保留，另一侧补 NULL—左外连接保左表全部；右外保右表；全外连接保两侧
📝 简答模板：等值连接用"="作运算符，是普通的 θ 连接，结果中两个关系的全部属性都保留（含重复列）；自然连接是在共有属性上按值相等进行的连接，并且自动去掉一列重复属性。可以说"自然连接 = 等值连接 + 去重列"。
对应到 SQL（预习第 5 章）：自然连接 NATURAL JOIN；等值连接 JOIN ... ON A.x = B.x（SELECT * 时会看到两列 x）；外连接 LEFT/RIGHT OUTER JOIN。MySQL 不支持 FULL OUTER JOIN，用 LEFT JOIN UNION RIGHT JOIN 代替。

八、SQL 简介：分类与特点（识记）

识记 SQL 语言的分类、特点。
分类缩写关键字作用
数据定义语言DDLCREATE / ALTER / DROP定义、修改、删除数据库与表等结构（第 3、6、7 章）
数据操纵语言DMLINSERT / UPDATE / DELETE表中数据的增删改（第 4 章）
数据查询语言DQLSELECT查询数据（第 5 章，占分最重）
数据控制语言DCLGRANT / REVOKE权限与安全性控制（第 8 章）；事务 COMMIT / ROLLBACK 亦属控制类
SQL 的特点（简答）：
① 一体化——DDL/DML/DQL/DCL 一种语言贯通，语言风格一致；
② 高度非过程化——只需指出"做什么"，不必指明"怎么做"，存取路径由系统决定；
③ 两种使用方式——交互式（独立在客户端执行）与嵌入式（嵌入 C/Python 等宿主语言，需配SQLCA 与主变量）；
④ 语言简洁、易学——核心动词只有 9 个；
⑤ 面向集合——一次操作一批元组；
⑥ 支持三级模式：视图对应外模式、基本表对应模式、存储文件对应内模式。
🔑 第⑥条几乎每年换种问法出现："SQL 中，视图对应三级模式中的哪一级？"→ 外模式；基本表 → 模式；存储文件 → 内模式。

九、本章速记小结

一张表 = 一个关系：行=元组、列=属性、列出自的集合（同类型值的集合）=域、一个值=分量；度=列数、基数=行数；行列无序、分量原子、元组不重复。
三类完整性：实体（主码唯一非空）→ PRIMARY KEY；参照（外码为空或在被参照表中存在）→ FOREIGN KEY；用户定义 → CHECK / NOT NULL。
八种运算口诀：选择管行、投影管列（且去重）；并差交要相容；笛卡尔积度相加、基数相乘；连接=笛卡尔积+条件筛选；"全部"用除法。
等值 vs 自然：自然连接在同名列上做且删重复列。
SQL 四分类：DDL 建结构、DML 改数据、DQL 查询、DCL 控权限；视图=外模式、基本表=模式。
符号别写错：σ（选择 sigma）、π（投影 pi）、⋈（连接 join）、÷（除）、ρ（更名）。
