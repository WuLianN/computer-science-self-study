一、SELECT 的子句与执行顺序 ⭐⭐

识记 SELECT 语句包含的子句及各子句功能。
FROM→WHERE→GROUP BY→HAVING→SELECT→DISTINCT→ORDER BY→LIMIT

上面是逻辑执行顺序（先取数据、再筛、再分组、最后才决定输出哪些列），与书写顺序不同——这正是"为什么 WHERE 里不能写聚合函数、ORDER BY 里却能用 SELECT 的列别名"的原因。

子句功能一句话要点
FROM指定查询的表（可多表、可子查询）表可加别名；多表用逗号或 JOIN
WHERE行条件（针对基本表/视图）不能出现聚合函数，因为分组前每行还无从统计
GROUP BY按一列或多列取值分成组SELECT 里的非聚合列必须全部出现在 GROUP BY 中
HAVING组条件（筛选分组）必须跟在 GROUP BY 之后，可以使用聚合函数
SELECT列（投影）与计算、去重可写常量、表达式、聚合函数、别名
ORDER BY按列升序 ASC（默认）/ 降序 DESC 排序可多列、可用别名、可用聚合结果
LIMIT限制返回的行数（MySQL 特有）LIMIT 偏移量, 行数，偏移从 0 开始
⚠️ 标准 SQL 里没有 LIMIT（用的是 TOP / FETCH FIRST）；本课程基于 MySQL，写 LIMIT 是对的。另外没有 GROUP BY 时也可以直接用聚合函数（整表当成一组）。

二、投影查询（简单应用）

识记 投影查询的含义；简单应用 SELECT 子句投影指定列/全部列、修改列标题、计算列值、去掉重复行。
投影＝从表中选出若干列（垂直方向切），关系代数里的 π。 
SELECT * FROM student;                          -- 全部列
SELECT sno, sname FROM student;                 -- 指定列（顺序自定，不必与表一致）
SELECT DISTINCT sdept FROM student;             -- 去掉重复行（DISTINCT 作用于整个结果行）
SELECT sno AS 学号, sname AS 姓名 FROM student;  -- 修改列标题（别名，AS 可省略）
SELECT sno, sname, '在校学生' AS 状态 FROM student;   -- 常量列
SELECT sno, '2026-' - sage AS 出生年 FROM student;   -- 计算列：表达式作用于每一行
🔑 DISTINCT 放在列清单最前面、只出现一次，作用于整行组合；SELECT DISTINCT sdept, ssex 是对 (系,性别) 组合去重，不是对每列分别去重。

三、选择查询：WHERE 的七类条件 ⭐

识记 选择查询的含义；简单应用 WHERE 子句：表达式比较、指定范围、空值判断、LIKE 匹配、正则查询。
类型写法例坑
比较运算= > < >= <= != <>WHERE sage >= 20MySQL 里 != 与 <> 等价
范围BETWEEN … AND …（闭区间）WHERE sage BETWEEN 20 AND 23等价于 sage>=20 AND sage<=23；否定用 NOT BETWEEN
集合IN (…) / NOT IN (…)WHERE sdept IN ('计算机','数学')IN 比多个 OR 简洁；可用子查询提供列表
字符匹配LIKE + % _ ESCAPEWHERE sname LIKE '刘%'%=任意长度(含空串)，_=一个字符
正则匹配REGEXP / RLIKEWHERE sno REGEXP '^2021'MySQL 的 LIKE 不支持正则元字符
空值IS NULL / IS NOT NULLWHERE grade IS NULL绝不能写 = NULL（结果永远是 UNKNOWN）
逻辑组合AND > OR > NOT（用括号最稳）WHERE ssex='男' AND sage<=20AND 优先级高于 OR，复杂条件一定加括号
-- 名字第二个字是"小"的同学
SELECT * FROM student WHERE sname LIKE '_小%';
-- 查含下划线 "_" 本身：用 ESCAPE 转义
SELECT * FROM student WHERE sname LIKE 'a\\_b' ESCAPE '\\';
-- 未选课（成绩为空）的记录
SELECT sno, cno FROM sc WHERE grade IS NULL;

四、LIKE 与 REGEXP 的异同 ⭐ 简答

领会 LIKE 与 REGEXP 的异同。
对比项LIKEREGEXP
匹配方式整串模式匹配，必须从头到尾符合部分匹配：只要串中存在符合模式的部分即为真
通配符只有 %（任意长度）与 _（单字符），可配 ESCAPE正则元字符：^ $ . [] | * + ? {n,m} 等
定位需靠 % 表达前后位置用 ^ 表头、$ 表尾
表达力 / 性能简单直观、易写；索引可用前缀模式（'abc%'）表达力强、写法复杂；以 _ 或 % 开头的 LIKE 与多数 REGEXP 都全表扫描
SELECT * FROM student WHERE sname LIKE '%明%';      -- 名字中含"明"
SELECT * FROM student WHERE sname REGEXP '明';      -- 同上（REGEXP 不必加 %）
SELECT * FROM student WHERE sno REGEXP '^2021[0-9]{4}$';  -- 2021 开头的 8 位学号
📝 相同点：都写在 WHERE 中做字符串模式匹配，都可取反（NOT LIKE / NOT REGEXP）。不同点：LIKE 用 % 和 _ 两种通配符且要求整个值匹配模式，REGEXP 用正则语法且只要子串匹配成功即可。

五、分组查询与聚合函数 ⭐

识记 聚合函数、GROUP BY、HAVING 的含义；简单应用 分组查询和统计计算。
聚合函数作用对 NULL
COUNT(*)组内行数计入
COUNT([DISTINCT] 列)该列非空值的个数忽略 NULL
SUM / AVG求和 / 平均值（只用于数值列）忽略 NULL（所以 AVG 分母是非空个数）
MAX / MIN最大值 / 最小值（也可用于字符串、日期）忽略 NULL
-- 每个系的学生人数
SELECT sdept, COUNT(*) AS 人数 FROM student GROUP BY sdept;

-- 平均分不低于 80 的课程号与平均分（筛"组"→ HAVING）
SELECT cno, AVG(grade) AS 平均
  FROM sc GROUP BY cno HAVING AVG(grade) >= 80;

-- 先筛行再分组：WHERE 与 HAVING 同时出现
SELECT sno, COUNT(*) AS 门数, MAX(grade)
  FROM sc WHERE grade IS NOT NULL
  GROUP BY sno HAVING COUNT(*) >= 3;
⚠️ 三大铁律：①WHERE 里不许有聚合函数（要筛组用 HAVING）；②SELECT 中的非聚合列必须出现在 GROUP BY 里（MySQL 8 默认 ONLY_FULL_GROUP_BY 会直接报错）；③执行顺序是 WHERE 先于 GROUP BY，GROUP BY 先于 HAVING——所以 WHERE 不能用 SELECT 里刚定义的别名，而 ORDER BY / HAVING 里可以引用聚合。
🔑 HAVING vs WHERE 简答模板：WHERE 在分组前按行过滤，作用于基本表/视图的列，不能含聚合函数；HAVING 在分组后按组过滤，必须与 GROUP BY 一起出现，可以使用聚集函数。

六、排序与限制行数

识记 ORDER BY、LIMIT 的语法格式；简单应用 排序查询、限制返回的行数。
-- ORDER BY：默认升序 ASC；可多列（前一列相同才比后一列）；可用别名/列号/表达式
SELECT sno, sdept, sage FROM student
  ORDER BY sdept ASC, sage DESC;

-- LIMIT：MySQL 特有。LIMIT 行数 或 LIMIT 偏移量,行数（偏移从 0 计）
SELECT * FROM sc ORDER BY grade DESC LIMIT 5;         -- 前 5 名
SELECT * FROM sc ORDER BY grade DESC LIMIT 5, 5;       -- 跳过前 5 行，再取 5 行（6~10 名）

-- 组合套路：求成绩最高的学生（Top-1 问题）
SELECT sname, grade FROM student JOIN sc USING(sno)
  ORDER BY grade DESC LIMIT 1;
⚠️ 想取"某组的最高分记录"不能只靠 ORDER BY+LIMIT 混着分组来写，要用子查询（第八节）。另：ORDER BY 放在 LIMIT 前面，颠倒会语法错误。

七、连接查询 ⭐⭐

识记 连接方式、交叉连接、等值/非等值/自然/自连接的含义；领会 单表与多表查询异同、内连接与外连接区别、左/右/全外连接区别、INNER JOIN 与 WHERE 的异同；简单应用 内连接、外连接、交叉连接。
连接写法结果
交叉连接（笛卡尔积）CROSS JOIN（或 FROM a, b 不带条件）行数＝两表行数相乘，一般不是想要的，用来理解其它连接
内连接 · 等值INNER JOIN … ON A.x = B.x只保留匹配上的行
内连接 · 非等值ON A.x BETWEEN B.lo AND B.hi用 >、<、BETWEEN 等条件匹配
自然连接NATURAL JOIN / JOIN … USING(列)自动按同名属性等值匹配并合并重复列（对应第 2 章概念）
左外连接LEFT [OUTER] JOIN左表全部 + 右表匹配，右表无匹配处补 NULL
右外连接RIGHT [OUTER] JOIN右表全部 + 左表匹配补 NULL
全外连接标准 SQL FULL OUTER JOIN两侧都保留。MySQL 不支持，用 LEFT JOIN UNION RIGHT JOIN 实现
自连接同一张表起两个别名再连处理表内层级/比较（如"比小明年龄大的学生"）
-- ① 等值内连接（隐式写法：条件放 WHERE —— 老教材常用）
SELECT s.sno, s.sname, c.cname, sc.grade
  FROM student s, sc, course c
  WHERE s.sno = sc.sno AND sc.cno = c.cno;

-- ② 显式内连接（推荐写法，条件放 ON）
SELECT s.sname, sc.grade
  FROM student s INNER JOIN sc ON s.sno = sc.sno;

-- ③ 左外连接：没选课的学生也要显示（成绩列为 NULL）
SELECT s.sno, s.sname, sc.cno
  FROM student s LEFT JOIN sc ON s.sno = sc.sno;

-- ④ 自连接：查询与"01 班学生同龄"的学生
SELECT DISTINCT a.sno, a.sname
  FROM student a JOIN student b ON a.sage = b.sage
  WHERE b.sdept = '01班' AND a.sno <> b.sno;
📝 简答模板（INNER JOIN + ON 与 FROM + WHERE 的异同）：对内连接而言两者结果相同；差别在于——①语义上 ON 是"连接条件"、WHERE 是"筛选条件"，把连接条件写进 WHERE 会让多义混合、可读性差；②外连接时二者不同：条件写在 ON 里作用于连接阶段（不匹配的行仍保留并补 NULL），写在 WHERE 里作用于连接之后（会把补 NULL 的行筛掉，外连接退化成内连接）；③用 CROSS JOIN 或不带条件时，WHERE 写法会产生笛卡尔积中间结果，效率低。
🔑 内连接 vs 外连接：内连接只保留两表中满足连接条件的元组；外连接也以连接条件为基础，但还把不匹配的元组保留下来，缺失的一侧填 NULL。左外保左表全部、右外保右表全部、全外两边都保。

八、子查询：IN / 比较 / EXISTS ⭐

识记 子查询的含义；领会 IN、比较、EXISTS 子查询的含义；简单应用 用 IN 谓词联结父子查询、用比较子查询关联、用 EXISTS 测试子查询是否返回行。
子查询＝嵌在另一个语句中的 SELECT（子查询在先、父查询在后）。按位置分：WHERE 子句、FROM 子句（派生表）、SELECT 列表（标量子查询）；按是否引用外层列分：不相关子查询（独立执行一次）与相关子查询（对外层每一行执行一次）。
类型规则例
IN 子查询子查询返回一列多行，父查询判断值是否属于该集合见 ①
比较子查询子查询必须返回单个值（标量）；配 = > <；配 ANY/SOME（至少一个）、ALL（全部）时含义不同见 ②③
EXISTS 子查询只判断子查询结果是否非空，返回真/假；几乎都是相关子查询，SELECT 里常写 *，不用关心返回什么列见 ④
-- ① IN：查询选了"数据库"这门课的学生姓名
SELECT sname FROM student
  WHERE sno IN (SELECT sno FROM sc WHERE cno IN
                     (SELECT cno FROM course WHERE cname = '数据库'));

-- ② 标量子查询：查询成绩高于全表平均分的学生
SELECT sno, grade FROM sc
  WHERE grade > (SELECT AVG(grade) FROM sc);

-- ③ ALL / ANY：比"计算机系所有学生年龄都大"的学生
SELECT * FROM student
  WHERE sage > ALL (SELECT sage FROM student WHERE sdept = '计算机');
  -- > ALL ＝ 大于最大值；> ANY ＝ 大于最小值即可

-- ④ EXISTS：查询至少选了一门课的学生（相关子查询）
SELECT sname FROM student s
  WHERE EXISTS (SELECT * FROM sc WHERE sc.sno = s.sno);

-- ⑤ 派生表：子查询当表用（MySQL 要求必须给别名）
SELECT s.sno, s.sname, t.平均
  FROM student s JOIN (SELECT sno, AVG(grade) AS 平均
                        FROM sc GROUP BY sno) AS t
    ON s.sno = t.sno WHERE t.平均 >= 85;
⚠️ 四个常错：①子查询必须加括号；②出现在 =、> 右边的子查询只能返回一个值，多值要用 IN；③经典陷阱"NOT IN 遇到子查询结果含 NULL 时整体为空"——要防 NULL 用 NOT EXISTS；④相关子查询里 EXISTS 不返回数据、只返回真假，别写 SELECT COUNT(*) 之类期望取值。

九、联合查询 UNION

识记 联合查询的概念与遵循的规则；简单应用 用 UNION 将多个查询合成为一条 SQL 语句。
联合查询把多个 SELECT 的结果纵向合并成一个结果集（对应关系代数的"并"）。 
SELECT sno, sname FROM student WHERE sdept = '计算机'
UNION
SELECT tno, tname FROM teacher WHERE dept = '计算机';

SELECT sno FROM sc WHERE cno = 'C01'
UNION ALL                              -- 保留重复行、不去重，效率更高
SELECT sno FROM sc WHERE cno = 'C02';
UNION 必须遵循的规则：①各 SELECT 的列数相同；②对应列数据类型相容（可转换）；③结果集的列名取自第一个 SELECT；④默认自动去重（等价 UNION DISTINCT），要保留重复用 UNION ALL；⑤ORDER BY / LIMIT 只能写在最后一个 SELECT 之后，作用于合并后的整体结果，且 ORDER BY 里只能用第一个 SELECT 的列名/别名/列号；⑥多个 UNION 从左到右结合，需要改变顺序用括号。
🔑 用途辨析：UNION 是纵向（按行）合并两个结构相同的结果集；JOIN 是横向（按列）拼接两个表。题干说"把 A 和 B 的名单合在一起"→ UNION；"既要 A 的列又要 B 的列"→ JOIN。

十、综合例题与常见错因

综合应用 综合运用多个知识点编写与调试 SQL。
例 1（考纲·题型举例·简单设计题）用 SQL 查询每个出版社出版的图书总数量。
SELECT 出版社, COUNT(*) AS 数量 FROM 图书 GROUP BY 出版社;

例 2 查询选修了 3 门以上课程且至少一门不及格的学生学号、选课门数。
SELECT sno, COUNT(*) AS 门数
  FROM sc GROUP BY sno
  HAVING COUNT(*) > 3 AND MIN(grade) < 60;

例 3 查询没选"数据库"课的学生姓名（三种写法思路都要会）。
SELECT sname FROM student WHERE sno NOT IN
   (SELECT s.sno FROM student s JOIN sc ON s.sno = sc.sno
     JOIN course c ON c.cno = sc.cno WHERE c.cname = '数据库');

例 4 每门课的平均分并按平均分降序取前 3 名。
SELECT cno, AVG(grade) AS 平均 FROM sc
  GROUP BY cno ORDER BY 平均 DESC LIMIT 3;
⚠️ 卷面常见扣分点：关键字拼错（GROUP BY 写成 GROUP、ORDER BY 写成 ORDER）、子句顺序颠倒（把 HAVING 写在 GROUP BY 前）、逗号/引号漏写、非聚合列没进 GROUP BY、= 写成 ==、用 WHERE grade = NULL。写完按"FROM→WHERE→GROUP BY→HAVING→SELECT→ORDER BY→LIMIT"顺序默念一遍。

十一、本章速记小结

执行顺序：FROM → WHERE → GROUP BY → HAVING → SELECT(→DISTINCT) → ORDER BY → LIMIT。
投影：DISTINCT 放列清单前、作用于整行；AS 改列标题；表达式可算列值。
选择：BETWEEN 是闭区间；空值只能 IS NULL；LIKE 用 % 和 _，REGEXP 用正则且子串匹配即真。
分组：WHERE 不能放聚合、HAVING 专管组；非聚合列必须进 GROUP BY；COUNT(列) 忽略 NULL、COUNT(*) 不忽略。
连接：内连只留匹配；外连保留不匹配补 NULL（左保左、右保右，MySQL 无全外）；自连接同表起两别名；外连接的条件要写在 ON，写在 WHERE 会退化成内连接。
子查询：多值配 IN、单值配比较运算符、判存在用 EXISTS（返回真假、常写 SELECT *）；> ALL＝比最大值、> ANY＝比最小值。
联合：列数相同、类型相容、列名取第一个、默认去重（ALL 不去重）、ORDER BY/LIMIT 只在最后写一次。
Top-N：ORDER BY 列 DESC LIMIT n；MySQL 里"取每组前几名"要用相关子查询或窗口函数（ROW_NUMBER()，了解）。
