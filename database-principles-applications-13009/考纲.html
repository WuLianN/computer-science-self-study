Ⅰ · 课程性质与课程目标

课程性质和特点
通过本课程学习掌握数据库基本原理和相应的设计能力、编程能力，为后继课程、课程设计及应用系统开发提供数据管理技术支撑。实践性强：既要掌握数据库系统安装、配置、管理和维护技能，又要具备数据库设计能力和 SQL 编程能力。
课程目标（5 条）
课程以 MySQL 为平台，系统介绍数据库原理及应用，并涵盖大数据、NoSQL 等前沿内容。考生应：
  1. 掌握数据库技术的基本概念、原理、方法和技术。
  2. 掌握 SQL 语言查询和编程的基本技术，具备 SQL 编程能力。
  3. 掌握数据库系统安装、配置和数据库管理和维护的基本技能。
  4. 掌握设计数据库的基本方法，具备数据库设计能力。
  5. 了解数据库技术的最新发展。
课程重点和难点
重点：数据模型与关系型数据库概念，数据库和表数据操作、数据查询、视图和索引、数据完整性、关系数据库设计理论和数据库设计。
难点：关系模式规范化（目的、原则、方法及实操）；依据需求分析进行概念设计和逻辑设计（画 E-R 图并转化为关系模式）；编写 SQL 查询语句。

Ⅱ · 考核目标（四个能力层次）

识记识别记忆知识点的概念性内容（基本定义、语法格式、步骤方法、限定规则、特点等），能正确表述、选择和判断。
领会领悟知识点内涵和外延，熟悉知识点间区别与联系，学习数据库发展历程与数据管理技术新发展，能对数据处理领域相关问题做简单分析。
简单应用运用少量知识点解决一般应用问题：分析执行结果、编写简单 SQL、验证给定 SQL 语句的正确性和运行结果等。
综合应用综合运用多个知识点解决较复杂数据处理问题：独立进行数据库概念结构设计和逻辑结构设计，编写和调试 SQL 语句。

Ⅲ · 课程内容与考核要求（考纲 10 章）

第 1 章 数据库概论（建议 4 学时）

学习目的与要求：从基本概念出发，介绍数据模型、数据库系统结构、大数据简介；重点理解数据模型的概念、分类和组成要素。
课程内容：1. 基本概念 ｜ 2. 数据模型 ｜ 3. 数据库系统结构 ｜ 4. 大数据简介
考核知识点与要求
（一）基本概念：识记数据库 DB、数据库管理系统 DBMS、数据库系统 DBS 的概念；领会数据管理技术的发展。
（二）数据模型：识记数据模型的概念、分类、组成要素；领会概念模型、实体间联系、实体-联系方法和 E-R 图，逻辑模型（层次/网状/关系模型）；简单应用根据有关信息设计 E-R 图。
（三）系统结构：识记数据库系统的系统结构、三级模式；领会二级映像和数据独立性。
（四）大数据简介：识记大数据基本概念；领会大数据的处理过程、数据管理技术的发展。
重点：DB/DBMS/DBS 概念、概念模型、逻辑模型。难点：根据信息设计 E-R 图。

第 2 章 关系数据库系统模型（建议 6 学时）⭐ 关系代数必考

学习目的与要求：掌握关系模型的数据结构、关系的完整性、关系操作与关系代数运算规则。
课程内容：1. 关系模型 ｜ 2. 关系代数 ｜ 3. SQL 简介
考核知识点与要求
（一）关系模型：识记三个组成部分、关系操作组成及关系操作语言特点；领会完整性规则、关系数据结构的形式化定义。
（二）关系代数：识记概念、运算三要素、运算分类；领会运算规则、等值连接与自然连接的区别；简单应用进行简单的关系代数运算。
（三）SQL 简介：识记SQL 语言的分类、特点。
重点：关系数据结构、完整性、关系操作、关系代数运算规则。难点：关系代数运算。

第 3 章 MySQL 数据库和表（建议 6 学时）

学习目的与要求：掌握数据库与表的创建、选择、修改、删除，掌握 CREATE/ALTER/DROP DATABASE 和 CREATE/ALTER/DROP TABLE/SHOW TABLES 语句。
课程内容：1. MySQL 简介 ｜ 2. 定义数据库 ｜ 3. 表的基本概念 ｜ 4. 数据类型 ｜ 5. 定义表
考核知识点与要求
（一）简介：识记SHOW DATABASES 查看已有数据库。
（二）定义数据库：识记CREATE/ALTER/DROP DATABASE、USE 语句；简单应用四类语句的使用。
（三）表的基本概念：识记表的概念与组成；领会表结构含义、表/列/属性关系、表结构组成。
（四）数据类型：识记MySQL 常用数据类型；领会类型含义、数字类型选择、类型选择遵循的原则。
（五）定义表：识记创建/查看/修改/删除表语句；简单应用CREATE TABLE、ALTER TABLE、DROP TABLE、SHOW TABLES 的使用。
重点：建表、改表、删表、查看表的语句和方法。难点：上述语句的实际使用。

第 4 章 表数据操作（建议 6 学时）

学习目的与要求：掌握用 INSERT / UPDATE / DELETE 对表数据进行增加、修改、删除。
课程内容：1. 插入数据 ｜ 2. 修改数据 ｜ 3. 删除数据
考核知识点与要求
（一）插入：识记插入语句的概念与类别；领会全列插入、指定列插入、多条记录插入、REPLACE 语句、插入查询结果语句的含义；简单应用正确编写上述插入语句。
（二）修改：识记修改全部记录与修改指定记录两种方法；简单应用UPDATE 语句完成记录修改。
（三）删除：识记删除数据的两种方法、删除全部记录的两种方式；领会删除指定记录与删除全部记录的区别；简单应用DELETE 语句完成记录删除。
重点/难点：INSERT、UPDATE、DELETE 的用法。

第 5 章 数据查询（建议 12 学时）⭐⭐ 全课程最高学时·核心大题

学习目的与要求：掌握 SELECT / WHERE / GROUP BY / HAVING / ORDER BY / LIMIT 子句进行投影、选择、分组、排序、限制行数查询，掌握多表查询。
课程内容：1. SELECT 语句 ｜ 2. 投影查询 ｜ 3. 选择查询 ｜ 4. 分组查询和统计计算 ｜ 5. 排序查询和限制结果数量 ｜ 6. 连接查询 ｜ 7. 子查询 ｜ 8. 联合查询
考核知识点与要求
（一）SELECT 语句：识记包含的子句及各子句功能。
（二）投影查询：识记含义；简单应用SELECT 子句投影指定列/全部列、改列标题、计算列值、去重等。
（三）选择查询：识记含义；领会LIKE 与 REGEXP 的异同；简单应用WHERE 子句：表达式比较、指定范围、空值判断、LIKE 字符串匹配、正则表达式查询。
（四）分组查询与统计：识记聚合函数、GROUP BY、HAVING 含义；简单应用分组查询和统计计算。
（五）排序与限制：识记ORDER BY、LIMIT 语法格式；简单应用排序查询、限制返回行数。
（六）连接查询：识记连接方式、交叉连接、等值/非等值/自然/自连接含义；领会单表与多表查询异同、内连接与外连接区别、左/右/全外连接区别、INNER JOIN 与 WHERE 的异同；简单应用内连接、外连接、交叉连接查询。
（七）子查询：识记含义；领会IN、比较、EXISTS 子查询含义；简单应用IN 谓词连接父子查询、比较子查询关联、EXISTS 测试子查询是否返回行。
（八）联合查询：识记概念与遵循规则；简单应用UNION 将多个查询合成一条 SQL。
重点：六大子句 + 连接/子查询/联合查询。难点：SELECT/WHERE/GROUP BY/HAVING/ORDER BY/LIMIT 及联合查询语句的综合运用。

第 6 章 视图和索引（建议 6 学时）

学习目的与要求：理解视图和索引概念与作用，掌握视图的创建/修改/删除/查询/更新，掌握三种创建索引方法与两种删除索引语句。
课程内容：1. 视图及其作用 ｜ 2. 视图操作 ｜ 3. 索引及其作用 ｜ 4. 索引操作
考核知识点与要求
（一）视图及作用：识记视图含义；领会视图优点。
（二）视图操作：识记操作内容；领会CREATE/ALTER/DROP VIEW 及 SELECT 查询视图、更新视图的含义；简单应用创建/修改/删除/查询视图，通过视图插入、删除、修改数据。
（三）索引及作用：识记索引概念与分类；领会正确使用索引的优点、建立索引的建议。
（四）索引操作：识记三种创建索引方法；领会两种删除索引方法；简单应用CREATE INDEX / ALTER TABLE 建索引（含建表同时建索引）、SHOW INDEX 查看、DROP INDEX / ALTER TABLE 删除。
重点：视图四类操作 + 更新，索引创建与删除。难点：视图/索引相关语句的熟练运用。

第 7 章 数据完整性（建议 6 学时）⭐ 约束语句必考

学习目的与要求：掌握用 CREATE TABLE / ALTER TABLE 创建与删除 PRIMARY KEY、UNIQUE、FOREIGN KEY、CHECK 约束。
课程内容：1. 概述 ｜ 2. 实体完整性 ｜ 3. 参照完整性 ｜ 4. 用户定义的完整性
考核知识点与要求
（一）概述：识记数据完整性概念、约束机制优点；领会MySQL 完整性类型（实体/参照/用户定义）及约束含义。
（二）实体完整性：领会主键约束、唯一性约束含义及区别；综合应用数据库设计中正确用语句实现实体完整性。
（三）参照完整性：识记定义外键需遵守的规则；领会参照完整性规则、外键约束含义；简单应用SQL 创建/删除/修改外键约束；综合应用设计中实现参照完整性。
（四）用户定义的完整性：识记检查约束和非空约束含义；领会可使用的语句；综合应用设计中实现用户定义完整性。
重点/难点：四类约束（PK/UK/FK/CHECK）的创建与删除语句。

第 8 章 安全管理（建议 6 学时）

学习目的与要求：掌握 MySQL 权限表、用户管理、权限管理语句。
课程内容：1. 权限表 ｜ 2. 用户管理 ｜ 3. 权限管理
考核知识点与要求
（一）权限表：识记权限表所在数据库名、包含哪些表。
（二）用户管理：识记操作及语句；简单应用CREATE USER / DROP USER / RENAME USER / SET PASSWORD。
（三）权限管理：识记操作及语句；领会可授予权限的组类及含义、权限级别值的格式及含义；简单应用GRANT / REVOKE 授予与撤销权限。
重点/难点：用户管理与权限管理六条语句的正确有效使用。

第 9 章 关系数据库设计理论（建议 8 学时）⭐⭐ 规范化大题高发

学习目的与要求：掌握关系模式规范化的目的、原则和方法，具备对关系模式进行规范化的能力。
课程内容：1. 设计理论概述 ｜ 2. 关系模式规范化 ｜ 3. 数据依赖的公理系统
考核知识点与要求
（一）理论概述：识记关系数据库概念、理论包含内容；领会各内容间关系、如何判断好的关系模式。
（二）规范化：识记规范化含义、数据依赖类型和含义、码与范式含义；领会函数依赖、完全/部分/传递函数依赖，1NF/2NF/3NF/BCNF/4NF 与多值依赖含义，规范化的目的、方法和过程；简单应用分析模式主码、写出函数依赖关系；综合应用用 1NF/2NF/3NF 规范化方法解决应用问题。
（三）公理系统：识记Armstrong 公理系统含义；领会闭包及其计算；简单应用确定候选码。
重点：规范化的目的、原则和方法。难点：规范化关系模式。

第 10 章 数据库设计（建议 4 学时）⭐ E-R 图综合题

学习目的与要求：理解数据库设计方法和步骤，掌握概念结构设计与逻辑结构设计，能画 E-R 图并转化为关系模式。
课程内容：1. 设计概述 ｜ 2. 需求分析 ｜ 3. 概念结构设计 ｜ 4. 逻辑结构设计 ｜ 5. 物理结构设计
考核知识点与要求
（一）概述：识记设计的特点与方法；领会基本步骤。
（二）需求分析：识记任务；领会方法。
（三）概念结构设计：识记概念结构含义；领会方法和步骤；简单应用局部 E-R 模型设计；综合应用全局 E-R 模型设计。
（四）逻辑结构设计：识记任务；领会步骤；综合应用E-R 模型向关系模型转换。
（五）物理结构设计：识记任务。
重点：概念结构与逻辑结构设计方法。难点：根据需求画 E-R 图并转化为关系模式。

附录 · 题型举例
