一、起源与发展历程（领会）

领会 大数据的起源和发展历程。
年份里程碑事件要记住的关键词
1980未来学家托夫勒《第三次浪潮》把大数据称为"第三次浪潮的华彩乐章"最早的文字性提及（概念萌芽）
1996SAS 公司预测"大数据"将成为未来十大热门技术之一较早从技术角度提出
2001Gartner（Meta Group）分析师 Doug Laney 提出数据管理 3V 架构3V 的最早出处：Volume / Velocity / Variety
2008《自然》Nature 出版"大数据"专刊进入主流学术视野
2011麦肯锡全球研究所报告《大数据：创新、竞争和生产力的下一个前沿领域》⭐ 最常考：标志大数据概念正式兴起
2012美国宣布"大数据研究与发展计划"；《大数据时代》（维克托·迈尔-舍恩伯格）出版上升为国家科技战略
2015国务院印发《促进大数据发展行动纲要》，大数据列入我国国家战略国内政策节点
🕐 记忆主线：1980 提概念 → 2001 定 3V → 2011 麦肯锡报告"正式兴起" → 2012 国家战略 → 2015 中国纲要。单选常问"大数据概念正式兴起的标志"，答案是 2011 年麦肯锡报告，不是 2008 年《自然》专刊。

二、大数据的定义（识记）

识记 大数据的定义。
麦肯锡口径（最常背的一条）：大数据是指尺寸（数量）大到超出传统数据库软件工具抓取、存储、管理和分析能力的数据集合，其关键在于如何快速获得有价值的信息。
维基百科 / 通用口径：无法在一定时间范围内用常规软件工具进行捕捉、管理和处理的数据集合，是需要新处理模式才能具有更强的决策力、洞察发现力和流程优化能力的海量、高增长率和多样化的信息资产。
定义里必须出现的三个要素：①数据量大（超出常规工具能力）；②处理时效要求高（一定时间内 / 快速）；③要产生价值（决策力、洞察力）。只写"数据很多"是不完整的定义。
📝 名词解释答题模板：大数据是指规模巨大到无法用传统数据库和软件工具在合理时间内完成采集、存储、管理与处理的数据集合，需要借助分布式、并行化的新技术模式，才能从中获得洞察与决策价值。

三、大数据的特点：5V（识记）⭐

识记 大数据的特点。
Volume 大量容量从 TB 到 PB、EB 级 Variety 多样结构化 + 非结构化 Value 价值密度低总量大但单位价值低 Velocity 高速时效要求高、流式处理 Veracity 真实/准确数据的准确性与可信度
V含义说明与典型例子对应技术挑战
Volume 数据量大存储规模巨大由 TB 级跃升到 PB、EB 甚至 ZB 级；如全国手机信令、视频监控流分布式存储（HDFS）
Variety 类型多样数据种类多结构化（表）+半结构化（XML/日志）+非结构化（文本、图像、音频、视频）NoSQL、多模态处理
Value 价值密度低价值总量高、密度低24 小时监控视频里只有几秒有用；搜索日志大部分无意义挖掘与清洗（沙里淘金）
Velocity 处理速度快时效性要求高要求流式/实时处理而非批处理，"1 秒定律"流计算、内存计算（Spark）
Veracity 真实性数据质量与可信度噪声、造假、缺失多，需保证准确、可追溯数据治理、质量控制
⚠️ 两个高频陷阱：① Value 指"价值密度低"，不是"没有价值"——答题要写"整体价值高、单位数据价值密度低"；② 早期只讲 3V/4V（Volume、Variety、Value、Velocity），5V 是加了 Veracity。若题目问"4V 特征"，去掉真实性即可，别整题空着。

四、大数据的分类（领会）· 本章难点

领会 大数据的分类。
① 按数据结构分类（最重要的一条分类线）：
类型是否有固定结构典型形式占比存储/处理工具
结构化数据有，二维表逻辑关系数据库表、财务记录约 10%～20%MySQL、Oracle
半结构化数据部分有，自描述标签XML、JSON、HTML、日志文件合占约 80% 以上
（非结构化是主体）		NoSQL、HDFS
非结构化数据无固定结构文本、图像、音频、视频、地理位置、网页对象存储、多媒体分析
② 按数据来源分类：①系统日志/业务数据（企业 ERP、交易、订单）；②网络与社交数据（网页、微博、评论）；③感知数据（传感器、RFID、摄像头、GPS、可穿戴设备，即物联网数据）。
③ 按生成主体/领域分类：互联网数据、科研数据（天文、基因）、政务与公共数据、产业/企业数据。
🎯 押题："大数据中占比最大的是哪一类数据？"→ 非结构化（和半结构化）数据；这也正是关系数据库处理不了、必须引入 NoSQL 与分布式文件系统的根本原因（第 2、3、5 章的立项理由）。

五、数据采集方法（领会）· 本章难点

领会 数据采集方法。
采集渠道主要方法 / 工具要点
网络数据网络爬虫（Web Crawler）分三类：通用爬虫（搜索引擎整库）、聚焦爬虫（按主题定向抓取）、增量式爬虫（只抓新增/更新）；流程：URL 队列 → 下载 → 解析 → 抽取 → 存储
感知数据传感器、RFID、摄像头、GPS、可穿戴设备物联网自动采集，实时、连续、量大
系统日志 / 业务数据日志采集（Flume 类）、数据抽取工具（Sqoop 类）、ETL服务器日志、交易流水；从业务库批量抽取入仓
人工 / 众包问卷、访谈、录入、众包标注规模小但质量可控，常用于标注数据（供机器学习训练）
采集后必做的一步——数据预处理（简单应用常考）：①数据清洗（去重、补缺失、纠错误、去噪声）；②数据集成（多源合并、统一格式与编码）；③数据变换/规约（格式转换、离散化、抽样降维）；④数据加载（写入分布式存储或数仓）。
⚠️ 易混：爬虫是"抓"，ETL/Sqoop 是"搬"，传感器是"生"。题目问"以下哪种不属于大数据采集方式"，出现"人工抽样调查"时通常仍算采集方式（只是规模小）；出现"数据可视化"则不属于采集环节（属最后一环）。

六、大数据技术的内容与处理流程（领会）

领会 大数据技术的内容。
大数据处理的五个环节（简答"大数据处理流程"按此顺序作答）
各环节要回答的问题：①采集——数据从哪来、怎么抓；②预处理——脏数据怎么洗；③存储与管理——单机存不下怎么办（→ 分布式文件系统 HDFS、NoSQL）；④分析挖掘——算不动怎么办（→ 并行计算 MapReduce/Spark、机器学习）；⑤展现与应用——怎么让人看懂并决策（→ 可视化、推荐、预测）。
🔗 与后续章节对应：②③ → 第 3 章 HDFS、第 5 章 NoSQL；④ → 第 4 章 与 第 13 章。

七、关键问题与关键技术（领会）⭐ 重点

领会 大数据的关键问题与关键技术。
（一）大数据带来的关键问题（简答常考 4～6 条）：
  1. 数据存储问题——海量数据存不下、扩容成本高 → 需要分布式、可扩展、低成本的存储。
  2. 数据处理（计算）问题——传统单机数据库/处理方式算不动、时效不达标 → 需要并行与流式计算。
  3. 数据治理与质量问题——异构、噪声、缺失、口径不一 → 需要清洗、标准化、元数据管理。
  4. 数据安全与隐私保护问题——集中存储放大泄露风险，个人信息滥用 → 需要权限、加密、脱敏、法规。
  5. 数据分析与价值发现问题——有数据没洞察 → 需要挖掘算法、机器学习与可视化。
  6. 数据共享与标准问题——"数据孤岛""部门墙" → 需要交换标准与开放平台。
（二）大数据关键技术（⭐ 重点清单，几乎每章就是一块技术）：
技术类别解决什么代表产品 / 技术本大纲对应章
数据采集把数据收上来爬虫、传感器/RFID、日志采集、ETL第 1 章
分布式存储存得下、可靠GFS / HDFS、对象存储第 3 章
分布式数据库 / NoSQL非结构化数据的高效读写HBase、Redis、MongoDB、云数据库第 5 章
计算与处理框架算得快MapReduce、Spark、流计算第 4 章
资源管理与调度集群资源怎么分YARN、Mesos第 2 章
分布式协调集群一致性、选主ZooKeeper第 2 章
数据分析与挖掘提炼价值机器学习、深度学习、决策树/聚类/回归第 8、9、13 章
云计算与虚拟化按需供给算力IaaS/PaaS/SaaS第 12 章
可视化与交互看懂数据图表、大屏、报表第 6 章
一句话记住技术主线："采—存—算—管—用"。采集（爬虫/传感器）→ 存储（HDFS/NoSQL）→ 计算（MapReduce/Spark）→ 管理调度（YARN/ZooKeeper）→ 应用（机器学习/可视化）。分布式存储与并行计算是两大支柱，也是考纲点名的课程重点。

八、大数据时代的三大思维变革（拓展）

《大数据时代》三个"不是…而是…"（简答/辨析偶考，也帮助理解）：
变革传统做法大数据思维
要全体，不要抽样随机样本分析可处理全样数据（n = all），样本即总体
要效率，不要精确追求精确无误接受数据的混杂性/不精确，换取规模与速度
要相关，不要因果追问"为什么"关注"什么与什么一起发生"，用相关关系预测
⚠️ 别答成"大数据不需要因果、不要质量"——规范表述是"不再执着于因果与绝对精确，而转向相关关系与整体效率"。这是价值观层面的取舍，不是技术放弃质量（Veracity 仍要求可信）。

九、本章速记小结

  1. 时间轴五节点：1980 托夫勒 → 2001 Laney 3V → 2008 Nature → 2011 麦肯锡（正式兴起） → 2012 国家战略。
  2. 定义三要素：量大超常规工具 + 一定时间内处理 + 产生决策价值。
  3. 5V：Volume 大量、Variety 多样、Value 价值密度低、Velocity 高速、Veracity 真实性。
  4. 分类：结构化 / 半结构化 / 非结构化，非结构化占八成以上；来源分系统日志、网络社交、感知物联。
  5. 采集四路：爬虫（通用/聚焦/增量）、传感器 RFID、日志与 ETL、人工众包；采集后要清洗集成变换加载。
  6. 技术主线："采—存—算—管—用"，两大支柱是分布式存储与并行计算。
  7. 思维变革：全样而非抽样、效率而非精确、相关而非因果。
