一、预测建模与特征构建（领会）

领会 特征选择的作用、特征提取方法。
预测建模（Predictive Modeling）：用特征（自变量 X）→ 目标（因变量 y）的映射来建模，即从历史样本中学习规律，再对新样本给出预测。数据被分为训练集（学规律）与测试集（验效果）；任务分为分类（y 离散）与回归（y 连续）。
几个术语要分清：特征（属性/变量）＝描述样本的可测量性质；特征构建＝从原始数据造出可用于学习的特征（含变换、组合、派生指标，如由"出生日期"派生"年龄"）；特征提取＝通过变换把原始高维信息压缩成新表示（PCA、傅里叶、纹理统计量）；特征选择/子集选择＝不改变特征本身，只从原有特征中挑一个子集。
好特征的标准：①相关性——与目标确有统计联系；②充分/区分性——能把不同类别分开；③低冗余——彼此不重复；④鲁棒（不变性）——对噪声、光照、尺度、视角等干扰稳定；⑤简洁、可解释、计算代价可接受。
🎯 一句话记本章：特征的质量在很大程度上决定了后续学习/分类的性能上限——模型只是在给定的特征上尽力逼近这个上限。

二、数据预处理的内容和方法（简单应用）⭐

简单应用 数据预处理的内容和方法。
内容做什么常用方法
数据清洗去错、去重、补全缺失值（均值/中位数/众数填补、回归或 KNN 插补、删除）、异常值（3σ/箱线图 IQR 剔除或截断）、重复记录合并、不一致编码统一
数据集成多源合并连接/合并、模式统一、实体识别、冲突消解（同名不同单位）
数据变换改量纲/改形态最小-最大规范化 x′=(x−min)/(max−min)、Z-score 标准化 x′=(x−μ)/σ、对数/幂/Box-Cox 变换、离散化分箱（等宽/等频/基于熵）、one-hot 独热编码、二元化
数据约简减量不损信息维约简（特征选择、PCA 主成分）、数值约简（抽样、直方图、聚合）、记录约简（去冗余）
✏️ 会算两种规范化（填空/计算常考）：设 min=10、max=50、x=30，则最小-最大规范化 x′=(30−10)/(50−10)=0.5；若 μ=25、σ=10，则 Z-score x′=(30−25)/10=0.5。前者把值压到 [0,1]，后者得到"偏离均值几个标准差"。

三、特征选择的动机与方法（领会）⭐

领会 特征选择的动机；识记 常用的特征选择方法。
动机（为什么要选特征，六条）：①降维、缓解维度灾难（样本相对高维越来越稀疏）；②减轻过拟合、提升泛化能力；③缩短训练与预测时间、降低存储与计算成本；④提高或至少保持精度（去掉噪声与无关特征后往往更好）；⑤增强可解释性（模型更简洁、变量含义清晰）；⑥便于采集——实际部署时可以少装传感器、少埋点。
三大类方法做法优缺点
过滤式 Filter
（包装在外、先筛后学）		用与标签无关的统计量给每个特征打分：相关系数、卡方检验、互信息/信息增益、方差、距离判别；按单独相关性排名取前 k 个快、与学习算法解耦、可扩展到高维；但只看单变量，忽略特征间交互与冗余，可能留下相关特征、丢掉有用特征
包裹式 Wrapper
（围着模型转）		把学习算法的性能（准确率、误差、交叉验证得分）当评价函数，搜索子集：前向选择、后向选择、逐步回归、最佳优先、模拟退火/遗传效果好、能考虑特征组合；但需反复训练，计算代价高，易过拟合到评价数据
嵌入式 Embedded把选择融进训练目标：L1/LASSO 稀疏正则、决策树按信息增益自然选特征、正则化 + 权重排序折中：效率接近过滤式、效果接近包裹式
📌 另有一个常考概念子集选择方差：不同数据划分/不同随机种子下选出的特征子集差异很大，说明选择结果不稳定（这也是"特征选择是开放性问题"的原因，即教材 8.3 节主题——该节不考，了解即可）。

四、相关性及其计算方法（简单应用）⭐⭐

简单应用 相关性及其计算方法。
含义：相关性衡量两个变量线性关联的强弱与方向。常用皮尔逊相关系数：

rxy = Σ (xi − x̄)(yi − ȳ) ÷ √[ Σ (xi − x̄)² · Σ (yi − ȳ)² ]，取值 [−1, 1]；|r| 越接近 1 越相关，r>0 正相关、r<0 负相关，r=0 只是没有线性相关（仍可能有非线性关系）。

判读经验：|r| ≥ 0.8 高度相关，0.5～0.8 中等相关，< 0.3 弱相关。相关 ≠ 因果，且对异常值敏感。
例：计算 4 个样本、3 个特征与目标 y 的相关系数。

Σ(y 离差²) = 2.25+0.25+0.25+2.25 = 5；Σ(A 离差²) = 10；Σ(B 离差²) = 20；Σ(C 离差²) = 10。

A 与 y：分子 = (−2)(−1.5)+(−1)(−0.5)+(1)(0.5)+(2)(1.5) = 3+0.5+0.5+3 = 7 ⇒ rAy = 7/√(10×5) = 7/7.071 ≈ 0.990

B 与 y：分子 = 3(−1.5)+1(−0.5)+(−1)(0.5)+(−3)(1.5) = −10 ⇒ rBy = −10/√(20×5) = −1.000（完全负相关）

C 与 y：分子 = (−2)(−1.5)+1(−0.5)+(−1)(0.5)+2(1.5) = 3−0.5−0.5+3 = 5 ⇒ rCy = 5/√(10×5) = 5/7.071 ≈ 0.707

按单独相关性排名（取 |r|）：B(1.000) > A(0.990) > C(0.707)。

再算特征之间的相关：rAB = (−6−1−1−6)/√(10×20) = −14/14.142 ≈ −0.990；rBC = (−6+1+1−6)/√(20×10) = −10/14.142 ≈ −0.707 ⇒ A 与 B 高度冗余。

✏️ 答题三步：①求均值 → ②列离差、算两个平方和与交叉积 → ③代公式并说明结论（谁最相关、谁与谁冗余）。符号一定别丢：负号代表"取值越大、目标越小"，其绝对值才是相关强度。

五、单独不相关的相关特征与冗余特征（领会）⭐

领会 单独相关性排名、单独不相关的相关特征、冗余特征。
① 单独相关性排名：把每个特征单独与目标算一个分数（|r|、信息增益、卡方值），降序排列取前 k 个。简单高效，是过滤式的代表做法；缺点正如下两条。
② 单独不相关的相关特征（异常见）：某些特征单独看与目标几乎无关（r≈0），但与其他特征联合后却非常有用——因为线性相关只测"单变量线性关系"，测不出交互/非线性关系。经典示意是"异或型"数据：

A 的离差 = (−0.5,−0.5,0.5,0.5)，B 的离差 = (−0.5,0.5,−0.5,0.5)，y 的离差 = (−0.5,0.5,0.5,−0.5)。
Σ(A−Ā)(y−ȳ) = 0.25 − 0.25 + 0.25 − 0.25 = 0 ⇒ rAy = 0；同理 rBy = 0。
但 y 完全由 A、B 联合决定（y = A ⊕ B）。若按"单独相关性排名"，A 与 B 会被同时判为无用而丢弃——这就是过滤式的致命盲区。

③ 冗余特征：与已选特征高度相关的特征（如上面的 A 与 B，rAB≈−0.99；或第 4 节中 D=2A 时 rDA=1）。冗余特征几乎不提供新信息，却会增加维度、计算量与共线性带来的不稳定性。处理方法：设置冗余阈值（如 |r| > 0.9 即舍弃）、mRMR（最大相关最小冗余）准则——在"与目标最相关"和"与已选特征最不相关"之间取平衡，或先做聚类分组、每组只留代表。
⚠️ 简答模板："为什么不能只做单独相关性排名？"→ 答：①只反映线性、单变量关系，测不出特征交互，会漏掉"单独不相关但联合相关"的特征；②不检查特征之间的关系，容易选出彼此高度冗余的特征，浪费维度且可能降低稳定性。

六、前向选择与后向选择算法（综合应用）⭐⭐

综合应用 前向选择算法和后向选择算法。
前向选择（Forward Selection，由少到多）后向选择（Backward Selection，由多到少）
起点空集 S = ∅全集 S = 全部特征
每步动作在剩余特征中，选出使评价函数最优的那一个加入 S在当前 S 中，找出去掉后评价函数下降最小（或反而提升）的那一个剔除
停止条件达到目标子集大小 k；或加入后提升不足阈值；或性能不再改善剩到目标大小 k；或再剔除就明显变差
特点贪心、步数少（1+2+…n 次评估），适合特征数多；但一旦加入不会回溯，可能漏掉"只有成对才有用"的特征贪心、开始时模型最全，能自动去掉无用与冗余特征；但每步都要重训，特征多时代价大、易受无关特征干扰
变体逐步回归（Stepwise）＝前向 + 每轮回头剔除变差的；悬浮搜索（SFFS/SFBS）＝允许回溯的增强版；最佳优先＝在子集空间中按分数开/闭表搜索
算例（承接第 4 节数据）：特征集 {A, B, C}，D=2A 为 A 的完全冗余副本；评价函数用"子集与 y 的多元拟合优度"（示意上按 |r| 与冗余惩罚）；目标：选 2 个特征。
① 前向选择：

S=∅ → 第一轮比 rAy=0.990、rBy=1.000、rCy=0.707 ⇒ 取 B，S={B}。

第二轮考察加入 A/D/C 的增益：A 与已选 B 的 |rAB|=0.990（几乎重复）⇒ 增益≈0；D 与 A 完全共线 ⇒ 增益 0；C 与 B 的 |rBC|=0.707（相对低）且与 y 相关 0.707 ⇒ 增益最大的是 C。
结果 S = {B, C}。

⚠️ 纯"贪心 + 只看与 y 的相关"的朴素前向会先取 B、再取 A（0.990 > 0.707），从而选出一对高度冗余的 {B, A}——所以实际算法必须带冗余惩罚/最小冗余准则。

② 后向选择：

S={A,B,C}（完整集）→ 逐一"试删"看性能：删 A ⇒ 与 B 冗余、损失极小 ⇒ 候选删 A；删 B ⇒ 丢掉最强预测因子，性能大跌；删 C ⇒ 损失中等。
第一轮删 A，S={B,C}；第二轮再看：删 C 会使性能明显下降（C 与 y 有 0.707 的相关），删 B 更不可 ⇒ 停止。

结果 S = {B, C}，与前向一致。若把 D 也放进全集，后向会先把 D、A 这一对冗余的先后剔除。

🧭 怎么选：特征数 n 大、样本少 → 前向（评估次数少）；n 中等且希望剔除无关项 → 后向；两者结果常不同，因为都是贪心算法、不保证最优。答综合题时务必写出每一步的候选打分与被选/被删项，并点明停止条件。

七、图像的主要特征与特征分类（识记）⭐

识记 图像主要特征、图像特征分类。⚠️ 本节起对应教材 8.4 节（8.3 节不考）。
图像四大主要特征：颜色特征、纹理特征、形状特征、空间关系特征。
分类口径分为说明 / 例子
按是否需人工计算视觉特征（自然特征）与统计特征（人为特征）视觉特征＝人眼可直接感知的颜色、纹理、形状；统计特征＝需经变换或测量才得到，如频谱、直方图
按与目标的关系内部特征与外部特征内部特征＝单个区域自身的性质（颜色、纹理、形状）；外部特征＝目标之间的空间关系
按覆盖范围全局特征与局部特征全局＝整幅/整区域的统计量（颜色直方图、纹理统计）；局部＝关键点描述子（边缘角点、SIFT/HOG 类）
按抽象层次低层特征与高层（语义）特征低层＝像素级统计的亮度色彩纹理；高层＝物体类别、场景含义，需由深度学习自动学习（"语义沟" gap）

八、颜色特征与常用颜色空间（识记）

颜色特征的性质：是一种全局特征，描述图像或区域所对应景物的表面性质；基于像素点；对方向、尺寸、角度变化不敏感（因而鲁棒、被广泛用于图像识别与检索），但也因此不能很好地捕捉对象的局部/空间细节。
常用颜色空间：RGB 是最基本的（与设备相关的三通道相加模型）；图像分析与检索中更常用HSI / HSV（色调 H、饱和度 S、亮度/明度 I(V)）——因为它把色度与亮度分离，更接近人类视觉直觉、受光照变化影响小；此外 YCbCr 常用于视频与 JPEG 编码，Lab / LCh 为设备无关的均匀色彩空间。题目问"最常用颜色空间"时，若选项偏工程/检索通常答 HSV(HSI)，若问最基础的则答 RGB。
颜色特征的四种表示/提取方法：①颜色直方图——统计各色分量的像素分布，最常用，优点是不受旋转、平移影响（归一化后还不受尺度影响），缺点是丢失空间分布信息；②颜色矩——用均值（一阶）、方差（二阶）、偏度（三阶）描述颜色分布，维度极低；③颜色相关图 / 颜色聚合向量——把颜色的空间相关性纳入进来；④颜色集/颜色量化——把颜色空间划分为若干代表色。

九、形状特征与二值形状图像（简单应用）⭐

领会 形状与二值图像表示、基于形状特征的应用、有效形状特征特性；简单应用 由灰度图像获取二值形状图像的方法。
形状的两类表示：轮廓特征（针对物体的外边界，如边界链、傅里叶描述子、形状上下文）与区域特征（关系到整个形状区域，如面积、周长、紧致度、圆形度、不变矩）。
有效（好的）形状特征应具备的特性：①几何不变性——对平移、旋转、缩放不变；②独特性/区分能力强——不同形状差异明显；③完备性——能完整表达形状信息、可复原；④鲁棒性——对噪声、断裂、遮挡、分割误差不敏感；⑤低维、简洁、可计算（灵活性与抽象性）。
常用形状描述子：边界链码与周长/面积比、圆形度/紧致度、不变矩（Hu 矩）、傅里叶形状描述子、形状上下文、骨架与欧拉数。
步由灰度图得到二值形状图像的流程常用做法
① 预处理去噪、增强、平滑中值/高斯滤波、直方图均衡、灰度化（彩色→单通道）
② 阈值分割（二值化）前景/背景分离全局阈值 Otsu（最大类间方差）、自适应（局部）阈值、双阈值；或先做边缘检测（Sobel/Canny/Laplacian）再闭合
③ 形态学处理修补与去碎点腐蚀、膨胀、开运算（去小亮点）、闭运算（补小洞）、连通域填充
④ 轮廓提取与表示得到形状连通域标记 / 边界跟踪（Moore 邻域追踪）→ 按 8 邻域输出边界链（Freeman 链码）或区域掩膜，再计算描述子
🔗 基于形状特征的应用：目标识别与分类、工业零件视觉检测、图像检索（按形状查相似图）、医学影像（细胞/器官形态分析）、手势与字符识别。

十、纹理特征与空间关系特征（领会）⭐

领会 纹理特征的作用、属性与提取方法；空间关系特征的提取方法。
纹理的作用：描述图像或区域所对应景物的表面性质（质地），也是全局特征；用于区分材料/表面类型（木纹 vs 金属、布料、地面覆盖）、图像分割与检索。局限：纹理只是表面特性，不能完全反映物体的本质属性，所以单靠纹理得不到高层次的图像内容；且它不是基于单像素，而需在包含多个像素的区域内做统计计算。
纹理的属性：粗糙度、光滑度、颗粒度、随机性、规律性（方向性/周期性）——常表现为缓慢变化或周期性的纹理排列。
四类纹理提取方法思路代表
统计法用邻域灰度的统计分布刻画灰度共生矩阵 GLCM（角二阶矩/能量、对比度、熵、相关性）、均值方差、局部二值模式 LBP
几何法把纹理看成纹理基元的规则排列基元分割、空间排列/拓扑描述
模型法用随机过程/概率模型拟合自回归（AR）、马尔可夫随机场、分形模型
信号处理法变换域中的频带响应特征傅里叶功率谱、Gabor 滤波器组、小波变换
空间关系特征：指图像中分割出的多个目标之间的空间位置或相对方向关系。常见关系：连接/邻接、交叠/重叠、包含/包容；位置信息分相对空间位置（上下左右）与绝对空间位置（距离与方位）。
空间关系特征的提取与表示方法：①九交/方位图模型（把目标的外接框方向划分为上、下、左、右等方位关系）；②字符串表示——一维字符串（沿某方向的目标次序，如"ABC"表示左右顺序）与二维字符串 / 2D 字符串（同时表达上下与左右）；③直角坐标图 / 距离方位表示；④图模型/拓扑关系。匹配时通常与颜色、纹理等特征联合使用（"颜色 + 空间关系"能大幅减少误检），缺点是关系组合多、匹配复杂度高。

十一、姿态估计方法与特征提取概述（领会）

领会 姿态估计方法的分类、图像特征分类、特征提取的目的与方法。
姿态估计（Pose Estimation）方法两大类：
类别做法特点
基于模型的方法预先建立物体的（多为三维）几何模型，通过图像与模型的匹配/配准反求位姿（如迭代最近点 ICP、轮廓拟合、已知标记点的 PnP 解算）精度高、几何含义明确；需要良好的初始值与精确模型，对遮挡敏感
基于学习的方法从大量带标注样本中学习"图像特征 → 姿态参数"的映射（回归、分类 + 投票、神经网络/深度学习端到端）不需显式模型、鲁棒性与泛化好；依赖训练数据、可解释性弱
按输出还可分 2D 姿态估计（图像中的关节位置）与 3D 姿态估计（空间坐标/旋转）；按是否使用标记分标记式与无标记式。
特征提取概述（目的与方法）：目的是把原始像素转换为能表征内容、便于识别与检索的低维、强区分度、稳定的表示。方法上分为代数特征提取（如 PCA 主成分/特征脸、矩阵分解、SVD——从数据本身的统计结构取特征）、几何/空间特征提取（边缘、角点、轮廓）、变换域特征（傅里叶、小波）、统计特征（直方图、GLCM）以及神经网络自动学习特征（用卷积网络逐层从低层纹理到高层语义自动得到特征，无需人工设计，见第 9 章与第 13 章）。

十二、本章速记小结

  1. 预测建模：特征 X → 目标 y；好特征＝相关、区分强、低冗余、鲁棒、简洁。
  2. 预处理四件事：清洗、集成、变换（规范化/标准化/离散化/编码）、约简（维约简 + 数值约简）。
  3. 特征选择三方法：过滤式（快、只看单变量）、包裹式（准、代价高）、嵌入式（折中）；动机六条含"降维、防过拟合、提速、提精度、可解释、易采集"。
  4. 相关性：r = Σ离差积 ÷ √(Σ平方积)，∈[−1,1]，看绝对值定强弱；相关≠因果、只测线性、怕异常值。
  5. 两个坑：单独不相关的相关特征（异或型，r=0 却联合决定 y）与冗余特征（彼此高度相关）——所以要有 mRMR / 阈值去冗余。
  6. 前向 vs 后向：前向从空集贪心加、后向从全集贪心删；本例两者都收敛到 {B, C}；朴素前向易选成冗余对 {B, A}。
  7. 图像四大特征：颜色（全局、基于像素、对方向尺寸不敏感；直方图/矩/相关图）、纹理（表面质地，粗糙/光滑/颗粒/随机/规律；统计-几何-模型-信号四类法）、形状（轮廓 vs 区域；不变性/独特/完备/鲁棒/简洁）、空间关系（邻接/重叠/包含；一维与二维字符串、方位图）。
  8. 灰度 → 二值形状四步：预处理去噪 → 阈值分割（Otsu/自适应）→ 形态学（开闭运算）→ 轮廓跟踪与链码表示。
  9. 姿态估计两类：基于模型（配准求解，精确但需初值）vs 基于学习（数据驱动，鲁棒但依赖标注）。
🎯 6 学时分配：①特征提取基础 + 预处理 1 学时；②相关性计算 1 学时（务必亲手算一遍例 4）；③前向/后向选择 1 学时（综合应用大题）；④单独不相关与冗余 0.5 学时；⑤图像特征（颜色/形状/纹理/空间关系/姿态）2.5 学时——清单最多，识记题主产地。⚠️ 教材 8.3「特征选择方法的开放性问题」不考，但"相关特性、足够特征子集、子集选择方差"这些词若出现在选项中，仍按"不列入考核范围"处置。
