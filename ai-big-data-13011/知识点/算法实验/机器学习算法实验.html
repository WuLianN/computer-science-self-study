一、距离的度量与计算（简单应用）⭐⭐

简单应用 各种距离度量的计算（考纲第 13 章／教材 15.1 节）。
为什么要算距离：距离（相似度）是聚类、KNN 分类、协同过滤推荐、检索、异常检测的共同基础——"物以类聚"要靠一个可计算的"像不像"来定义。设两个 n 维样本 x = (x₁,…,xₙ)、y = (y₁,…,yₙ)。
名称公式直觉 / 适用
欧氏距离
（L2）		d = √[ Σ (xi − yi)² ]直线距离，最常用；对量纲敏感，需先标准化（第 8 章 min-max / Z-score）
曼哈顿距离
（L1 / 街区距离）		d = Σ |xi − yi|沿坐标轴走的"城市街区"距离；对异常值更稳健
切比雪夫距离
（L∞ / 最大值距离）		d = maxi |xi − yi|只看差异最大的那一维；国际象棋 king 的步数
闵可夫斯基距离
（Minkowski，通式）		d = ( Σ |xi − yi|p )1/pp=1 曼哈顿、p=2 欧氏、p→∞ 切比雪夫——三者是同一族的特例（概念题常考）
标准化欧氏距离d = √[ Σ ((xi − yi)/σi)² ]各维先除以标准差，消除量纲与方差影响
马氏距离d = √[ (x−y)T S−1 (x−y) ]，S 为协方差矩阵考虑维度相关性与尺度，与量纲无关；适合椭圆分布数据
汉明距离两等长串不同位置的个数二进制编码、类别序列、纠错码；不算数值差
编辑（莱文斯坦）距离把一串改成另一串所需插入/删除/替换最少次数长度可不等；文本纠错、DNA 序列
余弦距离cos θ = (x·y)/(‖x‖‖y‖)；距离 = 1 − cos θ只看方向不看长短，文本向量、推荐常用
相关距离1 − r（皮尔逊相关系数，见第 8 章）衡量线性相关程度，对整体平移/缩放不敏感
算例：A = (1, 2, 6)、B = (4, 6, 2)，求各距离。

差值向量 A−B = (−3, −4, 4)。

度量代入d(A, B)
欧氏（p=2）√(9+16+16)= √41 ≈ 6.40
曼哈顿（p=1）3+4+4= 11
切比雪夫（p=∞）max{3,4,4}= 4
闵氏 p=3(27+64+64)1/3= ∛155 ≈ 5.37
汉明三个位置都不同= 3

✏️ 再练一维（K-均值/近邻最常用）：x=(2,2)、y=(0,4)、z=(1,3) 到原点比较：欧氏 d(x,y)=√8≈2.83、d(x,z)=√2≈1.41；曼哈顿 d(x,y)=4、d(x,z)=2；切比雪夫 d(x,y)=2、d(x,z)=1——同一批点、不同度量大小排序一般一致，但换一批点就可能翻盘（见第二节要点）。

二、距离选择的陷阱与相似度（简单应用）

要点说明
量纲必须统一欧氏距离下"年龄(1~100)"会淹没"收入(0~10)"的差别；先规范化/标准化，或改用马氏/标准化欧氏
维度灾难维数很高时所有点对的距离趋于相等，基于距离的方法失效；对策：降维（PCA）、特征选择、改用余弦
距离 ≠ 相似按数据语义选度量：数值连续→欧氏/曼哈顿；文本向量→余弦；类别串→汉明/编辑；考虑相关性→马氏
相似度的性质相似度量 sim 一般要求 对称、0≤sim≤1、当且仅当 x=y 取 1；满足三角不等式才叫度量/距离。⚠️ 余弦"距离"不满足三角不等式，严格说不是度量
非数值与混合属性分类属性用差异表（同取值记 0、异记 1）；序数属性用秩次归一；混合属性加权组合 d=Σ wkdk，缺失维剔除并重归一权重
🎯 常见考法："哪种距离在 p→∞ 时退化为切比雪夫？"→闵可夫斯基；"衡量文本向量方向差异常用？"→余弦；"判断等长二进制编码差异？"→汉明；"变长字符串最少编辑次数？"→编辑距离。

三、常用聚类算法（识记）⭐

识记 常用的聚类算法（考纲第 13 章／教材 15.2 节）。
聚类（Clustering）＝无监督学习：不使用标签，按样本间相似度把数据分成若干"簇"，使簇内相似性尽可能大、簇间差异性尽可能大（这句是聚类好坏准则、也是简答必写句）。
类别代表算法思想特点 / 局限
基于划分K-均值、K-中心点(K-Medoids/PAM)、K-模态/K-原型、CLARA预设 k 个中心，反复"分配—重算中心"优化 SSE简单快速；须先定 K、只发现球状等大小簇、对初值与异常值敏感（K-Medoids 用真实点当中心更抗噪）
基于层次BIRCH、CURE、ROCK、AGNES(凝聚)、DIANA(分裂)自底向上逐层合并或自顶向下分裂，形成树状图 dendrogram不必预设 K、可视化好；合并不可撤销、开销大 O(n²)
基于密度DBSCAN、OPTICS、DENCLUE把足够密集的点连成簇，分核心/边界/噪声点任意形状簇、自动识别噪声、不必设 K；对 ε 与 MinPts 敏感、密度不均时差
基于网格STING、WaveCluster、CLIQUE空间划成有限单元格，在网格上统计聚类速度极快、与数据顺序无关；精度受网格粒度限制
基于模型GMM 高斯混合＋EM、隐马尔可夫、SOM、均值漂移假设数据由若干分布生成，拟合参数得软聚类给出属于各簇的概率、统计扎实；计算复杂、假设可能不成立
⚠️ 单选："不属于常用聚类算法"的干扰项常是逻辑回归、朴素贝叶斯、决策树（监督分类）、Apriori（关联规则）。K-均值、DBSCAN、层次聚类、均值漂移、GMM、BIRCH 才是聚类。

四、K-均值聚类原理与迭代算例（简单应用）⭐⭐

简单应用 K-均值聚类算法原理。
算法五步（背下来 + 会 trace）：① 指定聚类数 K；② 随机选 K 个初始中心（或 K-均值++ 按距离加权选，改善初值）；③ 分配——每个样本分给距离最近的中心，成 K 个簇；④ 更新——把每个簇的均值（质心）作新中心；⑤ 重复③④ 直到中心不再变化 / 目标函数收敛 / 达最大迭代次数。
目标函数（簇内平方和 SSE，最小化）：J = Σk Σx∈Ck ‖x − μk‖²。"更新为何取均值"的标准答案：均值能最小化该簇的平方误差。
算例：一维数据 {1, 2, 3, 8, 9, 10}，K = 2，初始中心 μ₁ = 1、μ₂ = 8（欧氏距离即绝对差）。

第 1 轮 分配：各点到 μ₁=1 与 μ₂=8 的距离 (0/7)(1/6)(2/5)(7/0)(8/1)(9/2) ⇒ C₁={1,2,3}，C₂={8,9,10}（3 与 8 分界在 4.5）。

第 1 轮 更新：μ₁=(1+2+3)/3=2；μ₂=(8+9+10)/3=9。中心变了（1→2、8→9），继续。

第 2 轮 分配：到 2 与 9 的距离 (1/8)(0/7)(1/6)(6/1)(7/0)(8/1) ⇒ 归属仍是 C₁={1,2,3}、C₂={8,9,10}。

第 2 轮 更新：μ₁=2、μ₂=9——与上轮完全相同 ⇒ 收敛，聚类结束。

结果评价：SSE(C₁)=(1−2)²+(2−2)²+(3−2)²=2；SSE(C₂)=(8−9)²+(9−9)²+(10−9)²=2；总 J=4，两簇紧密且分离良好。

🔧 初值敏感的直观体会：若初始取 μ₁=3、μ₂=8，第 1 轮分得 C₁={1,2,3}、C₂={8,9,10} 恰好一步到位；但换一批点，初值不同会收敛到 SSE 更大的局部最优——这就是要用 K-均值++／多次随机重启取最小 SSE 的原因。

二维 trace 的通用做法（若给散点坐标）：草稿列表"点 → 到各中心距离 → 最近中心"，逐点算完再各自求均值；每轮把新旧中心都写出并比较，明确写"中心不再变化 ⇒ 收敛"这句结论。

五、聚类好坏准则与影响因素（领会）

好聚类准则：簇内相似性（紧密度）越大、簇间差异性（分离度）越大，效果越好——两个方向同时优化。
影响 K-均值效果的主要因素说明与对策
① K 值大小太小欠拟合、太大碎簇；用肘部法（SSE 下降拐点）、轮廓系数峰值、业务含义确定
② 初始中心选择易陷局部最优；对策 K-均值++（按距离平方概率选点）、多次重启取最优
③ 相似性测度（距离）换曼哈顿后中心应取中位数而非均值；量纲差异会让某维主导——先标准化
④ 数据与异常值离群点严重拉偏质心（K-Medoids 或先剔除）；簇非球状/大小悬殊/密度不均时失效（改 DBSCAN/GMM）
⑤ 准则函数与终止条件目标函数是否单调下降、迭代上限与阈值决定是否"假收敛"
评价指标内部（无标签）：SSE、轮廓系数 SC、DB 指数 DBI（越小越好）、Dunn 指数（越大越好）；外部（有参考标签）：Jaccard 系数、FM 指数、Rand 指数

六、最常用回归与线性回归原理（识记 / 领会）⭐⭐

识记 最常用的回归；领会 线性回归原理。
回归（Regression）＝监督学习，输出是连续数值（与分类的区别就在输出离散/连续；预测房价、销量、温度、股价属回归）。最常用的回归＝线性回归。
线性回归原理三句话：①模型 ŷ = a + b x（多元 ŷ = w₀ + w₁x₁ + … + wₙxₙ）；②准则——最小二乘法使残差平方和 Σ(yi − ŷi)² 最小；③求解——对 a、b 求偏导并令为 0，得闭式解（也可梯度下降迭代）。

公式（必记）： b = Σ(xi−x̄)(yi−ȳ) ÷ Σ(xi−x̄)² = Lxy/Lxx；a = ȳ − b·x̄（回归直线必过样本中心 (x̄, ȳ)——常考判断）。

算例：广告费 x 与销量 y 五次观测 x = 2,4,5,6,8；y = 30,40,60,50,70，求回归方程并预测 x=10。

x̄ = 25/5 = 5；ȳ = 250/5 = 50。

x 离差 −3,−1,0,1,3 ⇒ Σ(x−x̄)² = 9+1+0+1+9 = 20。

y 离差 −20,−10,10,0,20 ⇒ Σ(y−ȳ)² = 400+100+100+0+400 = 1000。

离差积 = (−3)(−20)+(−1)(−10)+0×10+1×0+3×20 = 60+10+0+0+60 = 130。

b = 130/20 = 6.5；a = 50 − 6.5×5 = 17.5 ⇒ 回归方程 ŷ = 17.5 + 6.5x。预测 x=10 ⇒ ŷ = 17.5 + 65 = 82.5。

拟合优度：r = 130/√(20×1000) = 130/141.42 ≈ 0.919，R² = r² ≈ 0.845 ⇒ 广告费可解释销量约 84.5% 的变动，线性关系强、可用于预测。（R² 越小越不可信；回归系数显著性 p<0.05 才算该变量作用显著。）

📌 扩展口径：实践中简单线性回归常被带正则化的回归替代——LASSO(L1，可压系数为 0 顺带选特征)、Ridge(L2，治多重共线性)、Elastic Net(L1+L2)；非线性用多项式回归、回归树、SVR、深度学习。逻辑回归名字带"回归"其实是分类方法（输出经 Sigmoid 映射成概率，接第 9 章）。

七、回归评价指标（领会）

指标公式读法
均方误差 MSE(1/n) Σ (yi − ŷi)²越小越好；对大误差惩罚重
均方根误差 RMSE√MSE与原始量纲一致，便于解释
平均绝对误差 MAE(1/n) Σ |yi − ŷi|稳健、直观，不受极端值过度影响
决定系数 R²1 − SSE/SST，SST = Σ(yi − ȳ)²≤ 1，越接近 1 拟合越好＝"被模型解释的变异性比例"
MAPE(1/n) Σ |(yi − ŷi)/yi|百分比误差，跨量级比较（真值近 0 时不适用）

用第六节数据复核：SST=1000、残差 = 实际−预测 = (30−30.5, 40−43.5, 60−50, 50−56.5, 70−69.5) = (−0.5,−3.5,+10,−6.5,+0.5)，SSE=0.25+12.25+100+42.25+0.25=155 ⇒ R² = 1 − 155/1000 = 0.845（与 r² 吻合）。MSE=31、RMSE≈5.57、MAE=(0.5+3.5+10+6.5+0.5)/5=4.2。

八、分类合理判断的两个常用指标（识记）⭐⭐

识记 对分类的合理判断常用的两个指标及概念。
答案：精确率（Precision，查准率）与召回率（Recall，查全率）。二者从两个互相拉扯的角度评价分类器，只看其一会被"全判正/全不判正"钻空子，须成对使用。
混淆矩阵（以"是否患病"为正类）：
实际 \ 预测预测为正预测为负
实际为正TP 真正例（查得对）FN 假负例（漏报）
实际为负FP 假正例（误报）TN 真负例
指标公式含义 / 何时更重要
精确率 PrecisionTP / (TP + FP)"报出来的有多少是对的"——误报代价高时优先（垃圾邮件拦截、精准推送）
召回率 RecallTP / (TP + FN)"该找出来的找全了多少"——漏报代价高时优先（疾病筛查、欺诈/入侵检测、安防布控）
F1 值2PR / (P + R)P 与 R 的调和平均，需兼顾时用
准确率 Accuracy(TP + TN) / 总数直观，但类别不平衡时误导（患病率 1% 时"全判健康"仍有 99% 准确率、召回 0）
ROC / AUC横轴 FPR=FP/(FP+TN)，纵轴 TPR=召回AUC 越大越好（理想 1，瞎猜 0.5）；不受阈值与类别比例影响
算例：100 人筛查（20 人实际患病），算法报警 15 条，其中 12 条确为患病者。求 P、R、F1、准确率。

TP=12、FP=15−12=3、FN=20−12=8、TN=80−3=77。

精确率=12/15=0.80；召回率=12/20=0.60；F1=2×0.8×0.6/1.4=0.686；准确率=(12+77)/100=0.89。

🔎 判读：准确率 0.89 看着漂亮，却漏掉 40% 病人——筛查场景召回优先，应降低判定阈值提召回（代价是误报增多、精确率下降）。"准确率虚高、召回不足"正是"只看准确率"的典型错误。

🎯 必背：P 分母是"预测为正的总数"、R 分母是"实际为正的总数"；一句话——精确率看"报得准"、召回率看"找得全"。附带 KNN 分类要点：K 取奇数避免平票、距离加权可缓解样本不均。

九、决策树基本思想（领会）⭐⭐

领会 决策树的基本思想（考纲第 13 章／教材 15.3 节）。
定义：决策树（Decision Tree）是用树形结构做分类（或回归）的监督学习模型，由根节点、内部节点（特征测试）、分支（测试取值）、叶子节点（类别结论）组成；根到叶的一条路径＝一条合取规则（"且"链），整棵树＝一组不相交规则的析取（"或"集）。
基本思想（简答标准答案四句）：①以带标签的训练样本为基础；②每次选一个最优属性划分，把样本分成若干子集；③递归地对子集重复划分，直到每个分支下实例同类（子集"纯"）或无属性可用；④用停止条件与剪枝控制规模，得到可解释规则。特点：每次划分都基于"最显著"特征、无需归一化、可处理混合类型、可解释性强（远比神经网络透明，呼应第 9 章局限）。
三个关键要素：特征选择（用哪个属性——信息增益/增益率/基尼）、树的生成（递归划分到停止）、树的剪枝（防过拟合）。
算法划分准则树形备注
ID3信息增益最大多叉只处理离散属性；偏爱取值多的属性（本章计算主场景）
C4.5信息增益率最大多叉，可连续二分修正 ID3 偏好；能处理缺失值与连续值
CART分类用基尼指数、回归用平方误差二叉可分类可回归；随机森林/GBDT 的基学习器

十、熵与信息增益（领会）⭐⭐⭐ 难点

领会 信息增益和熵。难点：熵的理解和应用。
信息量（自信息）：事件 x 携带的信息 I(x) = −log₂ P(x)。越不可能发生的事，一旦说出越"有信息"（"明天下雨"信息量小，"太阳西升"信息量巨大）。
熵（信息不确定度，必背）：样本集 D 有 k 类、第 i 类占比 pi：

H(D) = − Σi=1..k pi log₂ pi　（规定 0·log₂0 = 0）

熵的直觉（"如何理解熵"就写三句）：①类别均匀分布时熵最大（最难判类，二分类为 1 bit，k 类为 log₂k）；②纯（同类）时熵最小 = 0；③取值范围 0 ≤ H ≤ log₂k。熵就是"消除不确定性所需的信息量 / 混乱程度"。
条件熵：给定属性 A 后剩余的不确定性＝按 A 各取值分组、分组求熵再按样本比例加权平均：H(D|A) = Σv (|Dv|/|D|)·H(Dv)。
信息增益（ID3 选择标准）：Gain(D,A) = H(D) − H(D|A) ＝「划分前的熵」−「划分后的条件熵」＝知道属性 A 后类别不确定度减少的程度；选增益最大的属性做当前节点。
必备对数值速查（考试无计算器，务必背）：
plog₂ p−p log₂ p
1/2=0.5−10.500
1/4=0.25−20.500
3/4=0.75−0.4150.311
1/3=0.333−1.5850.528
2/3=0.667−0.5850.390
1/5=0.2−2.3220.464
0（同类）—0（纯集熵为 0）

推论：两纯类各半 H=1；"4 类各 1/4" H=2；"5 类各 1/5" H=log₂5=2.322；"2/3 与 1/3" H=0.918；"3/4 与 1/4" H=0.811。

⚠️ 易错三点：①熵与类别数绑定（k=2 才最大 1，k=4 最大 2）。②条件熵要按分组样本数加权，不是简单平均各组熵。③信息增益天生偏爱取值多的属性（极端如用"编号"每样本一组、增益最大却无用），这正是 C4.5 改用增益率的理由。

十一、基于信息增益生成决策树（综合应用）⭐⭐⭐ 大题

综合应用 基于信息增益的决策树生成。
解题四步（照此书写，步骤分不丢）：① 算总熵 H(D)；② 对每个属性算条件熵 H(D|A) 与增益 Gain(D,A)；③ 取增益最大者作当前节点并分支；④ 对非纯子集递归重复①—③（纯集直接成叶），最后画图 + 写 if-then 规则。
【热身算例】D 有 6 个样本，4 正 2 负；属性 A 取值 a₁（3 样本全正）、a₂（3 样本 1 正 2 负），求 A 的信息增益。

总熵 H(D) = −(4/6)log₂(4/6) − (2/6)log₂(2/6) = 0.390 + 0.528 = 0.918。

条件熵 H(D|A) = (3/6)·H(a₁) + (3/6)·H(a₂) = (3/6)(0) + (3/6)(0.918) = 0.459（a₁ 纯→0；a₂ 是 1 正 2 负→0.918）。

增益 Gain(D,A) = 0.918 − 0.459 = 0.459。直觉：用 A 划分后不确定度从 0.918 降到 0.459，减半——增益就是"省下的这部分熵"。

【官方大题·水果分类】（大纲附录原题）：5 个样本，属性 颜色/形状/大小，类别 苹果/香蕉/樱桃/西瓜/橘子，构造决策树并画出。
编号颜色形状大小类别
1红球一般苹果
2黄弯月一般香蕉
3红球轻樱桃
4绿椭球重西瓜
5橘球一般橘子

第 0 步·总熵：5 样本分属 5 个不同类别（各占 1/5）⇒ H(D) = −5×(1/5)log₂(1/5) = log₂5 ≈ 2.322 比特（类别完全均匀→满熵）。

第 1 步·逐个属性算条件熵与增益：

属性各取值分到的类别（纯度）H(D|A)Gain = 2.322 − H(D|A)
颜色红{苹果,樱桃}=2、黄{香蕉}、绿{西瓜}、橘{橘子}各 1(2/5)×1 = 0.4001.922 ⭐最大
形状球{苹果,樱桃,橘子}=3、弯月{香蕉}、椭球{西瓜}(3/5)×log₂3 = (3/5)×1.585 = 0.9511.371
大小一般{苹果,香蕉,橘子}=3、轻{樱桃}、重{西瓜}(3/5)×1.585 = 0.9511.371

第 2 步·定根节点 = 颜色（Gain 1.922 最大）。黄→香蕉、绿→西瓜、橘→橘子 都是纯叶；红分支含 {苹果(一般)、樱桃(轻)} 不纯，进入第 3 步。

第 3 步·红子集（2 样本，H=1）递归：先看形状——苹果球、樱桃球同形无法区分（条件熵仍为 1、增益 0）；改看大小——一般(苹果)、轻(樱桃) 各 1 且都纯 ⇒ H(红|大小)=0、Gain=1。⇒ 红分支下选大小节点：轻→樱桃、一般→苹果。

水果类别？　（根节点＝颜色，Gain=1.922 最大） ├─ 颜色=黄 → 香蕉 ├─ 颜色=绿 → 西瓜 ├─ 颜色=橘 → 橘子 └─ 颜色=红 → 大小？（红子集 Gain=1，形状无法区分苹果/樱桃） ├─ 大小=轻 → 樱桃 └─ 大小=一般 → 苹果
把树翻译回规则（综合应用题加分收尾）：IF 颜色=黄 THEN 香蕉；IF 颜色=绿 THEN 西瓜；IF 颜色=橘 THEN 橘子；IF 颜色=红 AND 大小=轻 THEN 樱桃；IF 颜色=红 AND 大小=一般 THEN 苹果。
🎯 本题真正考到的三件事：①每个属性都要算一遍增益再比较；②不纯子集递归处理；③发现苹果与樱桃"同形"、形状分不开→改用大小（数据本身决定可分性）。写得出第③点的思考，是"综合应用"与"死套公式"的分水岭。

十二、变体：增益率、基尼指数与剪枝（了解）

准则 / 技术公式 / 做法解决什么问题
增益率（C4.5）GainRatio = Gain ÷ IV(A)，分裂信息 IV(A)=−Σ(|Dv|/|D|)log₂(|Dv|/|D|)惩罚取值过多的属性（分母随取值数增大），修正 ID3 偏好
基尼指数（CART）Gene(D)=1−Σ pi²，加权后取最小（近似熵但无需算对数，更快）二分裂、二叉树；选基尼最小的划分
剪枝预剪枝划分前就停（最大深度、叶最少样本、增益阈值）；后剪枝先建满树再自底向上把子树换成叶决策树极易过拟合；以少量训练误差换泛化能力
随机森林 / GBDT多棵树投票(分类)/平均(回归)；Bagging 降方差、Boosting 降偏差单树不稳定→集成提升精度与稳健（接第 9 章）
回归树 / 模型树叶子给常数（回归树）或一段线性模型（模型树），划分准则改为平方误差最小让决策树也能做回归任务
