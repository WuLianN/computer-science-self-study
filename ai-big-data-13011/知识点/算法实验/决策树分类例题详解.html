一、题目在问什么

题意：样本共 30 名学生，记录了三个变量——性别（女 / 男）、班级（IX / X）、身高（1.5 ~ 1.8 米）。其中 15 人在闲暇时间打板球（Cricket），另 15 人不打。要建立决策树模型预测谁会打板球，问：应该按哪个属性先划分？
划分方式分支打球不打球合计打球占比
性别女 Female281020%
男 Male1372065%
班级IX 类681443%
X 类971656%
先核对数据（防止抄错数）：

性别口径：女 2+8=10，男 13+7=20，共 30；打球 2+13=15，不打球 8+7=15。

班级口径：IX 6+8=14，X 9+7=16，共 30；打球 6+9=15，不打球 8+7=15。✔ 两种口径对得上同一个总体。

🎯 解题目标只有一个：分别算「按性别划分」和「按班级划分」的信息增益 Gain，谁大就选谁作根节点。身高是连续值，另作说明（见第六节）。

二、三个公式与对数速查表

① 熵（不纯度）：H(D) = −Σ pi log₂ pi。约定 0·log₂0 = 0。熵越大越不纯；二分类中 50/50 时熵最大 = 1，全属一类时 熵 = 0（纯）。
② 条件熵（划分后的加权不纯度）：H(D|A) = Σv (|Dv| / |D|) · H(Dv)。权重是各分支的样本数占比，不是分支个数的简单平均——这是本题第一个易错点。
③ 信息增益（不纯度下降了多少）：Gain(D, A) = H(D) − H(D|A)。增益越大，说明这个属性把"混在一起"的样本分得越开，ID3 算法就选它作当前节点。
常用 −p·log₂p 速查（保留三位，教材取两位）：
p0.50.20.80.650.356/148/149/167/16
−p·log₂p0.5000.4640.2580.4040.5300.5240.4610.4670.522

例：−0.2·log₂0.2 = −0.2×(−2.322) = 0.464。注意是 log 以 2 为底，用计算器的 ln / lg 会全盘错。

三、第 1 步：父节点熵 H(D)

1父节点（未划分）：打球 15 人、不打球 15 人，p₁ = p₂ = 15/30 = 0.5。

H(D) = −(15/30)·log₂(15/30) − (15/30)·log₂(15/30)

　　 = −0.5×(−1) − 0.5×(−1) = 1

💡 教材那句"这里的 1 表明它是一个不纯节点"怎么理解：因为 H=1 正好是二分类熵的最大值，说明父节点里两类各占一半、最"混乱"——所以才有划分的必要。后面每个划分都要看能把这 1 降下来多少。

四、第 2 步：按性别划分

2先算两个子节点的熵：

女性节点（10 人：2 打 / 8 不打）
H(女) = −(2/10)·log₂(2/10) − (8/10)·log₂(8/10)
　　　 = 0.2×2.322 + 0.8×0.322 = 0.464 + 0.258 = 0.72

男性节点（20 人：13 打 / 7 不打）
H(男) = −(13/20)·log₂(13/20) − (7/20)·log₂(7/20)
　　　 = 0.65×0.621 + 0.35×1.515 = 0.404 + 0.530 = 0.93

再按样本数加权，得条件熵：
H(D|性别) = (10/30)×0.72 + (20/30)×0.93 = 0.24 + 0.62 = 0.86

信息增益： Gain(D, 性别) = 1 − 0.86 = 0.14

直观读法：划分后女性组只有 20% 打球、男性组有 65% 打球，两组的比例明显拉开——不确定性从 1 降到了 0.86，降了 0.14。男性分支 65% 已经明显偏向"打球"，可以拿它做判断了。

五、第 3 步：按班级划分

3同样先算两个子节点的熵：

IX 类节点（14 人：6 打 / 8 不打）
H(IX) = −(6/14)·log₂(6/14) − (8/14)·log₂(8/14)
　　　 = 0.524 + 0.461 = 0.99

X 类节点（16 人：9 打 / 7 不打）
H(X) = −(9/16)·log₂(9/16) − (7/16)·log₂(7/16)
　　　 = 0.467 + 0.522 = 0.99

加权条件熵：
H(D|班级) = (14/30)×0.99 + (16/30)×0.99 = 0.99

信息增益： Gain(D, 班级) = 1 − 0.99 = 0.01

⚠️ 为什么班级几乎没用：IX 组 43% 打球、X 组 56% 打球，两个分支都还是"差不多一半打一半不打"，跟父节点的 50/50 几乎一样。划分完熵基本没降，所以增益只有 0.01——不是"班级完全无关"，而是这一次划分几乎没减少不确定性。

六、身高怎么处理？（连续属性）

身高 1.5 ~ 1.8 米是连续值，每个学生取值都不同，无法像性别 / 班级那样"每个取值算一个熵"。ID3 原始做法要求属性是离散的，所以必须先离散化：例如按 <1.6 / 1.6~1.7 / ≥1.7 分段，或选一个阈值做二分（如"≥1.7 米"与"<1.7 米"），再统计每段的打球人数，才能套用同样公式。
本题没有给出按身高分段后的人数分布，所以身高这一步无法计算；教材的结论是在可比较的两个离散属性中"按性别划分的信息增益最高"。考试若给身高分段表，就照前面同样的三步算增益、再一起比大小。
📌 延伸（了解）：连续属性的标准处理是扫描所有可能阈值，逐个算增益取最大（C4.5 / CART 的做法）；决策树因此容易过拟合，需要剪枝。本章只要求离散属性的手算。

七、比出胜负：画出决策树

结论：Gain(D, 性别) = 0.14 > Gain(D, 班级) = 0.01，所以根节点选「性别」；这就是教材图 15.22 的结果。
图 15.22 数据分布示意（紫色＝打球，灰色＝不打球；条形长度＝打球占比）
根节点：性别（Gain = 0.14） ├─ 女（10 人，2 人打球 20%）→ 判为「不打球」（多数类） └─ 男（20 人，13 人打球 65%）→ 判为「打球」（多数类）
⚠️ 严谨一点的说法：两个子节点熵分别是 0.72 和 0.93，仍然不纯，理论上要拿剩余属性继续递归划分。但本题剩下的离散属性只有班级（Gain 仅 0.01），身高又未给分段分布，所以教材示意到这一层为止。若考卷追问"为何停止"，答"剩余属性无法再显著降低不纯度"即可。

八、易错点、答题模板与自测

易错点正确做法
把 0.86 当答案0.86 是条件熵 H(D|性别)，题目问的"信息增益"是 1−0.86 = 0.14，看清问的是哪个量
条件熵取平均权重是分支样本数占比 10/30、20/30，不是 (0.72+0.93)/2；本题恰好接近才不易察觉
用 ln 或 lg熵的定义固定 log₂；教材常给 log₂ 值，背熟 0.5→−1、0.2→−2.322 等常用值
熵大＝纯反过来：熵越大越不纯；纯节点 H=0，二分类最不纯 H=1
"增益 0.01"写成"无关"只能说该属性本次划分几乎无贡献，不等于两变量独立
直接拿身高算熵连续属性必须先离散化 / 选阈值；没给分段数据就说明无法计算
✏️ 考试答题模板（照这个顺序写，分步给分）：

① H(D) = −(15/30)log₂(15/30)×2 = 1（父节点最不纯）

② H(女)=0.72，H(男)=0.93；H(D|性别)=(10/30)×0.72+(20/30)×0.93=0.86；Gain=0.14

③ H(IX)=0.99，H(X)=0.99；H(D|班级)=0.99；Gain=0.01

④ 0.14 > 0.01 ⇒ 根节点选性别；女→不打球、男→打球（按多数类判）；身高需离散化后再比较。

自测一题：若女性 10 人中改为 5 人打球、5 人不打球，H(女) 与性别总增益如何变化？

女性变成 50/50 ⇒ H(女)=1（比原来的 0.72 更不纯）。男性不变仍为 0.93。

H(D|性别) = (10/30)×1 + (20/30)×0.93 = 0.333 + 0.622 = 0.95，Gain = 1 − 0.95 = 0.05。

相比原来的 0.14，增益大幅下降——因为女组不再能用性别区分是否打球了。但 0.05 仍大于班级的 0.01，根节点依然选性别。
