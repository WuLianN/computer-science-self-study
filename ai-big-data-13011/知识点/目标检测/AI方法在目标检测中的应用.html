一、贝叶斯网络基本概念（识记）⭐⭐

识记 贝叶斯网络基本概念。
定义（必背）：贝叶斯网络（Bayesian Network，BN）又称信念网络或有向无环图模型，是一种把变量间的条件依赖关系用有向无环图（DAG）表示、并用条件概率表量化的概率图模型，用来在不确定、不完整的信息下进行知识表达与推理。由 Judea Pearl 于 1985 年系统提出。
两大组成部分：①网络结构＝有向无环图，节点表示随机变量（可观测的、隐的、参数均可能），有向边表示变量间的依赖/因果关系，箭头指向"果"；无环保证推理不会绕回来。②网络参数＝每个节点的条件概率表 CPT，记作 P(Xi | Pa(Xi))，Pa 为父节点集；没有父节点的根节点用先验（无条件）概率表示。
图 11-1 贝叶斯网络＝有向无环图（定性结构）＋条件概率表（定量参数）
概念要点
联合概率分解网络的联合分布等于各节点在其父节点条件下概率的乘积：P(X₁,…,Xₙ) = ∏ P(Xi | Pa(Xi))——这是它省存储、可推理的根本原因
条件独立性
（局部马尔可夫性）		给定父节点，该节点与其非后代节点条件独立；因此不必描述所有变量间的关系，只需刻画"局部"依赖
先验 / 后验先验 P(H) 是观测前的信念；贝叶斯定理 P(H|E) = P(E|H)·P(H) / P(E) 把证据 E 转化为后验 P(H|E)，即"由果溯因"的推理
推理（推断）已知证据变量取值，求查询变量的概率分布；基本方法是枚举/边际化（把隐变量全部求和消去），另有置信传播、变量消元等
学习分结构学习（从数据或专家知识确定 DAG）与参数学习（估计 CPT，如极大似然、EM 算法处理含隐变量的情形）
静态 vs 动态静态贝叶斯网络描述一次性的依赖关系；动态贝叶斯网络 DBN 把变量按时间片展开、相邻时间片之间连边，用于时序与行为建模（监控中"因果时序关系"的常用工具，与隐马尔可夫模型 HMM 关系密切——HMM 可视为最简单的 DBN）
优缺点优点：可解释、能表达因果与不确定性、小样本也能建模、缺数据时可用专家经验补；缺点：结构难获取、父节点多时 CPT 呈指数膨胀、变量间条件独立假设未必成立、连续与动态问题推理复杂
在监控中的作用把"运动目标—行为环节—事件—报警"建成概率网络，用带噪证据反推事件（如非法入侵）发生的概率，实现降低误报、支持不确定性下的事件检测
🎯 一句话答名解：贝叶斯网络是用有向无环图表示变量间条件依赖、用条件概率表表示依赖强度，从而对不确定知识进行表示与推理的概率图模型。答时把"DAG + CPT + 条件独立 + 概率推理"四个词都写到。

二、视频监控系统的演进与框架（领会）⭐⭐

领会 视频监控系统框架。
三代演进：模拟闭路电视（CCTV）→ 数字化 / 网络化监控（DVR、IP 摄像机）→ 智能化 / 分布式视频监控。传统系统只能"看得见、存得下、事后查"，靠人盯屏幕，数据量大、响应慢、易疲劳漏判；智能视频监控（IVSS）让摄像头具备"人眼＋人脑"，自动分析视频内容，识别物体、发现异常并以最快方式报警、过滤掉无关信息。
系统物理框架（三层，简答常考）：
  1. 前端采集层——摄像机、镜头、云台、防护罩、补光/红外、拾音器等，完成图像与声音的采集。
  2. 传输层——同轴电缆、光纤、网线、无线（Wi-Fi/4G/5G）及编解码设备，把前端数据送到后端，并把控制指令回传前端；瓶颈常是带宽不足导致卡顿丢帧、延迟不同步。
  3. 后端（处理 / 控制 / 存储 / 显示）层——服务器与智能分析设备做视频分析与结构化，NVR/磁盘阵列为存储，大屏与客户端为显示，管理平台的控制与报警联动。
智能分析的功能框架（软件流水线）：图像采集 → 预处理（灰度、滤波去噪、增强）→ 运动目标检测（前景提取）→ 目标分类（人/车/其他）→ 目标跟踪（轨迹）→ 行为分析与理解（正常/异常）→ 事件判断、报警与联动 → 人机界面与检索统计。
图 11-2 智能视频监控系统的两层含义：物理构成三层 ＋ 智能分析流水线
⚠️ 易错：题目问"视频监控系统框架"时，要分清是问物理组成（前端/传输/后端）还是功能流程（检测/分类/跟踪/行为/报警）。稳妥答法：先写三层构成，再写分析流程，并点明智能监控的关键是"自动理解视频内容"。

三、目标跟踪与识别的五个步骤（领会）⭐

目标跟踪可分为五步（背这条序列）：运动检测 → 目标分类 → 目标跟踪 → 行为分析 → 行为识别。以"跟踪人体"为例：先从实时图像序列中检测出运动物体，再判定其中的人体，然后跟踪其运动轨迹，接着分析并选定有异常行为的人，最后对该人持续跟踪并报警。
环节任务常用方法主要困难
运动检测
（前景提取）		把变化区域从背景中分离出来帧间差分法、背景差分（减背景）法、光流法、自适应高斯混合模型（GMM）背景建模、码本/ViBe光照变化、阴影、树叶雨点等背景抖动、缓慢与静止运动、摄像头抖动
目标分类判断前景是人 / 车 / 其他轮廓与形状特征、长宽比、面积变化，纹理与颜色特征（接第 8 章），深度模型（CNN、目标检测器）目标粘连、遮挡、形态多变
目标跟踪在连续帧中保持同一目标编号、生成轨迹卡尔曼滤波（线性高斯预测）、均值漂移 Mean-Shift（颜色直方图吸附，避免目标粘连）、粒子滤波（非线性非高斯）、块匹配/相关跟踪、 SORT/DeepSORT目标丢失与编号混乱（ swapped ）、遮挡、交叉、外观相似
行为分析从轨迹与区域变化中提取行为特征轨迹方向/速度/停留、进出区域、越线、光流与运动能量行为多样性、时空尺度不定
行为识别把特征映射到事件语义并判断正常/异常规则/模板匹配、状态机、贝叶斯网络与 HMM/DBN、机器学习分类器定义"异常"本身依赖场景，误报率高

四、多视角目标识别方法（领会）⭐

领会 多视角目标识别及消失/重现目标识别方法。
为什么要多视角：单台固定摄像机存在视野盲区、遮挡、姿态与光照随视角剧烈变化三大瓶颈，导致目标"看不清、认不出、跟不住"。多视角（多摄像机）系统用多个视点互补，扩大覆盖、减少遮挡，并可从不同方位获得同一目标的多样外观，显著提高识别的稳定性与准确率。
方法 / 关键技术做法与要点
① 多视角特征级融合识别同一目标在各视点分别提取特征（颜色、纹理、形状、人脸姿态各不同），按权重合并判决；对姿态造成的差异用视角不变的描述子弥补
② 视角建模 / 多视角模板为目标的不同视角分别建模板或子分类器（正脸/侧脸、车的车头/车侧），识别时先判视角再匹配对应模板；或用流形/子空间把多视角图像编码到同一表示（如典型相关分析 CCA、判别典型分析 DCCA）
③ 摄像机标定与坐标关联建立各视点的内外参数与映射关系（单应矩阵、对极几何、"地面映射/homography"），把一个画面里的像素位置换算到世界坐标或另一画面，为跨视角配对提供几何依据
④ 时空约束一致性用时间同步 + 位置相邻 + 速度合理约束候选配对："这个时刻它不可能同时出现在两地""两个画面中目标尺寸应随距离一致变化"，与轨迹预测联合判定
⑤ 目标重识别（Re-ID）跨镜头/跨视角把同一个目标再认出来：以外观特征（行人：颜色、衣着、身体比例、局部特征；人脸：多视角人脸特征）＋轨迹上下文构造相似度，做全局匹配，是多视角系统的核心环节
⑥ 多智能体分布式协同把每台摄像机看成一个智能体，各自主管局部区域，通过通信、协商与投票融合得到全局一致的识别结论——正好衔接第十一节的"重点"内容
📌 答题框架（简答）：先说"单视角三难（盲区/遮挡/姿态变化）"，再说"几何配准 + 时间同步 + 外观多样互补 + 特征或决策级融合 + 重识别"这一套组合拳，最后点出可"以多智能体协作方式组织"。

五、消失 / 重现目标的识别方法（领会）⭐

问题定义：目标在跟踪过程中因遮挡、离开视野、光照剧变、检测漏帧而"消失"，稍后又"重现"。系统必须回答两问：①它是不是真的消失了？②重现的这个是不是刚才那一个（如何接上原有编号与轨迹）？这就是目标消失判定 + 重现再认（轨迹重连）问题。
阶段常用方法
消失的检测与判定跟踪目标连续若干帧匹配得分低于阈值/预测位置无对应前景即置为"疑似消失"；再区分短暂遮挡（面积骤减、轮廓被别的物体覆盖）与真正离场（越过边界、进入盲区），并按场景设定保持时间与计数容忍
消失期的轨迹维持用运动模型外推（卡尔曼滤波/匀速模型预测位置与速度）、历史轨迹与运动趋势、区域转移概率（该目标惯常进入哪个视野）建立"候选出现区"，把该目标编号挂入候选/休眠队列而不是立刻删除
重现时的再认匹配新目标出现后，按外观相似度（颜色直方图、纹理、形状、边缘、深度特征）、时空合理性（距离—时间—速度约束：从消失点到重现点所需时间是否成立）、尺寸与类别一致性以及轨迹方向连续性做加权匹配；相似度超阈值则沿用原编号、接回原轨迹，否则新建编号
跨视角的消失/重现在 A 摄像机消失往往等于"进入 B 的视野"：靠摄像机拓扑邻接关系 + 坐标映射 + 时间窗口在 B 画面中搜索匹配目标，实现跨镜头接力跟踪；外观相似无法判定时用多视角投票/贝叶斯融合降低错配
再认失败的兜底设置超时清除与全局重识别（在归档库中按外观检索历史目标），并对无法确认者标记"疑似同一人"交由人工复核——这也是异常报警里"目标遗留/丢失"事件的判定基础
🎯 口诀："判消失—存轨迹—等重现—三比对（外观、时空、类别）—接编号"。答题时把"为什么不能直接删除（遮挡会导致编号频繁重置、统计失真）"写出来更完整。

六、异常行为描述方法（领会）⭐

领会 异常行为描述方法。
核心思路两条路线：①基于规则/模型（自顶向下）——先由人定义什么动作算异常（越线、闯入禁区、逆行、聚集），用几何与时序规则、状态机、事件演算、贝叶斯网络/HMM 表达并匹配；②基于数据（自底向上）——不预设定义，学习"正常"的分布，把偏离正常模式的判为异常（统计模型、聚类、一分类/重构误差、深度学习）。前者可解释、误报可控但覆盖面窄；后者能发现未见过的异常但难定义、误报多。
描述方法怎么描述能刻画的行为
轨迹（时空路径）描述把目标质心序列写成带方向的折线，用起点—途经区—终点及方向、速度、加速度、停留时长等参数描述；可用轨迹相似度度量（如编辑距离/Fréchet 距离）与模板比对，或用轨迹聚类得到"惯常路径"逆行、徘徊、非法停留、偏离常规路线、异常聚集/疏散
区域—事件规则描述在画面中预置警戒区、禁入区、越界线、单向通道，把行为写成规则式事件：进入/离开/穿越/滞留超时/逆向穿越（形如 IF 目标进入禁区 AND 持续 > T THEN 报警）入侵、翻越、遗留物/丢失物、超员、拥堵
基于人体姿态与动作序列描述提取身体轮廓、关节点/骨架、肢体角度与质心高度变化曲线，描述动作的时间演化（有的用动作时态模板或"跌倒＝宽高比骤变＋质心快速下降＋静止"）跌倒、蹲下、攀爬、打斗、奔跑、挥舞
基于运动场/光流描述用区域光流的方向直方图、运动能量、时空显著性刻画整体运动模式，不依赖逐个目标的分割，适合人群人群骚乱、异常流动、群体聚集、全局异常
概率与图模型描述用贝叶斯网络 / 动态贝叶斯网络 / HMM 描述"低层特征 → 原子动作 → 复合事件"的因果与时序关系，输出事件的后验概率；隐状态即行为类别，观测即检测到的特征需要不确定性推理、多证据综合的复杂事件（非法入侵等）
基于统计的正常模型描述对位置—方向、速度、出现时段、轨迹簇建立概率分布（高斯混合、核密度、混合贝叶斯模型），异常＝低似然/高重构误差未定义过的、少见的行为；夜间出现、异常时段活动
描述时应具备的要素（答题要点）：主体（谁）、动作/状态（做了什么）、空间（在哪个区域、朝哪个方向）、时间（何时、持续多久、先后顺序）、程度与置信度（多异常、把握多大）——即"何时何人何地做了何事、可疑程度几何"，这也是把描述结果写成结构化报警事件的字段。

七、人脸识别系统流程（简单应用）⭐⭐

简单应用 人脸识别系统流程。
定义：人脸识别（Face Recognition）＝用人脸特征进行生物特征身份识别，回答"这是谁（1:N 辨认）"或"他是不是本人（1:1 验证）"，是生物特征识别中应用最广的方向之一。
  1. 图像采集——可见光/近红外/深度摄像头获取人脸图像或视频帧，控制分辨率、光照、姿态与距离（采集质量决定上限）。
  2. 人脸检测——从图像中找出所有人脸并给出定位框（位置、大小、姿态），过滤掉非人脸区域。这是第一步"能不能找到"。
  3. 人脸对齐（预处理）——定位关键点（眼、鼻、嘴等），据此做旋转/缩放/仿射变换把人脸归一化到标准姿态与尺寸；同时做光照归一化、去噪、遮挡处理，目的是让待比较的脸处于可比状态。
  4. 特征提取与表示——把对齐后的人脸编码成特征向量：传统法用几何特征（五官距离比例）、整体/局部统计（主成分分析"特征脸 Eigenface"、LDA"Fisherface"）、纹理特征（LBP）；深度法用 CNN 端到端学出高维嵌入（度量学习/ArcFace 类损失）。
  5. 人脸匹配与识别——与底库（注册库）比对：1:1 验证算相似度判断是否同一人；1:N 辨认在库中检索最近邻，按阈值与 Top-K 给出候选身份。
  6. 决策输出与后处理——输出身份、置信度与候选列表；活体检测（防照片/视频/面具攻击）、多帧/多视角投票、质量评分与拒绝机制，并把结果落库用于布控报警、考勤、通行。
性能与干扰因素说明
评价指标识别率/准确率、误识率 FAR（接受非本人）、拒识率 FRR（拒绝本人）、等错误率 EER、Top-K 命中率；验证与辨认的口径不同
主要难点姿态（侧脸）、光照、遮挡（口罩、眼镜）、表情与年龄变化、分辨率低/模糊、样本内差异大与类间差异小、底库规模与实时性、隐私与合规
🎯 流程必背六步：采集 → 检测 → 对齐 → 特征提取 → 匹配识别 → 决策与后处理。简答时要写出每一步要达到的目标（考纲明确这么要求），不能只列名词。

八、多视角人脸检测算法（简单应用）

简单应用 多视角人脸检测算法。
难点：正脸检测器在侧脸、俯仰、旋转下性能骤降——因为特征分布随视角改变。多视角人脸检测的思路是用一组视角专用检测器 + 融合判定覆盖姿态空间。
算法要点说明
① 分类器族（视角分派）为不同角度区间分别训练检测器（如 0°、±30°、±60°、90° 侧脸），或用级联（Cascade）结构：先用便宜的正脸/粗略级快速排除大量非人脸窗口，再逐层调用更专门的角度分类器，兼顾速度与召回（Haar+Adaboost 级联、HOG+SVM 是典型）
② 多尺度滑窗搜索图像金字塔 × 窗口尺度组合，逐尺度滑动窗口判断"是否人脸"，输出候选框并按置信度与非极大值抑制（NMS）去重
③ 视角归一化后再检测先估计或归一化姿态（用 3D 模型/单应把侧脸"摆正"，或合成虚拟新视角），再交给正脸检测器——把多视角问题降维成单视角问题
④ 多视点摄像机融合多个摄像头同时从不同方位拍摄同一场景，各视点独立检测后按标定关系把候选投影到同一空间坐标，判断是否指向同一人头；对某视点被遮挡的人脸，由其他视点补位
⑤ 决策级融合（投票）各视点对"某位置存在人脸/属于某人"给出判决或概率，用多数投票、加权投票、D-S 证据理论或贝叶斯融合合并；配合置信度阈值抑制误检——正是本章"多任务决策融合"与投票策略的落点
⑥ 深度学习方案单阶段/两阶段检测器（YOLO、SSD、RetinaFace、MTCNN）在含大姿态变化的数据上训练，直接输出框 + 关键点 + 姿态角；配合姿态感知 NMS、锚框按视角分组、多任务头（检测/对齐/识别共享主干）

九、多视角人脸跟踪算法（简单应用）

简单应用 多视角人脸跟踪算法。
任务：在视频序列中持续定位每张人脸并保持其身份编号，为识别提供稳定、清晰、多姿态的帧。跟踪质量直接决定后续识别（第 8 章的"好特征"要靠跟得住的轨迹来采集）。
方法类别原理与代表算法适用与短板
基于样条/模板的形变跟踪把人脸轮廓或表观建模为可形变的样条曲线/模板（如 TLD 中的跟踪器＋学习器），逐帧在预测位置搜索最优形变匹配点；对平面内旋转、俯仰引起的轮廓变化适应较好能跟随姿态渐变；大侧脸、快速运动、严重遮挡时易跟丢
基于统计特征（均值漂移 Mean-Shift）用目标颜色/亮度直方图建模，在后一帧中迭代移动到相似度（巴氏距离）最大的位置；核密度估计求模。计算快、无需学习适合目标外观稳定的场景；对相似颜色背景、光照剧变敏感，单目标居多
基于状态估计的跟踪卡尔曼滤波（线性高斯）／扩展卡尔曼／粒子滤波（非线性非高斯、可多峰）维护位置—速度—尺度状态，用预测引导检测、用检测更新状态能在遮挡期外推位置、抑制抖动；粒子数大时计算量高
检测—跟踪联合（Tracking-by-Detection）每帧重新检测人脸，再用运动/外观相似度做数据关联分配编号：SORT（卡尔曼预测＋匈牙利算法IoU匹配）、DeepSORT（再加深度外观特征与马氏距离，专为频繁遮挡、重现再认设计）与第五节"消失/重现"完全对应，是工程主流；依赖检测器精度
多视角协同跟踪①几何配准＋邻接关系建立各视点共见的"世界坐标"，目标在 A 视点消失即按时空约束在 B 视点搜索接棒；②各视点独立跟踪后做轨迹级/决策级融合（投票、加权、D-S）产生统一身份；③利用多视点互补外观更新表观模型，抵抗单视角遮挡与姿态退化解决遮挡与视角依赖两大瓶颈；需要摄像机标定、时间同步与通信开销
📌 易混辨析："人脸检测"= 单帧里找到脸；"人脸跟踪"= 跨帧保持同一张脸及其身份编号；"人脸识别"= 判断是谁。三者顺序是 检测 → 跟踪 → 识别，跟踪的价值在于挑出最清晰、姿态最好的若干帧交给识别，并用多帧投票提高稳定性。

十、多任务决策融合的编程架构（简单应用）⭐

简单应用 多任务决策融合的编程架构。
问题：一个监控系统同时要跑多路视频流、多种算法（检测/跟踪/人脸识别/行为分析/车牌…），各任务在不同视点给出可能冲突的结论（A 说这是张三、B 说没找到脸），必须调度任务并融合判决。"编程架构"要回答的正是：怎么组织这些模块、怎么通信、怎么合并结果。
架构要素常见方案
分层职责数据级融合（多路视频/多传感器原始信息拼接）→ 特征级融合（各模块输出特征向量再合并、降维）→ 决策/判决级融合（各模块先各自出结论，再由融合器投票/加权），层级越高越通用、越易实现
组织范式①管道（Pipeline）：采集→检测→跟踪→识别→报警，简单但缺反馈；②黑板（Blackboard）模式：一块公共"黑板"存中间结论，各知识源按需读取并发布，由控制器调度——天然适合多任务协作与不确定性推理；③多智能体（MAS）：每个摄像头/算法是一个智能体，用消息通信、协商与投票达成一致（去中心化、可扩展）；④主从/中心式：融合中心统一汇聚判决（集中式融合）
并发与调度多路流并行/线程池/生产者—消费者队列；实时性优先时按丢帧策略、关键帧抽取、算法分级（先粗后精）分配算力；GPU 批处理推理
通信机制共享内存 / 消息队列 / RPC / 中间件（DDS、MQTT、gRPC）；统一消息协议与时戳，保证跨模块可关联（时间同步是多任务融合的前提）
融合规则多数投票、加权投票（按各模块置信度或历史准确率定权）、二叉投票（逐轮两两对决）、计分投票（Borda 计分取总分最高）、D-S 证据理论、贝叶斯融合；输出置信度并支持弃权/转人工
结果与反馈统一事件数据结构（主体—行为—时间—地点—置信度）落库；提供检索、复核、误报反馈闭环以调整权重与阈值——"越用越准"
计分投票（Borda）小算例——多智能体协商的计算机实现长什么样：

三个智能体（A/B/C）对四项处理方案甲、乙、丙、丁按偏好排序（第一名得 3 分、第二名 2 分、第三名 1 分、第四名 0 分）：

智能体 \ 方案甲乙丙丁偏好排序

B0321乙 > 丙 > 丁 > 甲

十一、拓展：多智能体与投票策略（考纲疑点自查）

⚠️ 疑点说明（重要）：广东 13011 考纲在本章写的"重点：多智能体的概念、实现及其协商方式；难点：投票策略的计算机实现"，与另一门课广东 07844《人工智能导论》第 11 章"多智能体系统"的重点/难点表述逐字相同；而本节对应的教材第 11 章只有 11.1 智能视频监控系统、11.2 人脸识别系统两节，并无多智能体正文。因此有两种可能：①命题时沿用了相近课程的"重点难点"模板（则按教材两节复习即可）；②确实期望考生具备多智能体常识。稳妥做法：以 11.1/11.2 的考核知识点为绝对主线，下面的内容当作 20 分钟的"防意外"拓展——它同时也能帮你把第十节的"多任务决策融合"理解得更顺。
智能体（Agent）：能通过感知器感知环境、通过执行器作用于环境，并自主地为实现目标而行动的计算系统/软件实体。性质：自治性、反应性、主动性（面向目标）、社会能力（与他人协作通信），另有移动性、可靠性、时效性等。
与其他软件实体的区别：普通程序由人驱动、被动执行、边界固定；智能体常驻运行、由事件/目标驱动、能自主决策并主动与其他实体交互，且对环境的感知与影响是连续的。
智能体的五种实现方式（由简到繁）核心思想
① 简单反射型只用当前感知按"条件—动作"规则反应，不看历史、不建模世界
② 基于模型的反射型维护内部世界模型记录感知不到的状态（如目标被遮挡时的位置）
③ 基于目标的有目标，能选择有助于达成目标的动作（搜索/规划）
④ 基于效用的目标可能冲突，用效用函数权衡并选期望效用最大的动作
⑤ 学习型有学习元件＋性能元件，能从经验改进自身，适应环境变化
结构补充：包孕结构＝把感知、推理、行动等模块层层嵌套/封装组织；BDI 逻辑结构＝用Belief（信念）— Desire（愿望）— Intention（意图）三态刻画智能体的心智状态，由信念推出愿望、承诺为意图后驱动行动。
多智能体协商（Negotiation）三种工具：
  1. 投票（Voting）——每个智能体是一个投票人，用多数投票、二叉投票、计分投票等产生对各智能体相对公平的结果（适合无价格的公共决策）。
  2. 拍卖（Auction）——每个智能体是一个买家，模拟拍卖的定价与交易行为分配资源，使各方收益（利润）最大（英式/荷式/第一价格/第二价格—维克里）。
  3. 谈判（Negotiation/Bargaining）——每个智能体是谈判者，用公理谈判、策略谈判等理论自动发现最优让步策略以达成一致（合作博弈）。
两个博弈论概念：纳什均衡——在其他各方策略不变时，任何一方单独改变策略都无利可图的策略组合（不一定是全局最优，"囚徒困境"即为一例）；帕累托最优（Pareto）——在不损害任何一方的前提下已无法再改善任何一方的资源配置状态。协商目标就是从纳什均衡走向帕累托改进。
🎯 拓展部分只需掌握到"能选出、能说出三种协商工具的名字和用途"这一档；真正的分数在 11.1/11.2 的清单与流程上。
