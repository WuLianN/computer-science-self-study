第1题点击展开答案
大数据处理流程的正确顺序是
A. 大数据采集→大数据统计与分析→大数据导入与预处理→大数据挖掘B. 大数据采集→大数据导入与预处理→大数据统计与分析→大数据挖掘C. 大数据导入与预处理→大数据采集→大数据统计与分析→大数据挖掘D. 大数据采集→大数据挖掘→大数据导入与预处理→大数据统计与分析
答案：B
解析：大数据处理的标准流程是"采集 → 导入与预处理（存储/清洗/转换）→ 统计与分析 → 挖掘（应用）"。先有数据才能预处理，预处理后才能做统计分析，最后才是更深层次的挖掘，故选 B。
考点：大数据处理流程
第2题点击展开答案
在函数式语言中，Map 表示对列表中的每个元素进行
A. 迭代计算B. 汇总计算C. 同一操作D. 筛选操作
答案：C
解析：Map（映射）的语义是把同一个函数/操作依次作用到列表的每个元素上，返回结果列表。B"汇总"对应 Reduce；D"筛选"对应 Filter。故选 C。
考点：Map 函数式操作
第3题点击展开答案
MapReduce 的组成部分 TaskTracker 与 JobTracker 通信是通过
A. 网络SocketB. 心跳机制C. 共享文件D. 远程过程调用
答案：B
解析：在经典 MapReduce（Hadoop 1.x）中，各 TaskTracker 周期性向 JobTracker 发送心跳（heartbeat）报告自身状态并领任务，JobTracker 据此调度与监控。故选 B。
考点：MapReduce 体系结构
第4题点击展开答案
MapReduce 中，下列任务的数量由 split 处理单元的数量决定的是
A. Reduce TaskB. Cleanup TaskC. Setup TaskD. Map Task
答案：D
解析：输入文件被切成若干 split（切片），每个 split 对应一个 Map Task，故 Map Task 数量由 split 数决定。Reduce Task 数量由用户配置（默认与分区数相关），Setup/Cleanup 是每个任务前后的辅助动作。故选 D。
考点：split 与 Map Task
第5题点击展开答案
下列情况体现了大数据应用"有本质提高"的是
A. 社会化推荐系统用新商业模式驱动位置信息业务B. Hadoop 集群几小时内构建完成C. 处理数据规模达 TB 级D. 降低设备采购成本
答案：A
解析："有本质提高"指大数据带来了业务模式/价值的质变，而非仅仅是速度快、规模大、成本低这些"量"的改善。B/C/D 都属效率或成本层面的提升；A 用数据驱动出新商业模式，属于应用层面的本质变革。故选 A。
考点：大数据应用价值
第6题点击展开答案
在医疗领域，大数据为医学影像分析提供方便，体现在
A. 减少患者就医次数B. 缩短患者住院时间C. 降低医疗设备价格D. 将数十万张图像构建识别图像模型，帮助医生诊断
答案：D
解析：大数据在医学影像上的直接价值是：汇聚海量影像样本训练图像识别模型，辅助医生做病灶识别与诊断（对应教材深度学习医疗影像案例）。A/B/C 是间接效果或无关项。故选 D。

第7题点击展开答案
在读写性能方面，NoSQL 数据库相比关系数据库的优势在于
A. 处理海量数据和高并发读写时效率更高B. 处理结构化数据时准确性更高C. 事务一致性保障更好D. 复杂查询（如 JOIN）效率更高
答案：A
解析：NoSQL 放弃关系模型强一致与复杂 SQL，换取海量数据、高并发读写的可扩展与高性能（A）。恰恰相反：事务一致性（C）和复杂 JOIN（D）是关系数据库的强项；B 也不构成 NoSQL 优势。故选 A。
考点：NoSQL 优势

把重点放在观察和模型化（理解）上的人工智能研究，称为

第9题点击展开答案
自动驾驶汽车自主性中，汽车通常可以自动驾驶，但在某些情况下人类必须参与其中的智能分级是
A. 2级B. 3级C. 4级D. 5级
答案：C
解析：本题按指定教材（郏东耀主编《大数据与人工智能》2022 年版）的分级口径作答。教材写"自动驾驶汽车包含五个级别的自主性"，逐条为：0 级人类要控制车辆的所有功能；1 级计算机可进行巡航控制或刹车等有限功能，一次只能控制一个功能；2 级汽车可自动执行两项功能；3 级汽车可自动执行所有安全功能，但出了问题司机可以进行干预；4 级汽车通常可以自动驾驶，但在某些情况下，人类必须参与其中；5 级是最终目标，汽车完全自动驾驶。题干与4 级的表述几乎逐字一致，故选 C。
⚠️ 口径提示（易错）：若按现行标准 SAE J3016 / 国标 GB/T 40429—2021，"某些情况需人接管"属于 L3（有条件自动驾驶），L4 在限定运行设计域内无需人接管，会得出 3 级（B）。但自考以指定教材与考纲命题，本题只能答 4 级（C），切勿套用现行标准。两套口径的完整对照见下方考点链接。
考点：自动驾驶智能分级（教材口径）

运用计算机进行以人类智慧的机理和实现作为研究目标的工作，是为

第11题点击展开答案
下列不会改变空间维数的方法是
A. 标准化B. 空间嵌入C. 非线性扩展D. 特征离散化
答案：A
解析：标准化（z-score/归一化）只对每个特征做数值缩放，特征个数（空间维数）不变。空间嵌入会重映射到低/高维、非线性扩展（核/多项式）会升维、特征离散化常伴随独热展开使维数变化。故选 A。
注：若仅按"特征列数是否变化"理解，离散化本身也不增列，本题存在轻微争议；按教材"标准化不改变维数"的典型表述，取 A。
考点：特征变换与维数
第12题点击展开答案
在特征选择方法中，"古典统计"方法指的是
A. 不使用训练数据计算经验估计值B. 将训练数据分为训练集和验证集C. 仅使用部分训练数据计算经验估计值D. 使用所有训练数据来计算经验估计值
答案：D
解析："古典统计"式特征选择直接用全部训练数据估计各特征的评价统计量（经验估计值）来打分，不做训练/验证划分——这也是它易过拟合的原因。故选 D。
考点：特征选择方法

第14题点击展开答案
在 HDFS 中，文件块是容错和高可用机制中的
A. 存储单元B. 副本单元C. 计算单元D. 传输单元

第15题点击展开答案
第二名字节点（Secondary NameNode）的主要作用是
A. 接收或记录 HDFS 的实时变化B. 定期合并名字映像及其编辑日志C. 替代名字节点处理用户请求D. 存储文件的实际数据块
答案：B
解析：Secondary NameNode 并非热备，它定期把 fsimage（名字映像）与 editlog（编辑日志）合并生成新的映像，防止 editlog 过大、缩短 NameNode 重启时间。A 是 NameNode 本身；C 是 HA 中的 Standby NameNode；D 是 DataNode。故选 B。
考点：Secondary NameNode

第19题点击展开答案
HDFS 使用"异构存储"的原因是
A. 数据恢复时消耗网络带宽B. 提高数据访问速度C. 数据在接入热量方面有很大的差异D. 用于线上服务可能导致不稳定
答案：C
解析：HDFS 的异构存储（如 SSD + HDD）动机是数据"热度"（访问频率）差异大：热数据放快介质、冷数据放慢介质，兼顾性能与成本。故选 C。

第20题点击展开答案
HDFS 设计思想中的"分而治之"是指
A. 将文件分成多个副本存储在不同节点B. 当文件太大无法存储时，采用分段存储C. 将计算任务分配到不同节点执行D. 将文件元数据和实际数据分别存储
答案：B
解析：HDFS 的"分而治之"指把超大文件切分成固定大小的 Block 分段存储到集群，从而突破单机容量限制、便于并行访问。A 描述的是副本（容错），C 偏向 MapReduce 计算，D 是元数据分离机制。故选 B。
考点：HDFS 分而治之

二、名词解释题（每小题4分，共20分）

第21题点击展开答案
大数据的"4V"之"杂"
参考答案
要点：教材 4V 指大量（Volume）、多样（Variety）、真实（Veracity）、高速（Velocity）。其中"杂"即多样性 Variety——指数据类型与来源渠道繁多：除传统结构化数据外，还存在大量半结构化和非结构化数据（文本、日志、音频、图像、视频、位置信息等），需要不同的存储与处理方式。
考点：大数据 4V 特征
第22题点击展开答案
擦除码技术
参考答案
要点：擦除码（Erasure Coding，纠删码）是一种数据冗余与容错编码技术：把原始数据切成 k 个数据块，再编码生成 m 个校验块分布存储；当任意不超过 m 个块丢失时，可用剩余数据块与校验块恢复出原始数据。相比 3 副本，它能以更低存储开销达到同等容错能力（如 HDFS-EC）。
考点：擦除码 / 容错
第23题点击展开答案
BASE 原则
参考答案
要点：BASE 是对关系数据库 ACID 强一致的反向取舍，是 NoSQL/分布式系统的设计原则，含义为：Basically Available（基本可用）、Soft state（软状态，允许中间状态存在）、Eventually consistent（最终一致性）。即牺牲即时强一致，换取高可用与可扩展，允许数据在一段时间内不一致，但最终会达到一致状态。
考点：BASE 原则
第24题点击展开答案
狭义机器学习
参考答案
要点：广义"学习"泛指人或组织基于经验获得知识、技能或行为改进的过程；狭义机器学习专指计算机（机器）不做显式编程，通过算法从数据（经验）中自动学习规律、改善自身性能的过程，即研究如何模拟实现人类的学习行为以获取新知识/技能并不断优化。对应 Mitchell 定义：对于任务 T 和性能度量 P，性能随经验 E 自动提高。
考点：机器学习定义
第25题点击展开答案
自然语言理解
参考答案
要点：自然语言理解（NLU）是人工智能与计算机科学与语言学的交叉领域，研究让计算机读懂/听懂人类自然语言的语义，包括词法、句法、语义分析，使机器能正确解释文本或语音的意义并据此做出应答。它是自然语言处理（NLP）的核心组成部分，也是语言理解的关键难点。

第26题点击展开答案
简述相比 MapReduce，Spark 的优势。
参考答案
要点（分条）：①基于内存计算：中间结果驻留内存、不落盘，迭代与交互式计算比 MapReduce 快 10~100 倍；②DAG 执行引擎：以有向无环图优化调度，避免 MapReduce 多轮"落盘—再读"的开销；③通用统一：一套引擎同时支持批处理、流处理、SQL、机器学习（MLlib）、图计算（GraphX）；④API 丰富、开发简洁：支持 Scala/Java/Python/R，提供 RDD/DataFrame 等高阶算子，无需手写 Map/Reduce；⑤容错高效：靠 RDD 血缘（lineage）重算恢复，不必频繁写副本；并可运行在 HDFS/YARN 之上兼容生态。
考点：Spark 优势
第27题点击展开答案
简述常用的颜色特征提取与匹配方法。
参考答案
要点：颜色特征全局、对旋转/平移/缩放不敏感，常用：
①颜色直方图：统计各颜色（bin）出现频率，反映整体颜色分布；②颜色矩：用每个颜色通道的均值、方差、三阶矩刻画分布；③颜色相关图 / 颜色聚合向量（CAV）：表达颜色间的空间相关与聚合信息。
匹配（相似度量）方法：直方图相交、巴氏距离（Bhattacharyya）、卡方距离、相关，以及经验式距离 EMD；提取前常在 HSV 等更符合感知的颜色空间进行。
考点：颜色特征提取与匹配
第28题点击展开答案
目标检测是指将图像中感兴趣的目标检测出来并准确定位，简述这项技术的应用场景。

①智能视频监控与安防：行人/人脸检测、异常行为、周界入侵；②自动驾驶与智能交通：车辆、行人、交通标志与车道线识别；③医学影像：病灶、细胞、器官的检测定位；④工业质检：表面缺陷、零件计数；⑤零售与无人货架：商品识别；⑥遥感与无人机、军事目标识别、人机交互/AR 等。

第29题点击展开答案
简述语音识别系统必须处理的关键性问题。
参考答案
要点：①端点检测与切分：从连续语音中判断起止点、切分语音段；②特征提取：从声波中提取稳定有效的声学特征（如 MFCC）；③模型与匹配：声学建模 + 语言建模（模板匹配/HMM/端到端）完成识别；④ variability 与环境问题：说话人差异（音色/语速/性别）、口音方言、噪声与信道失配，需做鲁棒性与说话人自适应处理；⑤词汇与歧义：大词汇量、连读、同音词/多义词的语言学消歧；⑥实时性要求。

第30题点击展开答案
简述自然语言的基本特征。
参考答案
要点：①任意性：语言符号的形式与意义无必然联系；②线条性（线性）：符号只能按时间先后一字一字排列；③结构性/组合性与层次性：音素→词→短语→句子，有限规则可生成无限表达（生成性/递归性）；④社会性/约定俗成：由使用它的社会群体共同约定；⑤模糊性/歧义性与多义性：一词多义、结构歧义普遍存在；⑥开放性：词汇随时代不断增长变化。这些特征正是机器理解自然语言的难点来源。
考点：自然语言特征

第31题点击展开答案
某电商企业随着业务增长，每日产生的电子商务相关数据量大幅增加，需要处理大量用户行为日志、交易记录等数据，以分析用户消费习惯、优化商品推荐策略。目前该企业采用传统数据库存储和处理数据，但面临数据存储量不足、处理大规模数据时效率低下、无法快速响应离线数据分析需求等问题。企业计划引入 Hadoop 相关技术解决上述问题，初步考虑搭建 Hadoop 集群，并使用 Hadoop 核心组件处理数据。请帮助企业解答以下问题：
(1) 该电商企业引入 Hadoop 技术解决当前数据处理问题的选择是否合理？请说明至少 3 点理由。（分值待核）
(2) 若该企业需进一步优化数据处理能力，除 Hadoop 核心组件外，还可引入哪些 Hadoop 生态圈组件？请列举至少 2 个组件，并分别说明其作用。（分值待核）
参考答案
(1) 合理。理由（任答 3 点）：①存储量不足→ HDFS 可把海量用户日志、交易数据分块分布式存储、横向扩容，突破传统数据库单机容量瓶颈；②大规模数据处理效率低→ MapReduce/YARN 提供并行批处理框架，能把离线分析任务拆分到集群多节点并行执行；③无法快速响应离线分析→ Hadoop 生态（如 Hive）支持对海量数据做类 SQL 离线统计，契合"分析消费习惯、优化推荐"的批处理需求；④成本与扩展→ 可运行在廉价商用服务器上，随业务增长弹性扩容；⑤多类型数据→ schema-on-read，能灵活容纳结构化交易记录与半/非结构化行为日志。
(2) 生态圈组件（任举 2 个并说明作用）：①Hive：数据仓库工具，用 HQL（类 SQL）做离线统计分析，降低 MapReduce 开发门槛，适合用户行为/消费习惯统计；②HBase：分布式列式 NoSQL，支持海量数据的实时随机读写，适合在线查询用户画像、推荐结果；③Spark：内存计算引擎，比 MapReduce 快，适合迭代式机器学习（推荐模型）、交互式查询与流处理；④ZooKeeper：分布式协调服务，保障集群配置管理与高可用；⑤Flume / Kafka：日志采集与消息队列，实时汇聚用户行为日志；⑥Sqoop：实现 Hadoop 与传统关系数据库之间的批量数据导入导出。
考点：Hadoop 架构与生态组件
第32题点击展开答案
某房地产公司计划利用决策树算法预测单户住宅的售价，同时也考虑用该算法判断客户是否会续订房屋租赁订阅。请解答该公司的以下问题：
(1) 说明决策树可解决的两类问题及各自定义，并判断"预测单户住宅售价"和"判断客户是否续订租赁订阅"分别属于哪类问题？（分值待核）
(2) 简述决策树的树结构中根节点、决策节点、叶子节点的定义，并解释"剪枝"操作的定义及核心作用。（分值待核）
参考答案
(1) 两类问题：①分类（Classification）：目标变量是离散的类别，预测样本属于哪个类别；②回归（Regression）：目标变量是连续的数值，预测一个具体取值。
判断："预测单户住宅售价"输出是连续金额 → 回归问题；"判断客户是否续订租赁订阅"输出是"续订/不续订"两类 → 分类问题。
(2) 节点定义与剪枝：①根节点：树最顶层的节点，包含全部训练样本，是第一次做特征分裂判断的起点（没有入边/父分支）；②决策节点（内部节点）：对应某个特征（属性）的取值测试，按不同取值把样本划分到各子分支；③叶子节点：树的终端节点，不再继续分裂，给出最终预测结果（分类的类别 或 回归的数值）。
剪枝（Pruning）：在树生成后去掉过于细分、对提升整体分类/预测精度作用不大的分支（子树），用其上层节点或叶替代（分预剪枝与后剪枝）。核心作用：抑制过拟合、降低模型复杂度、提高对未见数据的泛化能力，同时使树更小、预测更快、更易解释。
考点：决策树分类与回归考点：决策树实验与剪枝
